# 봇 폴더 탐색 개선 · 2026-09-08

채팅을 32px 한 줄 목록으로 정리하고, 폴더 접기·펼치기와 hover/focus 조작을 추가했어요. 터치 화면은 44px 행과 항상 보이는 메뉴를 사용해요. 기존 색상 체계는 유지해요.

- 채팅 사이 드래그는 순서를 저장하고 폴더 헤더 드롭은 해당 폴더 끝으로 이동해요. 접힌 폴더 자동 펼침, Esc 취소, 검색 중 같은 폴더 정렬 방지, 메뉴의 위/아래 이동도 포함해요.
- 채팅 삭제 아이콘은 hover/focus에서 나타나고 기존 영향 조회·확인·CAS 절차를 유지해요. 터치에서는 채팅 메뉴에서 삭제해요. 폴더 설정은 헤더 메뉴에서 열어요.
- 선택하지 않은 채팅과 접힌 폴더도 진행 중인 작업을 작은 회전 표시로 보여줘요. 읽기 전용 집계 API는 종류/개수만 반환하며 본문을 보내지 않아요. 화면이 보이는 동안 약 2초마다 직렬 조회해요. 완료하면 표시를 제거하고, 과거 실패·미확인 완료 표시를 새로 도입하지 않았어요.
- `sortPosition`과 `beforeChatId`를 추가하고 schema/archive를 v11로 올렸어요. 새 채팅·포크는 맨 앞이며 폴더 해제는 내부 순서를 유지해 미분류 끝으로 이동해요. 다른 봇 이동·잘못된 기준 채팅·오래된 revision은 거부해요. 사용자 DB를 열거나 초기화하지 않았고 구버전 이관은 없어요.
