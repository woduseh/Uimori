# 전역 역할 모델 분리 결과 · 2026-09-09

## 적용 계약

설정 → 현재 모델에서 본문·번역·번역 거절 판정·표시 상태·이미지 선택 모델을 한 번 선택해요. 현재 프롬프트에서는 작문·번역 작업본과 옵션을 관리하고 저장 프리셋을 복사해 적용해요. 새 채팅과 기존 채팅은 같은 현재 설정을 사용하며 채팅별 저장이나 override는 없어요. 연결·모델 등록 화면은 역할 선택 화면과 구분해요.

거절 판정 모델과 자동 재요청 횟수·전체 호출 한도는 현재 모델 화면의 번역 영역으로 이동했어요. 채팅 헤더와 채팅 설정은 적용 값을 보여 주고 전역 설정으로 연결해요. 미지정·비활성·삭제·연결 사용 불가는 임의 대체 없이 안내하고 새 작업을 차단해요. 다른 탭의 변경과 열린 채팅의 서버 이벤트도 현재 표시를 갱신해요.

채팅 생성·수정·포크에서 역할 모델을 복사하거나 저장하는 경로, 새 채팅의 최근 모델 추천·중복 저장을 제거했어요. `profile.routes` 응답은 현재 전역 설정의 읽기 전용 표시예요. 기존 저장 값이 있어도 실행 기본값으로 사용하지 않아요. 전역 역할 값이 없는 v14 DB는 미지정으로 읽으며 읽기 시 DB를 변경하지 않아요. 사용자가 최초 전역 선택을 해야 해요.

새 Run과 새 번역 예약은 현재 설정을 고정하고 과거·진행 중 snapshot을 유지해요. 본문 재시도는 현재 설정의 새 분기/Run, 번역 재시도·수동 재번역은 현재 설정의 새 job이에요. 표시 상태·이미지 job 재시도와 같은 입력 후보는 기존 고정 설정을 유지해요. 포크는 과거 실행을 보존하고 이후 새 작업에 전역 설정을 사용해요. 상세 표는 [전역 모델 계약](../docs/GLOBAL-MODELS.md)에 있어요.

작품 상태 추적의 `StoryConfig.stateModel`과 `memory.model`은 상태·기억 기능의 독립적인 채팅 설정으로 남아요. 일반 본문·번역 역할의 override가 아니에요. 작문 보조의 전용 모델은 전역 작문 프롬프트에 있고 Run에 고정돼요. 문맥 요약도 고정된 기억/본문 모델을 사용하며 호출 도중 최신 전역 모델로 교체하지 않아요.
