# 장면 네비게이터

> 2026-09-08 후속: [UI 설계 v2](../docs/UI-DESIGN-V2.md)는 모바일의 헤더 아래 고정 바를 "제목 탭 → 장면 목록 시트"와 스크롤 시 나타나는 플로팅 최신 버튼으로 바꾸는 것을 제안해요. 데스크톱 눈금 레일과 `reader.navigation` 계약은 유지해요. 구현 전까지는 아래 현행 동작이 유효해요.

2026-09-08 구현·검증 결과예요.

- 본문 왼쪽 눈금에서 현재 읽는 장면을 표시하고, 요청 미리보기와 장면 이동을 제공해요. 사이드바와 독립되어 집중 읽기에서도 사용할 수 있어요.
- 모바일에서는 장면 번호/전체 수와 목록·최신 이동 버튼을 표시해요. 목록은 번호·요청 검색, 60개 단위 페이지, 페이지 이동 후 포커스 복원을 제공해요.
- 화면 높이에 따라 눈금 수를 제한하고 현재 장면은 항상 포함해요. 전체 항목은 목록에서 찾을 수 있어요.
- `reader.navigation`은 현재 분기의 `{id, number, label}` 목록이에요. 요청을 공백 정리 후 최대 100 code point로 제한하며, authored 시작문은 ‘시작 장면’으로 표시해요. 생성·수정·숨김 본문은 미리보기로 사용하지 않아요.
- 본문은 기존 5개 페이지를 유지하고 기존 장면 이동/URL/뒤로가기/읽기 위치 복원을 사용해요. 탐색은 생성·번역·상태 작업을 실행하지 않아요.
