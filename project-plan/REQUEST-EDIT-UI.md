# 채팅 요청 편집과 설정 작업 아이콘

2026-09-09 요청의 구현·검증 기록이에요. 병행 중인 도우미·문맥 작업과 공유 파일 소유 범위를 나누고, 앱/서버 진입점은 해당 작업에서 통합해요.

## 동작

- 요청 메시지 아래의 연필은 hover·키보드 초점에서 나타나고, 좁은 화면·터치에서는 바로 보여요. 메시지 자리에서 편집하고 취소하거나 수정한 요청을 보낼 수 있어요.
- 사용자가 선택한 동작은 **기존 응답을 보존하고 요청 직전에서 새 분기로 생성**이에요. 현재 설정으로 예약하며, 원래 Run의 요청·응답·후속 대화는 변경하지 않아요.
- 기존 입력창 초안과 요청 편집 초안을 분리해요. 요청 편집 초안은 브라우저 세션에 보존하고 취소·수락 시 정리해요. 수락 여부가 불확실한 전송은 기존 요청 확인 흐름에서 동일한 멱등키·본문으로 확인해요.
- 기존 `POST /api/runs/:id/retry`의 선택적 `request`가 편집 요청이에요. 생략하면 기존 다시 요청이며, 같은 본문이라도 편집과 반복 명령의 멱등키를 혼용하지 못해요. 분기 생성과 예약은 한 트랜잭션이에요.
- 번역·원문 직접 편집의 저장/취소, 채팅 설정 저장, 현재 모델 저장, 자동 후속 작업 저장, 이미지 등록을 접근 가능한 아이콘으로 정리하고 폼 하단 오른쪽에 배치했어요. 기존 비활성화·저장·충돌 처리를 유지해요.
- 채팅 설정의 작문/번역 프리셋 이름은 별도 줄이에요. 채팅 제목 모델과 자동 재요청 횟수의 요청된 설명을 제거했어요.
- 프롬프트 구성의 블록은 기본 접힘이에요. 펼침은 초안을 변경하지 않으며 기존 편집·드래그 검사는 블록을 명시적으로 열어요.
- 현재 모델/프롬프트 로딩 재조회는 문구 오른쪽의 새로고침 아이콘이에요.
- 프롬프트 블록 추가는 블록 제목 오른쪽의 `+`예요. 접힌 상태에서 눌러도 새 블록을 펼치고 이름 입력으로 이동해요.
- 모델 편집의 저장/끝내기는 오른쪽, 삭제는 왼쪽 아이콘으로 정리했어요. 기존 삭제 확인과 revision 검증은 유지해요.
- 긴 요청을 펼치면 축약 미리보기를 숨기고 접기와 전체 요청만 표시해요. 요청 오류의 전역 모델 설정 버튼은 오른쪽이에요.
- 원문 연결 정보와 본문 추정 비용은 장면 더보기에서 대화상자로 열어요. 닫으면 더보기 버튼으로 초점이 돌아와요.
- 채팅의 일회성 표시 문구 미리보기를 제거하고 봇·페르소나의 실제 저장되는 변환 편집기를 `표시 문구 바꾸기`로 안내해요.

## 보조 모델 예약 오류

- 운영 서버의 설정과 실행 snapshot을 읽기 전용으로 조사했어요. 번역 모델은 정상이나 거절 판정·상태·이미지가 참조한 모델에 남은 폐기 필드 `capabilityRevision`이 엄격한 검증에서 400을 발생시켰어요. 번역은 거절 판정 모델도 함께 고정하므로 예약 전에 실패했어요.
- 동일 설정의 번역·상태·이미지 snapshot 검증은 모두 실패했고 메모리에서 해당 내부 필드만 제외하면 모두 통과했어요. 모델 호출·운영 DB 변경은 하지 않았어요. 재현 증거는 `output/aux-model-debug-20260909/readonly-reproduction.log`예요.
- `ProductStore.modelSnapshot`이 새 실행용 모델을 읽을 때 폐기 필드만 제외해요. 저장된 모델 옵션과 과거 Run, 엄격한 외부 snapshot/archive 검증은 유지해요.
- 운영 서버는 이전 배포 코드이므로 로컬 수정만으로 운영 복구를 주장하지 않아요.
