# 서재·대표 이미지 개편 결과

2026-09-08. `90df1d2`의 봇 폴더·채팅 탐색 뒤 공유 작업공간에서 구현했어요. 기존 모델 필수 선택·삭제 개선과 병행 작업의 페르소나 후보 제한, 직접 편집 버튼, 프롬프트 편집 정리를 보존해 통합 검증했어요. 사용자 DB를 열거나 초기화하지 않았으며 커밋·푸시는 하지 않았어요.

## 사용 흐름

- 이름은 **서재**로 유지하고 봇·페르소나·모듈만 표시해요. 프롬프트는 왼쪽 탐색의 별도 화면으로 분리했어요.
- 봇은 이미지 카드, 페르소나·모듈은 이미지 목록을 기본으로 표시하며 분류별 카드/목록 선택을 기억해요. 검색·이름 정렬·상세 보기·직접 편집·새 채팅·최근 채팅 이어가기·복제·삭제를 제공해요.
- 분류별 한 단계 폴더를 생성·이름 변경·정렬·삭제하고 단일/다중 항목을 이동해요. 폴더 삭제는 자료를 같은 분류의 미분류로 옮겨요. 모바일에서도 선택 목록과 폴더 메뉴를 사용할 수 있어요.
- 상세에서 같은 패키지를 봇·페르소나·모듈 역할로 사용할 수 있어요. 역할 사용은 분류·ID·개정을 바꾸지 않아요. 일반 페르소나 선택창은 후속 사용자 요청에 따라 페르소나 분류만 표시해요.
- 편집 상단에서 대표 이미지를 업로드·기존 이미지 선택·해제하고 자료 저장으로 확정해요. 본문 전용 이미지를 대표로 선택하면 용도가 함께 바뀐다고 안내해요. 이미지 탭과 같은 초안 상태를 사용해요.
- 봇 탐색, 새 채팅, 빠른 페르소나 변경, 채팅 폴더 기본 페르소나, 자료 연결, 공유 모듈에 이미지 선택창을 연결했어요. 검색·폴더·키보드·중첩 Escape·포커스 복귀와 이미지 실패 대체 표시를 제공해요. 자료·대표 이미지 선택창 후보는 50개씩 표시해요.

## 저장 계약

정리 metadata는 내용 개정과 독립적이며 전역 revision CAS로 다중 이동을 원자적으로 검증해요. 이동·폴더 삭제가 채팅 소속이나 과거 Run을 바꾸지 않아요. 서재는 최신 대표 이미지를, 연결된 자료는 지정 개정의 대표 이미지를 사용해요. 업로드 취소·늦은 응답, 저장 성공 뒤 목록 갱신 실패, 다른 탭 변경, 고정 버전 조회를 처리해요.

독립 `lore/canon/skill/glossary` 자료 종류와 기타 자료 UI를 제거했어요. 공통 패키지 내부 로어·대상별 지침과 출처·권한·원문/Run snapshot·취소·불확실 실행 보호는 유지해요. 보조 실행의 구형 glossary/canon 문맥은 원문 시점의 공통 `references`로 정리했어요.

현재 schema/archive는 **v12**예요. 폴더·배치 metadata를 전체 archive/SQLite backup에 포함하고 참조·순서·분류·revision을 복원 시 검증해요. 구형 DB/자료의 이관이나 호환 UI를 추가하지 않았어요. 구현/API 계약은 [서재 문서](../docs/LIBRARY.md)를 봐요.
