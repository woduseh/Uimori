# 보조 작업 오류 안내와 표시 상태 복구

## 변경 범위

- 표시 상태 모델이 없던 원문의 기존 재시도는 생성 당시 snapshot을 사용하므로, 현재 채팅 설정을 저장해도 복구되지 않았다.
- 실패한 표시 상태 카드에 `현재 설정으로 장면 상태 새로 실행`을 추가했다. 현재 선택한 표시 상태 모델을 새 작업에 고정하고 원문의 source/hash 및 당시 자료 문맥은 유지한다. 과거 Run과 작업 기록은 수정하지 않는다.
- `POST /api/sources/:id/status`는 `expectedSourceHash`, `expectedJobId`로 화면 기준을 검사한다. 모델 누락이나 충돌 시 신규 작업 저장을 되돌린다.
- 보조 작업과 번역 구간에 알려진 오류 코드의 설명·조치를 표시한다. 알려지지 않은 오류의 원시 문자열은 표시하지 않는다.
- 작업 요청 오류 알림에 작업 종류를 붙이고 다음 요청 시작 시 이전 알림을 지워 장면 상태 오류와 번역 오류의 혼동을 줄인다.

## 확인 범위

사용자가 제공한 번역 화면에서는 첫 구간이 시도 1에서 실패하고 후속 구간이 대기 중인 것만 확인된다. 로컬 개발 DB에 해당 작업 기록이 없어 원격 서버의 번역 실패 원인은 확정하지 않았다. 오류 코드 확인을 요청했다. 실제 공급자 호출·원격 배포·사용자 DB 변경은 수행하지 않는다.
