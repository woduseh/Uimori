## 범위와 한계

합성 자료·로컬 SQLite·브라우저 검증이에요. 유료 호출·실제 외부 모델·개인 작품·물리 휴대폰·실제 IME·배포 검증은 하지 않았어요. 복잡한 Risu 자료는 제작 계약의 참고이며 원본 Lua 실행, 원본 파일 자동 변환, 완전 호환이나 이미지 선택의 의미 품질을 주장하지 않아요.

단일 패키지 JSON은 본문과 이미지 bytes를 포함하지만 연결된 공통 모듈·native Hidden 자료를 재귀 포장하지 않아요. 가져올 서재에 같은 ID·개정이 필요하며 전체 이동은 기존 전체 보관 기능을 사용해요. 명시 이미지 재선택은 현재 장착 목록을 사용하되 해당 원문 Run의 모델·역할 지침을 유지해요. 표현 변환으로 대응을 확인할 수 없는 이미지 위치는 임의로 추측하지 않아요.

커밋·병합·푸시는 이 작업에 포함하지 않았어요. 병행 공급자 작업이 도입하는 새 schema와의 통합 회귀는 이 작업트리 결과와 별개예요.
