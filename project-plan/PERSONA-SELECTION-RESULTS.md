# 페르소나 선택 흐름 단순화 (2026-09-09)

## 현재 계약

- 빠른 선택과 채팅 설정은 같은 `attachments` / `packageAttachments`를 사용해요. 선택한 페르소나는 새 본문 요청에 사용하고, ‘페르소나 없음’은 페르소나 장착을 해제해요.
- `ChatProfile`과 수정 API에서 `personaReference`를 제거했어요. 폐기된 필드를 보내는 수정 요청은 거부해요. 저장된 프로필의 과거 OFF 값은 `currentProfile`의 읽기 projection에서 제외하므로, 별도 저장 없이도 다음 요청에 선택한 페르소나를 사용해요. 운영 DB를 변경하거나 초기화하지 않아요.
- `ProfileSnapshot`에만 과거 실행용 필드를 유지해요. `core/persona-scope.ts`의 `historicalPersonaExcluded`는 과거 Run의 자료·패키지·도구·원문 구간·보관 검증 범위를 재현해요. 과거 Run snapshot과 실행 결과를 다시 쓰지 않아요.
- 장착 해제는 새 요청의 자료와 유지 로어 권한을 다시 계산하게 해요. 기존 대화에 적힌 내용은 남아요. 자료 귀속·revision CAS·초안 보호는 유지해요.
