# 독립 검토 — 요청한 변경과 완료 주장

사용자가 지정한 변경과 완료 주장을 관련 코드·계약·실행 증거로 검토해줘. 베타 진행의 기준은 [BETA-PLAN](../BETA-PLAN.md)이야. 요구사항 누락과 변경이 영향을 주는 저장·실행·권한 경계를 중심으로 확인하고, 이후 소스 변경으로 유효하지 않게 된 검사 결과를 구분해.

검토 중 코드·기대값·검증 기준은 수정하지 마. [QUALITY](../../docs/QUALITY.md#실행-시점)에 맞는 로컬·합성 검사는 별도 결과 경로에서 실행할 수 있어. 유료 모델 호출과 개인 원문 전송은 이 검토의 범위가 아니야.

발견한 문제마다 심각도·파일 위치·재현 조건·사용자 영향·수정 방향을 제시해. 문제가 없으면 확인한 범위에서 문제를 찾지 못했다고 말하고 미검증 범위를 밝혀줘. 무관한 전수 감사나 가상의 경고로 목록을 채우지 마.
