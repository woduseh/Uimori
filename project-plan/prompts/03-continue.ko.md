# 다음 구현 작업 / 중단된 작업 이어가기

현재 사용자 요청과 확정한 선택, 실제 작업트리 상태를 기준으로 이어가줘. [루트 지침](../../AGENTS.md)을 따르고 베타 작업은 [BETA-PLAN](../BETA-PLAN.md)에서 현재 목표·진행·기존 승인을 확인해. 과거 요약과 M0/M1 기록은 현재 완료 상태의 증거로 대신하지 마.

남은 사용자 결과를 구현하고 [QUALITY](../../docs/QUALITY.md#실행-시점)에 따른 검사까지 마쳐줘. 외부 전제나 사용자 결정 때문에 막힌 부분은 이유를 남기고 독립 작업은 계속해. 완료한 변경·검사·남은 범위를 정리하고, 후속 작업은 승인된 요청이나 Goal 범위에서 이어가줘.
