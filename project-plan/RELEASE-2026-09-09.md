# 전역 모델·페르소나·이미지 배치 통합 릴리스

## 포함 범위

- [전역 모델 설정](GLOBAL-MODELS-RESULTS.md): 본문·번역·거절 판정·표시 상태·이미지 모델을 전역에서 지정하고 새 실행에 고정해요. 기존 채팅의 모델을 자동 채택하지 않아요.
- [페르소나 선택](PERSONA-SELECTION-RESULTS.md): 선택하면 새 본문에 사용하고, ‘페르소나 없음’으로 해제해요. 과거 OFF 설정은 새 요청에 영향을 주지 않으며 과거 Run은 보존해요.
- [이미지 배치](IMAGE-PLACEMENT-RESULTS.md): 원문·번역의 문단 위치를 별도로 사용하고, 대표 이미지·프로필 전용 이미지는 후보에서 제외해요. 원문 자동 배치는 기본 OFF, 번역 자동 배치는 기본 ON이에요.
- 채팅·설정 UI 정리, 오류 표시 보정, 미사용 Run 제어 제거와 관련 문서·테스트를 포함해요.
- schema/archive는 v14를 유지해요. 미사용 `runs.issue` 컬럼은 현재 운영 DB와 새 DB의 보관 스키마를 일치시키기 위해 저장소에만 남겨요. UI/API 제어는 복원하지 않아요. 기존 보관 파일을 폐기할 수 있어도 운영 DB에서 새로 내보내는 파일의 복원은 계속 가능해야 해요.
