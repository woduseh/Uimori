# 본문 생성과 번역

모델과 프롬프트의 선택은 [전역 설정](GLOBAL-MODELS.md), Risu 평가 순서는 [프롬프트 실행](PROMPT-RUNTIME.md), 저장되는 데이터의 수명은 [실행 입력](EXECUTION.md)을 참고해요.

## 요청과 완료

요청을 접수할 때 현재 자료·모델·프롬프트·채팅 상태를 읽어 해당 실행의 입력을 구성해요. 실행 도중 다른 창에서 자료를 수정해도 이미 시작한 요청에 섞지 않아요. 잘못된 도구 인수는 수정 가능한 오류로 모델에 반환하고, 취소·통신 실패·호출 한도는 실행을 중단해요. 부분 출력과 실패한 출력을 완료된 원문으로 저장하지 않아요.

성공한 요청은 원문·카드 변수·Lua 메시지 변경·사용량을 저장해요. 전체 모델 입력과 도구 교환은 작업 중에 사용하지만 완료 후 영구 보존하지 않아요. Inspector와 진단 보고서는 남아 있는 요약 정보를 보여주며 과거 전체 요청을 재생하는 기능이 아니에요.

## JEV 거절 판정

본문 서비스 거절 감지는 **기본 꺼짐**이에요. **설정 → 역할별 모델**에서 켜면 본문 생성 후 Lua 출력 후처리 전에 JEV로 명시적 서비스 거절 여부를 확인해요. 작품의 장르·문체·품질을 평가하는 기능이 아니며, 인물의 대사나 인용을 서비스 거절로 취급하지 않도록 요청해요.

판정 기준은 기본 0.9이고 설정 범위는 0.5 초과~1이에요. 켠 경우에만 JEV 키와 판정 호출 예산을 요구해요. JEV는 **프로바이더·모델** 설정에서 앱에 키를 등록하며 일반 API 키와 같은 DB에 보관해요. 이 옵션은 로어 관련성·이미지 선택에 사용되는 JEV와 별개예요.

본문 생성은 끝났지만 판정 호출이 실패했다면 보존된 응답에서 **판정만 다시 시도**할 수 있어요. 생성 모델을 다시 호출하지 않고 판정과 필요한 출력 처리를 수행해요. 원래 요청 이후 이야기가 진행됐다면 오래된 위치에 몰래 삽입하지 않아요. 판정상 거절, 부분 생성, 이미 확정된 결과는 이 복구 대상이 아니에요.

## 번역

번역은 원문 전체를 한 번에 대상으로 삼아요. 새 작업은 현재 번역 모델·프롬프트·정책과 해당 원문 및 필요한 문맥을 사용해요. 실행 중인 번역은 예약한 입력을 유지하며, 늦게 끝난 작업이 더 최신 원문이나 사용자가 수정한 번역을 덮어쓰지 않도록 확인해요.

번역 거절 감지는 본문과 독립적으로 설정하며 기본 켜짐이에요. 켜면 JEV에 번역 후보 전체를 보내고 명시적 거절에 한해 정책에서 지정한 횟수만 다시 번역해요. 빈 응답·부분 출력·HTTP 오류·취소는 자동으로 새 번역을 반복하지 않아요. 이전 성공본이 현재 원문에 유효하면 재번역 실패 후에도 계속 보여줘요.

번역 생성 후 판정만 실패한 경우에는 **번역 판정만 다시 시도**로 후보를 재사용해요. 원문이 달라졌거나 더 최신 번역이 있으면 복구 대상에서 제외해요. 직접 번역 수정과 저장된 원문/번역 보기 전환은 모델을 호출하지 않아요.

## 다시 쓰기와 독립 사본

완성된 응답을 다시 쓰거나 과거 장면에서 다른 전개를 시작하면 해당 위치까지 **새 채팅 사본**을 만들어요. 이후 요청에는 현재 자료와 설정을 사용해요. 원본의 미래 메시지와 사본은 독립적이며, 과거 입력 snapshot을 공유하는 후보 분기 그래프는 사용하지 않아요.

같은 통신 요청을 재전송하면 같은 결과를 반환해 중복 생성을 막아요. 새 재작성 요청은 새로운 실행이며, 외부 공급자에게 이미 전송한 불확실한 요청을 서버 재시작만으로 다시 보내지 않아요.

구현 진입점은 `server/model-runner.ts`, `server/run-retry.ts`, `server/main-judgment.ts`, `server/product-auxiliary.ts`, `server/source-editing.ts`예요. 합성 테스트는 데이터 흐름과 저장 동작을 확인하지만 실제 모델의 창작·번역·판정 품질을 보장하지 않아요.

번역 요청 시 [봇별 번역 지침](TRANSLATION-GUIDES.md)을 현재 저장본에서 읽어 해당 작업에 고정해요. 기존 번역은 자동 교정하지 않으며, 새 번역·재번역에만 새 지침을 사용해요. 판정만 재시도할 때는 기존 후보와 지침을 유지해요.
