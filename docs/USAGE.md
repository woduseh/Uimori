# 사용 안내

[시작하기](../README.md) · [서재와 프롬프트](LIBRARY.md) · [항목 삭제](DELETION.md) · [프로바이더](PROVIDERS.md) · [개발·검증](DEVELOPMENT.md)

패키지에 상태·행동 버튼·주사위·날짜와 인물 목록 계산을 넣으려면 [패키지 동작 안내](PACKAGE-BEHAVIOR.md)를 확인해요. 자료 편집의 **상태와 행동**에서 자동·사용자·모델 호출 방법을 선택하고 **동작 검증 후 적용 → 자료 저장**해요. 상태를 바꾸지 않는 계산의 결과도 채팅의 **최근 행동 결과**에서 볼 수 있어요.

## 봇별 채팅과 폴더

자료 편집의 **로어**에서는 한 단계 폴더를 만들고 이름·설명·본문을 검색해요. 폴더와 사용 방법으로 좁힌 목록은 50개씩 표시하며 선택한 항목 하나만 편집해요. 체크박스로 여러 로어를 선택한 뒤 **폴더로 이동**할 수 있고, **폴더 관리 → 폴더 삭제 · 로어 유지**는 내용을 지우지 않고 미분류로 옮겨요. 폴더와 로어 편집은 자료 저장 시 함께 반영되며 패키지 JSON과 역할 사본에도 포함돼요. 폴더는 정리 용도이고 로어의 모델 전달 순서와 사용 방법을 바꾸지 않아요.

[로컬 앱 열기](http://127.0.0.1:4310) → **설정 → 프로바이더와 모델**에서 프로바이더·모델 프리셋 등록 → **현재 모델**에서 역할별 모델 선택 → **현재 프롬프트**에서 작문·번역 프롬프트와 옵션 설정 → **서재 → 봇**에서 자료 준비 → **새 채팅** 순서예요. 기존 채팅도 같은 전역 설정으로 바로 사용해요. 모델은 하나여도 자동 선택하지 않고 채팅별로 복사·저장하지 않아요. 페르소나·모듈·채팅 이름은 새 채팅의 **추가 설정**에서 바꿔요. 봇은 필수이고 만든 채팅은 그 봇에 계속 소속돼요. 모델 없이 채팅을 만들거나 작성된 시작문을 사용할 수 있지만, 생성·번역 등 실행할 역할에는 사용 가능한 전역 모델이 필요해요. [전역 설정과 실행 경계](GLOBAL-MODELS.md)를 참고해요. 모의 응답은 `NR_TEST_MODE=1`인 로컬 검증 서버에서만 사용해요.

새 채팅의 **장면 상태 자동 실행**은 기본으로 꺼져 있어요. 상태 모델을 선택하고 채팅 설정에서 켜면 이후 원고부터 적용돼요. 기존 채팅과 생성 기록의 설정은 그대로 유지돼요.

입력창은 비어 있거나 한 줄일 때 **더보기(⋯)·글·보내기(↑)** 한 줄이고, 두 줄 이상이 되면 글이 위에서 전체 폭을 쓰고 아래 줄에 ⋯와 ↑가 놓여요. 본문 모델은 헤더의 **모델 칩**에서 확인하고 누르면 전역 **현재 모델** 설정으로 이동하며, 보내기 단축키는 데스크톱 placeholder 끝과 보내기 버튼의 툴팁에 있어요(설정 → 일반에서 Enter 보내기 전환). 더보기(⋯)에서 페르소나·창작 프리셋·창작 옵션과 이번 요청의 조회 로어 제외를 선택하고, 조회 로어 제외를 켜면 입력창 위에 칩으로 표시돼 ×로 해제해요. 현재 프롬프트에 창작 옵션이 없으면 해당 버튼은 표시하지 않아요. 원문·번역의 직접 수정 중에는 일반 채팅 입력창이 접히며, 수정창에 초점이 이동해요. Escape·취소·저장 뒤에는 읽던 수정 버튼으로 돌아와요.

봇마다 채팅을 검색하고 한 단계 폴더로 정리해요. 폴더 사이 이동은 같은 봇 안에서만 가능해요. **폴더 해제 · 채팅 유지**는 채팅을 미분류로 옮겨요. 폴더 기본 페르소나는 앞으로 그 폴더에서 만드는 채팅에만 적용하며 기존 채팅의 선택을 바꾸지 않아요. 포크는 원래 봇과 폴더를 상속해요.

- **서재**: 봇·페르소나·모듈을 검색하고 편집해요. 분류 탭 아래 도구 한 줄은 **폴더 드롭다운(옆 ⋯에서 새 폴더·이름 변경·순서·삭제) · 검색 · 목록 관리**이고, 데스크톱에서도 별도 폴더 패널은 없어요. 자료 상세는 헤더의 **편집**과 **⋯**(다른 역할로 사용, 복제, 분류·폴더 이동, 삭제) 아래에 아바타·이름·소개, 주 행동 **새 채팅**(페르소나·모듈은 각 역할로 사용), 최근 채팅 이어가기, 로어·지침·이미지 개수 한 줄을 보여줘요. 같은 패키지 형식이며 분류별 폴더와 다중 이동으로 정리하고, 채팅에 연결할 때 사용할 역할을 정해요. 패키지 안에 본문·로어·역할별 지침·옵션·상태 표시·정규식 표현을 함께 보관해요. 자료를 저장하면 연결된 채팅의 다음 실행부터 최신 내용을 사용해요. 이미 예약한 실행과 과거 원문은 당시 내용을 유지하며 서재 분류 변경은 장착 역할을 바꾸지 않아요.
- **프롬프트**: 서재와 별도의 탐색 항목에서 작문·번역 프롬프트와 창작 프리셋을 관리해요. 서재와 같은 도구 한 줄 **폴더 드롭다운 · 검색 · 목록 관리(역할 필터·정렬·선택)**로 정리하고 프롬프트 편집기로 들어가 내용을 저장해요.
- **채팅 설정**: **기본** 묶음의 **봇·페르소나·모듈**, **프롬프트·창작 프리셋**, **모델**과 **고급** 묶음의 **상태와 문맥**, **이미지**, **자동 후속 작업** 여섯 분야예요(읽기 설정은 채팅 메뉴의 별도 대화상자). 소속 봇을 교체하지 않고 페르소나·추가 모듈을 조정해요. 창작 옵션 조합은 같은 프롬프트에서 저장한 같은 옵션 정의의 선택값을 다시 사용하는 기능이에요. 조합을 적용해도 본문은 바뀌지 않아요. 모델·프롬프트 분야는 현재 적용 내용을 확인하고 전역 설정으로 이동하는 곳이에요. 채팅별 모델 선택·프롬프트 참조는 저장하지 않아요. 입력창 더보기의 빠른 선택기에도 같은 조건을 만족하는 조합만 나와요. 다른 프롬프트의 조합이나 옵션 정의가 바뀌기 전의 조합은 표시하지 않아요.
- **작업 현황**: 원문과 보조 작업의 진행·실패·재시도를 확인해요. 채팅 헤더의 **채팅 메뉴(⋯)**에서 열고, 진행 중인 작업이 있을 때만 탐색 아래에 **진행 중 N** 줄이 나타나 같은 화면을 열어요. 요청별 실행 상세와 전체 역할의 사용량 Inspector에서 실제 입력·도구 결과·호출 수·미확인 비용을 볼 수 있어요.
- **읽기 설정**: 채팅 메뉴(⋯)에서 열고 새 원고의 기본 보기 언어, 본문 글꼴·크기, 집중 읽기 시작만 다뤄요. 화면 테마는 **설정 → 일반**에서만 바꿔요. 각 장면의 헤더 줄 오른쪽에서 **번역**과 **원문**을 전환하고, 번역이 없는 장면은 **번역 보기**를 눌렀을 때 번역을 시작해요. 헤더 줄의 장면 번호와 상태 표시를 누르면 그 응답의 작업 상세가 아래에 펼쳐져요. 장면 사이 이동은 데스크톱의 왼쪽 눈금 레일에서 하고, 모바일에서는 채팅 제목을 눌러 장면 목록을 열며 마지막 장면을 벗어나 읽는 동안 입력창 위의 ↓ 버튼으로 최신 장면에 돌아가요. 저장된 번역과 원문 사이의 보기 전환은 모델을 호출하지 않아요. 집중 읽기는 탐색과 입력창을 숨기는 표시 옵션이에요.
- **설정**: 앱 테마와 Enter 보내기, 재사용할 프로바이더·모델 프리셋, 내보내기·복원과 접속 해제를 관리해요. 데스크톱에서는 화면 중앙의 넓은 팝업, 작은 화면에서는 전체 화면으로 열려요. 설정은 **일반 / 프로바이더와 모델 / 에이전트 / 데이터 관리 / 접근 보안** 메뉴로 나뉘며 선택한 항목만 표시해요. 데스크톱은 왼쪽, 작은 화면은 상단에서 항목을 선택해요. 항목을 전환해도 입력 중인 프로바이더·모델 초안은 유지돼요. 작은 화면의 탐색 메뉴에서 서재·프롬프트·봇별 채팅·작업 현황·설정을 열 수 있어요.

기본 Enter는 줄바꿈이고 Ctrl/Cmd+Enter로 보내요. 설정에서 Enter 보내기를 선택하면 Shift+Enter로 줄을 바꿔요. 실제 휴대폰 키보드·IME 동작의 검증은 별도예요.

페르소나 선택기는 서재의 페르소나 분류에서 검색·폴더로 고를 수 있어요. 선택한 페르소나는 새 본문 생성에 사용하며, 사용하지 않으려면 **페르소나 없음**을 선택해요. 빠른 페르소나 선택과 **채팅 설정 → 봇·페르소나·모듈**은 같은 장착 상태를 사용해요. 선택을 해제해도 기존 대화 내용과 과거 Run의 실행 기록은 바뀌지 않아요.

원고의 **여기서 새 이야기로 이어가기**를 누르면 그 장면까지 별도의 채팅으로 복사해요. 헤더의 **채팅 메뉴(⋯)**에 있는 **여기까지 새 채팅으로 복사**는 현재 전개의 마지막 장면까지 복사해요. 같은 메뉴에서 읽기 설정·작업 현황·보관된 전개(전개가 둘 이상일 때)·채팅 삭제를 열고, 모바일에서는 집중 읽기도 여기서 켜요. 포크로 들어온 새 채팅에는 입력창 위에 원본 제목과 **원본으로 돌아가기**가 잠시 표시돼요. 원래 폴더에 사본이 생기고, 원본과 사본의 이후 설정·프롬프트·초안·생성은 독립적으로 유지돼요. 복사 자체에는 모델 호출이 없어요. 완료된 원문과 완료된 번역·표시 결과를 보존하고, 아직 진행 중이거나 실패한 작업을 복사하거나 재실행하지 않아요. 같은 복사 요청의 응답이 끊겨 다시 눌러도 사본을 중복 생성하지 않아요.

다른 분기는 **보관된 전개** 목록에서 읽을 수 있어요. 보기 전환은 모델을 호출하지 않아요. 번역은 새 성공본을 표시하고 재번역 실패 시 이전 성공본을 유지해요. 전체 원문을 한 번에 보내고 응답 앞 1,000자로 거절 여부를 판정해요. 거절만 기본 1회 추가 요청하며 수동 재번역은 현재 모델·프롬프트로 새 작업을 만들어요. 판정 모델은 번역 프롬프트 설정에서 지정해요. [자세한 계약](RUNTIME-SIMPLIFICATION.md)을 봐요. 다른 이야기를 열거나 화면을 닫아도 서버 작업을 취소하지 않아요.

`dev`는 빌드 후 실행해요. 이미 빌드했다면 `npm start`로 시작해요. **이전 버전 서버를 사용 중이면 그 터미널에서 Ctrl+C 후 `npm run dev`로 다시 시작해요.** 기본 DB는 `.local/narrative.sqlite`이고 검증 DB와 달라요. 현재 schema는 v15이며 정식 배포 전 구형 자료·채팅을 이관하거나 자동 백업하지 않아요. 호환되지 않는 기본 개발 DB는 서버를 중지하고 `npm run reset:dev`로 초기화해요. 이 명령은 테스트 자료를 삭제하므로 유지할 자료가 있는 서버의 초기화 수단으로 사용하지 않아요. 같은 DB의 두 번째 서버는 복구 전에 거절하며, 사용 중인 포트를 비우기 위해 다른 프로세스를 종료하지 않아요.

별도 합성 DB와 빈 포트가 필요하면 아래처럼 실행해요. 실제 선택된 URL은 `ready` JSON에 나와요.

```powershell
$env:NR_DB = Join-Path $PWD '.local/demo/story.sqlite'
$env:NR_PORT = '0'
npm start
# 종료 후 이 shell의 override 해제
Remove-Item Env:NR_DB, Env:NR_PORT -ErrorAction SilentlyContinue
```

기본 실행은 `127.0.0.1`에 바인딩해요. 서버 환경변수 `NR_ACCESS_TOKEN`으로 로컬 세션 인증을 선택할 수 있어요. PC·휴대폰 원격 접속은 [개인 서버 배포](SELF-HOST.md)의 HTTPS·접속 토큰·허용 주소 설정을 사용해요. 접속이 만료되면 다시 로그인하고, 설정의 **접속 해제**로 현재 브라우저 세션을 종료해요. 서버에서 진행 중인 생성은 브라우저의 접속 해제로 취소되지 않아요. 키 원문을 앱 자료나 대화에 넣지 마세요.

공급자 설정은 [프로바이더 안내](PROVIDERS.md)를 확인해요. 프로바이더 설정에는 인증 환경변수 이름이나 서버의 인증 파일 참조를 저장해요. 키 원문과 Codex 로그인 정보는 서버에서 관리해요.

**설정 → 데이터 관리 → 내보내기와 복원**에서 JSON 또는 일관된 SQLite 백업을 다운로드해요. JSON 복원은 **새 빈 DB**에서만 가능하고 프로바이더는 비활성화하며 비밀키 참조를 지워요. 원문 hash·분기·참조·파생 결과를 검사하고 잘못된 복원은 전체 rollback해요. SQLite 백업은 서버를 종료한 뒤 새로운 `NR_DB` 파일로 복사해 열 수 있어요. 채팅의 PNG/JPEG 에셋과 패키지의 PNG/JPEG/WebP 이미지는 파일당 2,000,000 bytes 이하로 SQLite 안에 함께 보관하므로 별도 이미지 디렉터리 복사가 필요 없어요.

## 계층형 구성과 집필

**채팅 메뉴 → 계층형 구성**에서 전체 주제 → 메인 스토리 → 큰 사건 → 회차 → 작은 사건을 원하는 만큼 만들어요. 모든 수준을 채울 필요는 없고, 구성을 만들지 않으면 기존처럼 다음 장면을 요청해 이어 쓰면 돼요.

각 항목에는 그 수준에서 정한 **의도**를 적어요. 회차나 작은 사건에서 **이 단위 집필**을 누르면 그 항목까지의 상위 의도와 그 항목의 하위 계획이 실제 생성 입력에 함께 들어가고, 결과는 기존 본편 경로에 저장돼요. 한 번에 한 단위만 집필하며, 구성을 만들었다고 본문이 자동으로 써지지는 않아요.

구성은 계획이에요. **집필 완료**는 실제 원문이 확정된 항목에만 붙고, 계획만 있는 항목은 **구성만 있어요**로 남아요. 상위에 결말이나 반전을 적어 두어도 그 단위가 올 때까지 현재 회차의 사실로 다루지 않아요.

도우미에게 "3화 분량을 주제부터 작은 사건까지 구성해 줘"처럼 요청하면 한 번에 구성을 만들어요. 도우미는 구성만 쓰고 본문은 쓰지 않아요. **고정** 아이콘으로 지켜야 할 조건을 못 박으면 도우미는 그 항목을 바꾸지 않고 충돌을 알려요. 이미 집필한 항목도 도우미가 고치지 않아요. 직접 수정은 화면에서 언제든 할 수 있어요.

과거 지점에서 포크하면 구성은 함께 오지만, 다른 갈래에서 나중에 집필한 회차는 계획만 남아요. 자세한 계약·제한은 [계층형 구성](OUTLINE.md)을 봐요.

## 장면 삽화

**설정 → 삽화**에서 생성기를 Codex(ChatGPT 구독의 이미지 생성) 또는 ComfyUI(원격 PC의 API)로 고르면 각 장면의 ⋯ 메뉴에 **삽화 생성**이 생겨요. 자동 생성을 켜면 새 본문이 저장될 때마다 장면당 1개를 예약하고, 장면당 최대 개수와 자동 재요청 횟수를 정할 수 있어요. 삽화는 본문·번역과 별도 작업이라 생성 중에도 읽고 쓸 수 있고, 실패해도 원문은 그대로예요. 결과는 장면 아래 삽화 영역에 표시되며 다시 요청·취소·삭제할 수 있어요. 채팅 설정 → 이미지에서 **캐릭터 디자인**·**그림체** 참조 이미지를 지정하면 Codex 경로에서 함께 보내요. 자세한 설정·오류 코드·검증은 [장면 삽화](ILLUSTRATIONS.md)를 봐요.

## 원문과 번역 직접 수정

장면 아래 도구 줄의 연필 버튼은 지금 보고 있는 원문 또는 번역을 수정하고, 같은 줄의 **⋯ 메뉴**에서 다른 쪽(**원문 수정** 또는 **번역 수정**)과 **현재 설정으로 새 번역**, **현재 설정으로 다시 요청**, **여기서 새 이야기로 이어가기**, **이미지 자동 배치**를 열어요. 이미지 배치는 현재 보기의 문단을 기준으로 동작하며 원문용과 번역문용 결과가 분리돼요. 자료의 대표 이미지와 프로필 전용 이미지는 후보에서 제외해요. 채팅의 봇·페르소나·모듈 설정에서 원문 자동 배치(기본 꺼짐)와 번역 자동 배치(기본 켜짐)를 따로 조절해요. 수정창에서 내용을 고치고 저장해요. 직접 저장에는 모델 호출이 없으며 번역 버전 선택은 제공하지 않아요. 원문을 수정하면 기존 번역은 무효화하고, 다음 **번역 보기**에서 수정한 원문을 번역해요. 수정된 원문은 다음 작문 요청의 이력에 반영하며, 이미 실행한 요청의 입력과 기존 후속 원고는 보존해요. 상태·요약은 영향을 받은 파생물을 무효로 표시하며, 의미적 재계산은 별도 복구 요청으로 진행해요.

다른 탭에서 먼저 저장했다면 충돌을 표시하고 작성 중인 초안을 유지해요. 새로고침 뒤에도 같은 탭의 편집 초안을 복원하며, 최신 저장 내용을 불러오는 동작은 별도로 선택해요. 편집 전에 시작한 번역이 늦게 끝나도 사용자가 저장한 내용을 덮어쓰지 않아요.

## 도우미와 독립 가정 장면

채팅·서재의 **도우미**에서 작품 질문과 자료 제작·편집을 요청해요. 본편과 입력창·대화 이력이 분리되며, 본편의 OOC는 계속 본편 입력으로 사용해요. 설정 → 현재 모델에서 **도우미 모델**을 먼저 선택해요. 선택하지 않으면 실행하지 않으며 다른 모델로 대체하지 않아요. 패널 설정에서 말투와 호출 한도를 조정할 수 있어요. 말투는 도우미의 설명에만 적용해요.

채팅별로 대화를 이어가고 서재에서는 **새 서재 작업**과 작업 선택기로 제작 이력을 나눠요. 응답 메뉴의 **도우미에게 물어보기**는 선택한 원문과 출처를 전달해요. 진행 중 후속 요청은 순서대로 대기하며, 패널이나 브라우저를 닫아도 서버 작업은 계속돼요. 중지 버튼으로 해당 작업을 취소할 수 있어요. 서버가 중단한 작업은 자동으로 재호출하지 않아요.

자료·프롬프트 편집기는 서버에 같은 초안을 보관해요. 아직 적용하지 않은 JSON 문법과 사람의 미저장 수정도 포함하며 도우미 요청 전에 동기화해요. 대상을 선택하고 “이 로어를 수정하고 저장해줘”처럼 명확히 요청하면 그 범위의 수정·저장을 수행해요. 검토·추천 요청은 저장 권한을 주지 않아요. 동시 수정은 제안으로 남겨 최신 내용을 덮지 않으며 **변경 내용·공유 영향·저장 이력**에서 확인해요. 저장 되돌리기도 현재 개정이 맞을 때 이전 내용을 새 개정으로 저장해요.

편집하지 않은 초안은 다른 곳에서 저장한 최신 내용으로 갱신해요. 미저장 수정이나 원시 JSON 입력이 있으면 그대로 보존하고 비교를 안내해요. 최신 내용을 불러오는 동안 새로 입력한 경우에도 그 입력을 덮어쓰지 않아요. 자료를 처음 저장하거나 역할 사본을 만들 때 펼친 편집 영역과 선택한 분야·로어 필터를 유지해요.

**초안 버리고 닫기/이동**을 선택하면 해당 서버 초안의 폐기를 확인한 뒤 화면을 닫아요. 폐기가 실패하면 오류와 편집 화면을 유지해요.

“이 채팅에서만 로어를 바꿔줘”는 선택한 자료 연결에만 변경분을 적용해요. 공유 자료 원본과 다른 역할의 같은 자료는 유지해요. **창작 옵션**에서 채팅 고정값과 도우미에게 맡길 옵션을 관리해요. 적용 순서는 전역 작업본 → 채팅 고정값 → 고정되지 않은 위임 필드 → 명시적인 일회 값이며, 일회 값은 다음 요청 예약에서 한 번 소비해요. 모델·전역 프리셋은 옵션 위임에 포함되지 않아요.

“다른 선택을 했다면 어떤 장면인지 써줘”는 요청 당시 최신 완료 본편과 현재 작문 설정을 사용한 **독립 가정 장면**을 만들어요. 본편의 전개·상태·요약·추첨·후속 요청은 바꾸지 않아요. 필요한 상태 계산이 진행 중이면 같은 원문을 기다리고 실패하면 이유를 알리고 멈춰요. 결과 질문·복사·직접 편집과 수정 요청을 지원하며, 수정은 원래 생성 문맥을 사용해요. 최신 본편을 다시 반영하려면 새 장면을 요청해요.

공급자가 공개 답변을 보내는 동안 받은 부분을 표시하고 재접속 시 이어받아요. 도구 인자·사고 과정·내부 평가 출력은 답변으로 표시하지 않아요. 최종 제출 검증이 필요한 응답은 완료 후 검증된 본문을 보여줘요. 부분 응답은 확정 원문과 구분하며 실패·취소 때도 상태와 함께 보존해요. 이미지 파일을 실제 모델 입력으로 읽는 기능은 후속 범위이고, 현재 도우미는 이미지 설명 등 텍스트 메타데이터만 다뤄요.

## 이야기 상태와 문맥·메모

상태 모듈은 숫자·문자·enum·불리언 필드와 허용 변화 규칙을 정의해요. 보조 모델은 원문 구간을 근거로 제안하고 앱의 reducer가 필드·근거·범위·중복을 검사한 뒤 값을 계산해요. **authoritative**는 직전 상태가 준비될 때까지 다음 원문 요청을 대기시키고, **continuity**는 원문을 바로 생성하되 상태 계산만 이전 결과를 기다려요. **annotation**은 화면에만 표시해요. 모듈 활성화 시 현재 장면을 초기값의 시작점으로 삼아요.

상태 설정은 채팅마다 최신 한 벌을 관리하며 revision으로 동시 저장 충돌을 검사해요. 과거 원문과 상태 작업은 당시 설정·모델·프로바이더를 자체 snapshot으로 보존해요. 원문 수정이나 사용자 메모·정정으로 무효해진 결과는 과거 기록으로 남기고 새 입력에서 제외해요. **현재 원문에서 상태 다시 확인**으로 앞 장면부터 복구할 수 있어요. **현재 장면에서 초기값으로 새 기준 적용**은 확인한 초기값으로 새 상태 기준을 만들며 이전 규칙을 기다리던 요청은 취소해요. 실패·중단된 모델 호출은 자동 재실행하지 않아요.

**채팅 설정 → 상태와 문맥**에서 요약과 메모를 관리해요. 요약을 저장·압축하기 전에 전역 본문 모델을 선택해 입력 예산을 정해요. **지금 압축**은 자동 임계값 아래에서도 최근 두 장면 이전 대화를 정리하고 본문 Run을 만들지 않아요. 이미 정리했거나 대상이 없으면 모델 호출 없이 완료해요. **요약 작성/편집**은 모델 호출 없이 새 revision을 저장하며 과거 요약으로 되돌리기도 현재 원문·메모와 맞을 때만 가능해요. 다른 탭의 저장·원문 변경은 충돌로 안내하고 초안을 유지해요.

메모·정정은 사용자가 명시한 내용이며 작성자와 시작 원문 ID/hash에 연결돼요. 수정·삭제는 새 대체/종료 기록으로 보존해 다른 분기와 과거 Run의 내용을 바꾸지 않아요. 유효한 메모는 요약과 함께 다음 입력에 들어가고, `notes.list/read`와 `story.search/read`는 같은 전개 범위만 조회해요. 매 장면 기억 항목 추출, 색인 재구축, `memory` 슬롯과 `memory.search/read`는 제거했어요. 긴 대화는 유효한 요약과 미압축 원문으로 이어가요. 상세 예산·CAS·실패 계약은 [CONTEXT-LIMITS.md](CONTEXT-LIMITS.md)를 봐요.

설정 → 현재 모델에서 **문맥 요약 모델**을 지정해요. 미지정이면 실제 압축이 필요한 작업만 멈추며 다른 모델로 대체하지 않아요. 사용자 요약·메모 편집 이후 늦게 도착한 자동 요약은 비활성 후보로 남고 활성 요약을 덮어쓰지 않아요. 요약은 파생 참고 문맥이며 원문이나 상태 판정을 대신하지 않아요.

본문 모델이 요약을 직접 쓰게 하려면 **모델 프리셋 편집 → 고급 → 선택형 문맥 도구**를 켜요. 그 프리셋으로 실행하는 본문 요청에서 모델은 한도 접근 알림을 보고 작업 요약을 저장(`context.write`)하고, 같은 요청 안에서 오래된 장면과 이전 조회 결과를 뺀 새 컨텍스트 창을 열 수 있어요(`context.new`). 원문은 그대로 보존되며 모델은 `story.list/search/read`로 언제든 다시 읽어요. 모델이 쓴 요약은 **상태와 문맥**에 `모델 작성`으로 표시되고 편집·되돌리기·압축은 똑같이 적용돼요. 사용자가 요약이나 메모를 고친 뒤 도착한 모델 저장은 비활성 후보로 남아요. 기본은 꺼져 있고, 켜도 85% 자동 압축은 대체 경로로 남아요. 상세 계약은 [CONTEXT-LIMITS.md](CONTEXT-LIMITS.md#선택형-모델-주도-메모전환)를 봐요.

포크는 선택 장면까지 유효한 상태·메모·요약과 과거 작업 snapshot을 복사해요. 선택 지점 이후의 요약·메모와 도우미 이력·초안은 가져오지 않아요. 현재 상태 활성화 지점이 복사 범위 밖에 있으면 사본에서 상태 설정을 새로 저장해 시작해요. 장면 예약은 원문 저장 성공 때 소비하며 상태창·정규식 미리보기는 저장 원문을 바꾸지 않아요.

현재 DB schema와 JSON archive는 **v15**이며 v15 archive를 새 빈 DB에 복원해요. 구버전 DB/archive는 이관하지 않아요. 원문·상태·메모·요약·도우미 작업·서버 초안과 변경 영수증의 소유권·hash·revision을 검증하며, 진행 중이던 작업은 자동 재전송하지 않아요. 사용자 DB는 자동 검사에 사용하지 않아요. 합성 검사는 계약을 확인하며 실제 의미 품질을 증명하지 않아요.
## 작문·번역 프롬프트 직접 편집

**채팅 설정 → 프롬프트·창작 프리셋**에서 작문과 번역 프롬프트를 각각 선택해요. **새 프롬프트 생성**을 누르면 선택한 역할의 기본 내용과 메시지 구성으로 초안을 시작해요. 탐색의 **프롬프트 → 새 프롬프트**에서도 같은 방식으로 재사용할 프롬프트를 만들어요.

프롬프트 이름을 정하고 **프롬프트 구성**의 블록을 펼쳐 이름·본문·역할·순서·조건·자료 배치를 수정해요. **본문 파일 불러오기**는 UTF-8 `.txt`/`.md`를 해당 평문 메시지에 넣어요. 조건·값·참조가 있는 본문은 템플릿 문법이나 JSON으로 구조를 유지하며 편집해요. 저장 버튼으로 프롬프트를 저장하고, 채팅 적용과 옵션 조합 저장은 각각 명시적으로 선택해요.

**프롬프트 구성** 전체와 각 블록을 접어도 초안은 유지돼요. 기본으로 접힌 **전송 미리보기**를 열고 **미리보기 갱신**을 누르면 블록 이름과 메시지 역할·순서를 확인할 수 있어요. 미리보기는 모델을 호출하지 않으며, 미적용 문법이 있으면 적용하거나 되돌린 뒤 저장해요.


## 채팅 폴더 탐색

탐색은 위에서 아래로 **새 채팅 · 채팅 검색 · 봇 전환 행 · 채팅 목록**, 아래에 **서재 · 프롬프트 · 설정**이에요. 봇 전환 행(아바타 · 봇 이름 ∨)을 누르면 최근 활동 순의 봇 목록과 검색, **새 폴더**, **서재에서 관리**가 팝오버로 열려요. 폴더에 넣지 않은 채팅은 제목 없이 목록 위에 평평하게 놓이고, 이름 있는 폴더만 접이식 제목으로 보여요. 폴더 이름을 눌러 접거나 펼치고, 폴더 오른쪽 `+`로 그 폴더에 새 채팅을 시작해요. `⋯`에서 폴더 이름·새 채팅 기본 페르소나를 설정해요. 폴더를 해제하면 채팅은 기존 순서대로 폴더 밖 목록의 끝에 이동해요.

채팅을 다른 채팅의 위·아래로 드래그해 순서를 바꾸고, 다른 폴더 이름 위에 놓으면 그 폴더 끝으로 이동해요. 접힌 폴더 위에 잠시 머무르면 펼쳐져요. 새 채팅·포크는 폴더 맨 위에 추가하며 작업 완료는 수동 순서를 바꾸지 않아요. 검색 중에는 다른 폴더로 이동할 수 있지만 같은 폴더의 순서는 바꾸지 않아요. 이동은 같은 봇 안에서만 가능해요.

마우스를 올리거나 키보드로 접근하면 채팅 메뉴와 삭제 아이콘이 나타나요. 터치 화면에서는 메뉴가 항상 보이고 폴더 이동·위/아래 이동·삭제를 제공해요. 삭제는 기존 확인 절차를 거쳐요. 작은 회전 표시는 선택하지 않은 채팅까지 진행 중인 작업을 나타내며, 접힌 폴더에도 표시해요. 상세 종류·개수는 표시의 설명으로 확인해요. 전체 작업 표시는 화면이 보이는 동안 약 2초마다 갱신해요.
