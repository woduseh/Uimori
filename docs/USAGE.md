# 사용 안내

[시작하기](../README.md) · [공급자 연결](PROVIDERS.md) · [개발·검증](DEVELOPMENT.md)

패키지에 상태·행동 버튼·주사위·날짜와 인물 목록 계산을 넣으려면 [패키지 동작 안내](PACKAGE-BEHAVIOR.md)를 확인해요. 자료 편집의 **상태와 행동**에서 자동·사용자·모델 호출 방법을 선택하고 **동작 검증 후 적용 → 자료 저장**해요. 상태를 바꾸지 않는 계산의 결과도 채팅의 **최근 행동 결과**에서 볼 수 있어요.

## 봇별 채팅과 폴더

자료 편집의 **로어**에서는 한 단계 폴더를 만들고 이름·설명·본문을 검색해요. 폴더와 사용 방법으로 좁힌 목록은 50개씩 표시하며 선택한 항목 하나만 편집해요. 체크박스로 여러 로어를 선택한 뒤 **폴더로 이동**할 수 있고, **폴더 관리 → 폴더 삭제 · 로어 유지**는 내용을 지우지 않고 미분류로 옮겨요. 폴더와 로어 편집은 자료 저장 시 함께 반영되며 패키지 JSON과 역할 사본에도 포함돼요. 폴더는 정리 용도이고 로어의 모델 전달 순서와 사용 방법을 바꾸지 않아요.

[로컬 앱 열기](http://127.0.0.1:4310) → **봇**에서 자료 준비 → **채팅 시작** 또는 탐색의 봇 선택 → **새 채팅** → 페르소나·프롬프트·창작 프리셋 선택 → **채팅 만들기** 순서예요. 봇은 필수이고 만든 채팅은 그 봇에 계속 소속돼요. 제목을 비워 두면 기본 이름을 사용하며, 시작 설정을 저장한 뒤 첫 요청을 보낼 수 있어요. 모델을 설정하지 않으면 기능 검증용 합성 원문과 모의 번역이 나와요.

봇마다 채팅을 검색하고 한 단계 폴더로 정리해요. 폴더 사이 이동은 같은 봇 안에서만 가능해요. **폴더 해제 · 채팅 유지**는 채팅을 미분류로 옮겨요. 폴더 기본 페르소나는 앞으로 그 폴더에서 만드는 채팅에만 적용하며 기존 채팅의 선택을 바꾸지 않아요. 포크는 원래 봇과 폴더를 상속해요.

- **봇·페르소나·모듈·프롬프트**: 상단 탐색에서 자료를 검색하고 편집해요. 봇·페르소나·모듈은 같은 패키지 형식이고, 채팅에 연결할 때 역할을 정해요. 패키지 안에 본문·로어·역할별 지침·옵션·상태 표시·정규식 표현을 함께 보관해요. 자료를 수정해도 채팅에 장착한 버전을 명시적으로 바꾸기 전까지는 선택한 버전으로 진행해요.
- **채팅 설정**: **봇·페르소나·모듈**, **프롬프트·창작 프리셋**, **모델**을 관리해요. 소속 봇을 교체하지 않고 페르소나·추가 모듈을 조정해요. 창작 프리셋은 특정 프롬프트 revision에 속한 옵션 조합이며 여러 채팅에서 재사용해요. 입력창의 빠른 선택기에는 현재 프롬프트에 맞는 조합만 나와요.
- **작업 현황**: 원문과 보조 작업의 진행·실패·재시도를 확인해요. 요청별 실행 상세와 전체 역할의 사용량 Inspector에서 실제 입력·도구 결과·호출 수·미확인 비용을 볼 수 있어요.
- **읽기 설정**: 새 원고의 기본 보기 언어, 본문 글꼴·크기와 테마를 정해요. 번역이 없으면 원문을 보여 주며 **번역 보기**를 눌렀을 때 번역을 시작해요. 저장된 번역과 원문 사이의 보기 전환은 모델을 호출하지 않아요. 집중 읽기는 탐색과 입력창을 숨기는 표시 옵션이에요.
- **설정**: 앱 테마와 Enter 보내기, 재사용할 연결·모델 프리셋, 내보내기·복원과 접속 해제를 관리해요. 데스크톱에서는 화면 중앙의 넓은 팝업, 작은 화면에서는 전체 화면으로 열려요. 설정은 **일반 / 연결과 모델 / 데이터 관리 / 접근 보안** 메뉴로 나뉘며 선택한 항목만 표시해요. 데스크톱은 왼쪽, 작은 화면은 상단에서 항목을 선택해요. 항목을 전환해도 입력 중인 연결·모델 초안은 유지돼요. 작은 화면의 탐색 메뉴에서 봇·자료·작업 현황·설정을 열 수 있어요.

기본 Enter는 줄바꿈이고 Ctrl/Cmd+Enter로 보내요. 설정에서 Enter 보내기를 선택하면 Shift+Enter로 줄을 바꿔요. 실제 휴대폰 키보드·IME 동작의 검증은 별도예요.

원고의 **여기서 새 이야기로 이어가기**를 누르면 그 장면까지 별도의 채팅으로 복사해요. 상단 **채팅 포크**는 현재 전개의 마지막 장면까지 복사해요. 원래 폴더에 사본이 생기고, 원본과 사본의 이후 설정·프롬프트·초안·생성은 독립적으로 유지돼요. 복사 자체에는 모델 호출이 없어요. 완료된 원문과 완료된 번역·표시 결과를 보존하고, 아직 진행 중이거나 실패한 작업을 복사하거나 재실행하지 않아요. 같은 복사 요청의 응답이 끊겨 다시 눌러도 사본을 중복 생성하지 않아요.

다른 분기는 **보관된 전개** 목록에서 읽을 수 있어요. 보기 전환은 모델을 호출하지 않아요. 번역은 최신 내용 하나만 표시해요. 정상 종료된 거절·빈 응답·구조 손상은 완료 구간을 보존하고 해당 구간만 최대 3회 시도해요. 시간 초과·연결 단절·HTTP 오류처럼 실행이 불확실한 실패는 사용자가 재시도를 눌러요. 다른 이야기를 열거나 화면을 닫아도 서버 작업을 취소하지 않아요.

`dev`는 빌드 후 실행해요. 이미 빌드했다면 `npm start`로 시작해요. **이전 버전 서버를 사용 중이면 그 터미널에서 Ctrl+C 후 `npm run dev`로 다시 시작해요.** 기본 DB는 `.local/narrative.sqlite`이고 검증 DB와 달라요. 현재 schema는 v11이며 정식 배포 전 구형 자료·채팅을 이관하거나 자동 백업하지 않아요. 호환되지 않는 기본 개발 DB는 서버를 중지하고 `npm run reset:dev`로 초기화해요. 이 명령은 테스트 자료를 삭제하므로 유지할 자료가 있는 서버의 초기화 수단으로 사용하지 않아요. 같은 DB의 두 번째 서버는 복구 전에 거절하며, 사용 중인 포트를 비우기 위해 다른 프로세스를 종료하지 않아요.

별도 합성 DB와 빈 포트가 필요하면 아래처럼 실행해요. 실제 선택된 URL은 `ready` JSON에 나와요.

```powershell
$env:NR_DB = Join-Path $PWD '.local/demo/story.sqlite'
$env:NR_PORT = '0'
npm start
# 종료 후 이 shell의 override 해제
Remove-Item Env:NR_DB, Env:NR_PORT -ErrorAction SilentlyContinue
```

기본 실행은 `127.0.0.1`에 바인딩해요. 서버 환경변수 `NR_ACCESS_TOKEN`으로 로컬 세션 인증을 선택할 수 있어요. PC·휴대폰 원격 접속은 [개인 서버 배포](SELF-HOST.md)의 HTTPS·접속 토큰·허용 주소 설정을 사용해요. 접속이 만료되면 다시 로그인하고, 설정의 **접속 해제**로 현재 브라우저 세션을 종료해요. 서버에서 진행 중인 생성은 브라우저의 접속 해제로 취소되지 않아요. 키 원문을 앱 자료나 대화에 넣지 마세요.

공급자 설정은 [연결 안내](PROVIDERS.md)를 확인해요. 브라우저와 DB에는 credential 환경변수 이름만 저장해요.

**설정 → 내보내기와 복원**에서 JSON 또는 일관된 SQLite 백업을 다운로드해요. JSON 복원은 **새 빈 DB**에서만 가능하고 연결은 비활성화하며 비밀키 참조를 지워요. 원문 hash·분기·참조·파생 결과를 검사하고 잘못된 복원은 전체 rollback해요. SQLite 백업은 서버를 종료한 뒤 새로운 `NR_DB` 파일로 복사해 열 수 있어요. 작은 PNG/JPEG 에셋은 파일당 2,000,000 bytes 이하로 SQLite 안에 함께 보관하므로 별도 에셋 디렉터리 복사가 필요 없어요.

## 원문과 번역 직접 수정

원고의 **원문 수정** 또는 **번역 수정**을 눌러 내용을 고치고 저장해요. 직접 저장에는 모델 호출이 없으며 번역 버전 선택은 제공하지 않아요. 원문을 수정하면 기존 번역은 무효화하고, 다음 **번역 보기**에서 수정한 원문을 번역해요. 수정된 원문은 다음 작문 요청의 이력에 반영하며, 이미 실행한 요청의 입력과 기존 후속 원고는 보존해요. M2 상태·기억은 영향을 받은 파생물을 무효로 표시하며, 의미적 재계산은 별도 복구 요청으로 진행해요.

다른 탭에서 먼저 저장했다면 충돌을 표시하고 작성 중인 초안을 유지해요. 새로고침 뒤에도 같은 탭의 편집 초안을 복원하며, 최신 저장 내용을 불러오는 동작은 별도로 선택해요. 편집 전에 시작한 번역이 늦게 끝나도 사용자가 저장한 내용을 덮어쓰지 않아요.

## 이야기 상태와 장기 기억

상태 모듈은 숫자·문자·enum·불리언 필드와 허용 변화 규칙을 정의해요. 보조 모델은 원문 구간을 근거로 제안하고, 앱의 reducer가 필드·근거·범위·중복을 검사한 뒤 값을 계산해요. **authoritative**는 직전 상태가 준비될 때까지 다음 원문 요청을 대기시키고, **continuity**는 원문을 바로 생성하되 상태 계산만 이전 결과를 기다려요. **annotation**은 화면에만 표시해요. 모듈 활성화 시 현재 장면을 초기값의 시작점으로 삼아요.

원문 수정이나 작가 선언 변경으로 무효해진 결과는 과거 기록으로 보존하면서 새 입력에서 제외해요. 상태는 앞 장면부터 **현재 원문에서 상태 다시 확인**, 기억은 **기존 원문 기억 정리**로 복구해요. 상태를 켰던 장면을 수정했다면 해당 장면 복구는 초기값에서 그 장면의 사건을 다시 계산해요. **현재 장면에서 초기값으로 새 기준 적용**은 값을 확인한 뒤 새 상태 기준을 만들며 이전 규칙을 기다리던 요청은 취소해요. 실패·중단된 실제 보조 호출은 자동 재실행하지 않아요.

장기 기억은 작가 선언, 관찰 사건, 요약, 인물 믿음, 가설을 구분해요. 처리한 원문이 연속으로 이어진 지점까지 색인 기준을 만들고, 이후 미처리 원문과 최근 원문을 다음 입력에 보완해요. 오래된 원문은 `story.search/read`, 기억은 `memory.search/read`로 현재 전개 안에서 회수해요. 원문을 삭제하거나 사용자가 수동으로 작품을 복제할 필요는 없어요. 필수 문맥이 설정한 한도를 넘으면 누락시키지 않고 복구·한도 조정을 안내해요.

장면 예약은 원문 저장이 성공했을 때 소비돼요. 상태창과 제한된 정규식 미리보기는 원문을 바꾸지 않으며 HTML 문자열을 실행하지 않아요. 에셋 manifest는 설명·인물·의상·장소를 검색하고 실제 존재하는 조합을 확인해요. 모델 미선택 상태는 합성 규칙으로 동작하며 실제 의미 추출 능력을 뜻하지 않아요.

M2 상태·기억·예약은 schema v4에서 도입했어요. 현재 DB schema와 JSON archive는 v11이며, 복원은 v11 archive를 새 빈 DB에 넣는 경우만 지원해요. 구버전 DB·archive는 이관하지 않아요. 과거 상태·source hash·의존성과 입력 snapshot, 봇 소속·폴더, 패키지 행동·판정 기회를 검증해요. 사용자 DB는 자동 검사에 사용하지 않아요.

## 작문·번역 프롬프트 직접 편집

**채팅 설정 → 프롬프트·창작 프리셋**에서 작문과 번역 프롬프트를 각각 선택해요. **간단 편집**에서 메시지의 본문을 고치고, **구성 편집**에서 같은 프롬프트의 메시지 역할·순서·조건·자료 배치를 수정해요. 기본 프롬프트를 불러오거나 새 프롬프트의 빈 본문부터 작성할 수 있어요. **본문 파일 불러오기**는 UTF-8 `.txt`/`.md`를 선택한 평문 메시지에 넣어요. **프롬프트 구성** 제목을 누르면 전체를 접고 펼칠 수 있으며 초안은 유지돼요. 서재의 **프롬프트**에서도 재사용할 구성과 옵션 조합을 관리해요.


## 채팅 폴더 탐색

봇의 채팅은 한 줄 목록으로 표시해요. 폴더 이름을 눌러 접거나 펼치고, 폴더 오른쪽 `+`로 새 채팅을 시작해요. `⋯`에서 폴더 이름·새 채팅 기본 페르소나를 설정해요. 폴더를 해제하면 채팅은 기존 순서대로 미분류 끝에 이동해요.

채팅을 다른 채팅의 위·아래로 드래그해 순서를 바꾸고, 다른 폴더 이름 위에 놓으면 그 폴더 끝으로 이동해요. 접힌 폴더 위에 잠시 머무르면 펼쳐져요. 새 채팅·포크는 폴더 맨 위에 추가하며 작업 완료는 수동 순서를 바꾸지 않아요. 검색 중에는 다른 폴더로 이동할 수 있지만 같은 폴더의 순서는 바꾸지 않아요. 이동은 같은 봇 안에서만 가능해요.

마우스를 올리거나 키보드로 접근하면 채팅 메뉴와 삭제 아이콘이 나타나요. 터치 화면에서는 메뉴가 항상 보이고 폴더 이동·위/아래 이동·삭제를 제공해요. 삭제는 기존 확인 절차를 거쳐요. 작은 회전 표시는 선택하지 않은 채팅까지 진행 중인 작업을 나타내며, 접힌 폴더에도 표시해요. 상세 종류·개수는 표시의 설명으로 확인해요. 전체 작업 표시는 화면이 보이는 동안 약 2초마다 갱신해요.
