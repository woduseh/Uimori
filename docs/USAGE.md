패키지에 상태·행동 버튼·주사위·날짜와 인물 목록 계산을 넣으려면 [패키지 동작 안내](PACKAGE-BEHAVIOR.md)를 확인해요. 자료 편집의 **상태와 행동**에서 자동·사용자·모델 호출 방법을 선택하고 **동작 검증 후 적용 → 자료 저장**해요. 상태를 바꾸지 않는 계산의 결과도 채팅의 **최근 행동 결과**에서 볼 수 있어요.

## 봇별 채팅과 폴더

자료 편집의 **로어**에서는 한 단계 폴더를 만들고 이름·설명·본문을 검색해요. 폴더와 사용 방법으로 좁힌 목록은 50개씩 표시하며 선택한 항목 하나만 편집해요. 체크박스로 여러 로어를 선택한 뒤 **폴더로 이동**할 수 있고, **폴더 관리 → 폴더 삭제 · 로어 유지**는 내용을 지우지 않고 미분류로 옮겨요. 폴더와 로어 편집은 자료 저장 시 함께 반영되며 패키지 JSON과 역할 사본에도 포함돼요. 폴더는 정리 용도이고 로어의 모델 전달 순서와 사용 방법을 바꾸지 않아요.

[로컬 앱 열기](http://127.0.0.1:4310) → **서재 → 봇**에서 자료 준비 → **봇으로 새 채팅** 또는 탐색의 봇 선택 → **새 채팅** → 본문 모델 확인 → **채팅 만들기** 순서예요. 사용 가능한 최근 모델을 제안하며, 최근 선택이 없고 사용 가능한 모델이 하나이면 미리 선택해요. 페르소나·모듈·프롬프트·번역 모델·채팅 이름은 **추가 설정**에서 바꿔요. 봇은 필수이고 만든 채팅은 그 봇에 계속 소속돼요. 제목을 비워 두면 기본 이름을 사용해요. 모델 없이 채팅을 만들거나 작성된 시작문을 사용할 수 있지만, 생성·번역 등 실행할 역할에는 모델을 선택해야 해요. 모의 응답은 `NR_TEST_MODE=1`인 로컬 검증 서버에서만 사용해요.

새 채팅의 **장면 상태 자동 실행**은 기본으로 꺼져 있어요. 상태 모델을 선택하고 채팅 설정에서 켜면 이후 원고부터 적용돼요. 기존 채팅과 생성 기록의 설정은 그대로 유지돼요.

입력창은 비어 있거나 한 줄일 때 **더보기(⋯)·글·보내기(↑)** 한 줄이고, 두 줄 이상이 되면 글이 위에서 전체 폭을 쓰고 아래 줄에 ⋯와 ↑가 놓여요. 본문 모델은 헤더의 **모델 칩**에서 보고 바꾸며, 보내기 단축키는 데스크톱 placeholder 끝과 보내기 버튼의 툴팁에 있어요(설정 → 일반에서 Enter 보내기 전환). 더보기(⋯)에서 페르소나·창작 프리셋·창작 옵션과 이번 요청의 조회 로어 제외를 선택하고, 조회 로어 제외를 켜면 입력창 위에 칩으로 표시돼 ×로 해제해요. 현재 프롬프트에 창작 옵션이 없으면 해당 버튼은 표시하지 않아요. 원문·번역의 직접 수정 중에는 일반 채팅 입력창이 접히며, 수정창에 초점이 이동해요. Escape·취소·저장 뒤에는 읽던 수정 버튼으로 돌아와요.

봇마다 채팅을 검색하고 한 단계 폴더로 정리해요. 폴더 사이 이동은 같은 봇 안에서만 가능해요. **폴더 해제 · 채팅 유지**는 채팅을 미분류로 옮겨요. 폴더 기본 페르소나는 앞으로 그 폴더에서 만드는 채팅에만 적용하며 기존 채팅의 선택을 바꾸지 않아요. 포크는 원래 봇과 폴더를 상속해요.

- **서재**: 봇·페르소나·모듈을 검색하고 편집해요. 분류 탭 아래 도구 한 줄은 **폴더 드롭다운(옆 ⋯에서 새 폴더·이름 변경·순서·삭제) · 검색 · 목록 관리**이고, 데스크톱에서도 별도 폴더 패널은 없어요. 자료 상세는 헤더의 **편집**과 **⋯**(다른 역할로 사용, 복제, 분류·폴더 이동, 삭제) 아래에 아바타·이름·소개, 주 행동 **새 채팅**(페르소나·모듈은 각 역할로 사용), 최근 채팅 이어가기, 로어·지침·이미지 개수 한 줄을 보여줘요. 같은 패키지 형식이며 분류별 폴더와 다중 이동으로 정리하고, 채팅에 연결할 때 사용할 역할을 정해요. 패키지 안에 본문·로어·역할별 지침·옵션·상태 표시·정규식 표현을 함께 보관해요. 자료를 저장하면 연결된 채팅의 다음 실행부터 최신 내용을 사용해요. 이미 예약한 실행과 과거 원문은 당시 내용을 유지하며 서재 분류 변경은 장착 역할을 바꾸지 않아요.
- **프롬프트**: 서재와 별도의 탐색 항목에서 작문·번역 프롬프트와 창작 프리셋을 관리해요. 서재와 같은 도구 한 줄 **폴더 드롭다운 · 검색 · 목록 관리(역할 필터·정렬·선택)**로 정리하고 프롬프트 편집기로 들어가 내용을 저장해요.
- **채팅 설정**: **기본** 묶음의 **봇·페르소나·모듈**, **프롬프트·창작 프리셋**, **모델**과 **고급** 묶음의 **상태와 기억**, **이미지**, **자동 후속 작업** 여섯 분야예요(읽기 설정은 채팅 메뉴의 별도 대화상자). 소속 봇을 교체하지 않고 페르소나·추가 모듈을 조정해요. 창작 프리셋은 같은 프롬프트 ID에서 재사용하는 옵션 조합이며 여러 채팅에서 재사용해요. 입력창 더보기의 빠른 선택기에는 현재 프롬프트에 맞는 조합만 나와요.
- **작업 현황**: 원문과 보조 작업의 진행·실패·재시도를 확인해요. 채팅 헤더의 **채팅 메뉴(⋯)**에서 열고, 진행 중인 작업이 있을 때만 탐색 아래에 **진행 중 N** 줄이 나타나 같은 화면을 열어요. 요청별 실행 상세와 전체 역할의 사용량 Inspector에서 실제 입력·도구 결과·호출 수·미확인 비용을 볼 수 있어요.
- **읽기 설정**: 채팅 메뉴(⋯)에서 열고 새 원고의 기본 보기 언어, 본문 글꼴·크기, 집중 읽기 시작만 다뤄요. 화면 테마는 **설정 → 일반**에서만 바꿔요. 각 장면의 헤더 줄 오른쪽에서 **번역**과 **원문**을 전환하고, 번역이 없는 장면은 **번역 보기**를 눌렀을 때 번역을 시작해요. 헤더 줄의 장면 번호와 상태 표시를 누르면 그 응답의 작업 상세가 아래에 펼쳐져요. 장면 사이 이동은 데스크톱의 왼쪽 눈금 레일에서 하고, 모바일에서는 채팅 제목을 눌러 장면 목록을 열며 마지막 장면을 벗어나 읽는 동안 입력창 위의 ↓ 버튼으로 최신 장면에 돌아가요. 저장된 번역과 원문 사이의 보기 전환은 모델을 호출하지 않아요. 집중 읽기는 탐색과 입력창을 숨기는 표시 옵션이에요.
- **설정**: 앱 테마와 Enter 보내기, 재사용할 연결·모델 프리셋, 내보내기·복원과 접속 해제를 관리해요. 데스크톱에서는 화면 중앙의 넓은 팝업, 작은 화면에서는 전체 화면으로 열려요. 설정은 **일반 / 연결과 모델 / 에이전트 / 데이터 관리 / 접근 보안** 메뉴로 나뉘며 선택한 항목만 표시해요. 데스크톱은 왼쪽, 작은 화면은 상단에서 항목을 선택해요. 항목을 전환해도 입력 중인 연결·모델 초안은 유지돼요. 작은 화면의 탐색 메뉴에서 서재·프롬프트·봇별 채팅·작업 현황·설정을 열 수 있어요.

기본 Enter는 줄바꿈이고 Ctrl/Cmd+Enter로 보내요. 설정에서 Enter 보내기를 선택하면 Shift+Enter로 줄을 바꿔요. 실제 휴대폰 키보드·IME 동작의 검증은 별도예요.

페르소나 선택기는 서재의 페르소나 분류에서 검색·폴더로 고를 수 있어요. **채팅 설정 → 봇·페르소나·모듈 → 본문에서 페르소나 참조**는 선택한 페르소나를 유지하면서 본문 생성의 참조 여부를 바꾸는 설정이에요.

원고의 **여기서 새 이야기로 이어가기**를 누르면 그 장면까지 별도의 채팅으로 복사해요. 헤더의 **채팅 메뉴(⋯)**에 있는 **여기까지 새 채팅으로 복사**는 현재 전개의 마지막 장면까지 복사해요. 같은 메뉴에서 읽기 설정·작업 현황·보관된 전개(전개가 둘 이상일 때)를 열고, 모바일에서는 집중 읽기도 여기서 켜요. 원래 폴더에 사본이 생기고, 원본과 사본의 이후 설정·프롬프트·초안·생성은 독립적으로 유지돼요. 복사 자체에는 모델 호출이 없어요. 완료된 원문과 완료된 번역·표시 결과를 보존하고, 아직 진행 중이거나 실패한 작업을 복사하거나 재실행하지 않아요. 같은 복사 요청의 응답이 끊겨 다시 눌러도 사본을 중복 생성하지 않아요.

다른 분기는 **보관된 전개** 목록에서 읽을 수 있어요. 보기 전환은 모델을 호출하지 않아요. 번역은 최신 내용 하나만 표시해요. 정상 종료된 거절·빈 응답·구조 손상은 완료 구간을 보존하고 해당 구간만 최대 3회 시도해요. 시간 초과·연결 단절·HTTP 오류처럼 실행이 불확실한 실패는 사용자가 재시도를 눌러요. 명시 재시도는 현재 모델·프롬프트·구간 기준으로 장면 전체를 다시 번역하며 이전 완료 구간을 교체해요. 다른 이야기를 열거나 화면을 닫아도 서버 작업을 취소하지 않아요.

`dev`는 빌드 후 실행해요. 이미 빌드했다면 `npm start`로 시작해요. **이전 버전 서버를 사용 중이면 그 터미널에서 Ctrl+C 후 `npm run dev`로 다시 시작해요.** 기본 DB는 `.local/narrative.sqlite`이고 검증 DB와 달라요. 현재 schema는 v13이며 정식 배포 전 구형 자료·채팅을 이관하거나 자동 백업하지 않아요. 호환되지 않는 기본 개발 DB는 서버를 중지하고 `npm run reset:dev`로 초기화해요. 이 명령은 테스트 자료를 삭제하므로 유지할 자료가 있는 서버의 초기화 수단으로 사용하지 않아요. 같은 DB의 두 번째 서버는 복구 전에 거절하며, 사용 중인 포트를 비우기 위해 다른 프로세스를 종료하지 않아요.

별도 합성 DB와 빈 포트가 필요하면 아래처럼 실행해요. 실제 선택된 URL은 `ready` JSON에 나와요.

```powershell
$env:NR_DB = Join-Path $PWD '.local/demo/story.sqlite'
$env:NR_PORT = '0'
npm start
# 종료 후 이 shell의 override 해제
Remove-Item Env:NR_DB, Env:NR_PORT -ErrorAction SilentlyContinue
```

기본 실행은 `127.0.0.1`에 바인딩해요. 서버 환경변수 `NR_ACCESS_TOKEN`으로 로컬 세션 인증을 선택할 수 있어요. PC·휴대폰 원격 접속은 [개인 서버 배포](SELF-HOST.md)의 HTTPS·접속 토큰·허용 주소 설정을 사용해요. 접속이 만료되면 다시 로그인하고, 설정의 **접속 해제**로 현재 브라우저 세션을 종료해요. 서버에서 진행 중인 생성은 브라우저의 접속 해제로 취소되지 않아요. 키 원문을 앱 자료나 대화에 넣지 마세요.

공급자 설정은 [연결 안내](PROVIDERS.md)를 확인해요. 연결 설정에는 인증 환경변수 이름이나 서버의 인증 파일 참조를 저장해요. 키 원문과 Codex 로그인 정보는 서버에서 관리해요.

**설정 → 데이터 관리 → 내보내기와 복원**에서 JSON 또는 일관된 SQLite 백업을 다운로드해요. JSON 복원은 **새 빈 DB**에서만 가능하고 연결은 비활성화하며 비밀키 참조를 지워요. 원문 hash·분기·참조·파생 결과를 검사하고 잘못된 복원은 전체 rollback해요. SQLite 백업은 서버를 종료한 뒤 새로운 `NR_DB` 파일로 복사해 열 수 있어요. 채팅의 PNG/JPEG 에셋과 패키지의 PNG/JPEG/WebP 이미지는 파일당 2,000,000 bytes 이하로 SQLite 안에 함께 보관하므로 별도 이미지 디렉터리 복사가 필요 없어요.

## 원문과 번역 직접 수정

장면 아래 도구 줄의 연필 버튼은 지금 보고 있는 원문 또는 번역을 수정하고, 같은 줄의 **⋯ 메뉴**에서 다른 쪽(**원문 수정** 또는 **번역 수정**)과 **현재 설정으로 새 번역**, **여기서 새 이야기로 이어가기**, **이미지 선택**을 열어요. 수정창에서 내용을 고치고 저장해요. 직접 저장에는 모델 호출이 없으며 번역 버전 선택은 제공하지 않아요. 원문을 수정하면 기존 번역은 무효화하고, 다음 **번역 보기**에서 수정한 원문을 번역해요. 수정된 원문은 다음 작문 요청의 이력에 반영하며, 이미 실행한 요청의 입력과 기존 후속 원고는 보존해요. M2 상태·기억은 영향을 받은 파생물을 무효로 표시하며, 의미적 재계산은 별도 복구 요청으로 진행해요.

다른 탭에서 먼저 저장했다면 충돌을 표시하고 작성 중인 초안을 유지해요. 새로고침 뒤에도 같은 탭의 편집 초안을 복원하며, 최신 저장 내용을 불러오는 동작은 별도로 선택해요. 편집 전에 시작한 번역이 늦게 끝나도 사용자가 저장한 내용을 덮어쓰지 않아요.

## 이야기 상태와 장기 기억

상태 모듈은 숫자·문자·enum·불리언 필드와 허용 변화 규칙을 정의해요. 보조 모델은 원문 구간을 근거로 제안하고, 앱의 reducer가 필드·근거·범위·중복을 검사한 뒤 값을 계산해요. **authoritative**는 직전 상태가 준비될 때까지 다음 원문 요청을 대기시키고, **continuity**는 원문을 바로 생성하되 상태 계산만 이전 결과를 기다려요. **annotation**은 화면에만 표시해요. 모듈 활성화 시 현재 장면을 초기값의 시작점으로 삼아요.

상태·기억 설정은 채팅마다 최신 한 벌을 관리해요. 저장은 현재 설정을 교체하며 내부 revision으로 다른 탭의 저장 충돌을 검사해요. 과거 설정 목록을 따로 쌓지 않아도 각 원문 생성과 상태·기억 작업은 당시의 설정·모델·연결 snapshot을 보존해요. 상태 모듈의 기준과 원문 hash는 계속 구분하므로, 설정을 고쳤다고 과거 상태나 입력이 바뀌지 않아요.

원문 수정이나 작가 선언 변경으로 무효해진 결과는 과거 기록으로 보존하면서 새 입력에서 제외해요. 상태는 앞 장면부터 **현재 원문에서 상태 다시 확인**, 기억은 **기존 원문 기억 정리**로 복구해요. 상태를 켰던 장면을 수정했다면 해당 장면 복구는 초기값에서 그 장면의 사건을 다시 계산해요. **현재 장면에서 초기값으로 새 기준 적용**은 값을 확인한 뒤 새 상태 기준을 만들며 이전 규칙을 기다리던 요청은 취소해요. 실패·중단된 실제 보조 호출은 자동 재실행하지 않아요.

포크는 선택한 장면까지의 완료된 상태·기억과 그 작업의 설정 snapshot을 복사해요. 현재 설정의 상태 활성화 지점이 복사할 전개 밖에 있으면 현재 설정은 사본에 적용하지 않으며, 과거 설정을 자동으로 다시 선택하지 않아요. 이 경우 사본에서 상태·기억 설정을 새로 저장해 시작해요. 복사된 과거 작업은 자신의 기준을 유지하고, 새 설정은 그 기준과 구분돼요.

장기 기억은 작가 선언, 관찰 사건, 요약, 인물 믿음, 가설을 구분해요. 처리한 원문이 연속으로 이어진 지점까지 색인 기준을 만들고, 이후 미처리 원문과 최근 원문을 다음 입력에 보완해요. 오래된 원문은 `story.search/read`, 기억은 `memory.search/read`로 현재 전개 안에서 회수해요. 원문을 삭제하거나 사용자가 수동으로 작품을 복제할 필요는 없어요. 필수 문맥이 설정한 한도를 넘으면 누락시키지 않고 복구·한도 조정을 안내해요.

장면 예약은 원문 저장이 성공했을 때 소비돼요. 상태창과 제한된 정규식 미리보기는 원문을 바꾸지 않으며 HTML 문자열을 실행하지 않아요. 에셋 manifest는 설명·인물·의상·장소를 검색하고 실제 존재하는 조합을 확인해요. 상태·기억을 모델로 처리하려면 각 역할의 모델을 선택해요. 로컬 검증 서버의 합성 규칙은 실제 의미 추출 능력을 뜻하지 않아요.

M2 상태·기억·예약은 schema v4에서 도입했어요. 현재 DB schema와 JSON archive는 v13이며, 복원은 v13 archive를 새 빈 DB에 넣는 경우만 지원해요. 구버전 DB·archive는 이관하지 않아요. 과거 상태·source hash·의존성과 입력 snapshot, 봇 소속·폴더, 패키지 행동·판정 기회를 검증해요. 상태·기억 작업의 과거 설정은 자체 snapshot으로 검증하며, 같은 설정·상태 모듈 revision을 공유하는 기록들의 내용도 일치해야 해요. 사용자 DB는 자동 검사에 사용하지 않아요.

## 작문·번역 프롬프트 직접 편집

**채팅 설정 → 프롬프트·창작 프리셋**에서 작문과 번역 프롬프트를 각각 선택해요. **새 프롬프트 생성**을 누르면 선택한 역할의 기본 내용과 메시지 구성으로 초안을 시작해요. 탐색의 **프롬프트 → 새 프롬프트**에서도 같은 방식으로 재사용할 프롬프트를 만들어요.

프롬프트 이름을 정하고 **프롬프트 구성**의 블록을 펼쳐 이름·본문·역할·순서·조건·자료 배치를 수정해요. **본문 파일 불러오기**는 UTF-8 `.txt`/`.md`를 해당 평문 메시지에 넣어요. 조건·값·참조가 있는 본문은 템플릿 문법이나 JSON으로 구조를 유지하며 편집해요. 저장 버튼으로 프롬프트를 저장하고, 채팅 적용과 옵션 조합 저장은 각각 명시적으로 선택해요.

**프롬프트 구성** 전체와 각 블록을 접어도 초안은 유지돼요. 기본으로 접힌 **전송 미리보기**를 열고 **미리보기 갱신**을 누르면 블록 이름과 메시지 역할·순서를 확인할 수 있어요. 미리보기는 모델을 호출하지 않으며, 미적용 문법이 있으면 적용하거나 되돌린 뒤 저장해요.


## 채팅 폴더 탐색

탐색은 위에서 아래로 **새 채팅 · 채팅 검색 · 봇 전환 행 · 채팅 목록**, 아래에 **서재 · 프롬프트 · 설정**이에요. 봇 전환 행(아바타 · 봇 이름 ∨)을 누르면 최근 활동 순의 봇 목록과 검색, **새 폴더**, **서재에서 관리**가 팝오버로 열려요. 폴더에 넣지 않은 채팅은 제목 없이 목록 위에 평평하게 놓이고, 이름 있는 폴더만 접이식 제목으로 보여요. 폴더 이름을 눌러 접거나 펼치고, 폴더 오른쪽 `+`로 그 폴더에 새 채팅을 시작해요. `⋯`에서 폴더 이름·새 채팅 기본 페르소나를 설정해요. 폴더를 해제하면 채팅은 기존 순서대로 폴더 밖 목록의 끝에 이동해요.

채팅을 다른 채팅의 위·아래로 드래그해 순서를 바꾸고, 다른 폴더 이름 위에 놓으면 그 폴더 끝으로 이동해요. 접힌 폴더 위에 잠시 머무르면 펼쳐져요. 새 채팅·포크는 폴더 맨 위에 추가하며 작업 완료는 수동 순서를 바꾸지 않아요. 검색 중에는 다른 폴더로 이동할 수 있지만 같은 폴더의 순서는 바꾸지 않아요. 이동은 같은 봇 안에서만 가능해요.

마우스를 올리거나 키보드로 접근하면 채팅 메뉴와 삭제 아이콘이 나타나요. 터치 화면에서는 메뉴가 항상 보이고 폴더 이동·위/아래 이동·삭제를 제공해요. 삭제는 기존 확인 절차를 거쳐요. 작은 회전 표시는 선택하지 않은 채팅까지 진행 중인 작업을 나타내며, 접힌 폴더에도 표시해요. 상세 종류·개수는 표시의 설명으로 확인해요. 전체 작업 표시는 화면이 보이는 동안 약 2초마다 갱신해요.
