# 전역 역할 모델과 현재 프롬프트

모든 봇·채팅은 전역 역할 모델과 현재 작문·번역 프롬프트를 기본값으로 사용해요. 채팅 설정에서 **작문 프롬프트 프리셋과 본문 모델**만 이 채팅에 고정할 수 있어요. 카드 스크립트 보조 모델도 전역 설정에서 선택해요. 번역과 보조 작업은 전역 설정을 유지해요. 채팅을 만들거나 기존 채팅을 열 때 모델·프롬프트를 다시 저장하지 않아요.

## 사용 흐름

1. 설정의 프로바이더와 모델 등록에서 프로바이더와 모델 프리셋을 등록해요. 등록은 역할 선택과 별개예요.
2. 설정 → 역할별 모델에서 본문·번역과 선택 기능인 도우미·컨텍스트 정리·제목·카드 스크립트 보조 모델을 지정해요. 모델이 하나여도 자동 선택하지 않아요. 카드 스크립트 보조 모델의 기본값은 없음이에요. 로어 선별·본문과 번역 거절 판정·이미지 배치는 등록한 TypeSafe AI의 JEV를 사용해요.
3. 같은 화면의 **작업 동작**에서 번역 작업 호출 한도와 본문·번역 거절 감지 정책을 설정해요.
4. 설정 → 현재 프롬프트에서 작문·번역 프리셋을 선택하고 전역 기본 옵션을 조정해요. 본문·토글 선언·협업 구성은 선택한 프리셋의 편집기에서 저장해요.
5. 봇을 선택해 새 채팅을 만들거나 기존 채팅을 열어 대화해요. 채팅 설정의 프롬프트·모델 선택은 기본적으로 **전역 따르기**예요. 프리셋을 고르면 이 채팅에 고정하고, 전역 따르기로 바꿔 저장하면 고정을 해제해요. 헤더의 모델 칩과 채팅 설정은 모델·프롬프트의 고정 여부를 표시해요.

미지정·삭제·비활성 모델이나 사용 불가 프로바이더는 해당 본문·번역 작업을 차단해요. 임의의 다른 모델로 대체하지 않아요. 원본 카드의 Lua 모델 호출에도 연결 권한과 호출 예산을 적용해요. 과거 snapshot에 프로바이더 정보가 있어도 실제 전송 권한은 매 호출 최신 프로바이더의 활성 상태·endpoint·저장된 인증 설정으로 확인해요.

상단 모델 이름을 누르면 **이 채팅의 본문 모델** 선택 창이 열려요. 검색해서 선택하면 현재 채팅의 모델만 다음 요청부터 바뀌며, **기본값 사용**은 모델 고정만 해제해요. 작문 프롬프트 고정과 전역 역할 모델은 그대로예요. 새 모델 등록과 연결 편집은 선택 창의 **모델 관리**에서 열어요. 채팅의 **생성 설정**에서는 모델, 프롬프트와 실행 옵션을 한 저장 버튼으로 저장해요. 각 저장의 수정 번호는 독립적이며 일부만 성공하면 나머지 초안을 유지해요.

## 저장과 실행 경계

`GET /api/model-workspace`는 `{revision, routes, translationPolicy, summaryLength, mainJudgmentEnabled, mainJudgmentThreshold, titleModel, helperModel, contextModel, scriptModel}`을 반환하고, `PUT`은 `expectedRevision`으로 동시 편집을 보호해요. 선택 기능 모델과 `scriptModel`은 `{id}` 참조 또는 `null`이며 PUT에서 생략하면 기존 값을 유지해요. `summaryLength`는 본문·도우미의 [요약 길이](CONTEXT-LIMITS.md#공통-요약-지침과-출력-여유)를 정해요. 프롬프트 선택과 같은 `prompt_workspace` JSON 행에 저장하므로 모델·프롬프트의 동시 저장 충돌도 CAS로 처리해요. 작문·번역 프롬프트는 프리셋 ID와 명시적인 전역 옵션만 저장하고, 본문과 기본 옵션은 원본의 최신 저장본에서 읽어요. 과거 실행은 접수 당시 스냅샷을 유지해요.

DB·archive의 버전과 지원 이관은 [migration](DATA-MIGRATIONS.md)을 봐요. 새 DB의 역할 모델은 미지정으로 시작하고 채팅 body의 모델 값을 전역 기본값으로 채택하지 않아요. API의 채팅 `profile.routes`는 고정 본문 모델을 포함한 현재 적용 설정의 읽기 전용 projection이에요. 채팅별 선택은 `profile.pinned.mainPromptPresetId`와 `profile.pinned.mainModel`에 ID로 저장해요. 프로필 수정에서 `pinned` 생략은 유지, `{}`는 전체 고정 해제이며 `expectedRevision`으로 충돌을 보호해요. 보관된 Run의 `snapshot.profile.routes/models`는 과거 실행의 고정 정보예요. 지원하지 않는 과거 DB/archive를 임의로 변환하지 않아요.

전역 선택과 채팅 고정은 모두 같은 프리셋 ID의 최신 저장본을 따라가요. 전역 기본 프롬프트로 선택한 프리셋은 다른 프리셋을 선택한 뒤 삭제할 수 있어요. 채팅에만 고정한 작문 프리셋이 삭제되거나 본문 모델·프로바이더가 비활성·삭제되면 새 본문 실행을 차단해요. 다른 모델이나 전역 프롬프트로 조용히 바꾸지 않으며, 채팅 설정을 열어 현재 ID를 확인하고 다시 선택하거나 해제할 수 있어요. 프롬프트의 소속·옵션 정의가 바뀌면 기존 채팅 옵션의 충돌 검사로 대기 옵션을 처리해요. 미저장 설정·옵션 초안과 진행 중 Run은 유지해요.

| 작업 | 모델·프롬프트를 읽는 시점 |
| --- | --- |
| 새 본문 실행 | 예약 시 채팅의 고정 프리셋·본문 모델 최신 저장본, 또는 전역 기본값을 Run에 고정 |
| 새 번역·수동 재번역 | 예약 시 현재 번역 모델·프롬프트·JEV 판정 정책을 job에 고정 |
| 새 도우미 작업 | 작업 예약 시 현재 `helperModel`과 컨텍스트 모델을 고정 |
| 자동·수동 컨텍스트 정리 | 상위 Run 또는 독립 context job 예약 시 `contextModel`을 고정 |
| 진행 중 작업 | 예약 때 고정한 값 유지. 설정 변경으로 교체하지 않음 |
| 본문 다시 쓰기·재시도 | 현재 설정과 해당 응답 직전 대화로 새 Run 생성. 중간 장면은 독립 채팅 사본을 사용하고, 마지막 응답은 성공 후 교체도 가능 |
| 번역 job 재시도 | 기존 계약대로 현재 모델·번역 프롬프트·정책으로 새 번역 job 예약 |
| 이미지 job 재시도 | 원래 job의 고정 입력·모델·snapshot 유지 |
| 카드 Lua의 모델 호출 | 원본 `LLM`·`simpleLLM`은 고정 본문 모델, `axLLM`은 고정 `scriptModel` 또는 본문 모델을 사용. Run 전체 `maxCalls`를 공유하고 본문 호출에 필요한 예산을 남김 |
| 독립 채팅 복사 | 선택 지점까지의 원문·메모·변수·채팅 고정 선택을 새 ID로 연결. 전체 실행 입력·호출 영수증은 복사하지 않으며 이후 새 작업은 현재 고정 선택 또는 전역 기본값 사용 |

source/hash·revision/CAS·idempotency·worker 소유권·취소·중복 방지 계약은 유지해요. 번역 응답을 JEV로 거절 판정하고 명확한 거절만 제한된 자동 재요청을 해요. 번역·조회·판정은 같은 전체 호출 한도를 사용해요. HTTP 오류나 불확실한 프로바이더 실행은 자동 재생하지 않아요.

## 화면의 전역 설정 읽기

같은 탭에서 `usePromptWorkspace()`를 사용하는 화면은 하나의 읽기 상태와 변경 알림 구독을 공유해요. 읽는 도중 저장·다른 탭의 변경·포커스 복귀 알림이 오면, 오래된 응답을 반영하지 않고 이어서 다시 읽어요. 마지막 화면 구독이 끝나면 진행 중 읽기를 취소하고 캐시를 비워요. 편집 초안과 예약된 실행 스냅샷은 이 읽기 캐시와 별개이며 변경하지 않아요. 구현은 `web/prompt-workspace-store.ts`, 경합·취소 검증은 `tests/prompt-workspace-store.test.ts`에 있어요.

## 현재 프롬프트와 옵션 조합

설정의 **현재 프롬프트**에서는 역할별 프리셋과 전역 옵션을 선택해요. 본문·토글 선언·프리셋 기본 옵션·협업 구성은 프롬프트 편집기에서 저장해요. 저장한 변경은 전역 선택과 해당 프리셋을 고정한 채팅의 다음 요청부터 자동 반영돼요. 별도로 최신 저장본을 적용하는 단계는 없어요. 원본 편집·가져오기 형식은 [프롬프트 실행](PROMPT-RUNTIME.md)을 봐요.

`CurrentPrompt.defaultValues`는 프리셋의 최신 저장값이며 `optionValues`는 명시적인 전역 사용자 옵션이에요. `values`는 두 값을 합친 현재 실효값이에요. 설정에서 기본값을 선택하면 전역 사용자 옵션을 해제하고 최신 프리셋 저장값을 사용해요. `defaultValues`와 `optionValues`는 Run snapshot에 넣지 않고 실효값만 고정해요. 이전 독립·무명 현재 본문은 부팅 시 별도 프리셋으로 보존하며, 구형 기본값과 다른 옵션은 사용자 지정값으로 유지해요.

옵션 변경·조합 불러오기는 현재 선택을 직렬 저장해 늦은 응답이 뒤의 입력을 덮어쓰지 않게 해요. 저장 실패·동시 변경은 초안을 보존하고, 프롬프트 교체 중에는 이전 옵션 입력을 막아요. 이미 예약한 실행은 바꾸지 않아요.

옵션 조합은 프리셋 ID에 속하며 저장 당시 `controls` 정의와 값을 보관해요. 적용 목록은 **같은 소속·역할·옵션 정의**가 일치하는 항목만 보여 주고 값만 바꿔요. 관리 목록은 같은 소속의 이전 정의도 **적용 불가**로 표시하며, 옵션 수정에서 호환되는 값을 보존하고 현재 정의로 다시 저장할 수 있어요. 서버는 수정할 조합과 원본 프리셋의 수정 번호를 함께 확인해요. 본문만 바뀌고 정의가 같으면 재사용할 수 있지만, 다른 프리셋이나 달라진 정의의 조합을 자동 보정해 적용하지 않아요. 조합 적용 후 직접 변경한 값이 현재 선택이며 저장 조합 자체를 수정하지 않아요.

입력창의 빠른 옵션 조합은 이 채팅의 고정 옵션을 바꿔요. **창작 옵션** 패널은 하나의 옵션 목록에서 값을 편집하고 **다음 생성에만 적용** 스위치로 저장 범위를 정해요. 끈 상태에서는 채팅 고정 옵션을 저장하고, 켠 상태에서는 변경한 옵션만 다음 생성에 한 번 적용하도록 예약해요. 범위를 바꿔도 입력한 변경은 유지하며, 스위치만 바꿔서는 저장하거나 예약하지 않아요. 고정 옵션에서 지정하지 않은 값은 이 채팅에서 사용하는 프롬프트의 기본값을, 1회 옵션에서 지정하지 않은 값은 기존 고정 옵션과 프롬프트 기본값을 따라요. 기존 예약은 별도 목록에서 취소하며 스위치로 취소하지 않아요. 전역 기본 옵션은 설정의 **현재 프롬프트**에서만 바꿔요. 모델·프롬프트 고정과는 별개이며, 소속·옵션 정의가 바뀌면 미저장 선택을 보존하고 최신 정의 검토를 요구해요. 옵션 그룹은 처음에 닫혀 있고 이후 열고 닫은 상태를 현재 기기에 기억해요. 소속·정의를 확인할 수 없는 조합은 자동으로 적용하지 않아요.

프롬프트 설정과 창작 옵션은 열거나 돌아왔을 때 최신 내용을 확인해요. 저장 실패·동시 변경은 초안을 보존하고 저장본 확인을 제공해요. 채팅 옵션은 편집 중 다른 곳에서 옵션이 바뀌면 입력을 유지하고, 저장·1회 예약·예약 취소를 누를 때 확인창을 열어요. **저장본 확인** 후 **입력 유지하고 계속 편집** 또는 **입력 버리고 저장본 불러오기**를 선택할 수 있어요. 없어진 옵션이나 사용할 수 없는 값은 이름·기존 값·이유를 먼저 보여줘요. 현재 입력을 유지하면 직접 바꾼 항목만 반영하고 다른 곳에서 바뀐 별도 항목은 유지해요. 사용하는 프롬프트가 바뀌면 이전 입력을 자동으로 옮기지 않아요. 확인창을 닫기만 하면 입력과 저장 기준은 그대로이고, 어느 쪽을 선택해도 실제 저장·예약은 별도로 눌러야 해요. 조회 실패는 안내 옆에서 다시 불러올 수 있어요.

## 별도 기능 모델

- 채팅 제목 모델은 설정 → 역할별 모델의 선택 항목 `titleModel`이에요. 기본은 미지정이며 자동 제목 생성을 끄고, 본문 모델로 대체하지 않아요. 지정하면 새 채팅의 첫 성공 응답 뒤 제목을 한 번 생성하며 사용자가 직접 바꾼 제목은 덮어쓰지 않아요. 본문·번역·이미지의 `TaskRole`이나 채팅 `profile.routes`에는 추가하지 않아요.
  - 새 채팅에서 제목을 직접 입력한 경우와 기존 채팅·포크는 자동 생성 대상이 아니에요. 생성 시작 시 모델·프로바이더와 첫 응답을 고정하고 최대 1회·25초·출력 256토큰으로 실행해요. 전송 전 attempt를 기록하며 실패·재시작 후 자동 재호출하지 않아요. 수동 제목 저장·원문 변경·채팅 삭제가 발생하면 늦은 결과를 적용하지 않아요.
  - 채팅 메뉴에서 제목을 200자까지 반복 수정할 수 있어요. `PATCH /api/chats/:id/title`의 `expectedTitleRevision`은 제목 이벤트 revision을 사용해 같은 문자열로 저장한 수동 의사와 ABA 충돌도 보호해요. 제목 변경은 원문·설정·폴더 revision을 바꾸지 않아요.
- 도우미 모델은 `helperModel`이에요. 기본은 미지정이며 본문 모델로 대체하지 않아요. 도우미 대화·도구 실행에 사용하고 본문 원고를 저장하는 역할과 구분해요. 별도의 가정 장면 생성은 제공하지 않아요. 다른 전개는 채팅 사본을 만든 뒤 일반 집필로 작성해요.
- 컨텍스트 정리 모델은 `contextModel`이에요. 기본은 미지정이며 실제 압축이 필요할 때만 작업을 차단해요. 단문 본문 실행·요약 직접 편집·정리 대상 없는 no-op은 컨텍스트 모델을 호출하지 않아요. 본문·도우미의 요약도 이 역할을 사용하고 다른 모델로 대체하지 않아요. 유효한 저장 요약은 재사용하고, 필요한 자동 정리는 host가 `contextModel`로 수행해요. 본문 모델용 컨텍스트 메모·창 전환 도구와 해당 프리셋 설정은 제공하지 않아요. 조건부 로어의 관련성 판단은 별도 JEV가 맡으며 컨텍스트 요약 모델과 분리돼요. 상세 계약은 [CONTEXT-LIMITS.md](CONTEXT-LIMITS.md)를 봐요.
- 카드 스크립트 보조 모델은 `scriptModel`이에요. 원본 Lua의 `axLLM`에서 사용하며, 미지정이면 해당 Run의 본문 모델을 사용해요. `LLM`과 `simpleLLM`은 본문 모델을 사용해요. 카드의 원본 low-level access 설정을 따르고, 키·endpoint·실제 모델 선택은 Uimori가 관리해요. 원본 스크립트와 모델 입력을 임의로 JEV로 바꾸지 않아요. 각 호출은 `script` 역할의 attempt와 사용량으로 기록하며 최신 연결 권한·Run 소유권·전체 호출 예산을 확인해요.
- **장면 해설 자동 생성**은 종료했어요. 역할별 모델 선택과 채팅의 자동 생성 설정, 읽기 화면의 해설 표시, 새 요청·재시도는 제공하지 않아요. 기존 DB의 설정·작업 기록은 보존하며 데이터 계약은 [채팅 실행 설정](DATA-MIGRATIONS.md#채팅-실행-설정)을 봐요. 카드 변수·상태창은 원본 Lua가 관리하고, Uimori 기억은 해당 채팅에서 일어난 사건의 요약과 메모만 관리해요. 별도의 상태 추출 모델이나 상태 준비 단계는 없어요.
- 작문 보조의 전용 모델은 해당 채팅에 적용하는 작문 프롬프트의 `collaboration.agents[].model`에 있어요. 전용 모델이 없으면 해당 Run의 본문 모델을 사용해요. 보조 지침·모델·공유 권한은 Run에 고정하고 메인만 원문을 저장해요.
- 전역 설정을 호출 도중 다시 읽지 않아요. 모델 프리셋의 평가 도구도 독립 설정이며 역할 선택으로 권한이나 호출 한도를 확장하지 않아요. 카드 스크립트 호출은 Run의 전체 `maxCalls`와 전송 전 attempt·사용량 경로를 공유하며, 복원 때 모델이나 코드를 재실행하지 않아요. 기록·미리보기는 저장된 모델을 읽을 수 있지만 실제 전송 시점에는 최신 프로바이더 권한을 반드시 확인해요.

## 완료 후와 다시 쓰기

실행 중 입력의 고정은 과거 전체 모델 요청을 영원히 보관한다는 뜻이 아니에요. 완료된 원문과 사용량은 유지하고 큰 입력은 정리해요. 다시 쓰기·새 번역·독립 사본의 다음 생성은 현재 자료와 모델 설정을 사용해요.
