# 전역 역할 모델과 현재 프롬프트

모든 봇·채팅의 **이후 시작하는 작업**은 같은 전역 역할 모델과 현재 작문·번역 프롬프트를 사용해요. 채팅을 만들거나 기존 채팅을 열 때 모델·프롬프트를 다시 저장하지 않아요. 채팅별 override나 전역/개별 전환은 없어요.

## 사용 흐름

1. 설정의 연결과 모델에서 연결·모델 프리셋을 등록해요. 등록은 역할 선택과 별개예요.
2. 설정 → 현재 모델에서 본문·번역·번역 거절 판정·표시 상태·이미지 배치 모델을 지정해요. 모델이 하나여도 자동 선택하지 않아요.
3. 같은 화면의 번역 영역에서 자동 재요청 횟수와 전체 호출 한도를 설정해요.
4. 설정 → 현재 프롬프트에서 현재 작문·번역 프롬프트와 옵션을 편집하거나 프롬프트 목록의 저장된 프리셋을 복사해 적용해요.
5. 봇을 선택해 새 채팅을 만들거나 기존 채팅을 열어 대화해요. 채팅에서는 적용 설정을 확인하고 전역 설정으로 이동해요.

미지정·삭제·비활성 모델이나 사용 불가 연결은 해당 작업을 차단해요. 임의의 다른 모델로 대체하지 않아요. 과거 snapshot에 연결 정보가 있어도 실제 전송 권한은 매 호출 최신 연결의 활성 상태·endpoint·credential 참조와 서버 origin 정책으로 확인해요.

## 저장과 실행 경계

`GET /api/model-workspace`는 `{revision, routes, translationPolicy}`를 반환하고, `PUT`은 `expectedRevision`으로 동시 편집을 보호해요. 현재 프롬프트와 같은 `prompt_workspace` JSON 행에 저장하므로 모델·프롬프트의 동시 저장 충돌도 CAS로 처리해요. 프리셋을 적용하면 현재 작업본으로 복사하며, 프리셋 후속 수정·삭제가 현재 작업본이나 과거 실행을 바꾸지 않아요.

기존 v14 DB에 역할 설정이 없으면 모두 미지정으로 읽어요. 기존 채팅 body의 모델 값은 전역 기본값으로 채택하지 않아요. 운영 DB 초기화·일괄 이관·삭제는 하지 않아요. API의 채팅 `profile.routes`는 현재 전역 설정을 보여 주는 읽기 전용 projection이며 채팅별 선택 저장 경로가 아니에요. 보관된 Run의 `snapshot.profile.routes/models`는 과거 실행의 고정 정보예요.

| 작업 | 모델·프롬프트를 읽는 시점 |
| --- | --- |
| 새 본문 실행 | 예약 시 현재 전역 설정을 Run에 고정 |
| 새 번역·수동 재번역 | 예약 시 현재 번역 모델·프롬프트·거절 판정 모델·정책을 job에 고정 |
| 진행 중 작업 | 예약 때 고정한 값 유지. 설정 변경으로 교체하지 않음 |
| 본문 ‘현재 설정으로 재시도’ | 원래 요청 직전 위치의 새 분기에서 현재 설정으로 새 Run 생성 |
| 번역 job 재시도 | 기존 계약대로 현재 모델·번역 프롬프트·정책으로 새 번역 job 예약 |
| 표시 상태·이미지 job 재시도 | 원래 job의 고정 입력·모델·snapshot 유지. 표시 상태의 명시적 새 요청은 현재 모델 사용 |
| 같은 입력 후보 실험 | 원래 고정 snapshot 계약 유지 |
| 채팅 포크 | 복사된 과거 원문·Run·결과 snapshot 보존. 이후 새 작업은 전역 설정 사용 |

source/hash·revision/CAS·idempotency·worker 소유권·취소·중복 방지 계약은 유지해요. 번역 응답 앞 1,000자만 별도 모델로 거절 판정하고 명확한 거절만 제한된 자동 재요청을 해요. 번역·조회·판정은 같은 전체 호출 한도를 사용해요. HTTP 오류나 불확실한 공급자 실행은 자동 재생하지 않아요.

## 별도 기능 모델

- 표시 상태 역할과 작품 상태 추적은 서로 다른 기능이에요. `StoryConfig.stateModel`과 `memory.model`은 작품의 상태·기억 기능 설정이며 기능 활성화·상태 모듈·출처 및 checkpoint와 함께 관리해요. 일반 본문·번역을 쓰기 위해 다시 설정할 필요는 없어요.
- 작문 보조의 전용 모델은 전역 현재 작문 프롬프트의 `collaboration.agents[].model`에 있어요. 전용 모델이 없으면 해당 Run의 본문 모델을 사용해요. 보조 지침·모델·공유 권한은 Run에 고정하고 메인만 원문을 저장해요.
- 문맥 요약은 명시된 요약 모델, 해당 Run에 고정한 기억 모델, 고정한 본문 모델 순으로 사용해요. 전역 설정을 호출 도중 다시 읽지 않아요. 모델 프리셋의 평가 도구도 독립 설정이며, 이번 전역화로 권한이나 호출 한도를 확장하지 않아요.

실제 검증 결과는 [CURRENT](../project-plan/CURRENT.md)에 기록해요. 로컬 합성 검사는 실제 공급자의 인증·품질·거절 판정 정확도나 물리적 휴대폰 검증을 대신하지 않아요.
