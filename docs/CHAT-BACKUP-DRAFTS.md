# 채팅 백업의 편집 초안

채팅 도우미가 참조한 초안은 본문, 적용 전 입력, 저장 기준과 과거 작업 영수증까지 보관해요. 가져온 초안은 `backup:<새 채팅 ID>:<원 editorKey 해시>` 이름으로 분리해 기존 편집기와 충돌하지 않아요.

전역 프롬프트 초안은 `backupOrigin.chatId`로 새 채팅에 귀속된 독립 보관본이에요. 원본의 `baseRevision`, `baseModel`, `baseHash`, `model`, `rawFields`, `unappliedFields`를 유지하므로 원본 전역 개정이 현재 앱보다 높아도 검증과 재내보내기가 가능해요. 목적지의 전역 프롬프트는 가져오기만으로 바뀌지 않아요. 공유 자료 초안은 기존 불변 자료 개정 검증을 그대로 유지해요.

독립 보관된 전역 프롬프트 초안의 저장·되돌리기·자동 새로고침은 `DRAFT_BACKUP_REBASE_REQUIRED`로 막아요. 현재 저장본을 확인하고 명시적으로 `rebase`를 실행해야 해요. `keep-draft`는 사용자 초안과 적용 전 입력을 보존하고 저장 기준만 현재 전역본에 연결해요. `saved`는 사용자가 선택한 현재 저장본으로 초안을 교체해요. 재연결 자체는 전역 프롬프트를 저장하지 않으며, 이후 저장에서도 현재 개정을 확인해요. 과거 영수증의 독립 보관 표시는 그대로 남아요.

도우미·초안·로어 영수증의 원 요청 digest는 원 요청 전체가 보관되지 않은 경우 역사 증거로 유지해요. 재배치한 영수증을 새 요청인 것처럼 해시하지 않아요. 원 command를 보유한 옵션 영수증의 해시는 새 소유 ID에 맞춰 다시 계산해요.
