# 작업실 사용량

**설정 → 사용량**에서 한국 시간 오늘·최근 7일·최근 30일·이번 달 또는 지정 기간의 호출을 확인해요. 실제 외부 호출 한 건(`attempts`)을 한 번만 합산하고 본문/도우미의 이미 합산된 usage를 다시 더하지 않아요. 후보·재시도·실패·취소가 실제 전송됐다면 포함해요. 모의 생성은 제외하며 배치 조회/재개를 새 호출로 만들지 않아요.

## 화면과 조회

기간 버튼은 즉시 조회하고, **직접 선택**에서는 두 날짜가 유효할 때 입력을 마치면 반영해요. 비용·호출·확인된 토큰, 비용 추이, 상위 모델, 상세 표 순서예요. CSV 내보내기 메뉴에서 모델별·일별·용도별 파일을 각각 받아요.

차트의 빈 날짜는 기록 없음이며, 점선 표시는 일부 금액 미확인이에요. 마우스·터치·키보드로 선택해 금액과 누락 호출 수를 확인해요. 60일을 넘는 조회는 최대 60개 구간으로 합치고 구간 길이를 표시해요. 작은 양수 금액은 `<US$0.01`로 표시하며, 원래 정밀도는 금액 도움말과 CSV에 유지해요.

평가 도구를 사용하는 본문 호출도 **본문 작성**에 포함해요. 스키마 12는 저장된 요청의 평가 도구 선언으로 확인할 수 있는 과거 미분류 호출만 보정해요. 요청이 이미 정리되어 협업/평가 여부를 입증할 수 없는 과거 항목은 미분류로 유지하고, 현재 모델 설정으로 과거 용도를 추정하지 않아요. 금액·토큰·호출 수는 바꾸지 않아요.

## 금액과 누락

공급자가 금액을 보고하면 그것을 사용해요. 보고액이 없을 때만 호출 당시의 동결된 요금과 토큰으로 계산한 추정액을 사용해요. 둘을 중복 합산하거나 현재 가격으로 과거를 다시 계산하지 않아요. 일부만 계산한 금액과 누락 호출 수를 따로 표시하고, 토큰/금액 미보고를 0 또는 무료로 바꾸지 않아요. 명시적으로 보고된 0은 0으로 유지해요.

구독 실행이나 로컬 ComfyUI의 비용/전력 요금을 추측하지 않아요. 이 표는 개인 사용 기록이지 공급자 청구서가 아니에요. 모델별·일별·용도별 상세 표·CSV는 같은 호출 집합을 다른 관점으로 보여주므로 서로 더하지 않아요. CSV는 UTF-8 BOM과 인용을 사용하고 모델 ID의 수식형 접두사를 이스케이프해요.

기간 경계는 `Asia/Seoul` 자정이며 종료일 전체를 포함해요. 과거 기록에 실제 호출 시각이 없으면 `시각 미확인`으로 별도 집계하고 선택 기간에 임의 배치하지 않아요. 기존에 지워진 실행, 남아 있지 않은 협업 구분이나 호출 시각은 복구할 수 없어요. 상세 집계 도입 시점을 화면에 표시해요.

## 기록과 삭제

기존 attempts에 시각·용도·테스트 여부와 작은 숫자형 추정 결과를 추가해요. 집계는 원문·프롬프트 JSON을 전량 읽지 않아요. 삭제 정리도 완료된 요청·응답 전문을 JS로 읽거나 파싱하지 않고 숫자 컬럼만 남겨요. 진행 중인 호출이 늦게 정산되는 경우에만 동결된 최소 요금 정보를 유지해요. 협업 agentId와 도우미 purpose는 호스트가 분류하며 모델 출력으로 요금 분류를 바꾸지 않아요. 새 입력 번역과 연결 테스트도 실제 전송 경계에서 기록하지만 요청/응답 본문을 이 장부에 저장하지 않아요. 기존 연결 테스트는 남아 있는 전송 영수증만 한 번 옮겨요.

**채팅·도우미 대화·삽화 삭제 후에도 사용량 합계는 남아요.** 콘텐츠 연결·원문·프롬프트·원시 응답·오류 상세·사용자 요금 메모는 제거하고 시각·모델·용도·토큰·금액만 유지해요. 늦게 돌아온 결과도 삭제된 본문을 장부에 다시 저장하지 않아요. 내용이 지워진 과거 모델 ID를 새 모델 설정으로 바꾸거나 이전 제목을 별도로 보관하지 않아요.

개별 채팅 백업/복사는 실행 장부를 옮기지 않아요. 전체 DB 복구에는 포함돼요. 데이터가 없는 기간을 청구액 0으로 단정하지 말고 기록 범위를 함께 확인하세요.

## API와 검증

`GET /api/usage?from=YYYY-MM-DD&to=YYYY-MM-DD`, `GET /api/usage/export?...&group=day|model|kind`는 읽기 전용이고 기존 작업실 인증을 요구해요. 조회 자체가 모델 호출·요금 재조회·예약 작업을 시작하지 않아요.

`tests/usage-report.test.ts`, `tests/usage-display.test.ts`, `tests/pricing-store.test.ts`는 보고/추정/부분/미확인 구분, KST 경계, 동일 호출 중복 방지, 삭제 후 개인정보 제거, 과거 버전 이행, CSV를 검사해요. 입력 번역 테스트는 사용량 숫자 외의 모든 DB 내용 불변과 초안 미보관을 함께 확인해요. `npm run verify:personal-features`는 실제 루프백 합성 공급자로 두 번 전송한 영수증을 HTTP/API/데스크톱·모바일 화면/CSV까지 확인해요. 외부 유료 모델은 호출하지 않아요.

`npm run verify:browser -- --grep SPUI`는 다크/라이트·데스크톱/모바일 배치, 차트의 미확인 금액, 잘못된 기간, 오류 후 재조회와 설정의 저장 전 상태를 합성 데이터로 검사해요.
