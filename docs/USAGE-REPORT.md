# 작업실 사용량

작업실에서 발생한 AI 모델 호출 이력과 토큰 사용량, 추정 비용을 확인하고 내보내는 방법을 안내해요.

## 사용량 화면과 기간 조회

- **화면 위치**: **설정 → 사용량**에서 확인해요.
- **조회 기간 선택**:
  - 빠른 선택: 한국 시간(`Asia/Seoul`) 기준 **오늘**, **최근 7일**, **최근 30일**, **이번 달**을 즉시 조회해요.
  - **직접 선택**: 시작일과 종료일을 모두 올바르게 입력하면 조회가 반영돼요. 기간 경계는 한국 시간 자정 기준이며 종료일 전체를 포함해요.
- **화면 구성 순서**:
  1. 비용, 호출 수, 확인된 토큰 수 요약
  2. 비용 추이 차트
  3. 상위 모델 목록
  4. 상세 사용 내역 표
- **차트 표시 규칙**:
  - 데이터가 없는 날짜는 '기록 없음'으로 표시해요.
  - 점선으로 표시된 구간은 일부 금액이 미확인 상태임을 뜻해요.
  - 최근 호출이 있는 구간의 상세를 먼저 표시하며, 마우스·터치·키보드로 다른 구간을 선택해 금액과 누락 호출 수를 확인할 수 있어요.
  - 선택한 구간은 같은 기간을 새로 조회해도 유지되며 금액은 최신 결과로 갱신돼요.
  - 60일을 넘는 긴 기간을 조회하면 최대 60개 구간으로 자동 병합하고 구간 길이를 함께 표시해요.
  - 작은 양수 금액은 `<US$0.01`로 표기하며, 본래 정밀도는 금액 도움말(툴팁)과 CSV 파일에 유지해요.
- **CSV 내보내기**: 내보내기 메뉴에서 **모델별**, **일별**, **용도별** 파일을 각각 내려받을 수 있어요. CSV는 UTF-8 BOM과 인용을 사용하며, 모델 ID의 수식형 접두사를 이스케이프해요. 모델별·일별·용도별 표와 CSV는 동일한 호출 집합을 서로 다른 관점에서 보여주므로 서로 더하지 마세요.

## 호출 집계와 용도 분류 기준

- **실제 외부 호출 기준**: 외부 프로바이더로 실제 전송된 호출 한 건(`attempts`)을 정확히 한 번만 합산해요. 본문이나 도우미 화면에 이미 합산된 usage를 다시 더하지 않아요.
- **집계 포함 범위**: 후보 생성, 재시도, 실패, 취소된 호출이라도 실제 전송되었다면 포함해요. 모의 생성(mock)은 제외하며, 비동기 배치 조회나 재개를 새 호출로 만들지 않아요.
- **본문 작성과 평가**: 평가 도구를 사용하는 본문 호출도 **본문 작성**에 포함해요. 요청이 이미 정리되어 협업/평가 여부를 입증할 수 없는 과거 항목은 미분류로 유지하며, 현재 모델 설정으로 과거 용도를 추정하지 않아요. 금액, 토큰 수, 호출 수는 바꾸지 않아요.
- **원작 참고 호출**: 본문 집필 전에 수행한 **원작 참고** 호출은 사용량에서도 같은 이름으로 집계해요. 이미 저장된 참고문을 재사용했다면 새 호출로 세지 않아요. 전용 수동 분석과 원작 질문 기능은 종료되었으며, 기존 도우미 창에서 나눈 질문은 도우미 사용량으로 기록해요. 과거 호출의 분류는 바꾸지 않아요.

## 비용 계산과 단가 관리

- **보고액 우선 원칙**: 프로바이더가 응답에서 실제 금액을 보고하면 그것을 사용해요.
- **단가 기반 추정액**: 프로바이더 보고액이 없을 때만 호출 당시의 동결된 요금과 토큰으로 계산한 추정액을 사용해요. 둘을 중복 합산하거나 현재 가격으로 과거를 다시 계산하지 않아요.
- **미확인 및 누락 표시**: 일부만 계산한 금액과 누락 호출 수를 따로 표시하며, 토큰이나 금액 미보고를 0 또는 무료로 바꾸지 않아요. 프로바이더가 명시적으로 보고한 0은 0으로 유지해요.
- **추정 범위 한계**: 구독형 정액제 실행이나 로컬 ComfyUI의 비용 및 전력 요금을 추측하지 않아요. 이 표는 개인 사용 기록이지 프로바이더 공식 청구서가 아니에요. 데이터가 없는 기간을 청구액 0으로 단정하지 말고 기록 범위를 함께 확인하세요.
- **단가의 출처**: 제조사별 공식 단가표를 앱에 내장하지 않아요. 프로바이더가 실제 금액을 주지 않은 호출은 사용자가 직접 입력한 단가, 또는 해당 연결에서 지원하는 모델 카탈로그 단가로 추정해요. 현재 자동 카탈로그 단가는 실제 `ai-gateway.vercel.sh` 연결의 Vercel 모델 목록을 사용하며, 다른 게이트웨이나 직접 API에 임의로 적용하지 않아요. 유효한 단가가 없으면 비용 미확인으로 표시해요. 레거시 형식의 `mode:official`은 지원 연결의 현재 카탈로그 선택을 뜻해요.
- **도우미를 통한 단가 갱신**: 도우미에게 공식 가격 페이지 확인과 저장된 모델의 단가 갱신을 요청할 수 있어요. 과거 비용과 이미 접수한 요청은 당시 고정한 단가를 유지해요. [도우미 검색과 단가 변경](HELPER-TOOLS.md#web-search-and-model-pricing)

## 삭제 및 복원 시 사용량 보존 규칙

- **삭제 후에도 영구 보존**: **채팅·도우미 대화·삽화를 삭제한 후에도 작업실 전체 사용량 합계는 그대로 남아요.**
- **개인정보 제거**: 삭제가 진행되면 콘텐츠 연결, 원문, 프롬프트, 원시 응답, 오류 상세, 사용자 요금 메모는 제거하고 호출 시각, 모델, 용도, 토큰 수, 금액만 유지해요. 늦게 돌아온 결과도 삭제된 본문을 장부에 다시 저장하지 않아요. 내용이 지워진 과거 모델 ID를 새 모델 설정으로 바꾸거나 이전 제목을 별도로 보관하지 않아요.
- **백업 범위**: 개별 채팅 백업이나 복사는 실행 장부를 옮기지 않아요. 반면 전체 SQLite DB 복구에는 사용량 장부가 온전히 포함돼요.

## 구현 참고

- **`attempts` 테이블과 경량 집계**: `attempts` 테이블에는 호출 시각, 용도, 테스트 여부와 작은 숫자형 추정 결과만 저장해요. 사용량 집계는 원문이나 프롬프트 JSON을 전량 읽지 않으며, 삭제 정리 시에도 완료된 요청·응답 전문을 JS로 읽거나 파싱하지 않고 숫자 컬럼만 남겨요.
- **지연 정산 및 분류 주체**: 진행 중인 호출이 늦게 정산되는 경우에만 동결된 최소 요금 정보를 유지해요. 협업 `agentId`와 도우미 `purpose`는 호스트가 분류하며 모델 출력으로 요금 분류를 바꾸지 않아요.
- **입력 번역 및 연결 테스트**: 입력 번역과 연결 테스트도 실제 전송 경계에서 기록하지만 요청 및 응답 본문은 이 장부에 저장하지 않아요.
- **시각 미확인 기록**: 과거 기록에 실제 호출 시각이 없으면 `시각 미확인`으로 별도 집계하고 선택 기간에 임의 배치하지 않아요. 기존에 지워진 실행, 남아 있지 않은 협업 구분이나 호출 시각은 복구할 수 없으며, 상세 집계 도입 시점을 화면에 표시해요.
- **도우미 단가 도구 계약 (`model.pricing.read/update`)**:
  - 도우미는 `model.pricing.read/update` 도구로 저장된 모델의 단가만 수정할 수 있어요.
  - 최신 수정 번호 `expectedRevision`을 확인하며, 인증 정보가 없는 HTTPS `sourceUrl`과 확인 날짜 `checkedAt`이 필수예요.
  - 단가 단위는 USD / 100만 토큰(`USD/100만 토큰`)이에요.
  - `null`은 미확인, `0`은 무료임을 확인한 요금이에요. Flex, Batch, 캐시 유지 시간, 긴 컨텍스트 단가는 해당 출처에 따라 따로 지정하며 임의 할인을 추측하지 않아요.
  - 도우미 웹 검색 지원 여부는 선택한 프로바이더 어댑터와 모델, 계정에 따라 달라져요. 검색 도구의 별도 사용료는 토큰 단가 기반 추정에 포함되지 않을 수 있어요. 검색 지원이나 합성 프로토콜 검사는 실제 검색 성공, 최신 가격, 청구액을 입증하지 않아요.
- **조회 API 엔드포인트**:
  - `GET /api/usage?from=YYYY-MM-DD&to=YYYY-MM-DD`
  - `GET /api/usage/export?...&group=day|model|kind`
  - 읽기 전용이며 기존 작업실 인증을 요구해요. 단순 조회가 모델 호출, 요금 재조회, 예약 작업을 시작하지 않아요.
- **테스트 스위트**:
  - 단위 및 기능 검사: `tests/usage-report.test.ts`, `tests/usage-display.test.ts`, `tests/pricing-store.test.ts` (보고/추정/부분/미확인 구분, KST 경계, 동일 호출 중복 방지, 삭제 후 개인정보 제거, 시각 미확인 기록, CSV 생성 검증. 입력 번역 테스트는 사용량 숫자 외 모든 DB 내용 불변과 초안 미보관 확인).
  - 종단 간 검증: `npm run verify:personal-features` (실제 루프백 합성 프로바이더로 두 번 전송한 영수증을 HTTP/API/데스크톱·모바일 화면/CSV까지 확인, 외부 유료 모델 미호출).
  - 브라우저 검증: `npm run verify:browser -- --grep SPUI` (다크/라이트 테마, 데스크톱/모바일 배치, 차트의 미확인 금액, 잘못된 기간 입력, 오류 후 재조회 및 설정의 저장 전 상태를 합성 데이터로 검사).
