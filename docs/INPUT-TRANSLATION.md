# 전송 전 입력 번역과 요청 복사

입력창 옆의 **번역**을 누르면 현재 초안을 선택한 언어로 번역해 같은 입력창에 넣어요. 번역문을 직접 수정한 뒤 기존 보내기로 전송해요. 번역은 선택적인 편집 도구이며 자동 전송하거나 모든 요청에 끼어들지 않아요.

## 사용 흐름

목표 언어는 영어가 기본이며 영어·일본어·한국어·중국어·프랑스어·독일어·스페인어 중 고를 수 있어요. 마지막 선택은 이 브라우저에 기억해요. 별도의 봇별/채팅별 언어 설정이나 입력 전용 모델 설정은 없어요. **전역 모델 설정의 번역 모델**이 필요해요.

번역을 적용하면 입력창 아래에서 **번역 전 원문 보기**와 **되돌리기**를 사용할 수 있어요. 여러 번 번역하거나 번역문을 수정해도 처음 보존한 원문으로 되돌아가며, 무한 편집 이력은 만들지 않아요. 원문은 현재 탭의 채팅/분기별 임시 복구 데이터여서 새로고침 후에도 확인할 수 있어요. 다른 기기와 동기화되는 기록이 아니에요.

번역 대기 중에도 입력을 수정할 수 있어요. 수정한 뒤 원래 글로 돌아왔더라도 자동 교체하지 않고 **이전 초안의 번역**으로 표시해요. 필요하면 내용을 확인한 후 직접 입력을 바꿀 수 있으며, 이때 밀려나는 현재 초안은 되돌리기 대상으로 보존해요. 이미 보존한 원문이 있다면 그 원문을 유지해요. 취소·언어 변경·다른 채팅/분기로 이동·전송은 진행 중인 번역을 무효화해요. 늦은 응답으로 다른 초안이 바뀌지 않아요.

보내기를 눌렀다는 이유만으로 원문을 지우지 않아요. **서버의 전송 수락이 확인되면 해당 전송의 임시 원문을 정리**해요. 전송 실패나 수락 여부가 불명확한 동안은 원문과 입력을 유지하고, 기존 ‘이전 요청 확인’ 흐름으로 복구해요. 최종적으로 보낸 문장만 요청 기록과 작문 입력에 들어가요. 번역 전 원문을 별도 메시지나 영구 메타데이터로 저장하지 않아요. 번역하지 않은 입력은 기존대로 전송해요.

이번 입력 번역은 새 장면 요청 입력창에 제공해요. 과거 요청 수정창·도우미 입력창까지 번역 도구를 추가하는 범위는 아니에요.

## 번역의 범위와 비용

한 번 누를 때 기존 번역 모델에 한 번 요청해요. 본문 번역의 판정·자동 재시도·도구 탐색은 실행하지 않아요. 생성 프리셋의 모델 옵션과 공급자 연결을 재사용하지만 **한국어 본문 번역 프롬프트는 적용하지 않아요**. 요청의 의미·부정·시점·불확실성과 강도를 유지하고, OOC/마크다운/템플릿 구문을 보존하도록 별도의 짧은 지침을 전달해요. 입력 요청에 답하거나 장면을 대신 작성하는 역할이 아니에요.

[봇 번역 지침](TRANSLATION-GUIDES.md)의 표기 목록 중 입력에서 원문 또는 번역 표기가 발견되는 항목을 문맥 참고로 사용해요. 양방향으로 참고하되 기계적인 역치환은 하지 않아요. 한국어 문체를 지정하는 자유 지침 전체는 전달하지 않아요. 선택한 분기에서 마지막으로 저장된 본문의 끝 3,000자까지를 문맥으로 제공하며, 일부 발췌인지 표시해요. 전체 대화·로어 검색이나 별도 에이전트는 없어요.

현재 입력/전송 한도인 **4,000자**를 그대로 사용해요. 번역 결과가 한도를 넘거나 일부만 생성되었거나 공급자가 거절하면 원래 입력을 유지하고 오류를 알려요. 결과를 조용히 자르지 않아요. 호출은 최대 120초 후 중단하며 취소·연결 종료·서버 종료도 공급자 요청에 전달해요. 공급자가 이미 처리한 비용까지 취소된다는 보장은 없어요.

번역 결과를 무조건 정확하다고 보장하지 않아요. 모델이 문법·고유명사·요청 강도를 제대로 보존했는지는 전송 전에 확인해 주세요. 로컬 합성 검증은 실제 모델의 번역 품질을 측정하지 않아요.

## 저장된 사용자 요청 복사

요청 메시지의 수정 아이콘 옆에 **요청 복사**가 있어요. 번역해서 보냈다면 최종 전송문을, 번역하지 않았다면 원래 전송문을 복사해요. 줄바꿈·공백·OOC·마크다운을 포함한 저장 문자열 전체가 대상이며, 긴 요청이 접혀 있거나 봇의 표시용 변환이 적용되어 있어도 변환 전 저장된 요청을 복사해요.

수정 권한이나 생성 상태와 무관하게 복사할 수 있어요. 복사만으로 전송·분기 생성·모델 호출·저장 변경은 발생하지 않아요. 성공하면 잠깐 체크 아이콘과 ‘요청 복사됨’을 표시하고, 실패하면 클립보드 권한 안내를 표시해요. 좁은 화면의 과거 요청은 기존처럼 메시지를 누르면 액션이 나타나며, 키보드 포커스로도 접근할 수 있어요. 브라우저가 클립보드 쓰기를 허용하는 환경이 필요해요.

## 구현 경계

- `core/input-translation.ts`: 지원 언어, 입력/문맥 한도, 독립 번역 지침과 표기 선택.
- `server/input-translation.ts`: `POST /api/chats/:id/input-translation`의 읽기·단일 공급자 호출. 본문/source/job를 생성하지 않으며 앱 DB에 초안이나 입력 번역 호출 본문을 기록하지 않아요. 공유 공급자 어댑터와 인증 경로를 사용해요.
- `web/useInputTranslation.ts`: 작성 화면/초안 개정 식별, 취소, 임시 원문·오래된 결과의 처리.
- `web/useStory.ts`: 기존 초안과 전송 수락 시점 연결. 요청 기록 형식은 변경하지 않아요.
- `web/InputTranslation.tsx`: 입력창 도구와 원문/이전 초안 결과 표시.
- `web/RequestMessage.tsx`: 저장된 요청의 정확한 클립보드 복사. 표시 문자열과 분리해요.

임시 원문은 `sessionStorage`의 `input-translation:<기존 draft 키>`에 보관하며, 목표 언어는 `localStorage`의 `uimori:input-translation-language`에 저장해요. 브라우저 저장소가 제한되면 원문은 활성 편집기 메모리에만 남을 수 있어요. 공급자 자체의 기록 정책과 앱의 임시 저장은 별개예요.

## 검증

```sh
npm run quality
npm test -- tests/input-translation.test.ts tests/request-edit.test.ts tests/api-errors.test.ts
npm run build
npm run verify:input-translation
```

서버 검증은 모델/프리셋 분리, 표기와 분기 문맥, 성공/실패의 DB 비변경, 잘린 결과 거부와 서버 종료 취소를 확인해요. 브라우저 검증은 입력 번역·원문 복구·수정·새로고침·취소·오래된 응답·전송 실패/불확실성·최종 전송문만 남기기·복사 성공/실패를 확인해요. 기존 요청 수정과 Reader 전송 복구 검사도 함께 실행해요. 테스트는 임시 DB, 합성 응답과 로컬 브라우저를 사용해요.
