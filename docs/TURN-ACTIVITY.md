# 응답별 작업 현황

요청 말풍선 아래 한 줄에 장면 번호, 상태 표시, 배지(직접 수정한 번역)가 놓이고, 그 줄을 누르면 작업 상세가 바로 아래에 펼쳐져요. 본문이 없는 생성 중·실패 요청도 같은 줄을 사용해요. 기본은 접힘이며, 여러 응답을 동시에 펼칠 수 있어요. 상태 변경이 패널을 자동으로 열거나 닫지 않아요.

- 본문 생성이 실행 중이면 상태 문구가 지금 단계를 보여 줘요: 컨텍스트 정리, 로어 선별, 원작 참고, 본문 작성 순이에요. 각 준비 단계가 끝난 순간 다음 단계로 갱신돼요. 원작 참고 결과가 이미 저장된 재시도는 원작을 다시 참고하는 동안에도 본문 작성으로 보일 수 있어요.
- 완료된 응답은 체크 표시만 보여요. "작업 현황: 본문 완료" 문구는 화면에서 숨기고 보조 기술에는 남겨요. 진행 중·실패·불확실 상태는 표시와 짧은 문구를 함께 보여요.
- 본문이 없는 요청은 헤더 줄 아래에 진행 중이면 흐린 자리표시 세 줄, 실패·중단·거부·부분 생성이면 카드 하나(제목, 오류 한 줄, 현재 설정으로 재시도 · 요청 다시 편집 · 모델 설정 · 상세)를 보여요. 그 카드가 화면에 들어오면 입력창 위 상태 줄은 같은 실패를 반복하지 않아요.
- 원문·번역 보기 전환은 헤더 줄의 오른쪽 끝에 놓이지만 접기 요소의 summary 밖에 있어요. 전환을 눌러도 패널이 열리거나 닫히지 않고, 상태 문구에 전환 버튼 글자가 섞이지 않아요. 펼친 작업 상세는 모바일에서도 전환 버튼 아래의 빈 폭까지 장면 헤더 전체 너비를 사용해요.
- 펼침 선택은 채팅·Run ID별 sessionStorage에 보존해요. 새로고침과 생성 중 응답의 본문 전환에도 유지해요. 저장소 접근이 제한되면 현재 화면의 선택만 유지해요.
- 접힌 줄은 본문과 진행·실패·취소된 후속 작업을 구분해요. 현재 원문 hash에 연결된 최신 번역·이미지 슬롯을 사용해요.
- 펼치기 자체는 모델 호출이나 재시도를 하지 않아요. 원문 취소·요청 편집·현재 설정 재시도·보조 작업 관리는 기존 명시적 제어를 사용해요.
- 펼친 박스는 상태 배지·모델·비용·토큰 한 줄, 컨텍스트 막대, 프롬프트·페르소나·대화 요약·캐시·로어 영수증, 후속 작업 한 줄씩, **작업 현황에서 보기**와 **원본 기록** 순으로 구분선만 두고 배치해요. 기록이 없는 항목은 생략하고, 호출 기록이 없는 장면은 한 줄로 알려요. 후속 작업은 진행 중이거나 확인이 필요할 때만 오류와 복구 동작을 그 자리에서 펼쳐요. 호출별 가격 표와 전체 시도 목록은 작업 현황에만 있어요.
- 캐시·로어 영수증은 박스를 처음 열 때, 실행 snapshot과 실제 입력은 **원본 기록**이나 로어 목록을 펼칠 때 읽어요. 현재 수정본의 작업과 생성 당시 원문의 실행 기록을 구분해요. 동일한 컨텍스트 오류를 두 번 표시하지 않아요.
- 사이드바의 작업 현황과 앱 전체 진행 알림은 유지해요. 현재 페이지에 속한 과거 작업의 상태는 별도로 조회하며, 이전 응답을 조회해도 오래된 실패 알림을 다시 만들지 않아요.

Reader 작업 현황에는 본문·번역·이미지 배치·삽화를 표시해요. 본문 준비 중 자동 요약은 해당 본문 실행 상세에서, 수동 컨텍스트 정리는 채팅 설정의 기억과 메모에서 확인해요.

앱 전체 작업 알림에서 삽화 등의 상세를 읽어도 작업을 다시 실행하지 않아요. 이미 새 실행으로 바뀐 작업은 이전 알림의 결과로 표시하거나 자동으로 확인 처리하지 않아요.

삽화는 내부 작업마다 같은 이름을 나열하지 않고 **장면 선택 / 그림 생성 n/m컷 완료 / 번역 위치 연결**로 묶어요. 재생성은 같은 컷으로 세고, 실패 컷과 번역 위치 미지정 개수는 따로 보여줘요. 작업 정보는 현재 원문 hash에 연결된 삽화만 사용해요. **원본 기록**의 **삽화**를 고를 때 단계별 누적 사용량을 조회하고, 위치만 다시 연결하는 버튼은 명시적으로 누를 때만 모델 작업을 예약해요. 진행 아이콘은 공통 회전 스타일을 사용하며 운영체제의 동작 줄이기 설정에서는 회전하지 않아요.
