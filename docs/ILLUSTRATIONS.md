# 장면 삽화 생성

완성된 응답의 서로 다른 순간을 포착해, 대표 삽화는 장면 맨 위에 한 번, 다른 삽화는 해당 사건이 일어난 본문 문단 뒤에 자연스럽게 배치하는 기능이에요.

삽화 생성은 본문 작성이나 번역과 완전히 분리된 작업 큐에서 비동기로 실행돼요. 삽화가 만들어지는 중이거나 일시적으로 실패하더라도 본문 읽기, 이어쓰기, 번역 작업은 방해받지 않고 계속 진행할 수 있어요. 지원하는 생성기는 **Codex 프로바이더의 공식 이미지 생성 도구**와 **원격 PC의 ComfyUI API**예요.

> [!NOTE]
> 기존의 **이미지 배치**(`image` 역할: 이미 카드나 서재에 등록된 이미지를 문단 사이에 골라 넣는 기능)와는 완전히 다른 기능이에요. 삽화는 장면에 맞춰 새로운 이미지를 생성하고, 배치는 기존 이미지를 선택해요. 두 기능은 저장 테이블, 작업 큐, 설정이 완전히 분리되어 있어요.

## 시작하기와 생성 환경 설정

**설정 → 삽화**의 **현재 삽화 설정** 카드에서 실효 프리셋, 생성기, 모델, 필수 설정 상태를 한눈에 확인할 수 있어요. (이 상태는 설정의 충족 여부를 뜻하며 실제 외부 서버 연결이나 로그인 성공을 보증하는 것은 아니에요.)

### 1. Codex 생성 환경 설정

1. **설정 → 에이전트**에서 개인 ChatGPT 유료 구독 계정으로 로그인해요.
2. **설정 → 삽화 → Codex 생성 환경**에서 이미지 생성 도구를 실행할 **Codex 삽화 모델**을 선택해요.
3. **프롬프트 모델**에서 장면을 분석하고 그림 지시문을 작성할 텍스트 모델을 골라요. (같은 Codex 모델을 두 역할에 모두 지정하거나, 다른 고성능 텍스트 모델에 프롬프트 작성을 맡길 수 있어요.)

### 2. ComfyUI 생성 환경 설정

1. 원격 PC의 API 주소(예: `http://192.168.0.10:8188`)를 입력해요.
2. 장면을 분석해 프롬프트로 변환할 **프롬프트 모델**(어떤 텍스트 모델 프리셋이든 가능)을 지정해요.
3. ComfyUI에서 **Export (API)**로 저장한 워크플로 JSON을 프리셋에 등록하고 선택해요.
4. **ComfyUI 연결 확인** 버튼을 누르면 원격 서버의 `GET /system_stats`를 호출해 서버 버전과 장치 상태를 점검해요.

## 자동 생성과 수동 요청

### 자동 생성

새 본문이 저장될 때 자동으로 삽화 계획을 예약해요.

- **자동 컷 수**: **내용에 맞게 선택**(기본 최소 0컷, 최대 10컷)과 **고정 상한**을 지원해요. 모델은 이야기의 길이와 시각적 변화에 맞춰 범위 안에서 필요한 컷을 고르며, 최대 컷 수는 반드시 채워야 할 목표가 아닌 상한선이에요. 그릴 만한 사건이 없으면 생략해요.
- 새 작업실에서는 자동 생성 기능 자체가 기본적으로 꺼져 있어요. 응답별 전체 컷 상한은 최대 10컷까지 설정할 수 있어요.

### 수동 생성과 개별 조작

- **장면 메뉴에서 요청**: 각 장면 머리글의 ⋯ → **삽화 생성**을 누르고 원하는 최대 컷 수를 골라 요청해요. 원하는 구도나 분위기가 있다면 연출 요청을 함께 적을 수 있어요.
- **완료된 삽화 조작**: 각 그림에 마우스를 올리거나 탭하면 **접기** 버튼과 ⋯ 메뉴가 나타나요.
  - **대표 삽화로 지정 / 본문 위치로 보내기**: 해당 컷을 장면 맨 위 대표 삽화로 올리거나 원래 문단 위치로 내려요.
  - **현재 설정으로 다시 그리기**: 같은 순간에 대해 새 그림을 생성해요. 변경 요청을 적으면 기존 프롬프트를 참고해 원하는 부분만 바꾸고, 비워 두면 최신 설정으로 새로 해석해요. 새 그림이 성공할 때까지 기존 그림은 화면에 유지돼요.
  - **생성 상세**: 사용한 모델, 프롬프트 원문, 토큰 사용량을 확인해요.
  - **삽화 삭제**: 해당 컷의 이미지와 생성 기록을 삭제해요.
- **작업 상태 조작**:
  - **다시 요청**: 연결 실패 등으로 중단된 작업을 다시 실행해요.
  - **결과 확인**: 원격 타임아웃 등으로 접수 여부가 불확실했던 ComfyUI 작업의 완료 결과를 조회해 회수해요.
  - **취소**: 진행 중인 생성 작업을 취소해요.

## 인물 외형과 참고 이미지

인물의 외형과 그림체를 지정해 삽화의 일관성을 높일 수 있어요.

- **참고 이미지 지정**: **채팅 설정 → 이미지 → 삽화 참고**에서 채팅에 등록된 이미지나 카드의 에셋을 **캐릭터 디자인** 또는 **그림체** 참조로 지정해요. 실제 참고 이미지 바이트는 참조 기능을 지원하는 Codex 이미지 생성 턴에만 전달돼요.
- **기본 인물 외형**: 봇·페르소나·모듈 편집 화면의 **번역 지침 → 기본 인물 외형 → 고급 설정**에서 인물별 이름, 외형 묘사, 참조 이미지를 등록해요. CCv3 `data.extensions.uimori.illustrationProfiles` 규격으로 보관되어 같은 카드를 쓰는 모든 채팅이 공유해요.
- **채팅별 외형 편집과 복원**: 채팅에서는 공유 기본 외형을 보여주며, **편집**을 누르면 채팅 전용 사본으로 복사되어 자유롭게 수정할 수 있어요. **복원**을 누르면 사본을 삭제하고 최신 기본 외형을 다시 상속받아요.
- **도우미 지원**: 도우미에게 “미라의 카드와 초상화를 보고 삽화용 외형을 제안해 줘”라고 부탁하거나, “미라는 두 번째 안으로 바꾸고 준과 아라는 새 인물로 등록해 줘”처럼 요청해 여러 인물을 한 번에 저장할 수 있어요.
- **구간별 외형 메모**: 의상이나 소지품이 일시적으로 바뀔 때는 “항구에 도착한 장면부터 출항하는 장면까지 미라에게 붉은 코트를 입혀줘”처럼 작성된 장면 구간에 임시 외형 메모를 붙일 수 있어요. 기본 인물 설정은 유지하면서 해당 구간만 반영돼요.

## 본문 읽기와 삽화 표시

- **문단 뒤 슬롯 배치**: 본문의 일반 문단, 제목, 구분선, 인용, 목록, 표, 코드 블록 뒤의 안전한 Markdown 경계에 삽화를 배치해요. 저자가 작성한 스타일이나 입력 상태를 보존하기 위해 메시지 Shadow DOM의 실제 삽화 위치에만 슬롯을 넣어요.
- **본문 밖 삽화**: 다음과 같이 정확한 본문 위치를 특정하기 어려운 그림은 본문 아래 **본문 밖 삽화** 영역에 모아서 보여주며 각 컷에 이유를 표시해요.
  - 저자가 작성한 HTML 태그 내부라 경계를 나눌 수 없는 경우
  - 표시 변환으로 인해 텍스트 자체가 크게 달라진 경우
  - 번역문 위치가 아직 지정되지 않았거나 불확실한 경우 (`null`)
  - 원문 수정 이전에 생성되었던 이전 그림인 경우
- **번역 위치 다시 연결**: 번역문이 바뀌거나 위치가 어긋나면 이미지는 그대로 보존하고 위치만 다시 매핑해요. **번역 위치 다시 연결** 버튼으로 언제든 다시 요청할 수 있어요.
- **접기 제어와 읽기 보호**:
  - 개별 컷의 접기 상태와 **모두 접기 / 모두 펼치기**는 브라우저에 저장돼요.
  - **읽기 설정 → 삽화 기본 표시**에서 새 컷의 기본 펼침 상태를 정할 수 있어요.
  - 사용자가 이미 읽고 지나간 위쪽 문단에서 그림이 뒤늦게 완성되면, 읽던 화면이 갑자기 밀려나지 않도록 일시적으로 접힌 상태로 렌더링해요.
- **삽화 크게 보기**: 이미지를 클릭하면 새 창 대신 모달 뷰어가 열려 원본 비율로 확대해 볼 수 있어요. (닫기 버튼, Escape 키, 배경 클릭으로 닫힘)
- **작업 현황과 사용량**:
  - 장면 작업 현황에서 **장면 선택**, **그림 생성 n/m컷**, **번역 위치 연결** 단계를 구분해서 보여줘요.
  - **삽화 호출과 토큰**을 펼치면 누적 호출 수, 입력/출력 토큰, 다시 그리기와 JEV 판정 내역을 단계별로 확인할 수 있어요.

## 삽화 프리셋

**설정 → 삽화 → 프리셋**에서 프리셋을 만들고 편집·복제·삭제하거나 JSON 파일로 가져오고 내보낼 수 있어요.

### 1. 프리셋의 구성과 우선순위

- **프리셋 저장 내용**: **생성기(`codex` 또는 `comfyui`), 이름, 설명, 그림 지침**, 그리고 ComfyUI 전용 워크플로 JSON과 추가 제외 지침을 저장해요.
- **생성 환경과의 분리**: 모델 선택, ComfyUI 접속 주소, 인증 정보, 자동 생성 정책은 프리셋이 아닌 공용 **생성 환경**에 저장돼요. 프리셋을 바꾸면 사용하는 생성 환경도 함께 전환되지만 공용 환경의 저장값 자체를 덮어쓰지는 않아요.
- **적용 우선순위**: **현재 채팅 → 현재 봇 → 작업실 기본 → 내장 기본** 순서로 적용돼요. 채팅이나 봇에서 **상위 설정 따르기**를 누르면 해당 선택을 해제해요.
- **저장과 적용의 분리**: 프리셋 편집 내용은 저장 즉시 이전 작업에 소급 적용되지 않으며, 해당 프리셋을 쓰는 채팅의 **다음 생성 예약부터** 반영돼요. 이미 진행 중인 작업이나 과거 결과는 당시 고정된 설정을 유지해요.

### 2. 프리셋 파일 형식

파일 확장자는 `.uimori-illustration.json`이며, 형식은 다음과 같아요.

```json
{
  "format": "uimori-illustration-preset",
  "version": 2,
  "preset": {
    "title": "수채화",
    "generator": "codex",
    "description": "부드러운 빛과 종이 질감",
    "styleGuidance": "watercolor, soft light, textured paper",
    "comfyui": { "workflow": "", "negativeGuidance": "" }
  }
}
```

- v2 파일은 생성기 정보를 포함해요. 생성기 필드가 없는 이전 v1 파일은 워크플로 유무에 따라 ComfyUI 또는 Codex로 자동 인식해요.
- 파일 크기는 16MiB, 워크플로 문자열은 400,000자, 그림/제외 지침은 각각 200만 자까지 저장할 수 있어요.
- 워크플로 JSON에 개인 API 키나 로컬 파일 경로가 포함되어 있지 않은지 공유 전에 반드시 확인해 주세요.

### 3. 그림 지침 작성 요령

프리셋의 **그림 지침** 필드 하나에 원하는 화풍, 색감, 조명, 선의 느낌, 질감, 그리고 피해야 할 표현을 자유롭게 적어요. 자연어, 불릿 목록, Markdown, JSON 형식을 모두 지원해요.

#### 생성기별 해석 방식

- **Codex**: 공통 시각적 지침을 이미지 생성 도구에 전달해요. 캐릭터 참조는 외형, 스타일 참조는 화풍을 전달하는 역할을 맡아요. ComfyUI 전용 태그 문법은 제외돼요.
- **ComfyUI**: 프롬프트 모델이 지침을 읽고 각 컷의 `{prompt, negativePrompt, caption}`을 작성해요. 워크플로의 `{{prompt}}`, `{{negative}}`, `{{seed}}` 자리에 해당 내용이 자동 치환돼요.

특정 체크포인트 모델의 문법이 필요하다면 그림 지침에 명시할 수 있어요. 예를 들어 [Anima 공식 모델 카드](https://huggingface.co/circlestone-labs/Anima#prompting)나 [OpenAI 이미지 프롬프팅 안내](https://developers.openai.com/api/docs/guides/image-prompting)를 참고해 다음과 같이 작성할 수 있어요.

```text
ComfyUI에서 Anima용 프롬프트를 작성할 때:
외형과 사물은 간결한 태그로, 가림 관계와 표현 조건은 자연어로 설명한다.
일반 태그에는 언더스코어 대신 공백을 사용한다.
```

## 설정 항목과 한도

| 항목 | 설정 범위 | 설명 |
| --- | --- | --- |
| **생성기** | `codex` / `comfyui` | 프리셋에서 선택하며, 연결 주소 및 모델은 해당 생성기의 공용 환경을 사용해요. (`fixture`는 테스트 전용) |
| **자동 생성** | 켜기 / 끄기 | 새 본문 저장 직후 자동으로 계획을 예약해요. 후보 응답, 작성된 도입문, 포크 복사본에는 실행되지 않아요. |
| **자동으로 고를 최대 컷 수** | 1~8컷 (기본 1) | `automaticMaxTargets`. 응답 전체 한도 내에서 모델이 이야기 분량에 맞춰 필요한 만큼만 계획해요. |
| **장면당 최대 삽화 개수** | 1~8컷 | 현재 장면에 등록될 수 있는 서로 다른 컷의 총 상한이에요. 동일 컷의 재생성이나 다중 결과 이미지는 추가 컷으로 세지 않아요. |
| **자동 재요청 횟수** | 0~5회 | 네트워크 일시 단절, 명확한 원격 실행 실패 등 안전한 실패에만 적용해요. 전송 후 타임아웃이나 5xx 오류는 접수 불확실로 남겨 자동 재생성하지 않아요. |
| **그림 지침·제외 지침** | 각 200만 자 | 저장 보호 상한이에요. 실제 모델 전송 가능 여부는 요청의 전체 입력 토큰 예산으로 검사해요. |

## 구현 참고

### 작업 큐와 동시성 제어

- **작업 펌프 구조**: 하나의 삽화 펌프 안에서 텍스트 작업 1개와 렌더 작업 1개를 독립적으로 병행 실행해요. 같은 계획의 대표 컷부터 순서대로 렌더를 진행하며, 본문 작성 슬롯이나 사용자 입력 상태를 잠그지 않아요.
- **중복 방지 잠금**: 한 응답 내에서 장면 전체의 컷을 고르는 계획 작업은 1개만 진행돼요 (`ILLUSTRATION_PLAN_ACTIVE`). 다른 컷의 렌더는 독립 예약할 수 있지만 동일한 컷의 중복 실행은 방지돼요 (`ILLUSTRATION_ACTIVE`).
- **상태 머신**: `queued → running → completed | failed | cancelled | interrupted`. 사용자가 작업을 취소하면 `generation` 카운터를 증가시켜 지연 도착한 결과를 안전하게 폐기해요. 서버가 재시작되면 실행 중이던 작업은 `interrupted`로 변경되며 자동 재실행하지 않아요 (`queued` 작업은 재개).
- **작업 단위**: `illustration_jobs.input.task`는 `plan`, `render`, `placement`로 나뉘며, 이전 버전의 레거시 입력은 단일 `render`로 취급해요.

### 데이터베이스 스키마와 메타데이터

- **테이블 구성**:
  - `illustration_settings`: 전역 실행 환경 및 정책
  - `illustration_references`: 채팅별 참조 이미지 및 인물 외형 설정
  - `illustration_jobs`: 비동기 작업 큐 및 실행 상태
  - `illustration_images`: 생성된 이미지 BLOB 참조 및 메타데이터
- **프리셋 영속화**: 프리셋 엔티티는 공통 `versions` 테이블의 `illustration-preset` 리소스로 저장되고, 사용자 선택 상태는 `app_metadata`의 `illustration-preset-preferences`에 저장돼요. [데이터 형식](DATA-MIGRATIONS.md)
- **표시 소유권**: `app_metadata`의 `illustration-presentation:<sourceId>`가 대표 타깃, 컷별 최신 요청/표시 작업 ID, 번역문 hash와 위치 매핑을 소유해요. 작업 실행 입력과 화면 표시 선택을 엄격히 분리해 늦게 완료된 이전 요청이 새 선택을 덮어쓰지 못하게 방어해요.
- **원문 리비전 귀속**: 작업은 `source_revision`과 예약 당시의 `source_hash`에 귀속돼요. 사용자가 나중에 원문을 수정하더라도 완료된 삽화는 요청 당시 원문에 귀속되어 남으며 **수정 전 원문의 삽화**로 표시돼요. 실행 시점에는 예약 hash의 원문을 다시 조회해요 (`sourceAtHash`).
- **Reader 통신**: `GET /api/chats/:id/reader`는 현재 장면의 `illustrations` 목록을 반환하고, SSE 이벤트 `illustration.*` 및 `illustration-layout.updated`를 통해 해당 장면의 변경만 실시간 갱신해요. 작업 현황(`reader.activity`)에는 `kind: 'illustration'`으로 표시되며 본문 생성 진행 표시(`activeJobs`)를 방해하지 않아요.

### 도구 및 컨텍스트 계약

- **프롬프트 모델 읽기 도구**:
  - `illustration.sources.search`와 `illustration.sources.read`를 제공해요.
  - 예약 시점에 고정된 캐릭터 카드, 페르소나, 모듈의 native CHARX 설명과 로어북, 기존 성공 삽화의 캡션과 프롬프트를 검색하거나 페이지 단위로 읽을 수 있어요.
  - 별도의 쓰기 도구는 제공되지 않으며, 번역 위치 연결 작업에는 이 도구를 제공하지 않아요.
- **일관성 가이드 (`visualCanon`)**: 계획 수립 시 선택적으로 `visualCanon: [{name, appearance}]`를 구성해 같은 응답의 모든 컷이 인물 정체성을 공유하도록 프롬프트에 결정적으로 포함해요.
- **입력 토큰 예산**: 계획 단계에서는 응답 전체를 검토하며 모델의 전체 컨텍스트 예산을 초과하면 즉시 실패해요. 컷별 렌더와 번역 위치 연결에는 고정된 focus·visualBrief 및 관련 원문의 끝부분 최대 2,000 추정 토큰을 발췌해 전달해요.

### 이미지 처리와 저장소

- **이미지 파이프라인**: 모든 생성 결과는 64MiB 입력 한도 내에서 실제 이미지 디코더를 거쳐 고품질 WebP로 변환된 후 공통 `image_blobs` 저장소에 영속화돼요. `/api/illustration-images/:id`로 서빙돼요.
- **참조 이미지 처리**: 참조 이미지는 긴 변을 최대 1536px로 축소하여 Codex에 전달하며 확대나 자르기는 하지 않아요. 원본 bytes와 hash는 저장소에서 불변으로 보존돼요.
- **채팅 복사와 백업**: 독립 채팅 복사 및 개별 백업은 현재 화면에 표시된 성공 결과, 동일 컷의 변형 그룹, 대표 지정, 검증 가능한 원문/번역 위치만 복원해요. 문단 index와 텍스트 hash를 검증해 새 anchor를 부여하고, 불일치 시 보조 영역으로 이동해요. 미완료 작업이나 실패 기록은 복제하지 않아요.

### Codex 경로 기술 계약

- **턴 분리**: 계획 수립(프롬프트 모델)과 이미지 생성(Codex)은 완전히 다른 턴으로 실행돼요. 계획, 번역 위치 연결, ComfyUI 프롬프트 작성 턴에서는 웹 검색, code mode, 이미지 생성을 모두 끄고 `features.image_generation=false`를 명시해요.
- **프로세스 및 세션 재사용**: 동일한 계획의 연속 컷들은 단일 Codex 프로세스와 임시 ephemeral thread를 재사용해 컷마다 `turn/start`를 호출해요. 이미지 턴에서는 웹 검색과 JS 계산을 끄고 `features.image_generation=true`를 사용해요. [Codex 실행 경계](CODEX.md)
- **동시성 슬롯**: 텍스트 턴과 분리된 별도 슬롯(동시 실행 1개, 대기 8개)을 사용하며 `role: 'illustration'`으로 기록해요.
- **결과 수신**: `item/completed`의 `imageGeneration` 항목에서 base64 `result`를 우선 읽고, 비어 있다면 전용 디렉터리의 `savedPath` 파일을 읽은 뒤 삭제해요.
- **실패 코드**:
  - `CODEX_IMAGE_USAGE_LIMIT`: 유료 한도 초과 (자동 재요청 안 함)
  - `CODEX_IMAGE_UNAVAILABLE`: 명시적 생성 거부 (자동 재요청 안 함)
  - `CODEX_IMAGE_NOT_GENERATED`: 일반 생성 실패 (재요청 가능)

### Codex 이미지 요청의 JEV 사전 판정

이미지 생성 직전에 Codex로 보낼 텍스트(프롬프트 모델이 작성한 프롬프트 또는 예약된 장면 자료, 참조 이미지 라벨)를 JEV 모델로 사전 검사해요. (전체 원문이나 이미지 바이트를 검사하거나, 장면 선택 텍스트 턴을 사전에 차단하는 기능은 아니에요.)

- **판정 기준**: 컷을 묘사한 텍스트에 노골적인 성적 묘사가 필요한지 여부를 `noul` 지표로 판정하며, 점수가 0.9 이상이면 해당 컷의 이미지 요청을 보내지 않고 차단해요. (일반적인 로맨스나 키스, 비노골적인 연출은 일괄 차단 대상이 아니에요.)
- **차단 처리**: `ILLUSTRATION_CODEX_CONTENT_BLOCKED` 오류로 기록되며 자동 재시도 및 동일 입력 수동 재시도를 차단해요. 다른 컷의 작업이나 본문·번역 작업, 기존 성공 이미지는 정상적으로 유지돼요.
- **예외 처리**: JEV 키 미설정, 응답 오류, 8초 시간 초과, 입력 토큰 예산 초과는 `unavailable`로 기록하고 프로바이더의 자체 판단에 맡겨 생성을 계속 진행해요. 판정 호출은 `illustration-content` 사용량으로 귀속돼요.

### ComfyUI 경로 기술 계약

- **실행 순서**: 계획 모델 호출 → 컷별 워크플로의 `{{prompt}}`, `{{negative}}`, `{{seed}}` 치환 → `POST /prompt` → `GET /history/{prompt_id}` 폴링 → `GET /view` 이미지 다운로드.
- **워크플로 검증**: API 형식(`노드 ID → {class_type, inputs}`)만 지원하며 UI 형식(`nodes`/`links`)은 `COMFYUI_WORKFLOW_UI_FORMAT` 오류로 거절해요. 노드 구조는 변경하지 않고 `inputs` 문자열 내의 자리표시자만 1회 치환해요.
- **네트워크와 프록시**: `http://`와 `https://`만 허용하며 주소에 인증 정보나 쿼리를 포함할 수 없어요. 프록시 인증이 필요한 경우 **인증 헤더 환경변수**에 지정된 환경변수 값을 읽어 `Authorization` 헤더로 전달해요. 브라우저는 원격 서버에 직접 접근하지 않아요.
- **타임아웃과 결과 회수**: 요청 시간 초과(`COMFYUI_TIMEOUT`)가 발생해도 원격 서버의 렌더를 강제 중단하지 않아요. 작업은 `prompt_id`를 보존한 채 실패 상태로 남으며, 사용자가 **결과 확인**(`POST /api/illustrations/:id/reconcile`)을 누르면 원격 히스토리를 다시 조회해 완료된 이미지를 안전하게 가져와요.
- **취소**: 사용자의 명시적 취소 시에만 `POST /api/jobs/{prompt_id}/cancel`을 호출해요. 해당 API가 없으면 `POST /queue` `{delete: [id]}`로 대기열에서만 제거해요. (전역 `/interrupt`는 호출하지 않아요.)
- **실패 진단 코드**: `COMFYUI_PROMPT_REJECTED` (노드 설정 오류), `COMFYUI_EXECUTION_FAILED` (실행 도중 오류), `COMFYUI_SUBMISSION_UNCERTAIN` (접수 불확실, 자동 재제출 금지), `COMFYUI_RESULT_UNAVAILABLE` (접수 후 조회 실패).

### API 명세

| 경로 | 메서드 | 설명 |
| --- | --- | --- |
| `/api/illustration-settings` | `GET` / `PUT` | 전역 실행 환경 및 정책. `PUT`은 `expectedRevision` CAS를 사용해요. |
| `/api/illustration-presets` | `GET` | 내장 및 저장된 프리셋 목록과 범위별 선택 상태를 반환해요. |
| `/api/resources/save` | `POST` | 프리셋 저장 (`kind: 'illustration-preset'`). `expectedRevision` 지원. |
| `/api/resources/illustration-preset/:id` | `GET` | 프리셋 단일 항목을 조회해요. |
| `/api/resources/illustration-preset/:id/undo` | `POST` | 직전 저장본으로 되돌려요. |
| `/api/illustration-presets/selection` | `POST` | 범위별 프리셋 선택 (`scope: 'global'/'bot'/'chat'`, `targetId`, `presetId`, `expectedRevision`). |
| `/api/illustration-presets/:id/export` | `GET` | 프리셋을 JSON 파일로 내보내요. |
| `/api/illustration-presets/:id` | `DELETE` | 프리셋을 삭제해요 (`expectedRevision` 필요). |
| `/api/illustration-settings/comfyui/test` | `POST` | ComfyUI 연결을 점검해요 (`GET /system_stats`). |
| `/api/chats/:id/illustration-references` | `GET` / `PUT` | 채팅별 참조 역할 및 인물 외형 설정. |
| `/api/sources/:id/illustrations` | `POST` | 수동 삽화 계획을 예약해요 (`maxTargets`, `direction` 등 전달). `task: plan` 반환. |
| `/api/sources/:id/illustration-presentation` | `PATCH` | 대표 삽화 타깃 선택을 변경해요. |
| `/api/sources/:id/illustration-usage` | `GET` | 현재 원문의 단계별 삽화 누적 호출 수와 토큰 사용량을 조회해요. |
| `/api/sources/:id/illustration-placement` | `POST` | 기존 컷의 번역 문단 위치 재연결을 요청해요. |
| `/api/illustrations/:id/regenerate` | `POST` | 동일 타깃을 최신 설정으로 다시 그리는 새 작업을 예약해요 (`changeRequest` 지원). |
| `/api/chats/:id/illustrations`, `/api/illustrations/:id` | `GET` | 삽화 목록 및 단일 작업의 고정 입력을 포함한 상세를 조회해요. |
| `/api/illustrations/:id/retry` | `POST` | 실패한 작업의 고정 입력을 그대로 재시도해요. |
| `/api/illustrations/:id/cancel` | `POST` | 진행 중인 삽화 작업을 취소해요. |
| `/api/illustrations/:id` | `DELETE` | 해당 삽화 컷 및 생성 기록을 삭제해요. |
| `/api/illustrations/:id/reconcile` | `POST` | 기록된 ComfyUI `prompt_id`의 원격 결과를 회수해 저장해요. |
| `/api/illustration-images/:id` | `GET` | 영속화된 이미지 바이너리(WebP)를 스트리밍해요. |

테스트 모드(`UIMORI_TEST_MODE=1`)에서는 `/api/test/control`의 barrier·failure point `illustration`과 가상 생성기 `fixture`가 활성화돼요.
