# 장면 삽화 생성

완성된 응답의 서로 다른 순간을 포착해, 대표 삽화는 장면 맨 위에 한 번, 다른 삽화는 해당 사건이 일어난 본문 문단 뒤에 자연스럽게 배치하는 기능이에요.

삽화 생성은 본문 작성이나 번역과 완전히 분리된 작업 큐에서 비동기로 실행돼요. 삽화가 만들어지는 중이거나 일시적으로 실패하더라도 본문 읽기, 이어쓰기, 번역 작업은 방해받지 않고 계속 진행할 수 있어요. 지원하는 생성기는 **Codex 프로바이더의 공식 이미지 생성 도구**, **원격 PC의 ComfyUI API**, **NovelAI 이미지 생성 API**예요.

> [!NOTE]
> 기존의 **이미지 배치**(`image` 역할: 이미 카드나 서재에 등록된 이미지를 문단 사이에 골라 넣는 기능)와는 완전히 다른 기능이에요. 삽화는 장면에 맞춰 새로운 이미지를 생성하고, 배치는 기존 이미지를 선택해요. 두 기능은 저장 테이블, 작업 큐, 설정이 완전히 분리되어 있어요.

## 시작하기와 생성 환경 설정

**설정 → 삽화**는 **프리셋**과 **생성 환경**을 바로 보여줘요. 선택한 범위와 실제 적용 프리셋이 다르면 적용 범위 아래에 현재 적용 프리셋을 표시하고, 모델이나 ComfyUI 주소처럼 빠진 필수 설정은 프리셋 목록 위에 안내해요.

### 1. Codex 생성 환경 설정

1. **설정 → Codex 연결**에서 개인 ChatGPT 유료 구독 계정으로 로그인해요.
2. **설정 → 삽화 → Codex 생성 환경**에서 이미지 생성 도구를 실행할 **Codex 삽화 모델**을 선택해요.
3. **프롬프트 모델**에서 장면을 분석하고 그림 지시문을 작성할 텍스트 모델을 골라요. (같은 Codex 모델을 두 역할에 모두 지정하거나, 다른 고성능 텍스트 모델에 프롬프트 작성을 맡길 수 있어요.)
4. **그림 프롬프트 다듬기**를 켜면 프롬프트 모델이 참고 이미지를 보지 못한 채 쓴 초안을 Codex가 고쳐요. 선택된 순간과 구도, 분위기는 유지하고, 인물 외형과 그림체 묘사를 참고 이미지와 그림 지침에 맞춰 다듬어요. 다시 그리기의 변경 요청은 초안과 그림 지침보다 우선해요. 기본값은 프롬프트 모델이 작성한 지시문을 그대로 전달하며, 설정 변경은 새로 예약하는 작업에 적용돼요.

### 2. ComfyUI 생성 환경 설정

1. 원격 PC의 API 주소(예: `http://192.168.0.10:8188`)를 입력해요.
2. 장면을 분석해 프롬프트로 변환할 **프롬프트 모델**(어떤 텍스트 모델 프리셋이든 가능)을 지정해요.
3. ComfyUI에서 **Export (API)**로 저장한 워크플로 JSON을 프리셋에 등록하고 선택해요.
4. **ComfyUI 연결 확인** 버튼을 누르면 원격 서버의 `GET /system_stats`를 호출해 서버 버전과 장치 상태를 점검해요.

### 3. NovelAI 생성 환경 설정

1. NovelAI → 설정 → 계정에서 **Persistent API 토큰**을 발급해 **NovelAI 생성 환경**의 토큰 칸에 붙여 넣고 저장해요. 토큰은 서버의 비밀 저장소에만 남고 설정 응답·작업 입력·프리셋 파일에는 들어가지 않아요. 칸을 비워 두면 저장된 토큰을 유지하고, **저장된 토큰 삭제**를 누른 뒤 저장해야 지워져요.
2. **NovelAI 연결·잔여량 확인**은 `GET /user/subscription`으로 구독 등급, 잔여 Anlas, V5 사용량 게이지를 읽어요. 이미지는 만들지 않아요. Anlas는 응답의 `trainingStepsLeft.fixedTrainingStepsLeft`(구독분)와 `purchasedTrainingSteps`(구매분)의 합으로 보여줘요. 공식 스키마는 두 필드의 의미를 설명하지 않고 이 해석은 커뮤니티 클라이언트를 따른 것이라, 처음 쓸 때 NovelAI 화면의 잔액과 맞는지 확인해 주세요. V5 게이지는 `usage.percent`를 남은 비율로, `timeUntilNextPercent`를 1%가 회복되기까지 남은 시간으로 보여줘요.
3. **모델 ID**(기본 `nai-diffusion-5-full`), **프롬프트 모델**, 크기, 스텝, 프롬프트 가이던스, 샘플러를 골라요. 프롬프트 모델이 장면을 읽고 NovelAI용 태그 프롬프트와 제외 프롬프트를 써요.
4. Opus 구독의 무료 생성은 한 번에 한 장, 28스텝 이하, Normal 크기 조건이에요([구독 안내](https://docs.novelai.net/en/subscription)). 문서가 Normal 크기를 정의하지 않아서, 화면은 28스텝을 넘거나 면적이 1024×1024를 넘으면 Anlas가 소모될 수 있다고 표시해요. V5는 무료 조건이어도 별도의 Opus 사용량 게이지를 써요.
5. **캐릭터 참조**(Precise Reference)를 켜면 채팅의 **캐릭터 디자인** 참고 이미지를 예약 시점에 고정하고, 프롬프트 모델이 그 컷에 보이는 인물의 참조 번호만 골라 보내요. 참조 1장마다 생성할 때 5 Anlas가 추가되고 Opus 무료 생성에도 붙어요([Precise Reference 안내](https://docs.novelai.net/en/image/precisereference)). 문서상 V4.5 전용이라 다른 모델에서는 켜져 있어도 참조를 고정하지 않아요. 그림체 참고 이미지는 보내지 않아요.
6. NovelAI API 설명은 모든 생성 요청이 사람의 동작으로 시작돼야 한다고 요구해요([API 스키마](https://image.novelai.net/docs/doc.json)). 그래서 NovelAI 작업은 자동 재시도를 0회로 고정해요. 자동 생성은 사용자가 켠 경우에만, 사용자가 보낸 메시지의 응답에서 실행돼요.

## 자동 생성과 수동 요청

### 자동 생성

새 본문이 저장될 때 자동으로 삽화 계획을 예약해요.

- **자동 컷 수**: **내용에 맞게 선택**(기본 최소 0컷, 최대 10컷)과 **고정 상한**을 지원해요. 모델은 이야기의 길이와 시각적 변화에 맞춰 범위 안에서 필요한 컷을 고르며, 최대 컷 수는 반드시 채워야 할 목표가 아닌 상한선이에요. 그릴 만한 사건이 없으면 생략해요.
- 새 작업실에서는 자동 생성 기능 자체가 기본적으로 꺼져 있어요. 응답별 전체 컷 상한은 최대 10컷까지 설정할 수 있어요.

### 수동 생성과 개별 조작

- **장면 메뉴에서 요청**: 각 장면 머리글의 ⋯ → **삽화 생성**을 누르고 원하는 최대 컷 수를 골라 요청해요. 원하는 구도나 분위기가 있다면 연출 요청을 함께 적을 수 있어요.
- **완료된 삽화 조작**: 각 그림에 마우스를 올리거나 탭하면 **접기** 버튼과 ⋯ 메뉴가 나타나요.
  - **대표 삽화로 지정 / 본문 위치로 보내기**: 해당 컷을 장면 맨 위 대표 삽화로 올리거나 원래 문단 위치로 내려요.
  - **현재 설정으로 다시 그리기**: 같은 순간에 대해 새 그림을 생성해요. 변경 요청을 적으면 기존 프롬프트를 참고해 원하는 부분만 바꿔요. 다듬기를 사용한 그림에 Codex가 반환한 수정 프롬프트가 있다면 이 내용도 참고해요. 변경 요청을 비워 두면 최신 설정으로 새로 해석해요. 새 그림이 성공할 때까지 기존 그림은 화면에 유지돼요.
  - **생성 상세**: 사용한 모델, 프롬프트 원문, 토큰 사용량을 확인해요. Codex가 수정 프롬프트를 반환한 경우 초안과 함께 표시돼요.
  - **삽화 삭제**: 해당 컷의 이미지와 생성 기록을 삭제해요.
- **작업 상태 조작**:
  - **다시 요청**: 연결 실패 등으로 중단된 작업을 다시 실행해요.
  - **결과 확인**: 원격 타임아웃 등으로 접수 여부가 불확실했던 ComfyUI 작업의 완료 결과를 조회해 회수해요.
  - **취소**: 진행 중인 생성 작업을 취소해요.

## 인물 외형과 참고 이미지

인물의 외형과 그림체를 지정해 삽화의 일관성을 높일 수 있어요.

- **참고 이미지 지정**: **채팅 설정 → 이미지 → 삽화 참고**에서 채팅에 등록된 이미지나 카드의 에셋을 **캐릭터 디자인** 또는 **그림체** 참조로 지정해요. 실제 참고 이미지 바이트는 참조 기능을 지원하는 Codex 이미지 생성 턴에만 전달돼요.
- **기본 인물 외형**: 봇·페르소나·모듈 편집 화면의 **표현과 시각 → 기본 인물 외형**에서 인물별 이름, 외형 묘사, 참조 이미지를 등록해요. CCv3 `data.extensions.uimori.illustrationProfiles` 규격으로 보관되어 같은 카드를 쓰는 모든 채팅이 공유해요.
- **채팅별 외형 편집과 복원**: 채팅에서는 공유 기본 외형을 보여주며, **편집**을 누르면 채팅 전용 사본으로 복사되어 자유롭게 수정할 수 있어요. **복원**을 누르면 사본을 삭제하고 최신 기본 외형을 다시 상속받아요.
- **도우미 지원**: 도우미에게 “미라의 카드와 초상화를 보고 삽화용 외형을 제안해 줘”라고 부탁하거나, “미라는 두 번째 안으로 바꾸고 준과 아라는 새 인물로 등록해 줘”처럼 요청해 여러 인물을 한 번에 저장할 수 있어요.
- **구간별 외형 메모**: 의상이나 소지품이 일시적으로 바뀔 때는 “항구에 도착한 장면부터 출항하는 장면까지 미라에게 붉은 코트를 입혀줘”처럼 작성된 장면 구간에 임시 외형 메모를 붙일 수 있어요. 기본 인물 설정은 유지하면서 해당 구간만 반영돼요.

## 본문 읽기와 삽화 표시

- **문단 뒤 슬롯 배치**: 본문의 일반 문단, 제목, 구분선, 인용, 목록, 표, 코드 블록 뒤의 안전한 Markdown 경계에 삽화를 배치해요. 저자가 작성한 스타일이나 입력 상태를 보존하기 위해 메시지 Shadow DOM의 실제 삽화 위치에만 슬롯을 넣어요.
- **본문 밖 삽화**: 다음과 같이 정확한 본문 위치를 특정하기 어려운 그림은 본문 아래 **본문 밖 삽화** 영역에 모아서 보여주며 각 컷에 이유를 표시해요.
  - 저자가 작성한 HTML 태그 내부라 경계를 나눌 수 없는 경우
  - 표시 변환으로 인해 텍스트 자체가 크게 달라진 경우
  - 번역문 위치가 아직 지정되지 않았거나 불확실한 경우 (`null`)
  - 원문 수정 이전에 생성되었던 이전 그림인 경우
- **번역 위치 다시 연결**: 번역문이 바뀌거나 위치가 어긋나면 이미지는 그대로 보존하고 위치만 다시 매핑해요. **번역 위치 다시 연결** 버튼으로 언제든 다시 요청할 수 있어요.
- **접기 제어와 읽기 보호**:
  - 개별 컷의 접기 상태와 **모두 접기 / 모두 펼치기**는 브라우저에 저장돼요. 기본 표시와 다른 선택만 남기며, 가장 최근에 바꾼 500개 컷까지 기억해요.
  - **읽기 설정 → 삽화 기본 표시**에서 새 컷의 기본 펼침 상태를 정할 수 있어요.
  - 사용자가 이미 읽고 지나간 위쪽 문단에서 그림이 뒤늦게 완성되면, 읽던 화면이 갑자기 밀려나지 않도록 일시적으로 접힌 상태로 렌더링해요.
- **삽화 크게 보기**: 이미지를 클릭하면 새 창 대신 모달 뷰어가 열려 원본 비율로 확대해 볼 수 있어요. (닫기 버튼, Escape 키, 배경 클릭으로 닫힘)
- **작업 현황과 사용량**:
  - 장면 작업 박스는 완료된 삽화를 **삽화 n/m** 한 줄로 보여 주고, 진행 중이거나 확인이 필요하면 **장면 선택**, **그림 생성 n/m컷**, **번역 위치 연결** 단계를 그 자리에서 펼쳐요.
  - 작업 박스의 **원본 기록**에서 **삽화**를 고르면 누적 호출 수와 입력/출력 토큰을 단계별로 확인할 수 있어요.

## 삽화 프리셋

**설정 → 삽화 → 프리셋**에서 프리셋을 만들고 편집·복제·삭제하거나 JSON 파일로 가져오고 내보낼 수 있어요.

### 1. 프리셋의 구성과 우선순위

- **프리셋 저장 내용**: **생성기(`codex`, `comfyui`, `novelai`), 이름, 설명, 그림 지침**, 그리고 ComfyUI 전용 워크플로 JSON과 추가 제외 지침, NovelAI 전용 추가 제외 지침을 저장해요.
- **생성 환경과의 분리**: 모델 선택, ComfyUI 접속 주소, 인증 정보, 자동 생성 정책은 프리셋이 아닌 공용 **생성 환경**에 저장돼요. 프리셋을 바꾸면 사용하는 생성 환경도 함께 전환되지만 공용 환경의 저장값 자체를 덮어쓰지는 않아요.
- **적용 우선순위**: **현재 채팅 → 현재 봇 → 작업실 기본 → 내장 기본** 순서로 적용돼요. 채팅이나 봇에서 **상위 설정 따르기**를 누르면 해당 선택을 해제해요.
- **저장과 적용의 분리**: 프리셋 편집 내용은 저장 즉시 이전 작업에 소급 적용되지 않으며, 해당 프리셋을 쓰는 채팅의 **다음 생성 예약부터** 반영돼요. 이미 진행 중인 작업이나 과거 결과는 당시 고정된 설정을 유지해요.

### 2. 프리셋 파일 형식

파일 확장자는 `.uimori-illustration.json`이며, 형식은 다음과 같아요.

```json
{
  "format": "uimori-illustration-preset",
  "version": 2,
  "preset": {
    "title": "수채화",
    "generator": "codex",
    "description": "부드러운 빛과 종이 질감",
    "styleGuidance": "watercolor, soft light, textured paper",
    "comfyui": { "workflow": "", "negativeGuidance": "" },
    "novelai": { "negativeGuidance": "" }
  }
}
```

- v2 파일은 생성기 정보를 포함해요. 생성기 필드가 없는 이전 v1 파일은 워크플로 유무에 따라 ComfyUI 또는 Codex로 자동 인식해요. `novelai` 항목이 없는 파일은 NovelAI 제외 지침을 빈 값으로 읽어요.
- 파일 크기는 16MiB, 워크플로 문자열은 400,000자, 그림/제외 지침은 각각 200만 자까지 저장할 수 있어요.
- 워크플로 JSON에 개인 API 키나 로컬 파일 경로가 포함되어 있지 않은지 공유 전에 반드시 확인해 주세요.

### 3. 그림 지침 작성 요령

프리셋의 **그림 지침** 필드 하나에 원하는 화풍, 색감, 조명, 선의 느낌, 질감, 그리고 피해야 할 표현을 자유롭게 적어요. 자연어, 불릿 목록, Markdown, JSON 형식을 모두 지원해요.

#### 생성기별 해석 방식

- **Codex**: 공통 시각적 지침을 이미지 생성 도구에 전달해요. 캐릭터 참조는 외형, 스타일 참조는 화풍을 전달하는 역할을 맡아요. ComfyUI 전용 태그 문법은 제외돼요.
- **ComfyUI**: 프롬프트 모델이 지침을 읽고 각 컷의 `{prompt, negativePrompt, caption}`을 작성해요. 워크플로의 `{{prompt}}`, `{{negative}}`, `{{seed}}` 자리에 해당 내용이 자동 치환돼요.
- **NovelAI**: 프롬프트 모델이 `{prompt, negativePrompt, characters, caption}`을 써요. 계약에는 NovelAI 문법을 짧게 안내해요. 소문자 태그를 `, `로 구분하고 가중치는 `1.3::태그 ::`로 써요([태그 안내](https://docs.novelai.net/en/image/tags), [강조 안내](https://docs.novelai.net/en/image/strengthening-weakening)). 장면 공통 `prompt`에는 `2girls, 1boy` 같은 인원 태그와 배경·구도·조명·화풍을, `characters`에는 보이는 인물마다 `girl`/`boy`/`other`로 시작하는 외형·옷차림·표정·동작과 그 인물에게 번지면 안 되는 특징(인물별 제외 프롬프트)을 넣어요. 상호작용은 `source#hug`/`target#hug`/`mutual#hug`처럼 표시해요([다인물 안내](https://docs.novelai.net/en/image/multiplecharacters)). 프리셋의 그림 지침에 적은 NovelAI 문법과 태그는 그대로 보존해요.

특정 체크포인트 모델의 문법이 필요하다면 그림 지침에 명시할 수 있어요. 예를 들어 [Anima 공식 모델 카드](https://huggingface.co/circlestone-labs/Anima#prompting)나 [OpenAI 이미지 프롬프팅 안내](https://developers.openai.com/api/docs/guides/image-prompting)를 참고해 다음과 같이 작성할 수 있어요.

```text
ComfyUI에서 Anima용 프롬프트를 작성할 때:
외형과 사물은 간결한 태그로, 가림 관계와 표현 조건은 자연어로 설명한다.
일반 태그에는 언더스코어 대신 공백을 사용한다.
```

## 설정 항목과 한도

| 항목 | 설정 범위 | 설명 |
| --- | --- | --- |
| **생성기** | `codex` / `comfyui` / `novelai` | 프리셋에서 선택하며, 연결 주소 및 모델은 해당 생성기의 공용 환경을 사용해요. (`fixture`는 테스트 전용) |
| **자동 생성** | 켜기 / 끄기 | 새 본문 저장 직후 자동으로 계획을 예약해요. 후보 응답, 작성된 도입문, 포크 복사본에는 실행되지 않아요. |
| **자동으로 고를 최대 컷 수** | 1~10컷 (기본 10) | `automaticMaxTargets`. 응답 전체 한도 내에서 모델이 이야기 분량에 맞춰 필요한 만큼만 계획해요. |
| **장면당 최대 삽화 수** | 1~10컷 (기본 10) | 현재 장면에 등록될 수 있는 서로 다른 컷의 총 상한이에요. 동일 컷의 재생성이나 다중 결과 이미지는 추가 컷으로 세지 않아요. |
| **자동 재시도 횟수** | 0~5회 (기본 1) | 네트워크 일시 단절, 명확한 원격 실행 실패 등 안전한 실패에만 적용해요. 전송 후 타임아웃이나 5xx 오류는 접수 불확실로 남겨 자동 재생성하지 않아요. NovelAI 작업은 이 값과 관계없이 0회예요. |
| **그림 지침·제외 지침** | 각 200만 자 | 저장 보호 상한이에요. 실제 모델 전송 가능 여부는 요청의 전체 입력 토큰 예산으로 검사해요. |

## 원문 변경·복사 및 생성기별 안내

- **원문 수정 뒤 기존 삽화 표시**: 작업은 예약 당시 원문에 귀속돼요. 사용자가 나중에 원문을 수정하더라도 완료된 삽화는 요청 당시 원문에 귀속되어 남으며 **수정 전 원문의 삽화**로 표시돼요.
- **채팅 복사와 백업**: 독립 채팅 복사 및 개별 백업은 현재 화면에 표시된 성공 결과, 동일 컷의 변형 그룹, 대표 지정, 검증 가능한 원문/번역 위치만 복원해요. 문단 index와 텍스트 hash를 검증해 새 anchor를 부여하고, 불일치 시 보조 영역으로 이동해요. 미완료 작업이나 실패 기록은 복제하지 않아요.
- **Codex 실패 코드**:
  - `CODEX_IMAGE_USAGE_LIMIT`: 유료 한도 초과 (자동 재요청 안 함)
  - `CODEX_IMAGE_UNAVAILABLE`: 명시적 생성 거부 (자동 재요청 안 함)
  - `CODEX_IMAGE_NOT_GENERATED`: 일반 생성 실패 (재요청 가능)

### Codex 이미지 요청의 사전 판정

이미지 생성 직전에 Codex로 보낼 텍스트(프롬프트 모델이 작성한 프롬프트와 참조 이미지 라벨)를 판단 프로바이더(기본 TypeSafe AI / JEV)로 사전 검사해요. 다듬기를 켠 경우에도 사전 판정의 범위는 이미지 턴에 보내는 텍스트까지예요.

- **판정 기준**: 컷을 묘사한 텍스트에 노골적인 성적 묘사가 필요한지 여부를 `noul` 지표로 판정하며, 점수가 0.9 이상이면 해당 컷의 이미지 요청을 보내지 않고 차단해요. (일반적인 로맨스나 키스, 비노골적인 연출은 일괄 차단 대상이 아니에요.)
- **차단 처리**: `ILLUSTRATION_CODEX_CONTENT_BLOCKED` 오류로 기록되며 자동 재시도 및 동일 입력 수동 재시도를 차단해요. 다른 컷의 작업이나 본문·번역 작업, 기존 성공 이미지는 정상적으로 유지돼요.
- **예외 처리**: 판단 프로바이더 키 미설정, 응답 오류, 8초 시간 초과, 입력 토큰 예산 초과는 `unavailable`로 기록하고 프로바이더의 자체 판단에 맡겨 생성을 계속 진행해요. 판정 호출은 `illustration-content` 사용량으로 귀속돼요.

### ComfyUI·NovelAI 프록시 인증과 오류 코드

- **ComfyUI 네트워크와 프록시**: `http://`와 `https://`만 허용하며 주소에 인증 정보나 쿼리를 포함할 수 없어요. 프록시 인증이 필요한 경우 **인증 헤더 환경변수**에 지정된 환경변수 값을 읽어 `Authorization` 헤더로 전달해요. 브라우저는 원격 서버에 직접 접근하지 않아요.
- **ComfyUI 실패 진단 코드**: `COMFYUI_PROMPT_REJECTED` (노드 설정 오류), `COMFYUI_EXECUTION_FAILED` (실행 도중 오류), `COMFYUI_SUBMISSION_UNCERTAIN` (접수 불확실, 자동 재제출 금지), `COMFYUI_RESULT_UNAVAILABLE` (접수 후 조회 실패).
- **NovelAI 실패 코드**: `NOVELAI_TOKEN_MISSING`(토큰 없음, 요청 안 보냄), `NOVELAI_UNAUTHORIZED`(401/403), `NOVELAI_ANLAS_INSUFFICIENT`(402), `NOVELAI_BUSY`(429, 같은 계정의 다른 생성), `NOVELAI_REQUEST_REJECTED`(그 밖의 4xx, 모델 ID·크기 확인), `NOVELAI_UNREACHABLE`(연결 전 실패), `NOVELAI_RESULT_UNCERTAIN`(전송 후 시간 초과·연결 끊김·5xx), `NOVELAI_RESPONSE_INVALID`, `NOVELAI_IMAGE_INVALID`. 진단에는 HTTP 상태와 최대 300자의 NovelAI 메시지만 남겨요.
- **NovelAI 불확실한 결과와 취소**: NovelAI는 작업 ID를 돌려주지 않아 결과를 다시 조회할 수 없어요. 불확실한 실패도 **다시 요청**은 허용하며, 이때 저장된 프롬프트를 재사용해 이미지 요청만 다시 보내요. 취소하면 연결은 끊지만 NovelAI 쪽 생성은 끝까지 진행될 수 있어요.
