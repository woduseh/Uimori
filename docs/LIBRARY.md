# 서재와 자료 편집

서재는 봇·페르소나·모듈을, 프롬프트 목록은 작문·번역 프리셋을 관리해요. 자료 목록에서 선택하고 **편집**을 열어요. 저장되지 않은 입력은 이 기기 편집기에만 있으며 다른 기기로 동기화하지 않아요.

## 저장과 취소

**변경사항 저장**은 현재 자료를 갱신하고, **편집 취소**는 저장본을 다시 불러와요. 직전 저장 한 번을 되돌릴 수 있어요. 에이전트도 같은 저장 기능을 사용해요. 수정 번호 충돌이면 입력을 보존하고 최신 자료를 다시 읽도록 알려줘요. 별도 서버 초안·변경 제안·영구 저장 이력 검토 화면은 없어요.

원문 JSON·정규식·트리거도 저장할 때 함께 확인해요. 잘못된 입력은 지우지 않아요. `폼에 반영`은 원문 수정 후 GUI 편집을 계속할 때 사용하는 선택 동작이에요. [편집과 복구 상태](EDITING.md)

## 편집 영역

봇은 기본 정보·첫 메시지·로어북·에셋·고급 설정·제작 정보로 나눠요. 고급 설정에는 지침, 기본 변수·토글, HTML/CSS, Lua·정규식·트리거, 연결 모듈과 원문 JSON이 있어요. 프리셋은 구성·기본 옵션·변수·토글·정규식·협업을 편집해요.

저장된 봇·모듈·프리셋은 다음 생성부터 사용해요. 이미 작성한 대화 본문을 새 설정으로 다시 생성하지 않아요. 자료마다 모든 과거 개정을 보관하지 않으며, 보관할 별도 버전은 명시적으로 사본이나 [개별 백업](NATIVE-TRANSFER.md)으로 남겨요.

## 이미지 이름·설명과 WebP

에셋을 선택해 **이미지 이름**과 **설명**을 편집하고 자료를 저장해요. 목록·검색과 JEV 선택은 이 메타데이터를 사용해요. 기존 Risu 스크립트가 사용하는 참조 이름은 별도로 유지해요. 이름을 바꿔도 이미지 바이트를 다시 인코딩하지 않아요.

업로드 이미지는 서버 공통 경계에서 고품질 WebP로 변환해요. 해상도·투명도·애니메이션을 유지하는 방식으로 처리하며 픽셀 단위 무손실을 보장하는 설정은 아니에요. 기존 WebP는 그대로 저장하고 원본을 함께 이중 보관하지 않아요. 2MB 제한은 없고 입력 파일 64MiB 및 처리 픽셀·프레임 상한을 사용해요. 여러 파일은 제한된 동시 처리 수로 변환해요. [장면 삽화](ILLUSTRATIONS.md)도 같은 미디어 저장소를 사용해요.

## 정리와 교환

폴더·검색·대표 이미지는 서재 탐색용 정보예요. 원본 Risu 내보내기는 [Risu 교환](RISU-EXPORT.md), Uimori 설정과 의존 자료를 함께 옮길 때는 개별 백업을 사용해요. 키는 개별 내보내기에 들어가지 않아요. [삭제](DELETION.md), [전체 DB 복구](DATA-MIGRATIONS.md)

봇에는 [번역 지침](TRANSLATION-GUIDES.md) 편집 영역도 있어요. 자유 지침과 표기 목록을 같은 자료에 저장하며 페르소나·모듈에는 이 편집 영역을 표시하지 않아요.
