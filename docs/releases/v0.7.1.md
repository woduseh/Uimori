# Uimori v0.7.1

장면 코멘터리 기능과 사용하지 않는 코드를 정리한 유지보수 릴리스예요.

## 주요 변경

- **장면 코멘터리 기능 제거:** 표시 전용 코멘터리의 설정·모델 선택·생성·API·읽기 화면을 제거했어요. 과거 작업·결과·사용량 기록은 계속 읽을 수 있지만, 제거된 작업은 새로 실행하거나 재시도하지 않아요.
- **사용하지 않는 코드 정리:** 사용하지 않는 계보 해시·이야기 필드·저장 쓰기·삽화 입력 필드·상태 표시와 미지원 숫자형 thinking 설정 코드를 제거했어요. 기존 삽화 생성·native Risu·초안 및 복구 기능은 유지해요.
- **프로바이더 역할 처리 정리:** Anthropic 요청의 허용 역할 목록에서도 종료된 장면 해설(`status`) 역할을 제거했어요.

## 데이터 호환성

앱 버전은 **0.7.1**, DB는 계속 **스키마 15**예요. v0.7.0의 기존 작업실과 기록을 유지해 업데이트할 수 있으며 별도 데이터 변환은 없어요. 업데이트 전에는 일관된 SQLite 백업을 보관하고 진행 중인 생성·도우미 작업과 편집을 마쳐요.

## 설치와 업데이트

아래 태그 기반 설치는 `v0.7.1` 태그 발행 후 사용할 수 있어요.

```sh
git clone --branch v0.7.1 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x를 사용해요. 기존 설치는 [업데이트 안내](../UPDATES.md), Oracle 운영 설치는 [전용 배포 절차](../ORACLE-RELEASE.md)를 따르고, 업데이트 후 **설정 → 앱 정보·라이선스**에서 0.7.1을 확인해요. 태그·GitHub Release 발행만으로 실행 중인 앱이 업데이트되지는 않아요.

## 검증 범위

최종 릴리스 커밋의 GitHub Quality CI 통과를 발행 기준으로 사용해요. 이번 릴리스 준비에서는 로컬 전체 테스트를 반복하지 않아요. CI의 합성 검증은 실제 유료 모델의 응답 품질이나 물리 모바일 기기 동작을 증명하지 않아요. Oracle 배포 시에는 별도로 실제 이미지·DB 복제본·백업·HTTPS/API·쓰기 재개를 확인해요.
