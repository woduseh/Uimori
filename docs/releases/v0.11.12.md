# Uimori v0.11.12

2026년 10월 Node.js 보안 취약점 수정 릴리스예요.

- Docker 빌드·운영 런타임과 CI 개발용 Node.js를 **24.22.1**로 업데이트했어요.
- 앱 동작과 SQLite 스키마(15), 기존 데이터 포맷은 변경하지 않았어요. 데이터 마이그레이션이 필요하지 않아요.
- 운영 업데이트는 [Oracle 배포 절차](../ORACLE-RELEASE.md)의 백업·사전 검증·HTTPS 확인을 거쳐요.
