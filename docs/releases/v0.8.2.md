# Uimori v0.8.2

v0.8.1 이후 Risu 카드의 화면 크기 대응과 사용 중 상태 보존, 가져오기 검토의 명시적 취소를 개선한 안정화 릴리스예요.

## 주요 변경

- **Risu 카드 화면 크기 대응:** Reader와 시작문 미리보기에서 실제 브라우저의 화면 너비·높이를 표시용 CBS, 정규식, 이미지 표시 규칙, Lua `cbs()`에 전달해요. `{{screenwidth}}`, `{{screen_width}}`, `{{screenheight}}`, `{{screen_height}}` 변수를 지원하며 화면 크기 변경에도 다시 표시해요. `position: fixed` 패널과 버튼은 메시지 영역이 아니라 뷰포트 기준으로 배치하고, 절대 배치 배경은 메시지 영역 기준을 유지해요.
- **입력·선택 상태 유지:** 화면 크기 변화로 Risu 카드 표시가 다시 계산되어도, 같은 원문과 카드 변수 수정 번호의 식별 가능한 입력·체크박스·펼침 상태 및 포커스를 유지해요. CSS만 달라지면 기존 DOM을 그대로 유지해요. 원문·기본값·카드 변수 수정 번호가 실제로 바뀌면 새 내용을 우선 적용해요.
- **가져오기 검토 취소:** Risu 가져오기 검토 화면에 **가져오지 않고 닫기**를 추가했어요. 일반 X·Escape 닫기는 진행 중인 검토를 보존하지만 명시적 취소는 아직 적용하지 않은 선택과 준비 자료를 비우고 임시 파일 정리를 요청해요. 저장 진행 중이나 성공 여부가 불확실할 때는 취소할 수 없으며, 기존 등록 자료와 저장 기록은 삭제하지 않아요.

## 데이터 호환성

앱 버전은 **0.8.2**이고 SQLite 스키마는 여전히 **15**예요. 이미 스키마 15를 쓰는 v0.8.1 작업실의 자료·설정은 그대로 유지하며 별도 DB 마이그레이션이 필요하지 않아요. 업데이트 전에는 일관된 데이터 백업을 확보하고 진행 중인 생성·저장을 완료해 주세요. 이전 스키마의 직접 변환은 지원하지 않아요.

## 설치·업데이트

공개된 GitHub 릴리스의 `v0.8.2` 태그를 사용하세요.

```sh
git clone --branch v0.8.2 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md)를, Oracle 운영 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 참고하세요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.2`와 빌드 식별자를 확인해요. 릴리스 발행만으로 기존 서버가 자동 업데이트되지는 않아요.

## 검증 범위와 제한

카드 화면·조작 보존·가져오기 취소 동작은 합성 카드와 브라우저 기반 검증 대상이에요. 모든 실제 Risu 카드의 CSS·Lua 호환성이나 물리 기기 및 모델 응답 품질까지 보장하지는 않아요. 운영 이미지·기존 DB 복제본·HTTPS 및 쓰기 재개 상태는 Oracle 배포 절차로 별도 확인해요.
