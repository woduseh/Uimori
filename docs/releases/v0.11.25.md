# v0.11.25

화면의 중복 설명과 다국어 문구를 정리한 패치 릴리스예요. **DB 스키마는 15로 유지**하며 기존 원고, 채팅 및 설정은 그대로 보존해요.

- 도우미의 협업 설정, 프리셋 가져오기, 프로바이더·봇·프로필·삽화 설정에서 중복 안내를 줄여 화면을 간결하게 했어요.
- 채팅 삭제, 기억 보존, 요청 접수 및 재확인, 원작 참고, 프롬프트 저장 등에서 동작과 결과를 더 분명하게 설명해요.
- 한국어·영어·일본어·중국어(간체)의 메뉴와 안내 문구를 다듬었어요. 기존 기능과 데이터 저장 형식은 바꾸지 않아요.

기존 데이터 및 설정을 유지하는 업데이트예요. 실제 유료 모델 호출과 물리 기기 검증은 포함하지 않아요. 설치와 백업 절차는 [업데이트 안내](../UPDATES.md)를 참고해요.
