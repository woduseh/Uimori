# v0.15.6

원문·번역문에서 긴 구간을 선택하거나, 복사에 실패하거나, Risu 본문이 갱신될 때 선택 도구가 올바르게 동작하도록 고쳤어요.

- **긴 구간도 선택 도구를 쓸 수 있어요.** 선택한 내용이 화면 높이를 채워 위쪽과 아래쪽에 막대를 둘 공간이 없으면, 읽기 영역 안쪽에 막대를 배치해요. 읽기 영역 자체가 너무 작으면 예전처럼 막대를 띄우지 않아요.
- **클립보드 복사에 실패해도 선택을 잃지 않아요.** 권한 거절이나 브라우저의 클립보드 기능 부재를 알리고 막대를 유지해서 다시 복사할 수 있어요. 성공했을 때만 복사 완료를 알려 줘요.
- **Risu 본문을 갱신한 뒤 오래된 선택이 남지 않아요.** 선택한 글이 화면에서 사라지면 선택 막대를 닫고, 갱신 직후 오래된 선택으로 도우미나 책갈피 등의 동작을 실행하지 않아요.

**데이터 호환성:** SQLite 스키마 15를 유지하고 저장된 원고·번역·설정은 변경하지 않아요. 새 데이터 마이그레이션은 없어요. [업데이트 안내](../UPDATES.md)

**검증:** 선택 기능의 전체 브라우저 회귀 24개가 통과했어요. 새 테스트는 긴 선택 위치, 클립보드 거절 뒤 재시도, Risu Shadow DOM 본문 교체를 다뤄요. 실제 운영 데이터나 모바일의 네이티브 텍스트 선택, 다른 브라우저의 클립보드 권한 처리는 별도로 검증하지 않았어요.
