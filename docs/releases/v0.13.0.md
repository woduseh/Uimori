# v0.13.0

- **이야기 UI**에서 메신저, 댓글이 달린 게시물, 타임라인, 차트 같은 화면을 원고 속 장면에 배치할 수 있어요. 새로운 구성 요소와 스타일이 추가됐고, 이전 장면의 화면 배치도 이야기 UI를 켠 채팅의 다음 본문 생성에 전달돼요. [이야기 UI](../STORY-UI.md)
- **도우미의 도구 검색**에서 봇 설명 수정, 장면 오탈자 교정, 여러 채팅의 문구 찾기 같은 요청으로 관련 작업을 더 쉽게 찾을 수 있어요. 도구 목록을 용도별로 묶고, 모델이 받는 인자 설명에 입력값의 출처와 단위를 적었어요. [도우미 도구](../HELPER-TOOLS.md)
- **모델과 프롬프트**에 GPT-6.2, Claude Fable 5.2·Mythos 5.2, Gemini 4 Carbon의 모델 카탈로그 항목과 Phēmē v5.6.0 RP·소설 프리셋을 추가했어요. 프롬프트 관리의 기본 프롬프트에서 새 프리셋 사본을 추가할 수 있어요. [모델 파라미터](../MODEL-PARAMETERS.md) · [기본 프롬프트](../BUILTIN-PROMPTS.md)

**업데이트 전 진행 중인 생성과 Batch를 끝내 주세요.** 새 도구 이름과 정의가 이전 빌드에서 저장한 연속 실행 상태와 달라 일부 작업을 이어갈 수 없어요. SQLite 스키마는 15이며, 기존 작업실은 백업 후 업데이트할 수 있어요. 사용자 이야기 UI 테마는 기존 `--story-*` 토큰을 사용할 수 있어요. 예전 `--a2ui-*` 변수로 꾸민 부분은 새 테마 제작 문법에 맞춰 조정해 주세요.
