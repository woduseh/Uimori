# v0.11.18

헤일로 문양의 아이콘과 기본 배색을 새롭게 정리한 패치 릴리스예요. DB 스키마는 15로 유지해요.

- 코제키 우이의 헤일로와 머리색을 모티브로 크림색 문양과 검정에 가까운 남청색 배경을 적용했어요.
- 16/32px 파비콘은 단순화한 문양을, 48/64px과 홈 화면 설치 아이콘은 겹원과 구획선을 살린 정교한 문양을 사용해요. SVG는 표시 크기에 맞춰 전환해요.
- 기본 테마의 어두운 모드는 남청색 바탕과 크림색 강조를, 밝은 모드는 따뜻한 종이색과 청회색 잉크를 사용해요.
- 기존 여섯 팔레트, 사용자 테마, 밝게·어둡게·시스템 설정과 원고 자료는 유지해요.

크기별 SVG 표시, 설치 아이콘 규격, 기본 배색의 글자 대비와 데스크톱·모바일 팔레트 전환을 검증했어요. 이미 설치된 아이콘의 갱신 시점은 브라우저와 OS에 따라 달라질 수 있어요. 설치 및 데이터 보존 절차는 [업데이트 안내](../UPDATES.md)를 참고해요.
