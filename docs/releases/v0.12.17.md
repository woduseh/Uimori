# v0.12.17

- **하네스의 실행 진단**을 보강했어요. 본문·조언자·번역·컨텍스트·원작 참고·삽화·도우미·네이티브 Risu의 모델 호출에 시작·종료·경과 시간과 보고된 사용량·오류를 남겨요. 실행 중 예외가 발생한 호출도 결과 미확인 상태로 마감해요.
- **도구 실행 기록**은 제한된 인자 미리보기·해시, 상태·시간·결과 크기를 보존해요. 셸은 종료 코드·타임아웃·실제 출력 바이트와 잘림 여부도 기록해요. 성공 후 큰 입력·결과를 정리해도 작은 진단은 남으며, `task.inspect`에서 필요한 경우 페이지별로 조회할 수 있어요. 진단 기록이 모델 입력에 자동으로 추가되지는 않아요.
- **Codex 실행 기록과 사용량**의 정확성을 높였어요. 사전 내용 판정 호출도 사용량에 포함하고, 네이티브 도구 활동은 본문 없이 제한된 메타데이터로 기록해요. 재사용 세션의 마지막 호출과 세션 누계에 맞춰 캐시·추론 사용량도 같은 기준으로 읽어요.
- **도우미 사용량**은 접힌 상태에서 마지막 요청 입력과 이번 작업 출력을 간결한 K/M 표기로 보여줘요. 펼치면 정확한 누적 입력·출력과 캐시·추론 내역을 확인할 수 있어요. 입력 추정치는 추정으로, 보고되지 않은 값은 미확인으로 구분해요.
- **도우미 CLI**에서 `--contentId`처럼 도구 스키마에 맞는 camelCase 인자를 정상 처리해요. 내보낸 파일과 SQL 조회의 서로 다른 JSON 경로도 안내에 명시했어요.
- 장면 삭제 시 해당 채팅의 도우미 인자 미리보기도 정리해 삭제한 문구가 진단에 남지 않게 했어요. 실행 상태·시간·사용량·저장 영수증과 다른 채팅의 기록은 유지해요.

기존 봇·페르소나·채팅·원고·삽화·설정·저장 영수증은 유지돼요. **SQLite 스키마 15**를 유지하며 진단 테이블은 앱 시작 시 추가돼요. 진단은 작업·자료 삭제 정책과 전체 작업실 백업을 따르고, 과거에 남기지 않은 기록이나 보고되지 않은 사용량을 만들어 채우지 않아요.
