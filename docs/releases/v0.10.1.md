# Uimori v0.10.1

v0.10.0 이후 컨텍스트 요약 설정과 자동 채팅 제목 품질을 개선한 패치 릴리스예요.

## 주요 변경

- **세션 요약 길이 설정:** 설정 → 역할별 모델 → 대화와 자료 지원에서 자동 또는 2,048 / 4,096 / 8,192 / 16,384토큰 목표 상한을 선택할 수 있어요. 자동 기본값의 상한은 8,192토큰이에요.
- **도우미 요약 길이 설정:** 같은 화면에서 별도로 조정할 수 있어요. 자동 기본값의 상한은 4,096토큰이에요. 실제 길이는 모델 출력 설정·남은 입력 예산에 따라 더 짧아질 수 있고, 목표를 억지로 채우지는 않아요.
- **기존 기록 보존:** 압축한 장면도 원문을 유지해 검색·다시 읽기를 지원해요. 기존 체크포인트는 설정 변경만으로 무효화하거나 재생성하지 않으며, 과거 실행 스냅샷은 원래의 요약 한도를 유지해요. 도구 결과 압축은 기존 2,048토큰 정책을 유지해요.
- **채팅 제목 품질:** 생성된 본문과 요청을 바탕으로 인물·사건·장소 등 식별력 높은 요소를 우선하여, 짧고 구체적인 한국어 제목을 만들도록 지시문을 개선했어요. 이미 사용자가 지정한 제목은 덮어쓰지 않아요.
- **회귀 검증 보강:** 설정값의 유효성·보존 및 모바일 화면에서 독립 저장·새로고침 복원을 확인하고, 브라우저 테스트 후 원래 전역 설정을 복원해요.

## 데이터 호환성

앱 버전은 **0.10.1**, SQLite 스키마 버전은 기존 **15**를 유지해요. 일반 업데이트 시 기존 운영 데이터 볼륨·채팅·원본·체크포인트·모델 인증을 유지해요. 구형 스키마를 자동 변환하지 않아요.

## 설치 및 업데이트

```sh
git clone --branch v0.10.1 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설정 → 앱 정보·라이선스에서 버전 `0.10.1`을 확인하세요. 릴리스 공개만으로 운영 앱이 바뀌지는 않아요.

## 검증과 한계

정적 검사·프로덕션 빌드·컨텍스트 압축 및 설정 검증·브라우저 스모크 테스트를 수행했어요. 정확한 릴리스 SHA의 GitHub 필수 CI와 Oracle 이미지·DB·HTTPS 검증은 배포 시 별도 확인해요. 실제 모델의 장기 서사 기억 품질·요약 비용·제목 품질은 합성 테스트만으로 보장하지 않아요.
