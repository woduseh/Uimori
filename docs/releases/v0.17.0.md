# v0.17.0

도우미가 설정 화면에서만 하던 일을 더 많이 맡아요. 모델을 등록하고 지우고, 채팅에 붙은 페르소나와 모듈을 바꾸고, 장면을 숨기고, 책갈피와 채팅 폴더를 정리해요. 대신 되돌릴 수 없는 삭제와 비용이 드는 삽화 생성은 먼저 확인 카드로 물어요.

- **모델 등록과 삭제.** 이미 있는 연결에 새 모델을 등록하고, 쓰지 않는 모델을 지워요. 역할이나 조언자로 지정됐거나 채팅에 고정된 모델, 삽화 설정이 쓰는 모델은 지우지 않고 어디서 쓰는지 알려 줘요. 연결, 자격 증명, 엔드포인트는 지금처럼 설정 화면에서만 바꿔요.
- **채팅 구성과 정리.** 채팅에 첨부한 페르소나와 모듈, 로어 컨텍스트, Risu 작가 노트를 바꾸고, 장면을 작가 모델에게서 숨기거나 그 장면의 요청문을 끄고 고쳐요. 책갈피를 추가·수정·삭제하고, 봇별 채팅 폴더와 새 채팅의 기본 페르소나를 정리해요. 작가 노트, 요청문, 책갈피를 고치면 변경 카드에서 작업 전 글과의 차이를 볼 수 있어요. [도우미 도구](../HELPER-TOOLS.md)
- **설정 몇 가지를 더 바꿀 수 있어요.** 기본 본문·번역 프롬프트, 자동 번역과 번역 결과 언어, 새 채팅의 거절 뒤 자동 다시 생성과 로어 컨텍스트 기본값, 전역·봇·채팅별 삽화 프리셋 선택이에요.
- **확인 카드가 넓어졌어요.** 삽화 컷, 글꼴, 팔레트, 모델, 채팅 전용 로어를 지울 때도 서재 자료 삭제처럼 먼저 물어요. 전에는 이 삭제들이 확인 없이 바로 실행됐어요. **유료 생성 전에 확인**을 켜 두면 삽화 생성과 다시 그리기, 작업 다시 시도도 물어요. 삽화 생성 카드에는 그릴 장수가 나오고, 도우미는 한 번에 10장까지 예약해요. [도우미 변경 기록](../DELETION.md#도우미-작업-기록)
- **모델 삭제 안내를 바로잡았어요.** 삭제한 모델이 도우미, 컨텍스트 정리, 스크립트 모델로 지정돼 있었다면 지정은 남고, 다른 모델을 고를 때까지 그 역할의 호출은 오류로 멈춰요. 본문 모델로 대신 보내지 않아요. 동작은 예전과 같고, 설명서가 "기본 모델 지정이 모두 해제된다"고 잘못 적고 있었어요. [삭제와 정리](../DELETION.md)

**데이터 호환성:** SQLite 스키마 15를 유지하고 저장된 원고·번역·설정은 변경하지 않아요. 새 데이터 마이그레이션은 없어요. [업데이트 안내](../UPDATES.md)

**검증:** 전체 품질 검사, 단위 테스트, 번역·문서 검사, 브라우저의 확인 카드 시나리오와 모델 관리 화면 검사가 통과했어요. 새 도구는 합성 응답으로 도우미 실행 경로를 거쳐 확인했고, 실제 모델이 새 도구를 잘 골라 쓰는지는 실제 호출로 확인하지 않았어요.

- 새 도우미 작업: `model.register`, `model.delete`, `chat.profile.read`, `chat.profile.update`, `scene.context.update`, `chat.bookmark`, `chat.organize`, `illustration-preset.select`. `settings.update` 키: `global.mainPromptPreset`, `global.translationPromptPreset`, `global.autoTranslate`, `global.translationLanguage`, `newChat.autoRefusalRetryEnabled`, `newChat.autoRefusalMaxRetries`, `newChat.loreContext`. 모두 UI가 쓰는 저장 함수에 위임하고, 프롬프트 프리셋 적용과 자동 번역 기본값은 라우트 안의 코드를 함수로 빼서 라우트와 함께 써요.
- 확인 규칙: `helperConfirmationTrait` 하나가 `delete`(항상 보류)와 `paid`(유료 생성 확인을 켰을 때 보류)를 정해요. 이름이 `delete`·`remove`인 작업이나 `action` 값은 이 성질을 갖거나 이유를 적은 예외여야 하고, 보류되는 작업은 모두 카드 문구가 있어야 한다는 검사를 추가했어요. 사용 중인 모델의 삭제는 카드 없이 바로 거절해요.
- 검토 반영: Fable 조언자 검토에서 나온 지적 중, 한 작업에서 두 번 고친 글의 차이가 작업 전 글을 잃던 문제, 장면을 지워도 요청문 기록이 남던 문제, 사용 중인 모델 삭제가 카드부터 띄우던 문제, 책갈피 메모 기록, 바뀐 것 없는 프로필 저장이 수정 번호를 올리던 문제를 고쳤어요. 다시 그리기와 작업 다시 시도 카드가 대상 이름을 보여 주지 않는 점은 남겼어요.
- 되돌린 것: 모델 삭제 때 도우미·컨텍스트·스크립트 역할 지정을 비우는 수정은 넣었다가 되돌렸어요. 지정을 비우면 그 호출이 본문 모델로 넘어가는데, 기존 테스트(`tests/risu-native-model-selection.test.ts`)가 이를 막는 계약이에요.
