# v0.13.1

- **서재 폴더 표지**를 추가했어요. 폴더 안의 자료 이미지로 표지를 보여 주고, 원하는 표지 이미지를 직접 선택하거나 업로드할 수 있어요. 설정한 표지는 사이드바의 폴더 트리에도 표시돼요.
- **도우미 사용성**을 개선했어요. 처음 열었을 때 시작 안내를 제공하고, Enter로 메시지를 보낼 수 있어요. 대화 하단의 상태 표시도 간결하게 정리했어요.
- **번역 삽화 배치**에 판정 모델 우선 경로를 추가했어요. 이야기 UI 이미지 이름 해석을 개선하고, 일부 이미지를 사용할 수 없더라도 나머지 이야기 UI 블록을 유지해요.
- **읽기·번역 성능**을 다듬었어요. 읽기 화면과 초안 저장의 중복 작업을 줄이고, 번역 입력·이전 문맥은 필요한 시점에 준비하며, 사용하지 않은 입력을 오래 붙잡아 두지 않아요.
- **운영 안정성**을 보완했어요. 문서의 스크립트 콘텐츠 보안 정책과 브라우저 테마 색상을 개선하고, 오래된 Docker 이미지 정리에서 복구용 이미지를 보존하며 여러 태그가 붙은 이미지도 강제 삭제 없이 처리해요.

기존 **SQLite 스키마 15**를 유지해요. 일반 업데이트는 기존 봇·채팅·원고·번역·설정과 데이터 볼륨을 유지하고, 필요한 폴더 표지 저장 구조를 앱 시작 시 준비해요. [서재 안내](../LIBRARY.md) · [이야기 UI](../STORY-UI.md) · [업데이트 안내](../UPDATES.md)
