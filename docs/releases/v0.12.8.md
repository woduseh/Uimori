# v0.12.8

- Codex 삽화의 프롬프트 모델을 직접 선택할 수 있어요. 선택한 모델이 컷과 그림 프롬프트를 함께 정하고, Uimori가 그 문구를 그대로 Codex에 전달해요. 기존 설정에서는 사용하던 Codex 모델이 선택돼요.
- 채팅별로 인물 이름·외형과 참고 이미지를 저장할 수 있어요. 외형 메모는 Codex와 ComfyUI에 모두 적용하고, 실제 참고 이미지는 Codex에 첨부해요. 채팅 복사와 백업에도 인물 외형과 이미지 연결이 포함돼요.
- 삽화를 요청할 때 원하는 시점이나 구도를 적을 수 있어요. 다시 그릴 때는 같은 장면에서 바꾸고 싶은 부분을 지정하고 새 그림이 완성될 때까지 이전 그림을 볼 수 있어요.
- 자동 채팅 제목은 앱 언어에 맞춰 이야기 속 인물과 사건을 살린 작품 제목으로 생성해요. 제목 전용 최대 길이를 없앴어요.
- 내장 Phēmē 역할극·소설 프리셋을 5.5.0으로, Hermēneía를 1.2.0으로 업데이트했어요. 문맥 압축·삽화 등 고정 프롬프트와 JEV의 이미지 선택·거절 판정 기준도 다듬었어요.

SQLite 스키마는 **15**예요. 기존 작업실은 데이터 변환 없이 업데이트할 수 있어요. [업데이트 안내](https://github.com/woduseh/Uimori/blob/v0.12.8/docs/UPDATES.md)
