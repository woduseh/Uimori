# Uimori v0.11.5

완료된 장면과 도우미 답변에서 독서용 HTML 서식을 안전하게 표시하도록 지원 범위를 다듬은 패치예요.

## 변경 사항

- **루비 문자:** 일반 원문·번역·완료된 도우미 Markdown 본문에서 속성 없는 `<ruby>`·`<rb>`·`<rt>`·`<rp>`를 표시해요. 하나의 루비 묶음 안에 여러 독음 쌍을 사용할 수 있어요.
- **독서 서식:** `<u>`·`<sup>`·`<sub>`·`<mark>`·`<small>`·`<b>`·`<i>`·`<s>`·`<br>`의 제한된 형식을 지원해요. 하이라이트는 테마 색상을 따르며, 지원되지 않는 HTML과 속성 있는 태그는 문자 그대로 남겨요.
- **표시 검증:** Risu 네이티브 메시지의 HTML 생성 단계와 브라우저 Shadow DOM에서 루비 문자, 서식 표시 및 스크립트 차단을 회귀 검증해요. 생성 도중의 스트림은 여전히 원문 그대로 표시해요.

저장 원고·번역의 텍스트, 모델 호출 문맥, 기존 채팅이나 가져온 Risu 카드의 변환 규칙은 변경하지 않았어요. HTML 전체 실행은 허용하지 않아요.

## 업데이트와 데이터

앱 버전은 **0.11.5**, SQLite 스키마는 이전과 같은 **15**예요. 별도 데이터 마이그레이션은 없어요. 운영 중인 요청과 저장 작업을 마친 뒤 기존 작업실을 백업하고 업데이트하세요.

```sh
git clone --branch v0.11.5 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [업데이트 안내](../UPDATES.md)를, Oracle은 [운영 배포 안내](../ORACLE-RELEASE.md)를 참고하세요. 배포 후 설정 → 앱 정보·라이선스에서 `0.11.5`를 확인해요.

일반 본문에서 사용자의 기존 스크린샷과 완전히 같은 현상이 발생한 원인은 따로 재현되지 않았어요. 안전한 입력에 대한 합성 테스트와 브라우저 검증을 거쳤지만 모든 모델 출력 변형에서의 표시를 보장하지는 않아요.
