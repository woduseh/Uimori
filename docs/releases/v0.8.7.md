# Uimori v0.8.7

v0.8.6의 **읽기 위치 동기화와 복원 안정성**을 다듬은 패치 릴리스예요. 원고 생성·번역·책갈피 데이터 형식은 바뀌지 않아요.

## 주요 변경

- **조용한 읽기 위치 동기화:** 서버 위치 조회에 일시적으로 실패해도 반복적인 빨간 연결 경고를 띄우지 않아요. 실패 직후 10초 간격으로 다시 조회하거나 네트워크 복귀 이벤트마다 조회하지 않아요. 채팅에 진입하거나 화면으로 돌아왔을 때 다시 확인해요.
- **기기 내 읽기 위치 유지:** 정확한 로컬 스크롤 위치를 `localStorage`에 보관해 탭을 닫았다가 다시 열어도 복원할 수 있어요. 기존 `sessionStorage` 위치는 가능한 경우 자동으로 옮겨요.
- **저장소 장애 시 보호:** 브라우저의 영구 저장 공간이 부족하거나 쓰기가 차단되더라도 이전에 저장한 위치를 삭제하지 않아요. 현재 탭의 새로운 위치는 가능하면 `sessionStorage`에 임시 보관해요.
- **동기화 실패 복구:** 서버 재조회가 실패해도 앞서 확인한 정상 수정 번호를 잃지 않아요. 실제 저장 실패나 충돌 뒤에는 오래된 위치를 무조건 재전송하지 않고 다음 진입·화면 복귀에서 확인해요. 기존 다른 기기에서 이어 읽기와 수정 번호 충돌 방지는 유지해요.

## 데이터 호환성

앱 버전은 **0.8.7**, SQLite 스키마는 기존과 동일한 **15**예요. DB 마이그레이션은 없고 기존 서버 데이터·책갈피·원고는 유지해요. `localStorage`는 브라우저/오리진별로 보관되며, 브라우저 저장 데이터를 삭제하면 로컬 위치도 사라질 수 있어요. 저장소 사용 불가 시 탭을 닫은 뒤의 로컬 위치 복원까지 보장하지 않아요.

## 설치 및 업데이트

공개된 GitHub 릴리스의 `v0.8.7` 태그를 사용하세요.

```sh
git clone --branch v0.8.7 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.7`과 빌드 식별자를 확인하세요. GitHub 릴리스 발행만으로 운영 서버가 업데이트되지는 않아요.

## 검증 범위

읽기 위치 저장·충돌·로컬 캐시 이관 및 오류 복구는 단위 테스트와 합성 브라우저 테스트로 확인해요. 실제 휴대폰 종료 시점의 저장이나 모든 네트워크 장애 시나리오를 보장하지 않아요. Oracle의 이미지/DB 복제본 및 실제 HTTPS API 검증은 배포 도구에서 별도로 수행해요.
