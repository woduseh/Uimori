# Uimori v0.9.1

v0.9.0 이후 도우미의 저장 자료 복제와 프롬프트 편집을 개선한 패치 릴리스예요.

## 주요 변경

- **도우미 리소스 복제:** 도우미가 저장된 콘텐츠와 프롬프트 프리셋을 서버 안에서 직접 복제할 수 있어요. 기존 내용을 조각별로 읽어 다시 작성할 필요가 없으며, 원본은 보존하고 사본에는 새로운 식별자를 부여해요. 원본의 실행 취소 내역·선택 상태·옵션 세트는 복제하지 않아요.
- **프롬프트 부분 편집:** 도우미가 프리셋 제목을 독립적으로 수정하고 프롬프트 블록을 순서대로 추가·삭제·이동할 수 있어요. 기존 메타데이터를 보존하면서 변경을 한 번에 저장하며 실행 취소도 지원해요.
- **탐색 및 편집 대상:** 블록 개요 조회에 길이 제한을 적용하고, 검색 결과에서 바로 사용할 수 있는 편집 대상을 제공해요. 긴 메타데이터는 미리보기 또는 필요한 필드의 직접 조회로 다뤄요.
- **서재 UI:** 리소스 목록의 복제 동작이 도우미와 같은 복제 서비스를 사용하며, 복제 뒤 위치와 목록 갱신을 유지해요. 자동으로 붙는 사본 제목 길이와 이모지 경계를 처리해요.

## 데이터 호환성

앱 버전은 **0.9.1**이며 SQLite 스키마는 **15**로 유지해요. 일반 업데이트에서는 기존 사용자 데이터 볼륨·채팅·프리셋·모델 키를 보존해요. 다른 DB 스키마의 자동 변환은 제공하지 않아요.

## 설치 및 업데이트

릴리스의 `v0.9.1` 태그를 사용하세요.

```sh
git clone --branch v0.9.1 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.9.1`을 확인하세요. 릴리스 공개만으로 운영 서버가 업데이트되지는 않아요.

## 검증과 한계

리소스 복제의 원본 보존·독립 ID, 프롬프트 블록 순서와 실행 취소, 저장 및 서재 브라우저 동작을 합성 테스트로 확인해요. 실제 외부 모델을 통한 도우미 자율 작업 품질이나 유료 API의 응답은 검증 범위에 포함되지 않아요. 자세한 도구 계약은 [도우미 도구](../HELPER-TOOLS.md)를 참고해요.
