# Uimori v0.10.5

v0.10.4 이후 **과거 장면 및 사용자 입력의 미래 문맥 제어**를 추가한 패치 릴리스예요.

## 주요 변경

- **과거 입력 저장·재생성 분리:** 앞선 사용자 입력을 수정해 저장할 수 있어요. 기존 **수정 후 재생성**은 별도 채팅 분기로 동작하며 완료된 결과를 덮어쓰지 않아요.
- **입력과 장면 비활성화:** 사용자 입력만 또는 그 장면의 입력과 본문을 이후 모델 문맥에서 제외하거나 복원해요. 비활성화한 장면은 표시 상태와 장면 번호를 유지해요.
- **Risu 호환성:** 일반 채팅과 native Risu의 논리 메시지에도 변경 사항을 적용해요. 하나의 장면에 여러 사용자 메시지가 있으면 수정 입력을 한 메시지로 반영하면서 첨부 이미지를 유지해요. 편집 전 원래 입력도 볼 수 있어요.
- **요약·도우미·백업:** 이후 생성과 이야기 원문 조회, 도우미의 현재 채팅 검색, 요약 재사용 판정에 변경을 반영해요. 채팅 복사, 백업 및 transcript 내보내기/가져오기에서도 상태를 보존해요.

## 데이터 호환성과 한계

앱 버전은 **0.10.5**, SQLite 스키마 버전은 기존 **15**를 유지해요. 기존 DB에 선택적 `scene_context` 테이블을 추가하고 원래 장면·실행 기록·이미지·인증 정보는 그대로 유지해요. 이전 백업은 새 필드가 없어도 전부 활성 상태로 복원해요.

제외는 **미래 모델 문맥**에만 적용돼요. 이미 생성된 다음 장면, 개요·작가 노트와 로어에 기록된 동일 사건, 과거 Lua 부수효과는 자동 수정하지 않아요. 생성 중에는 과거 입력 변경을 제한해요. 영구 삭제 및 이후 장면 자동 재생성은 제공하지 않아요.

## 설치 및 업데이트

```sh
git clone --branch v0.10.5 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설정 → 앱 정보·라이선스에서 `0.10.5`를 확인하세요. 릴리스 게시만으로 서버가 자동 업데이트되지 않아요.

## 검증

정적 검사·프로덕션 빌드, 원본 실행 불변성, Risu native 메시지·Lua 콜백 회귀, 모델 문맥과 문맥 압축·도우미 SQL, 복사·백업 호환성, 모바일/데스크톱 입력 편집과 장면 메뉴를 검증해요. Oracle 운영 전환에는 동일 SHA의 필수 GitHub CI와 ARM64 이미지·운영 DB 복제본·실제 호스트 HTTPS/API smoke 검증을 사용해요.
