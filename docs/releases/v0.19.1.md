# v0.19.1

Docker 이미지에 MCP 작성 스킬이 빠지던 문제를 고쳤어요. 그 밖의 동작은 [v0.19.0](v0.19.0.md)과 같아요.

- **Docker 설치에서도 MCP 스킬을 제공해요.** v0.19.0의 Docker 빌드는 캐릭터 카드·로어북·프롬프트 프리셋·Risu 스크립트 스킬 파일을 이미지에 넣지 않았어요. 소스 설치는 영향이 없었어요.

**데이터 호환성:** SQLite 스키마 15를 유지하고 저장된 자료는 바꾸지 않아요. [업데이트 안내](../UPDATES.md)

<summary>변경 근거 (Claude Opus 5.5 작성)</summary>

- 범위: `v0.19.0..v0.19.1`.
- `.dockerignore`가 `docs/` 아래에서 `docs/*.md`만 빌드 컨텍스트에 넣었어요. 빌드 fingerprint는 `docs/skills/`를 포함하므로(`scripts/lib.mjs`), Oracle 배포의 이미지 검사가 이미지 안의 build identity와 소스 fingerprint가 다르다며 전환 전에 멈췄어요. 운영 앱은 바뀌지 않았어요. `docs/skills/`를 빌드 컨텍스트에 넣었어요.
