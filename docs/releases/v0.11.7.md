# Uimori v0.11.7

화면 언어를 한국어·English·日本語·简体中文 중에서 선택하고, Linux 도우미의 탐색·편집·저장 흐름을 개선한 패치예요.

## 변경 사항

- **화면 언어 선택:** 로그인 화면과 설정 → 일반에서 언어를 선택해요. 선택은 브라우저에 저장하고 같은 origin의 다른 탭에도 반영해요. 첫 접속은 한국어로 시작하며 저장 실패는 화면에 안내해요.
- **편집과 생성 보존:** 언어를 바꿔도 원고·자료·입력 초안·읽기 위치와 진행 중인 요청을 유지해요. 생성 언어와 저장 번역 언어는 화면 언어와 별도로 유지해요.
- **상태와 오류 표시:** 앱 안내, 접근성 이름, 숫자와 날짜를 선택한 언어로 표시해요. 삽화·작업 동작 실패 후 남은 오류도 언어 전환을 따라가도록 수정했어요. 외부 진단과 사용자 작성 내용은 보존해요.
- **PWA 표시:** 언어별 manifest와 푸시 안내를 지원하고, 서비스 워커가 재시작해도 저장한 표시 언어를 복구해요. OS 권한창과 설치된 앱의 manifest 갱신 시점은 브라우저·OS가 결정해요.
- **도우미 안전성:** 원격 main의 도우미 셸 수정도 포함해요. 셸 도구를 Linux 환경에서만 제공하고 검토 모드의 쓰기 제한을 유지해요.
- **토큰 기준 읽기 예산:** 모델에 전달하는 참고 자료·목록·미리보기의 기본 분량을 토큰 기준으로 계산해요. 명시한 문자 제한과 원문 좌표는 유지하고, Unicode 문자의 중간을 잘라 읽기가 진행되지 않는 경우를 처리해요. 저장 원고와 실제 프로바이더 사용량은 별개예요.
- **Linux 도우미 작업 흐름:** `uimori tools`와 `uimori call`로 셸 안에서 기존 앱 작업을 탐색·호출할 수 있어요. `uimori refresh`는 수정 중인 파일을 보존하면서 최신 저장본을 별도 파일로 제공해요. 저장 영수증·실행 취소·전송 실패 시 이미 반영된 변경의 중복 실행 방지도 보강했어요.

언어별 메시지 키·ICU 문법·인자 검사와 언어 전환·초안 보존·서비스 워커 회귀 검증을 추가했어요. 로컬 합성 검증은 실제 모델 품질, 모든 화면 조합, 실물 휴대폰 푸시나 OS 설치 수락을 보증하지 않아요. 자세한 동작은 [화면 언어 안내](../I18N.md)를 참고해요.

## 업데이트와 데이터

앱 버전은 **0.11.7**, SQLite 스키마는 기존과 같은 **15**예요. 별도 데이터 마이그레이션은 없어요. 운영 중인 작업을 마친 뒤 기존 데이터 백업과 업데이트를 진행하세요.

```sh
git clone --branch v0.11.7 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [업데이트 안내](../UPDATES.md)를, Oracle은 [운영 배포 안내](../ORACLE-RELEASE.md)를 참고하세요. 배포 후 설정 → 앱 정보·라이선스에서 `0.11.7`을 확인할 수 있어요.
