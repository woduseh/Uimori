# v0.18.1

장면의 컨텍스트 막대가 앱이 붙이는 지시문을 따로 보여 주고, 본문 모델이 이미 받은 자료를 다시 출력하느라 요청을 늘리던 일을 줄였어요. 그 밖의 화면과 생성 동작은 바뀌지 않아요.

- **컨텍스트 막대에 "앱 지시문" 구분이 생겼어요.** 앱이 모델에게 주는 작업 규칙과 이야기 UI 안내가 지금까지는 "기타"에 섞여 있었어요. 이야기 UI를 켠 실행에서는 "기타" 6.6K 토큰 중 약 6K가 이 안내였는데, 막대만 봐서는 입력이 어디에 쓰였는지 알 수 없었어요. 이제 따로 색을 받아서 보여요. [장면 작업 기록](../TURN-ACTIVITY.md)
- **본문 모델이 이미 받은 자료를 다시 읽지 않아요.** 본문 모델의 작업 공간 목록이 어떤 참고 자료와 장면이 요청에 이미 들어 있는지 표시해요. 표시가 없던 때에는 모델이 그 자료를 전부 다시 출력한 실행이 있었고, 왕복 다섯 번과 입력 약 6.8K 토큰이 더 들었어요.

**데이터 호환성:** SQLite 스키마 15를 유지하고 저장된 원고·번역·설정은 변경하지 않아요. 새 데이터 마이그레이션은 없어요. [업데이트 안내](../UPDATES.md)
