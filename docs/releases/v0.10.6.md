# Uimori v0.10.6

v0.10.5 이후 **Anthropic 프롬프트 호환성과 과거 장면의 전달 형식**을 보완한 패치 릴리스예요.

## 주요 변경

- **공통 Risu 프롬프트 사용:** 사용자 메시지 사이에 system 지시를 둔 `.risup`을 별도 Anthropic용 프리셋으로 고칠 필요를 줄였어요. `user → 연속 system → user` 배치에만 짧은 assistant 메시지를 전송용으로 한 번 추가해요.
- **원본과 이어쓰기 보존:** 저장된 프롬프트·원고·실행 스냅샷을 재작성하지 않고, 원래 메시지의 역할·순서·본문과 캐시 기준점을 유지해요. 기존에 허용되던 요청과 저장된 도구 후속 상태도 그대로 이어가며 보조 메시지를 중복 추가하지 않아요.
- **수정하지 않은 과거 장면의 형식 유지:** 과거 입력이나 문맥 상태를 바꾸지 않은 장면에는 불필요한 문맥 제어값을 붙이지 않아 기존 모델 전달 형식을 유지해요.

## 데이터 호환성과 한계

앱 버전은 **0.10.6**, SQLite 스키마는 기존 **15**를 유지해요. 이 릴리스는 DB 형식을 변경하지 않으며 원고·설정·자료·이미지·인증 정보를 보존해요. 스키마 15인 기존 설치는 정상 백업 후 업데이트할 수 있어요.

Anthropic 보정은 전송할 때만 적용돼요. 추가 assistant 발화가 모델 문맥에 들어가므로 의미와 생성 결과가 완전히 같다고 보장하지는 않아요. 모든 프롬프트·모델의 호환성이나 실제 캐시 적중을 보장하는 변경도 아니에요.

## 설치 및 업데이트

릴리스가 공개된 뒤 다음 태그로 설치해요.

```sh
git clone --branch v0.10.6 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설정 → 앱 정보·라이선스에서 `0.10.6`을 확인해요. 태그나 릴리스 게시만으로 운영 서버가 업데이트되지는 않아요.
