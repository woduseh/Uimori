# Uimori v0.11.4

장문 장면의 특정 표현을 읽고 안전하게 수정할 때 도우미의 반복 호출과 원고 전송량을 줄이는 패치예요.

## 변경 사항

- **라이브 장면 검색:** 도우미의 새 `scene.search`가 저장된 `original` 또는 표시 가능한 `translation`에서 리터럴 패턴을 찾아요. 전체 일치 개수·패턴별 개수, UTF-16 위치, 짧은 앞뒤 문맥과 `scene.patch`용 `editTarget`을 함께 돌려줘요. 여러 페이지가 필요하면 `nextSearch`를 그대로 사용해요. 오래된 검증 값은 거부하고, 검색 결과가 너무 크면 축소 재조회 경로를 안내해요.
- **정확한 다중 치환:** `scene.patch`의 변경 항목에 `expectedCount`를 선택적으로 지정해 같은 `oldText`가 정확히 N번 등장할 때 모두 치환할 수 있어요. 기본값은 이전과 동일한 1회예요. 일치 개수 불일치, 항목 간 또는 항목 내부의 범위 중첩, 오래된 버전은 **전체 저장 전** 거부해요. 정규식이나 검증 없는 `replaceAll`은 추가하지 않았어요.
- **장면 탐색 메타데이터:** `chat.read`가 활성 장면 기준 번호, 원문 길이, 장면 활성화 상태를 반환하고 `includePreview:true`일 때만 최대 120자의 원문 미리보기를 제공해요. 비활성화된 장면은 ID를 유지하지만 번호는 부여하지 않아요.
- **일관성 유지:** 기존 원문/번역 저장 검증, 번역 무효화 정책, 데이터 보존 방식은 그대로예요. `scene.read`의 페이지 제한과 동시 원문·번역 패치는 변경하지 않았어요.

## 업데이트와 데이터

앱 버전은 **0.11.4**, SQLite 스키마는 **15**로 이전 버전과 같아요. 업데이트 자체에 데이터 마이그레이션이나 저장 원고 변경은 없어요. 기존 작업을 마치고 백업한 뒤 업데이트하세요.

```sh
git clone --branch v0.11.4 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [업데이트 안내](../UPDATES.md)를, Oracle은 [운영 배포 안내](../ORACLE-RELEASE.md)를 참고해요. 배포 후 설정 → 앱 정보·라이선스에서 `0.11.4`를 확인해요.
