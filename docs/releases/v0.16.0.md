# v0.16.0

이야기 UI에 **현황 탭**이 생기고, 화면 블록이 깨졌을 때 원인을 보고 바로 고칠 수 있게 됐어요. 도우미는 이야기 UI 블록을 직접 쓰고 보여 줄 수 있고, 앱 사용 설명서를 읽고 답해요.

**업데이트 전에 확인할 것:** 자동 번역이 **번역 결과 언어**(기본값 한국어)로 이미 쓰인 본문을 건너뛰게 됐어요. 번역 프롬프트가 한국어가 아닌 언어로 번역하게 돼 있다면, 업데이트 뒤 **설정 → 일반 → 생성 기본값**에서 이 값을 그 언어로 바꾸거나 **항상 번역**을 골라 주세요. 그대로 두면 한국어로 쓴 장면은 자동 번역되지 않아요.

- **현황 탭.** 모델이 상태창·호감도·소지품처럼 장면을 넘어 이어지는 화면에 고정 이름을 붙이면, 데스크톱 사이드 패널에 **현황** 탭이 생겨요. 지금 읽는 장면 시점의 최신 화면을 보여 주므로, 앞 장면으로 스크롤하거나 분기한 채팅에서도 그 시점의 현황이 보여요. 이미 저장된 상태창에는 고정 이름이 없어서, 모델이 고정 이름을 붙여 새로 쓴 장면부터 탭이 생겨요(원문 편집에서 직접 붙일 수도 있어요). 기본 제공 스타일을 쓴 화면이면 패널 바탕도 그 색을 따르고, 이야기 UI 테마에 **현황 패널 CSS**를 넣어 따로 꾸밀 수도 있어요.
- **깨진 화면의 원인과 수정.** 변환하지 못한 블록은 접힌 상태로 표시되고, 펼치면 변환 오류(영문 메시지)와 원문을 보여 줘요. 원문 편집창에서는 화면 블록이 모델이 쓴 `<a2ui>` 형태로 보이며, 고쳐 저장하면 바로 화면으로 바뀌어요. 손대지 않은 블록과 그림 연결은 그대로 유지돼요. 화면 블록을 쓰는 동안에는 그 자리에 구성 중 표시가 나와요.
- **도우미의 이야기 UI.** 도우미가 장면의 화면 블록을 쓰거나 고칠 때 본문 모델과 같은 참고문을 읽어요. 답변 안에서도 관계도나 차트, 장면용 화면 미리보기를 읽기 전용으로 보여 줄 수 있어요. 이야기 UI 테마를 만들거나 고치면 작업 결과의 변경 카드 아래에 그 테마의 미리보기가 나와요.
- **도우미가 설명서를 읽어요.** 기능이 있는지, 어디에 있는지 물으면 앱 사용 설명서를 찾아 확인하고 답해요.
- **지난 호출의 비용 채우기.** 모델 단가를 등록한 뒤 도우미에게 요청하면, 가격 없이 기록돼 비용이 미확인으로 남은 지난 호출에 지금 단가로 추정 비용을 채워요. 호출 때 가격이 있었거나 프로바이더가 비용을 보고한 호출은 바꾸지 않아요. [사용량](../USAGE-REPORT.md#비용-계산과-단가-관리)
- **도우미의 헛걸음이 줄었어요.** 장면을 이어 읽을 때 확인값 없이 다음 쪽을 읽고, 작업실 DB 조회에서 열 이름이나 문법이 틀리면 고칠 수 있는 오류와 스키마를 받아 다시 시도해요.
- **휴대폰에서 선택 도구.** 터치로 글을 선택하면 읽기 영역 아래쪽 가장자리에 **다듬기**·**도우미에게 물어보기**·**책갈피**·**복사** 막대가 붙어요. 선택한 글이 그 자리를 가리면 위쪽 가장자리로 옮겨요.
- **같은 언어는 자동 번역하지 않아요.** 위의 **번역 결과 언어**로 이미 쓴 장면은 자동 번역을 건너뛰어요. 직접 요청한 번역은 그대로 실행해요. [자동 번역 연계](../PWA.md#알림-발송-조건과-옵션)
- **번역 거절을 바로 알아봐요.** 화면 블록이 있는 장면의 번역이 모델의 거절 문장으로 돌아오면, 형식 오류로 끝내지 않고 거절로 판정해 다시 시도해요.

**데이터 호환성:** SQLite 스키마 15를 유지해요. 이야기 UI 블록에는 선택 항목인 고정 이름(`$/_uimori/pin`)이, 이야기 UI 테마에는 선택 항목인 `boardCss`가, 자동 번역 기본값에는 번역 결과 언어가 추가됐어요. 이 항목이 없는 기존 원고와 테마 파일은 그대로 열리며, 새 데이터 마이그레이션은 없어요. [업데이트 안내](../UPDATES.md)

**검증:** 전체 품질 검사와 단위 테스트(3,200여 건), 이야기 UI·테마·사이드 패널·도우미 결과 브라우저 회귀가 통과했어요. 현황 탭 선택 규칙은 무작위 장면 체인으로 확인했어요. 실제 모델이 고정 이름을 붙이는지, 도우미가 참고문을 읽고 올바른 블록을 쓰는지는 실제 모델 호출로 확인하지 않았어요. 터치 선택 도구는 합성 터치 입력으로만 확인했고 실제 휴대폰에서는 확인하지 않았어요. 사용 설명서를 Docker 이미지에 넣는 빌드 변경은 이번 배포의 이미지 빌드에서 처음 확인해요.
