# Uimori v0.8.1

v0.8.0 이후 Risu 자료의 대용량 가져오기와 이미지 처리 경로를 안정화한 패치 릴리스예요. 기존 Gemini 연결·PDF 옵션, 로어·이미지 후보 선별 및 화면 개선은 그대로 유지돼요.

## 주요 변경

- **대규모 Risu v3 가져오기:** 가져오기 전에 큰 아카이브와 이미지 자료를 한 번 준비해 처리 단계에서 재사용하도록 정리했어요. 반복 읽기와 변환을 줄이고 큰 자료를 다루는 경로를 개선했어요.
- **이미지 준비 재사용:** 같은 Risu 자료가 서로 다른 이미지 종류로 참조돼도 준비한 이미지 데이터를 재활용하도록 수정했어요. 이 경우 불필요한 이미지 처리를 줄여요.
- **자료 형식과 오류 처리:** Risu 카드·모듈·네이티브 아카이브의 파싱 및 가져오기 경로를 분리·보완하고, 실패 메시지와 브라우저 가져오기 처리를 정리했어요.

## 데이터 호환성

앱 버전은 **0.8.1**, SQLite 데이터베이스는 계속 **스키마 15**예요. v0.8.0의 스키마 15 작업실은 데이터와 기존 설정을 유지한 채 업데이트할 수 있어요. 별도의 DB 마이그레이션은 없어요. 업데이트 전에는 일관된 백업을 확보하고 실행 중인 작업 및 저장을 완료해 주세요. 이전 스키마의 직접 변환은 제공하지 않아요.

## 설치와 업데이트

공개된 GitHub 릴리스의 `v0.8.1` 태그로 설치할 수 있어요.

```sh
git clone --branch v0.8.1 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 운영 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 뒤 **설정 → 앱 정보·라이선스**에서 앱 버전 `0.8.1`과 빌드 식별자를 확인해요. 릴리스 게시만으로 운영 서버가 자동 업데이트되지는 않아요.

## 검증 범위와 제한

새로운 가져오기 경로는 합성 아카이브·이미지 및 브라우저 테스트로 검증할 수 있지만, 모든 실제 Risu 자료의 구조·크기와 호환된다고 보장하지는 않아요. 운영 이미지·기존 DB 복제본·HTTPS와 쓰기 재개는 별도의 Oracle 배포 절차에서 확인해요.
