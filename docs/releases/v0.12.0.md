# v0.12.0

도우미를 Uimori 전반의 작업을 맡길 수 있는 넉넉한 작업 공간으로 개편했어요. 원고를 읽고 RP를 이어 가는 화면은 그대로 중심에 두고, 필요할 때 도우미를 옆에 열거나 크게 펼칠 수 있어요. **DB 스키마는 15로 유지**하며 기존 원고, 자료, 프롬프트, 설정과 도우미 대화를 보존해요.

- 탐색 메뉴의 도우미는 넓은 대화 작업 공간으로 열려요. 데스크톱에서는 대화를 검색하고 전환할 수 있고, 작은 화면에서는 제목 선택기를 사용해요. 실행 중이거나 대기 중인 대화도 구분해요.
- 원고·서재·프롬프트에서 연 도우미는 현재 작업 옆에 표시돼요. 확대와 복귀, 다른 대화 선택에서도 각 대화의 입력 초안과 원래 읽기·편집 화면을 유지해요. 편집 후 다시 확대하면 최신 입력을 반영하고, 전역 도우미에 숨겨진 편집기를 임의로 첨부하지 않아요.
- 답변에 실제 변경한 자료·프롬프트·설정이 연결돼 해당 위치를 바로 열 수 있어요. 설정 변경은 가능한 경우 이전 값과 새 값을 보여 주고, 삭제한 자료는 열기 버튼 없이 기록으로 남겨요. 일반 답변에는 불필요한 “변경 없음” 안내를 붙이지 않아요.
- 상세 사용량에서 모델 실행 요청, 도구 실행, 누적 입력·출력 토큰, 보고된 캐시·추론 토큰과 비용을 나눠 확인해요. 일부만 보고된 수치와 미확인 수치를 구분하며, 마지막 입력의 추정 토큰을 실시간 컨텍스트 점유율처럼 표시하지 않아요.
- 작업 현황에서 실패한 작업의 원인 확인을 누르면 해당 작업을 지정한 도우미 요청을 준비해요. 요청은 직접 전송하며, 원래 작업을 자동으로 재시도하지 않아요.
- 작업 공간·서재·프롬프트·설정·리더·공급자·삽화·네이티브 편집기의 중복 안내와 쓰이지 않는 문구·스타일을 정리했어요. 실제 오류의 복구 방법, 적용 범위와 저장하지 않은 변경 사항은 필요한 위치에 남겨요.

결과 목록은 확인된 변경 대상의 기록이에요. 과거 모든 작업의 변경 내용을 복원하거나 변경 한 줄씩 되돌리는 기능은 아니며, 기존 자료의 마지막 저장 복구 범위는 유지해요. 이전 작업이나 공급자가 보고하지 않은 사용량은 미확인으로 남을 수 있어요.

설치와 백업 절차는 [업데이트 안내](../UPDATES.md)를 참고해요. 로컬 합성 검증은 실제 유료 모델의 응답 품질이나 물리 기기의 입력 동작을 보증하지 않아요.
