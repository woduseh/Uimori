# v0.12.11

- 우이모리 도우미가 작업 목적에 따라 앱 작업 도구와 셸 탐색을 선택할 수 있도록 시스템 지침을 개선했어요. 셸부터 열도록 유도하는 절차는 제거하되 데이터 출처·리비전·저장 결과 검증은 유지했어요.
- `data.exec` 도구 설명을 간결하게 정리했어요. 대량 자료 탐색과 가공에는 셸을 활용하고, 집중된 앱 작업은 적절한 도구로 직접 수행할 수 있어요.
- UI 모션 스킬의 고정 작업 절차를 목표·불변 조건·영향 범위에 맞는 검증 기준으로 바꿨어요. 포커스, 접근성, 위치 안정성, 원고 보호 규칙은 유지돼요.

SQLite 스키마는 **15**로 유지하며 데이터 마이그레이션은 없어요. [개발 및 검증 안내](https://github.com/woduseh/Uimori/blob/v0.12.11/docs/DEVELOPMENT.md) · [업데이트 안내](https://github.com/woduseh/Uimori/blob/v0.12.11/docs/UPDATES.md)
