# Uimori v0.9.4

v0.9.3 이후 Android 모바일 브라우저에서 키보드를 열었을 때 입력창 아래에 빈 공간이 남는 문제를 완화하기 위한 패치 릴리스예요.

## 주요 변경

- **모바일 키보드 공간 조정:** viewport에 `interactive-widget=resizes-content`를 지정해 지원 브라우저가 소프트 키보드 등장 시 레이아웃 영역을 직접 줄이도록 요청해요. 채팅 입력창은 기존 Flex 레이아웃의 하단 배치를 그대로 사용해요.
- **호환성 유지:** 기존 `visualViewport` 높이 계산과 작성 중인 초안·한글 조합 처리를 보존하고, 불필요한 키보드 위치 강제 이동 로직은 추가하지 않았어요.
- **입력창 회귀 검사:** 좁은 화면에서 높이 축소·복원 후 입력창 하단 간격, 입력 포커스, 초안 보존과 기존 입력창 크기 동작을 검사해요.

## 데이터 호환성

앱 버전은 **0.9.4**, SQLite 스키마는 **15**예요. 일반 업데이트는 기존 운영 데이터 볼륨과 채팅, 설정 및 모델 인증 정보를 유지해요. 다른 DB 스키마에 대한 자동 변환은 제공하지 않아요.

## 설치 및 업데이트

릴리스의 `v0.9.4` 태그를 사용하세요.

```sh
git clone --branch v0.9.4 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. **설정 → 앱 정보·라이선스**에서 버전 `0.9.4`를 확인하세요. GitHub 릴리스 공개만으로 운영 서버가 업데이트되지는 않아요.

## 검증과 한계

정적 검사, 빌드, 입력창 회귀 테스트 및 릴리스 검증으로 영향 범위를 확인해요. Chromium의 화면 높이 변경 테스트는 실제 Android 소프트 키보드/삼성 인터넷의 IME를 재현하지 못해, 기기에서의 증상 해결은 배포 후 별도로 확인해야 해요.
