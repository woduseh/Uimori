# Uimori v0.8.10

v0.8.9 이후 **Gemini 도우미의 도구 호출 후속 요청**을 수정한 패치 릴리스예요. 원고·작업 데이터 및 API/DB 스키마는 변경하지 않아요.

## 주요 변경

- **Gemini 도우미의 HTTP 400 오류 수정:** Google Vertex AI에서 도우미가 도구를 호출한 뒤 추가 제어 텍스트를 도구 응답 뒤에 붙여 보내던 요청 형식을 바로잡았어요. 추가 제어 텍스트를 `functionResponse` 앞에 두어 Gemini가 후속 모델 응답을 생성할 수 있게 해요.
- **도구 호출 내역 보존:** 원본 모델 응답과 사고 서명(`thoughtSignature`), 도구 호출 식별자·응답 순서 및 추가 지시를 그대로 유지해요. Vertex AI와 Google AI Studio용 Gemini 인코더에만 적용하며 Claude·OpenAI·Codex 경로는 변경하지 않아요.

## 데이터 호환성

앱 버전은 **0.8.10**, SQLite 스키마는 **15** 그대로예요. DB 마이그레이션은 없으며 기존 작업실과 데이터 볼륨을 그대로 유지해요.

## 설치 및 업데이트

GitHub 릴리스의 `v0.8.10` 태그를 사용하세요.

```sh
git clone --branch v0.8.10 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.10`과 빌드 식별자를 확인하세요. GitHub 릴리스만 발행해서는 운영 서버가 업데이트되지 않아요.

## 검증 범위

Gemini 도구 호출·사고 서명·후속 제어 입력 및 다른 프로바이더 회귀 테스트를 수행했어요. Vertex AI의 실제 Gemini 4 Argon 모델에서 합성 읽기 도구 호출과 후속 응답이 HTTP 200으로 완료되는 것을 확인했어요. Oracle 배포는 정확한 릴리스 커밋의 GitHub CI 통과와 실제 호스트의 이미지·DB 복제본·HTTPS/API 확인을 요구해요.
