# Uimori v0.8.3

v0.8.2 이후 Risu 장면 표시와 네이티브 문맥 준비의 불필요한 연산을 줄이고, 외부 자료·서비스와의 호환성을 보완한 패치 릴리스예요.

## 주요 변경

- **긴 원고 표시 성능:** 완료된 메시지를 표시할 때 사용하지 않을 생성 문맥 전체를 다시 만들지 않도록 개선했어요. Risu 네이티브 장면의 CBS·Lua 표시와 필요한 경우의 전체 문맥 경로는 유지해요.
- **Risu 문맥 준비 성능:** 일반 텍스트에는 CBS 평가 환경을 미리 생성하지 않고, 실제 카드 표현식 파싱이 필요할 때만 준비해요. 기존 변수·역할 및 표시 결과는 유지해요.
- **Risu·캐릭터 자료 호환성:** CCv3 PNG의 기본 표지와 이름이 있는 첨부물을 보존하고, `icon`/`main` 인물 이미지를 우선해요. 지원 대상 Risu Lua의 역할 별칭과 중지 트리거도 처리해요.
- **이미지 생성·모델 오류 처리:** ComfyUI에 삽입한 프롬프트 문구를 그대로 유지하고, 히스토리 조회 중 HTTP 오류가 발생해도 이미 수락된 프롬프트 ID를 보존해 불확실한 작업을 자동 재제출하지 않아요. DeepSeek의 중단 사유를 구분하면서 부분 응답과 사용량을 유지해요.
- **테마 호환성:** 테마 HTML을 비활성 조각으로 파싱한 다음 정제해 맨 앞의 스타일도 보존하고, 지원하지 않는 스크립트는 명시적으로 안내해요.
- **유지보수:** 중복 래퍼와 불필요한 테스트 구조를 정리하고 외부 연동 계약 검토 및 성능 측정 도구를 추가했어요.

## 데이터 호환성

앱 버전은 **0.8.3**, SQLite 스키마는 계속 **15**예요. 스키마 15를 사용 중인 v0.8.2 작업실의 자료와 설정을 유지해 업데이트할 수 있으며 별도 DB 마이그레이션은 없어요. 업데이트 전에 일관된 백업을 확보하고 진행 중인 저장·생성을 마무리해 주세요. 이전 스키마의 직접 변환은 지원하지 않아요.

## 설치·업데이트

공개된 GitHub 릴리스의 `v0.8.3` 태그를 사용하세요.

```sh
git clone --branch v0.8.3 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md)를, Oracle 운영 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 참고하세요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.3`과 빌드 식별자를 확인하세요. 릴리스를 발행해도 기존 서버는 자동 업데이트되지 않아요.

## 검증 범위와 제한

Risu·외부 자료 호환성, 성능 및 오류 복구는 합성 입력과 로컬 검증 범위에 한정돼요. 실제 외부 모델 API의 응답 품질, ComfyUI GPU 작업, 모든 Risu 데스크톱 자료의 동작은 확인하지 않았어요. 운영 이미지·기존 DB 복제본·HTTPS 및 쓰기 재개 상태는 Oracle 배포 절차에서 별도로 확인해요.
