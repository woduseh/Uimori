# v0.11.21

로어의 연속성과 에이전트 조회 효율을 개선한 패치 릴리스예요. DB 스키마는 15로 유지해요.

- JEV가 선택한 로어를 성공한 생성 이후에도 유지해요. 이미 제공한 본문을 반복 선별하지 않고, 조회 로어 제거 또는 실제 대화 압축 시 재구성해요.
- 대화 정리를 마친 뒤 요약·최근 대화로 로어를 선별해요. 큰 목록의 사전 검색에도 요약을 반영해 짧은 이어쓰기 요청에서 필요한 설정을 찾도록 했어요.
- 동적 로어는 해당 턴의 참고 자료로 제공해요. 페메 v5.4.4 원본과 RisuAI 공통 프리셋은 수정하지 않으며, 대화 범위·캐시 기준점·명시적인 native 로어 위치를 유지해요.
- Linux runner가 설정된 메인 모델은 Bash·rg·jq·Python으로 복합 조회를 한 번에 수행할 수 있어요. 현재 자료부터 준비하고 다른 서재·대화는 필요할 때 읽어요. 큰 출력은 전체 로그를 남겨 원래 명령을 다시 실행하지 않고 필요한 부분을 확인할 수 있어요.
- 긴 단일 로어 읽기를 개선하고, 도우미·번역의 고정 누적 조회 제한을 실제 모델 입력 예산에 맞췄어요. Shell은 명시적으로 최대 5분 실행과 최대 64KB 출력 미리보기를 요청할 수 있고, Lua 모델 호출은 프로바이더의 실행 기한을 따라요.

정적 검사·빌드, 영향받은 실행 경로와 실제 Linux shell, 페메의 직접/번들 가져오기 및 요청 인코딩을 검증했어요. 실제 모델의 이야기 품질·비용·캐시 적중률 개선 수치를 의미하지는 않아요. 설치 및 데이터 보존 절차는 [업데이트 안내](../UPDATES.md)를 참고해요.
