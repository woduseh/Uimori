# v0.12.5

자료 저장과 복제의 **결과 불명 상태**를 안전하게 복구하도록 개선했어요. 기존 원고·자료·대화·이미지를 보존하며 **SQLite 스키마는 15로 유지**해요.

- 새 봇·페르소나·모듈·프롬프트·테마·삽화 프리셋을 생성하거나 서재에서 복제할 때, 요청별 멱등성 키를 사용해요. 서버가 저장했지만 응답만 유실되더라도 같은 요청으로 생성 결과를 재확인하므로 새 사본을 만들지 않아요.
- 서버는 기존 영수증 저장소에 작은 생성 식별자만 영속적으로 기록해요. 자료 생성과 영수증 저장이 하나의 트랜잭션이므로 부분 성공을 남기지 않아요. 오래된 클라이언트에서 요청 키를 보내지 않는 경우에는 기존 동작을 유지해요.
- 편집기의 결과 미확정 요청은 기기 내의 미저장 초안과 분리된 저장 항목으로 보관해요. 다른 탭의 입력을 덮어쓰지 않으며, 복구 성공 전에 입력한 후속 수정도 유지해요. 원래 요청을 확인할 때 후속 입력이 아직 문법적으로 완성되지 않았더라도 그 입력으로 원래 요청을 바꾸지 않아요.
- 다른 창에서 자료가 바뀌어 충돌한 뒤 사본 저장이 실패해도 충돌 경고를 유지해요. 실제 저장이 성공하거나 사용자가 저장본을 다시 확인할 때만 해제해요.
- 복구 저장소 읽기·쓰기 실패 시 무작정 신규 생성 요청을 보내지 않아요. 명확한 서버 거절 뒤에는 현재 수정 내용으로 새 요청을 시작할 수 있어요. 복구 관련 안내는 한국어·영어·일본어·중국어(간체)로 표시해요.

자료 저장과 복제는 [편집 안내](../EDITING.md), 설치 및 업데이트는 [업데이트 안내](../UPDATES.md)를 참고해요. 검증은 로컬 합성 데이터·브라우저 테스트를 중심으로 하며 외부 네트워크 중단의 모든 형태를 재현한 것은 아니에요.
