# v0.14.0

- **NovelAI로 장면 삽화를 그릴 수 있어요.** 삽화 프리셋에서 NovelAI를 고르면 프롬프트 모델이 NovelAI 태그 프롬프트를 써요. 등장인물마다 프롬프트·위치·부정 프롬프트를 따로 보내요. V4.5 모델에서는 캐릭터 참고 이미지를 쓸 수 있고, 연결 확인에서 Anlas 잔액을 보여 줘요. NovelAI는 사람이 직접 시작한 생성만 허용하므로 자동 재시도를 하지 않아요. [삽화](../ILLUSTRATIONS.md)
- **Gemini 4 Neon을 고를 수 있어요.** Google Agent Platform(Vertex)과 Google AI Studio 모델 목록에 추가했고, 사고 수준에 새 xhigh가 생겼어요. 기본 사고 수준은 high예요. [모델 파라미터](../MODEL-PARAMETERS.md)
- **Vertex 위치 비교에서 바로 위치를 바꿀 수 있어요.** 응답한 위치마다 "이 위치로 변경"이 붙어요.
- **화면 정리**
  - 설정이 상속하는 값은 모두 **기본값**으로 부르고, 다른 화면을 가리킬 때는 `설정 > 역할별 모델`처럼 메뉴 이름을 써요. 영어·일본어·중국어도 한국어 용어에 맞췄어요.
  - 남아 있던 상시 안내와 방어적 설명을 더 줄였어요. 하드코딩된 한국어 문구도 번역돼요.
  - 고정 옵션 모두 지우기, 폴더 삭제, Codex 연결 해제처럼 지우거나 끊는 동작은 한 번 확인해요.
  - 휴대폰에서는 입력 번역이 입력창 더보기 메뉴로 들어가서 요청 입력칸이 넓어졌어요.
  - 이미지가 없는 봇과 페르소나는 서재에서 이름 첫 글자 표지로 보여요.
  - 팔레트는 카드의 메뉴에서 편집·복제·내보내기·삭제해요. 중복 목록은 없앴어요.
  - 채팅 생성 설정은 본문 모델·창작 프롬프트부터 쓰는 순서대로 놓였어요.
  - **새 채팅 기본값**은 자동 번역처럼 바꾸는 즉시 저장돼요. 호출 한도는 입력란을 벗어나거나 Enter를 누를 때 저장해요.
  - 밝은 테마의 상태 문구 대비를 높였고, 본문에 등록 글꼴을 쓸 때 그 글꼴이 우선한다고 표시해요.
- **예전 저장 형식을 더는 읽지 않아요.** 지금 형식으로 바뀐 지 오래된 기록을 읽던 코드를 정리했어요. 서버가 DB를 열 때 남은 예전 형식 기록을 한 번에 지금 형식으로 고쳐 써요.

기존 **SQLite 스키마 15**를 유지해요. 업데이트 뒤 처음 시작할 때 예전 형식으로 남은 채팅 제목 이벤트, 삽화 설정·프리셋·작업, 도우미 기록, 모델 설정을 지금 형식으로 고쳐 써요. 이 단계는 한 트랜잭션이고, 이미 고친 기록과 JSON이 깨진 기록은 건드리지 않아요. **v0.13.4가 예전 형식을 읽는 마지막 버전이에요.** 오래된 백업을 보관한다면 v0.13.4 앱과 함께 보관하세요. 업데이트 뒤 DB를 복원하지 않고 앱만 v0.13.4로 되돌리면 삽화 설정을 저장할 수 없어요. 되돌릴 때는 업데이트 전 백업도 함께 복원하세요. 변경 커밋은 `v0.13.4..v0.14.0` 범위에 있어요.

- **NovelAI:** API 토큰은 자격 증명 표에만 저장하고 설정 응답·작업 입력에 넣지 않아요. 요청은 고정된 NovelAI 주소로만 보내요(`4f380ec5`, `4841a932`, `f3d3bb55`).
- **UI 검토 반영:** gemini-4-neon의 UI/UX 검토와 재검토를 반영했어요(`911d1cfd`부터 `fe74e423`까지).
- **주석과 우회 구현 정리:** 코드를 설명만 하던 주석을 지웠고, `npm run quality`가 허용되지 않은 주석을 거부해요(`517e71f5`). 타이머와 sleep에 기대던 리더·테스트 동기화를 조건 기반으로 바꿨어요.
- **저장 형식 업그레이드:** `server/stored-shape-upgrades*.ts`. 대상 기록 수는 운영 DB와 11-18·11-19 백업을 읽기 전용으로 세어 확인했어요. 시작할 때 예전 형식인 행만 SQL로 골라 고치고, JSON이 깨진 행 때문에 서버가 시작되지 않는 일은 없어요(`6ef7d115`). v0.13.0까지 브라우저에 쓰던 첨부 초안 형식은 셀 수 없어서 읽기를 유지해요(`f6932271`).
- **Gemini 4 Neon:** 사고 수준, 기본값, `MINIMAL` 거절, 무시되는 샘플링 값, 65,536토큰 제한은 2026-11-20의 Vertex 모델 가이드와 AI Studio 모델 카드를 따랐어요(`e25391aa`).
- **릴리스 전 검토:** Fable 조언자가 전체 범위를 검토했어요. 지적 중 첨부 초안 읽기와 시작 시 업그레이드 비용·실패 범위는 이번에 고쳤고, 폐지된 평가 설정이 남은 번역 작업은 운영 DB와 백업 두 곳에서 0건으로 확인했어요.
- **브라우저 검증 병렬화:** `verify:browser`가 작업자마다 서버와 DB를 따로 띄워 병렬로 실행해요. 로컬 전체 회귀가 약 38분에서 약 5분으로 줄었어요(`68c61d71`). 테스트끼리 전역 테마·팔레트 상태가 새던 문제도 고쳤어요.
- **로컬 검증:** quality, 전체 Vitest, tooling 테스트, 전체 브라우저 회귀를 통합 브랜치와 최종 후보에서 확인했어요.
- **배포 검증:** 배포할 때 해당 소스 커밋의 GitHub CI 전체 검증(브라우저 회귀 포함), Oracle에서의 실제 이미지 부팅, 운영 DB 복제본 호환성, 백업, HTTPS/API 검사를 거쳐요.
- **검증하지 않은 것:** 실제 NovelAI 생성 품질과 Anlas 표시값, 실제 Gemini 4 Neon 호출, 실제 Vertex 위치 변경 호출, 실제 휴대폰에서의 렌더링이에요.
