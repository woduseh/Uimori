# v0.12.18

- **안내 문구**에서 반복되는 설명을 덜고, 오류와 조작 이름을 간결하게 다듬었어요. 저장 충돌과 복구에 필요한 안내는 해당 작업 곁에 표시해요.
- **작은 화면**에서 설정 선택기, 첨부 오류, 테마 카드와 확인창의 문구·버튼이 겹치지 않도록 배치를 조정했어요. 한국어 안내는 어절 단위로 줄바꿈해요.
- **작성창과 도우미**의 완료 알림은 입력 중인 초안을 가리지 않도록 위치를 조정했어요. 긴 첨부 파일명은 안내 안에서 스크롤할 수 있어요.
- **장면·프롬프트·모델 설정**에서 화면 크기 전환과 저장 실패 후 확인 안내를 개선했어요. 저장된 항목과 작성 중인 내용은 유지해요.
- **영어·일본어·중국어** 수량 표기와 일부 오류·요금 안내를 정리했어요. 직접 입력한 다른 요금 메모는 그대로 표시해요.
- **사용자 문서**는 설치·업데이트와 기능별 사용 안내를 읽기 쉽게 정리했어요.

기존 봇·페르소나·채팅·원고·삽화·설정은 유지돼요. **SQLite 스키마 15**를 유지하며 데이터 마이그레이션은 없어요.
