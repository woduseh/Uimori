# Uimori v0.10.2

v0.10.1 이후 **사이드바 탐색과 활동 목록 사용성**을 개선한 패치 릴리스예요.

## 주요 변경

- **탐색 위치 정리:** 사이드바의 말풍선(봇·채팅)과 받은 편지함(활동) 아이콘 전환을 서재·프롬프트 아래로 옮겼어요. 접힌 아이콘 레일과 모바일 탐색 서랍에도 동일하게 반영했어요.
- **접이식 활동 그룹:** 확인할 활동 → 진행 중 → 최근 채팅 → 최근 도우미 작업 순서로 표시해요. 그룹별로 펼침 여부를 저장하며, 접혀 있어도 작업 수를 확인할 수 있어요.
- **목록 단계적 표시:** 펼친 활동 그룹 및 봇 내부 채팅 폴더는 처음 5개를 표시하고, 버튼을 누를 때 최대 20개씩 더 보여줘요. 접었다 펼쳐도 현재 표시 수는 유지하고, 새로고침 후에는 5개부터 시작해요.
- **최근 채팅의 일관성:** 확인할 활동이나 진행 중인 작업이 있는 채팅도 최근 채팅 목록에서 찾을 수 있어요. 도우미 작업은 폴더화하지 않고 시간순으로 유지하며 소속 채팅 정보를 함께 표시해요.
- **선택 채팅과 정렬 보호:** 현재 선택한 채팅이 첫 5개 밖에 있으면 상단의 이동 전용 바로가기로 보여줘요. 채팅 일부가 숨겨져 있어도 드래그 이동 시 올바른 위치에 삽입하고, 해당 바로가기 자체는 드래그 정렬 대상에서 제외해요.

## 데이터 호환성과 한계

앱 버전은 **0.10.2**, SQLite 스키마는 기존 **15**를 유지해요. 기존 채팅, 폴더, 활동 확인 기록, 운영 데이터 볼륨 및 인증 정보를 그대로 유지해요. 서버의 `/api/chats`와 `/api/activity-feed`는 종전처럼 전체 메타데이터와 최근 활동 기록을 조회하며, 이번 5개·20개 제한은 **화면 렌더링 단계**에 적용해요. 따라서 서버 전송량을 줄이는 API 페이지네이션을 도입한 것은 아니에요.

## 설치 및 업데이트

```sh
git clone --branch v0.10.2 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설정 → 앱 정보·라이선스에서 버전 `0.10.2`를 확인하세요. 릴리스 게시만으로 운영 서버가 자동 업데이트되지는 않아요.

## 검증

코드 정적 검사·프로덕션 빌드·브라우저 내 탐색/모바일/채팅 정렬 및 알림 이동 회귀 검증을 수행했어요. 최종 릴리스 SHA에 대한 GitHub 필수 CI 통과와 Oracle 이미지·데이터베이스·HTTPS 검증을 거쳐 운영 배포를 확정해요. 브라우저 합성 테스트만으로 실제 사용자 데이터의 모든 조합을 보장하지는 않아요.
