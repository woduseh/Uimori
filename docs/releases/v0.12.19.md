# v0.12.19

- **이야기 UI**를 켜면 모델이 본문 사이에 메시지 창, 게시판, 상태표, 선택지 등을 구성해요. 탭·입력·표·그래프 같은 공통 구성 요소를 조합하므로 봇마다 별도 HTML을 작성할 필요가 없어요.
- **화면 스타일**은 기본, 동양풍, 서양 판타지, 현대, 시대극 중 채팅별로 선택해요. 저장된 화면과 생성 중 화면에 적용하며 원문 데이터는 유지해요.
- **화면 속 행동**은 짧은 대화 또는 다음 장면 생성으로 이어져요. 주사위 결과는 한 번 기록해 재시도에도 유지하고, 이전 장면의 행동은 기존 채팅 분기로 이어갈 수 있어요.
- **장문·번역·Risu 호환**을 함께 지원해요. 완성된 UI 블록부터 표시하고, 번역은 구조와 행동을 보존해 문구만 바꿔요. 미전송 입력은 같은 브라우저 탭에서 원문·번역을 전환해도 유지돼요.
- **판단 프로바이더**를 역할별 모델 설정에서 선택할 수 있어요. 기존 TypeSafe AI / JEV 외에 OpenAI·Gemini Decisions와 호환 API를 사용할 수 있으며, 기존 설정의 기본값은 유지해요.

이야기 UI는 **채팅 설정 → 생성 설정 → 이야기 UI**에서 켜요. 사용법과 지원 범위는 [이야기 UI](../STORY-UI.md), 판단 연결 방법은 [프로바이더](../PROVIDERS.md#판단-프로바이더)를 참고해요. 실제 모델이 만드는 화면의 완성도는 모델과 요청에 따라 달라요.

기존 봇·페르소나·채팅·원고·삽화·설정은 유지돼요. **SQLite 스키마 15**를 유지하며 데이터 마이그레이션은 없어요.

이야기 화면은 A2UI 1.0과 원문에 저장된 화면 데이터를 사용해요. 기존 생성·번역·분기·백업 경로에 연결하고 별도 저장 서비스는 추가하지 않았어요. 초기 SDK 실험 앱은 제품에서 제외하고 실제 채팅 경로의 검증을 사용해요. 사용자가 제출한 이벤트를 서버에서 다시 계산하던 입력 검증을 줄이고, 원문 확인·중복 제출 방지·서버 주사위 기록은 유지했어요.

로컬 검증은 합성 모델 응답을 사용하며, 유료 제공사의 실제 화면 생성 품질을 입증하지 않아요. 검증 절차는 [개발 안내](../dev/DEVELOPMENT.md), 운영 업데이트 절차는 [업데이트 안내](../UPDATES.md)에 있어요.
