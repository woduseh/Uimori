# v0.13.2

- **사이드바에서도 폴더 표지**를 바꿀 수 있어요. 서재와 사이드바의 폴더 메뉴가 같은 표지 선택 창을 사용해요.
- **입력과 화면 반응**을 가볍게 했어요. 요청을 입력하는 동안 앱 전체를 다시 그리지 않고, 시작할 때 선택한 언어의 화면 문구만 불러와요. 목록 아바타와 폴더 표지는 작은 썸네일로 보여 줘요.
- **끝난 실행의 저장 공간**을 줄였어요. 실패·취소·중단·거절 등 원문 없이 끝난 실행은 표시와 재시도에 필요한 정보만 남기고 고정해 둔 입력 사본을 정리해요. 이런 실행이 쌓여 읽기 화면이 느려지던 문제를 줄였어요.
- **Lua 스크립트 처리**가 빨라졌어요. 채팅 기록은 스크립트가 실제로 읽거나 쓸 때만 해독해요.
- **도우미 도구 오류**가 고칠 항목을 알려 줘요. 잘못된 필드·허용 범위를 안내해 한 번에 바로잡을 수 있고, 검토된 Claude 모델에서는 반복되는 요청 앞부분을 캐시해요.
- **번역 삽화 배치**를 한 번만 해요. 자동 번역이 예약된 장면은 번역본에만 이미지를 배치하고, 원문 배치는 장면 메뉴에서 요청할 때 실행해요.
- **안내 문서**를 현재 화면과 동작에 맞게 정리했어요. 판단 프로바이더 구조, 바뀐 화면 이름(플롯·분기 등)과 현재 한도를 반영했어요.

기존 **SQLite 스키마 15**를 유지해요. 업데이트 후 처음 시작할 때 이전에 원문 없이 끝난 실행의 고정 입력을 한 번 정리하며, 장면 원문·번역·요청과 재시도 정보는 유지해요. [업데이트 안내](../UPDATES.md) · [실행 입력](../EXECUTION.md)
