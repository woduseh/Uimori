# v0.11.17

작업 메뉴와 설정을 간결하게 정리한 패치 릴리스예요. DB 스키마는 15로 유지해요.

- 장면·자료·프롬프트·모델·폴더 등의 메뉴를 작업별로 묶고 삭제를 마지막에 분리했어요.
- 글꼴 선택과 실제 적용 미리보기를 연결하고, 등록·삭제는 접힌 글꼴 관리로 옮겼어요. 접어도 입력 중인 파일과 이름은 유지해요.
- 연결이 끊긴 기억은 항목이 있을 때만 건수와 함께 표시해요. 실패 안내와 재시도는 접힌 내용 밖에 유지해요.
- 설정 목록에 이미 불러온 현재 값과 미저장 상태를 표시해요. 새로고침·직접 요약 작성·AI 요약 압축을 버튼 이름에서 구분해요.
- 모바일의 중복 여백과 글꼴 미리보기 높이를 줄였어요.
- 테마·팔레트·글꼴 선택을 바로 노출하고 만들기·가져오기·코드 편집은 테마 관리로 분리했어요. 기존 적용 범위와 편집 초안 보호는 유지해요.
- 전체 채팅 검색에서 선택지가 하나뿐인 범위 메뉴를 제거했어요.
- 도우미 작업 기록의 긴 요청은 세 줄로 접고 전체 보기를 제공해요. 원문 복사, 실패 사유와 저장한 변경 결과는 유지해요.

관련 모바일·데스크톱 브라우저 흐름, 저장 실패·초안 보존·테마 범위와 읽기 상태를 검증했어요. 설치 및 데이터 보존 절차는 [업데이트 안내](../UPDATES.md)를 참고해요.
