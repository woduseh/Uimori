# Uimori v0.9.6

v0.9.5 이후 도우미 작업을 더 쉽게 찾아보고, 과거 대화를 안전하게 분기할 수 있도록 개선한 패치 릴리스예요.

## 주요 변경

- **최근 도우미 작업:** 기존 최근 작업 화면에 작품 및 서재 도우미의 작업을 함께 표시하고, 해당 세션과 실행 기록으로 이동할 수 있어요. 진행·완료·실패 상태와 확정된 앱 작업 영수증 건수를 구분해요. 요청 본문은 활동 목록에 노출하지 않아요.
- **대화 분기:** 도우미 세션 메뉴에서 마지막 정상 완료 응답까지의 대화문을 독립된 새 세션에 복사해요. 모델 호출·도구 실행·저장된 변경·사용량은 복제하거나 재실행하지 않아요. 원본 세션을 삭제해도 분기된 대화와 과거 대화 검색은 유지돼요.
- **분기 중 전환 보호:** 네트워크 응답이 늦게 도착하는 동안 다른 세션을 선택했다면, 분기 완료 응답이 현재 선택을 강제로 바꾸지 않아요.
- **Gemini 4 Argon:** 모델 지원 정보와 사고 강도·직접 REST 출력 한도 처리를 보완했어요. Gemini 암묵적 캐싱은 계속 프로바이더가 관리하며, 다중 세션에서 실제 캐시 적중률을 높였다는 검증은 아직 없어요.
- **기존 동작 보존:** 자동 컨텍스트 압축, 도우미 작업별 실행 격리, 편집 영수증 및 요청 복구 경로를 유지해요.

## 데이터 호환성

앱 버전은 **0.9.6**, SQLite 스키마 버전은 **15**를 유지해요. 기존 15 버전 DB에는 도우미 분기의 텍스트 기록을 위한 `helper_seed_messages` 테이블만 추가해요. 일반 업데이트에서 운영 데이터 볼륨, 채팅, 설정 및 모델 인증을 보존하고, 기존 데이터를 초기화하지 않아요. 다른 DB 스키마를 자동 변환하지 않아요.

## 설치 및 업데이트

릴리스의 `v0.9.6` 태그를 사용하세요.

```sh
git clone --branch v0.9.6 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. **설정 → 앱 정보·라이선스**에서 버전 `0.9.6`을 확인하세요. GitHub 릴리스 공개만으로 운영 서버가 업데이트되지는 않아요.

## 검증과 한계

도우미 대화 분기/과거 기록 검색, 최근 작업 이동, Gemini 요청 인코딩, 세션 전환 지연 응답을 합성 테스트와 브라우저·정적·빌드 검사로 확인해요. 실제 Gemini 4 Argon API 캐시 적중률과 비용, 모든 외부 모델의 반응은 합성 검증만으로 증명할 수 없어요.
