# Uimori v0.11.9

모바일 원고 읽기 화면에서 장면 작업 현황의 펼친 상세 패널이 좁게 표시되던 문제를 고친 패치예요.

## 변경 사항

- **장면 작업 상세 너비:** 장면 제목과 원문·번역 전환 버튼은 같은 헤더 줄에 유지하고, 펼친 작업 상세·번역 상태·토큰 사용량·실행 정보는 장면 헤더의 전체 가로폭을 사용해요. 휴대폰에서 빈 공간이 남거나 내용이 불필요하게 줄바꿈되던 현상을 개선했어요.
- **모바일 화면 검증:** 320px·412px·1440px 화면에서 펼친 패널 너비, 전환 버튼의 배치, 가로 스크롤 발생 여부를 확인하는 브라우저 회귀 검사를 추가했어요. 좁은 320px 화면의 스크린샷도 남겨요.

## 호환성과 검증

이 변경은 CSS와 브라우저 회귀 테스트에 국한되며 원고 내용·저장 데이터·생성 및 번역 로직에는 영향을 주지 않아요. **SQLite 스키마 15**를 유지하고 데이터 변환은 필요하지 않아요. 기존 작업 현황 펼침 상태와 원문·번역 전환 동작은 유지해요.

기존 설치는 [업데이트 안내](../UPDATES.md)를, 오라클 운영 인스턴스는 [Oracle 릴리스 절차](../ORACLE-RELEASE.md)를 따라 업데이트하세요. 출시 버전은 설정 → 앱 정보에서 확인할 수 있어요.
