# v0.15.4

Gemini 4 도우미가 **Google AI Studio(AIS)**와 **Vertex AI**에서 실시간 웹 검색을 사용할 수 있게 됐어요. 원고를 읽거나 수정하는 앱 도구도 이전처럼 함께 사용할 수 있어요.

- **도우미가 필요할 때 웹을 검색해요.** Gemini 4 모델에서 `web.search` 도구를 제공해요. 최신 소식, 역사·장소 자료, 원고의 사실 확인 등 작업에 도움이 된다면 모델이 검색을 선택해요. 검색어의 주제나 길이, 창작 자료 활용 여부를 별도의 규칙으로 제한하지 않아요. 읽기 전용 검토 모드에서도 검색을 사용할 수 있어요.
- **검색과 앱 도구는 함께 동작해요.** Google의 `generateContent`는 한 요청에서 Google Search와 앱 함수 선언을 함께 쓸 수 없어서, 검색할 때에만 **같은 모델·연결을 이용한 검색 전용 요청을 추가**해요. 결과와 출처를 도우미에게 전달하고, 다음 단계에서 기존 앱 도구를 그대로 사용할 수 있어요. 검색 전용 호출에는 대화 전체나 원고 전체를 자동 첨부하지 않고 도우미가 만든 검색어만 전달해요.
- **검색 결과를 구분해 보여 줘요.** 출처 링크를 도우미에게 전달하고 Google Search Suggestions가 오면 작업 결과에 격리된 iframe으로 표시해요. 확인할 수 있는 출처가 없다면 검색으로 검증된 사실인 것처럼 꾸미지 않아요.
- **기존 호출 한도와 비용 기록을 유지해요.** 검색용 호출도 도우미 전체 모델 호출 횟수와 사용량에 합산돼요. 검색마다 추가 모델 요청 및 Google Search Grounding 요금이 부과될 수 있어요. Gemini 4 이외의 모델과 다른 프로바이더는 기존 동작을 유지해요.

**데이터 호환성:** SQLite 스키마 15를 유지하고 기존 원고·채팅·모델 설정은 바꾸지 않아요. 새 마이그레이션도 없어요. [데이터 호환성](../DATA-MIGRATIONS.md) · [업데이트 안내](../UPDATES.md)

**검증 범위와 알려진 문제:** AIS·Vertex 양쪽 요청 인코딩, 도우미의 검색→후속 작업, 출처·검색 제안 저장, 호출 사용량 집계를 합성 프로바이더 응답으로 테스트했어요. 실제 Google API 검색(유료 호출), 모든 모델·리전·계정에서의 검색 가용성, 휴대폰에서 검색 제안 렌더링은 검증하지 않았어요. Oracle 기본 HTTPS/API smoke도 유료 모델 호출은 하지 않아요.
