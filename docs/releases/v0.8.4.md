# Uimori v0.8.4

v0.8.3 이후 작업실 전반의 사용자 피드백과 화면 배치를 일관되게 정리하고, 오류 상황에서 기존 입력·자료를 지키도록 보완한 패치 릴리스예요.

## 주요 변경

- **안내·로딩 일관화:** 응답 대기, 번역, 설정, 집필 작업에 공통 알림과 로딩 표시를 적용하고, 중복 알림과 불필요한 오류 반복을 줄였어요.
- **실패 후 복구:** 읽기 재시도와 내보내기·백업 오류 표시를 보완했어요. 오류가 발생해도 이미 받은 본문과 저장하지 않은 초안은 가능한 한 유지해요.
- **설정 저장과 가져오기:** 저장 성공 이후 새로고침 실패를 별도 경고로 다루고, 리소스 가져오기 재시도에 기존 요청 식별자를 유지해 중복 생성을 피하도록 했어요. 더 최신의 설정을 확인하기 전에는 폴더 수정의 원래 리비전을 유지해요.
- **레이아웃과 조작:** 좁은 화면의 입력창·도우미·내보내기·탭 배치를 조정했어요. 줄바꿈되는 편집기 헤더 높이를 반영해 고정 내비게이션이 버튼을 가리지 않도록 했어요.
- **대화상자와 입력 보존:** 모델 목록 재조회로 초안이 사라질 상황에는 확인을 요청하고, 접은 폼의 메타데이터 입력을 유지하도록 했어요.
- **회귀 검증:** 설정, 도우미, 삽화, 작업실 및 모바일 화면의 합성 브라우저 테스트를 보강했어요.

## 데이터 호환성

앱 버전은 **0.8.4**, SQLite 스키마는 계속 **15**예요. 스키마 15를 사용 중인 v0.8.3 작업실은 기존 데이터를 유지하며 업데이트할 수 있고, 별도의 DB 마이그레이션은 없어요. 배포 전에는 진행 중인 작업을 마치고 일관된 백업을 확보해 주세요. 이전 스키마의 직접 변환은 지원하지 않아요.

## 설치·업데이트

공개된 GitHub 릴리스의 `v0.8.4` 태그를 사용하세요.

```sh
git clone --branch v0.8.4 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md)를, Oracle 운영 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 참고하세요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.4`와 빌드 식별자를 확인하세요. 릴리스 발행만으로 서버가 자동 업데이트되지는 않아요.

## 검증 범위와 제한

기존 변경의 로컬 단위·통합 및 합성 브라우저 검증은 실제 외부 모델·GPU 작업이나 모든 물리 기기의 동작을 보장하지 않아요. 운영 이미지, 기존 DB 복제본 및 HTTPS/API 검증은 Oracle 배포 절차에서 따로 확인해요.
