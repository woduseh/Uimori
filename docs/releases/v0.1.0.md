# Uimori v0.1.0

긴 원고를 읽고 다음 장면을 이어 쓰는 **개인용 창작 작업실**의 첫 0.1 릴리스예요. 실제 사용 흐름을 하나의 버전으로 묶는 초기 개발 릴리스이며, 1.0 수준의 API·자료 형식 호환성을 약속하지 않아요.

## 주요 기능

- 봇별 채팅·폴더, 독립 채팅 복사, 원문·번역 편집, 이야기 메모와 자동 요약.
- Risu CHARX·RISUM·RISUP 가져오기/내보내기와 지원 범위 내 CBS·Lua·정규식·HTML/CSS 실행.
- 앱에서 프로바이더·API 키와 역할별 모델 설정, 선택형 Codex 연결·JEV 판단·장면 삽화.
- 사용자 테마·색상·Custom HTML/CSS, 봇별 번역 지침, 전송 전 입력 번역과 저장된 요청 복사.
- SQLite 전체 백업과 개별 자료·채팅 백업, 모바일 읽기·설정 화면, 개인 작업실에 맞춘 저장·읽기 경량화.

이번 릴리스 정리에서는 **설정 → 앱 정보·라이선스**에 `v0.1.0`을 표시하고, Codex 연결에도 같은 패키지 버전을 전달하도록 통일했어요. 빌드 식별자는 별도로 유지하며 DB 버전은 변경하지 않아요.

## 설치와 업데이트

Node 24.14 이상 24.x와 npm을 사용하는 소스 설치:

```sh
git clone --branch v0.1.0 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

실행 후 `http://127.0.0.1:4310`을 열고 봇과 모델을 설정해요. 릴리스의 소스 압축을 사용해도 되며, 이 경우 압축을 푼 프로젝트 루트에서 `npm ci`부터 실행해요. Docker 설치는 저장소의 [개인 서버 안내](https://github.com/woduseh/Uimori/blob/v0.1.0/docs/SELF-HOST.md)를 따르세요. 사전 빌드된 공식 Docker 이미지는 이 릴리스에 포함하지 않아요.

기존 사용자는 **새로 설치하거나 DB를 초기화하지 말고**, [업데이트 안내](https://github.com/woduseh/Uimori/blob/v0.1.0/docs/UPDATES.md)의 백업·정지·버전 선택·재빌드 절차를 따라요. 기존 Oracle 설치는 [전용 배포 안내](https://github.com/woduseh/Uimori/blob/v0.1.0/docs/ORACLE-RELEASE.md)를 사용해요. 태그와 GitHub Release 발행은 운영 서버를 자동 배포하지 않아요.

업데이트 전에 DB 스냅샷과 실행 중인 앱/이미지 정보를 함께 보관하세요. 전체 DB에는 API 키와 이미지가 포함되며, 외부 Codex 로그인 파일은 별도예요. 지원하는 이전 DB는 한 번 갱신하므로, 되돌릴 때는 **이전 앱과 그에 맞는 업데이트 전 DB 백업**을 함께 복구해야 해요. 갱신된 DB를 구버전 앱으로 여는 다운그레이드는 지원하지 않아요. 정확한 형식은 [데이터 안내](https://github.com/woduseh/Uimori/blob/v0.1.0/docs/DATA-MIGRATIONS.md)를 확인해요.

## 알려진 제한

앱 내 업데이트 확인·설치와 무인 자동 업데이트는 없어요. 일반 Docker 업데이트 CLI는 실제 Docker 호스트에서의 검증이 완료되지 않은 실험적 경로이며, Oracle 전용 배포와 구별해요.

모든 Risu 봇·스크립트의 완전한 호환성을 보장하지 않아요. 지원 범위는 [가져오기 안내](https://github.com/woduseh/Uimori/blob/v0.1.0/docs/RISU-IMPORT.md)를 확인해요. 한 사람이 사용하는 앱이며 다중 사용자 계정·권한 분리는 제공하지 않아요. 실제 모델의 응답 품질·요금·제약은 사용하는 프로바이더에 따라 달라져요.

릴리스 검증의 자동화된 모델·Codex 호출은 합성 fixture를 사용해요. 실제 유료 모델 호출, 운영 DB 변경, Oracle 배포는 버전 발행 작업에 포함하지 않아요.
