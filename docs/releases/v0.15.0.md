# v0.15.0

- **도우미가 바꾼 내용을 보고 되돌릴 수 있어요.** 작업 결과에 대상마다 변경 카드가 붙어서 무엇이 추가되고 지워졌는지 보여 줘요. 카드에서 바뀐 자리를 열 수 있고, 그동안 도우미는 옆에 남아 있어요. 작업 하나가 바꾼 리소스, 장면 원문과 번역, 플롯과 노트는 작업 결과에서 한 번에 되돌려요. 그 뒤에 직접 고친 대상은 덮어쓰지 않고 건너뛰어요. 직전 리소스 수정만 되돌리던 막대는 이 기능으로 대체했어요. [도우미 변경 되돌리기](../EDITING.md#도우미-변경-되돌리기)
- **도우미가 삭제, 일괄 수정, 유료 요청은 먼저 확인을 받아요.** 보류된 작업은 작업 결과에서 승인하거나 거절해요.
- **도우미에게 계획만 받을 수 있어요.** 입력창에서 계획 모드를 고르면 아무것도 바꾸지 않고 계획만 답해요. 마음에 들면 그 계획을 그대로 실행시켜요.
- **도우미, 플롯, 창작 옵션이 오른쪽 패널 하나를 써요.** 탭으로 오가고 폭을 끌어서 조절해요. 본문은 읽기 폭을 유지해요.
- **키보드 단축키와 명령 팔레트가 생겼어요.** `Ctrl/Cmd+K`로 팔레트를 열어 화면과 동작을 찾아요. 내비게이션, 오른쪽 패널, 설정, 저장, 검색에 기본 단축키가 붙었고, 실행 중인 작업은 `Esc`를 두 번 눌러 멈춰요. 설정에서 단축키를 끌 수 있어요. [키보드 단축키](../USAGE.md#키보드-단축키)
- **장면이 쓰이는 동안의 화면이 달라졌어요.**
  - 쓰이는 중인 응답도 끝난 문단은 완성된 본문과 같은 모양으로 보여요. 화면은 더 짧은 간격으로 갱신돼요.
  - 지금 어느 단계인지 표시하고, 본문 끝을 보고 있을 때만 새 출력을 따라가요.
  - 도우미는 실행 중인 도구와 대상을 보여 주고, 연달아 읽은 항목은 한 줄로 접어요.
  - 다음 요청 하나를 미리 예약할 수 있어요. 지금 장면이 끝나면 이어서 보내요. [실행 중 다음 요청 예약](../GENERATION.md#실행-중-다음-요청-예약)
- **선택한 구절을 그 자리에서 다듬어요.** 본문에서 구절을 선택하면 선택 막대가 뜨고, 번역 구절도 다듬어 저장할 수 있어요. 선택 막대는 마우스 같은 정밀 포인터에서만 떠요. [선택 구절 퇴고](../EDITING.md#선택-구절-퇴고)
- **번역이 도착해도 읽던 화면이 바뀌지 않아요.** 원문을 읽는 중에 번역이 끝나면 자동으로 전환하지 않고 번역 보기를 제안해요.
- **설정 창이 넓어졌어요.** 데스크톱에서 설정 창이 커졌고, 편집 화면이 창 안에서 한 단계 들어가는 방식으로 열려요. 테마 미리보기는 테마 설정 옆에 고정돼요.
- **그 밖의 변경**
  - 입력창 위에 다음 요청에 적용될 항목을 한 줄로 보여 줘요.
  - 도우미 입력창도 앱의 전송 키 설정을 따르고, 작업 중에는 전송 자리에 중지 버튼이 놓여요.
  - 도우미 대화 목록이 채팅 목록과 같은 방식으로 동작해요. 읽음 상태를 서버에 저장해서 다른 기기에서도 같아요. 입력창 옆에 대화의 컨텍스트 추정치를 보여 줘요.
  - 바뀐 원고 초안이나 요청 수정은 `Esc`를 눌러도 확인 없이 버리지 않아요.
  - 한글, 한자, 가나 검색어는 두 글자부터 자동으로 검색해요.
  - 좁은 화면 배치로 바뀌는 폭을 한 값으로 맞췄어요. 키보드 포커스 표시가 굵어졌고, 화면과 대화상자의 제목이 한 단계 커졌으며, 대화상자와 메뉴가 부드럽게 나타나요.

기존 **SQLite 스키마 15**를 유지해요. 업데이트 뒤 처음 시작할 때 도우미 변경 기록 표를 빈 표로 추가하고, 기존 자료는 바꾸지 않아요. 이번 버전 전에 끝난 도우미 작업에는 변경 카드와 되돌리기가 없어요. [데이터 호환성](../DATA-MIGRATIONS.md) · [업데이트 안내](../UPDATES.md)

**알려진 문제:** 봇이 있는 채팅에서는 장면이 완성되는 순간 본문이 위아래로 조금 움직일 수 있어요. 봇의 화면 형식으로 그린 장면에서는 변경 카드가 바뀐 자리의 근처까지만 열어요.

변경 커밋은 `v0.14.1..v0.15.0` 범위에 있어요. gemini-4-neon과 함께 만든 개선안을 검토해 고쳐 쓴 계획의 0단계부터 8단계까지예요. 구현은 Claude Opus 5.5 서브에이전트가 단계별로 맡았고, 남은 항목은 `docs/plans/ux-redesign.md`에 있어요.

- **UI 원칙 축소:** `docs/UI-PRINCIPLES.md`를 앱 전체의 통일감과 오래 지킬 계약만 남기고 줄였어요(`26b2651a`).
- **실시간 응답:** 기존 SSE 경로로 옮겼다가 탭 여러 개에서 HTTP/1.1의 출처당 연결 수 제한에 걸려, 더 짧은 간격의 폴링으로 되돌렸어요(`4991edb2`, `a386acd5`). 완성된 문단은 `core/reading-markdown.ts`로 그려요(`4bbaea52`).
- **단축키:** 모든 단축키가 `web/shortcut-bindings.ts`의 동작 표 하나를 거쳐요(`97bd9514`). 저장 단축키는 포커스가 있는 편집기의 저장 버튼을 눌러, 버튼이 꺼져 있으면 저장하지 않아요(`52600cc0`).
- **화면 토큰:** 좁은 화면 전환 폭을 760px 하나로 맞췄고 `tests/style-media-widths.test.ts`가 허용 폭을 고정해요(`4bff9465`). 포커스 링 2px, 제목 18px, 겹침 요소 모션 150ms를 토큰으로 뒀어요.
- **오른쪽 패널과 설정:** `web/SidePanelTabs.tsx`가 도우미, 플롯, 창작 옵션을 한 패널에 담아요(`3b207d14`). 설정의 편집 화면은 `web/SettingsDetail.tsx` 틀을 같이 써요(`2a2c578e`). 도우미 읽음 상태는 `server/helper-read-state.ts`가 앞으로만 가는 값으로 저장해요(`628bb063`).
- **변경 기록:** `server/helper-changes.ts`가 작업과 대상마다 처음 손대기 전 상태와 순변경을 한 행으로 남겨요(`b699198c`). 비교는 `core/text-diff.ts`가 크기와 시간 한도 안에서 계산하고, 한도를 넘으면 비교를 생략했다고 표시해요(`1dee4525`).
- **되돌리기:** `server/helper-rollback.ts`가 일반 저장 경로로 복원해요. 대상은 리소스, 장면 원문과 번역, 플롯과 노트예요. 작업 뒤에 다른 쪽이 고친 대상, 저장하지 않은 입력이 열려 있는 대상, 본문이 지워진 대상은 되돌리지 않고 사유를 보여 줘요(`c34734cd`, `1c073ff9`). 시드 기반 속성 검사가 여러 작업과 단일 대상 되돌리기를 섞어 확인하고, 이 검사로 플롯과 노트를 ID까지 비교하던 결함을 찾아 고쳤어요(`be1e5eda`, `6037f39a`).
- **확인과 계획:** 실행 중인 도구 호출을 멈춰 둘 수 없어서, 보류된 호출은 `CONFIRMATION_REQUIRED`로 끝나고 다음 메시지가 한 번만 쓸 수 있는 확인 ID를 실어 보내요. 확인은 인자에 묶여 있어 다른 인자로는 쓸 수 없어요(`c5bb24d6`, `31cb3de0`). 계획 모드는 `592e9de0`, `e50c6f8e`예요.
- **선택 구절 다듬기:** 선택한 글이 저장된 원문이나 번역의 한 곳과 글자 그대로 일치할 때만 제자리 다듬기를 제안해요(`web/reader-selection.ts`, `4678f4ed`). 번역 구절 저장은 `fab00d41`이에요.
- **다음 요청 예약:** 예약은 메모리에 하나만 두고, 글만 세션 저장소에 복사해 둬요. 보낼 때 같은 멱등 키를 써서 두 번 보내지 않아요(`dfa0821a`).
- **테스트 격리:** 다른 테스트가 남긴 전역 테마와 옵션 재조회 시점에 기대던 브라우저 테스트 두 건을 고쳤어요(`48117c35`, `d60ceb8e`). 브라우저 테스트는 모션을 확인하는 경우가 아니면 줄인 모션으로 실행해요(`66ca6a45`).
- **로컬 검증:** 마지막 코드 커밋 `c0742b0b`에서 전체 브라우저 회귀 607개, UI 회귀 54개, Vitest 2,998개(건너뜀 42개), `quality`, 문서 검사, 번역 문구 검사를 통과했어요. Windows에서 실행했어요.
- **CI 검증:** 릴리스 커밋의 GitHub `Quality` 워크플로 통과를 확인한 뒤 태그와 릴리스를 발행해요. POSIX 셸이 필요한 테스트는 Windows에서 건너뛰므로 리눅스 CI에서 처음 실행돼요.
- **검증하지 않은 것:** 실제 모델 프로바이더로 하는 스트리밍, 도우미 되돌리기, 다음 요청 예약, 터치 화면에서의 선택 구절 다듬기, 실제 휴대폰에서의 렌더링이에요. `RACOM05` 브라우저 테스트가 전체 실행에서 한 번 실패했고 단독 실행 세 번은 통과했어요. 원인은 조사하지 않았어요.
