# Uimori v0.8.8

v0.8.7의 **원고 로딩 및 오류 복구 화면**을 다듬은 패치 릴리스예요. 원고 생성·번역·책갈피 데이터와 API/DB 형식은 바뀌지 않아요.

## 주요 변경

- **읽기에 어울리는 로딩 화면:** 원고가 없는 첫 조회에서 200ms 이내의 짧은 대기는 조용히 넘기고, 이후에는 원고 상단에 정적인 문단 모양 플레이스홀더를 표시해요. 약 3초 이상 지연되면 부드러운 안내를 추가하며 임의의 진행률이나 자동 재시도는 표시하지 않아요.
- **정확한 모델 안내:** 본문·모델 목록·전역 역할별 모델 설정의 조회가 끝나기 전에는 모델 미설정으로 단정하지 않아요. 역할별 모델 설정을 불러오지 못했다면 잘못된 미설정 경고 대신 재조회 버튼을 표시해요.
- **복구하기 쉬운 읽기 오류:** 첫 조회에 실패하면 독서 영역 중앙에 오류와 재시도 버튼을 표시해요. 재시도 중에는 상태를 알리고 중복 요청 버튼을 비활성화해요.
- **작성 중 초안과 원고 유지:** 읽기 조회 중에는 기존 초안을 편집할 수 있고, 실제로 보이는 원고가 있는 갱신에서는 원고와 읽기 위치를 유지해요. 기존 응답 순서 보호와 오류 복구도 그대로예요.

## 데이터 호환성

앱 버전은 **0.8.8**, SQLite 스키마는 **15** 그대로예요. 마이그레이션은 없으며 현재 스키마 15 작업실의 원고·채팅·모델 설정과 기존 데이터 볼륨을 유지해 업데이트해요.

## 설치 및 업데이트

GitHub 릴리스의 `v0.8.8` 태그를 사용하세요.

```sh
git clone --branch v0.8.8 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.8`과 빌드 식별자를 확인하세요. GitHub 릴리스 발행만으로 운영 서버가 업데이트되지는 않아요.

## 검증 범위

로딩 지연·실패 후 재시도·모델 설정 조회 상태와 채팅 전환은 합성 브라우저 테스트에서 확인해요. 실제 휴대폰과 외부 모델 응답 결과는 별도예요. Oracle 배포 도구는 정확한 커밋의 GitHub CI를 통과한 뒤 실제 호스트의 이미지·DB 복제본·HTTPS/API를 확인해요.
