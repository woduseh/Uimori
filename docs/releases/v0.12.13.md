# v0.12.13

- 삽화 프롬프트 모델이 현재 장면에 연결된 CHARX Description·로어북과 이전 삽화 기록에서 **필요한 정보만 검색·조회**할 수 있어요. 예약 당시의 자료를 유지해 재시도 중에도 외형 설정이 달라지지 않아요. 도우미·Codex 도구 지침도 목적 중심으로 간결하게 개선했어요.
- 여러 컷을 계획할 때 등장인물의 나이·얼굴·특징을 **공통 외형 기준(visualCanon)**으로 공유해요. 컷별 표정·의상·장면 변화는 따로 유지해요. Codex는 같은 삽화 계획의 렌더를 **하나의 세션에서 연속 실행**할 수 있고, 결과는 기존처럼 컷마다 저장·재시도해요.
- **삽화 개수 자동 결정** 모드를 추가했어요. 모델이 응답의 길이와 내용에 맞춰 설정된 **최소·최대 컷 수** 안에서 선택해요. 새 작업실의 기본 자동 범위는 0~10컷이며 자동 생성 스위치는 기본 꺼짐이에요. 기존 저장 설정은 고정 모드를 유지해요.
- 봇·페르소나의 **기본 인물 외형**을 자료 자체에 등록해 여러 채팅에서 공유할 수 있어요. CCv3의 `extensions.uimori`에 저장하며 CHARX 가져오기·내보내기에서 보존해요. 도우미도 기존 자료 수정 도구로 기본 외형을 등록하거나 고칠 수 있어요.
- 삽화 설정과 외형 편집의 중복 설명을 줄이고 한국어·영어·일본어·중국어 UI를 함께 정리했어요.

기존 채팅·삽화·이미지·CHARX 자료는 유지돼요. **SQLite 스키마 15**로 변함없으며 데이터 마이그레이션은 없어요. [개발 및 검증 안내](https://github.com/woduseh/Uimori/blob/v0.12.13/docs/DEVELOPMENT.md) · [업데이트 안내](https://github.com/woduseh/Uimori/blob/v0.12.13/docs/UPDATES.md)
