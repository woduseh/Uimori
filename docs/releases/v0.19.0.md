# v0.19.0

외부 에이전트가 서재 자료를 직접 고칠 수 있는 실험용 MCP 연결이 생기고, 평가 도구 기능이 빠졌어요. 화면 오류 문구와 새 항목 이름이 UI 언어를 따르고, 복원한 채팅·채팅 사본·자료 편집기에서 어긋나던 동작을 고쳤어요.

- **실험용 MCP 연결이 생겼어요.** 서버에 `UIMORI_MCP_TOKEN`을 설정하면 Claude Code나 Codex 같은 외부 에이전트가 `/api/mcp`로 저장된 봇·페르소나·모듈·프롬프트 프리셋을 읽고 고칠 수 있어요. 이 토큰은 MCP 경로만 열고 앱 접속 토큰과 달라야 하며, 설정하지 않으면 경로 자체가 없어요. MCP 도구에는 모델을 부르는 경로가 없어서 유료 생성은 실행되지 않아요. 캐릭터 카드·로어북·프롬프트 프리셋·Risu 스크립트 작성 스킬 네 개를 함께 제공해요. 도우미의 앞날을 정하기 전에 써 보려는 실험이라 이후 버전에서 빠질 수 있어요. [도우미 도구 (개발 문서)](../dev/HELPER-TOOLS.md#mcp-endpoint-experimental)
- **평가 도구 기능을 없앴어요.** 모델 프리셋의 평가 도구 설정이 사라졌어요. 이 설정을 켜 둔 프리셋은 더 이상 평가 도구를 보내지 않고, 켜지 않았던 프리셋의 요청은 바뀌지 않아요. 저장된 프리셋·내보낸 파일에 남은 값은 읽을 때 무시하고 다시 쓰지 않아요.
- **복원한 채팅의 도입문이 도입문으로 보여요.** `.chat.uimori`에서 복원한 채팅이 작성된 도입문을 요청 말풍선으로 보여 주고 1장으로 세어서, 뒤의 장면 번호·원고 범위·검색 번호가 하나씩 밀리고 도입문에 다시 쓰기가 보이던 문제를 고쳤어요. 이미 복원한 채팅도 따로 변환하지 않고 바로잡혀요. 복원한 채팅을 다시 내보내도 백업 모양이 바뀌지 않아요.
- **봇이나 모듈을 지운 채팅도 복사·백업돼요.** 봇을 삭제한 채팅의 분기·사본 재시도·복사가 실패하고, 삭제한 페르소나·모듈이 사본에서 빠지고, 그런 채팅의 백업 내보내기가 멈추던 문제를 고쳤어요. 채팅이 들고 있던 자료는 그대로 옮겨요.
- **다른 곳에서 저장한 내용이 열린 편집기에 바로 보여요.** 자료·프롬프트 프리셋 편집기는 다른 탭·기기에서 저장한 수정본을 창으로 다시 돌아올 때에야 알았어요. 이제 곧바로 반영하고, 고치던 초안이 있으면 바로 충돌로 알려요. 초안을 버리는 사이 다른 저장이 들어오면 버리기가 성공으로 보이지만 다시 열 때 초안이 돌아오던 문제도 고쳤어요.
- **화면 문구가 UI 언어를 따라요.** 서버가 오류를 코드로 보내고 화면이 현재 언어로 보여 줘요. 새 로어·폴더·토글, 이름 없이 붙여 넣은 이미지, 사본 제목, 사용량 CSV 머리글, 협업 템플릿도 현재 UI 언어로 만들어요. 이미 저장된 이름은 그대로예요. 영어·일본어 사본 접미사가 붙은 긴 제목이 길이 한도를 넘어 저장에 실패하던 문제도 함께 고쳤어요.
- **오래된 탭이 다른 곳의 변경을 덮어쓰지 않아요.** 다른 곳에서 바뀐 항목을 오래된 탭이 저장하거나 지우려 하면 덮어쓰지 않고 새로고침을 안내해요. 삭제 확인 대화상자는 연 순간의 항목을 지워요. 지운 봇·채팅에 남아 있던 테마·팔레트·배경 선택도 함께 정리해요.
- **그 밖의 수정:** 도우미 패널이 메시지를 배치하는 순간 위로 스크롤하면 다시 맨 아래로 끌려가던 문제, 삭제된 모델을 가리키는 역할이 남아 있으면 다른 역할 설정까지 저장되지 않던 문제를 고쳤어요. Risu 카드·프리셋 가져오기는 실패 뒤 다시 시도해도 두 번 저장되지 않고, 거절 응답이면 아무것도 저장되지 않은 거예요.

**데이터 호환성:** SQLite 스키마 15를 유지해요. 전체 작업실 복구와 `.uimori`·`.chat.uimori` 가져오기는 v0.18.0 이후 앱이 만든 백업을 지원해요. 서버를 열 때 예전 저장 모양을 고치던 단계를 없앴는데, v0.18.0이 열 때마다 같은 정리를 이미 마쳤어요. 그보다 오래된 백업은 v0.18.x에서 먼저 복원한 뒤 새로 백업해서 옮겨요. 예전 검색 색인 테이블은 처음 열 때 지우고, 아직 새 색인으로 옮기지 못한 장면은 다시 색인해요.
