# v0.12.16

- **도우미 도구 검색**을 목적 중심의 관련도 검색으로 바꿨어요. 자연스러운 영어 목적과 중첩 인자 이름으로 도구를 찾고, 반환된 후보의 정확한 스키마로 바로 실행할 수 있어요. 정확한 도구명은 해당 도구 하나만 반환하고, 여러 이름 조회는 중복을 제거해요.
- **도우미 셸의 첫 준비 비용**을 줄였어요. 전체 라이브러리와 모든 원고를 복사하는 대신 카탈로그와 고정 작업 스냅샷을 먼저 준비해요. 저장 자료의 본문은 `uimori export`로 선택하거나 전체 내보낼 수 있고, 반복 내보내기는 작업 중인 초안을 보존해요.
- **프로바이더 이어가기 상태**에서 도구 결과 본문의 중복 보관을 없앴어요. 원래 전송 대화는 그대로 유지하고, 이미 처리한 결과는 개수와 해시로 확인해요. 정상 읽기의 중복 토큰 계산과 파일·대화 해시 계산, 장면 배치 수정 뒤 반복 색인 갱신도 줄였어요.
- **테마 목록과 사용량 조회**는 필요한 정보만 반환해요. 테마 상세는 기존 읽기 도구로 확인하고, 사용량은 총계를 기본으로 일별·모델별·용도별 내역을 선택할 수 있어요. 화면의 전체 보고서와 저장된 데이터는 유지돼요.
- 셸 명령이 실패해도 **출력·이미지·확정된 저장 영수증**을 보존하며 활동 화면에는 실패 상태를 표시해요. `--help`처럼 보이는 문자열 값과 앞 공백이 있는 JSON도 CLI에서 올바르게 처리해요. 컨텍스트 여유가 있을 때는 비용 추정만으로 원문·이미지를 조기 압축하지 않아요.

## 업데이트 시 달라지는 계약

- 기존 셸 스크립트가 `library/`나 `chats/` 본문 파일을 바로 읽었다면 먼저 `uimori export '{"scope":"library","id":"…"}'` 또는 `uimori export '{"scope":"chats","id":"…"}'`를 실행해요. 전체 본문이 필요하면 `id` 대신 `all:true`를 사용해요. 카탈로그의 `materialized`가 준비 여부를 표시해요.
- 내부 프로바이더 이어가기 형식은 **v2**이며 v1 중단 상태는 지원하지 않아요. 진행 중인 생성과 재개 대기 Batch를 완료한 뒤 업데이트해요.

기존 봇·페르소나·채팅·원고·삽화·설정·저장 영수증은 유지돼요. **SQLite 스키마 15**로 변함없고 데이터 마이그레이션은 없어요. 성능 수치는 합성 자료의 검색·전송 준비 측정이며 실제 모델의 품질이나 요금 절감률을 보장하지 않아요.
