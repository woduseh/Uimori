# Uimori v0.8.9

v0.8.8의 **작업 알림과 장면 생성 요청 접수 확인**을 개선한 패치 릴리스예요. 운영 데이터·원고와 API/DB 스키마는 변경하지 않아요.

## 주요 변경

- **알림에서 바로 접수 확인:** 네트워크 응답을 잃어 수락 여부가 불확실한 장면 생성 요청은 작업 알림에서 바로 확인할 수 있어요. 이전 요청 식별키를 그대로 재사용하므로 이미 접수된 작업을 중복 생성하지 않아요. 서버가 실제로 접수하지 않았다면 이 과정에서 새로운 생성이 시작될 수 있어요.
- **알림은 잠시 숨기고 초안은 보존:** 「나중에」는 해당 탭의 하단 경고 표시만 숨겨요. 작성창의 「이전 요청 확인」과 보관된 복구 정보, 새 초안은 그대로 두며 새로고침해도 탭의 숨김 상태는 유지돼요.
- **실행 불확실 작업은 명시적으로 확인:** 이미 종료됐지만 결과를 확정할 수 없는 번역 등은 알림만 확인 처리할 수 있어요. 해당 작업의 이력과 종료 상태는 변경하지 않고, 후속 작업의 성공을 이유로 자동 확인하지도 않아요.
- **복구 실패 피드백과 모바일 간결화:** 재확인 도중 다시 실패하면 열려 있는 알림창 안에도 오류를 알려줘요. 불필요한 비활성 버튼과 긴 요청 식별자 노출을 줄였어요.

## 데이터 호환성

앱 버전은 **0.8.9**, SQLite 스키마는 **15** 그대로예요. DB 마이그레이션은 없고 기존 원고·채팅·설정·데이터 볼륨을 그대로 유지해 업데이트해요.

## 설치 및 업데이트

GitHub 릴리스의 `v0.8.9` 태그를 사용하세요.

```sh
git clone --branch v0.8.9 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.9`와 빌드 식별자를 확인하세요. GitHub 릴리스만 발행해서는 운영 서버가 업데이트되지 않아요.

## 검증 범위

알림·작업 이력의 단위 및 브라우저 회귀 테스트에서 재확인·오류 피드백·숨김·새로고침·중복 생성 방지·종료 상태 보존을 검증해요. 실제 휴대폰과 외부 모델 응답 결과는 별도로 확인해야 해요. Oracle 배포는 정확한 릴리스 커밋의 GitHub CI를 통과한 뒤 실제 호스트의 이미지·DB 복제본·HTTPS/API를 검사해요.
