# v0.12.7

도우미와 채팅을 함께 쓰는 화면, 모바일 편집과 설정 화면의 표시 및 조작을 개선한 패치예요.

- 도우미 답변이 자동으로 스크롤될 때 열어 둔 채팅 메뉴와 키보드 포커스가 유지돼요. 원고처럼 메뉴의 위치를 바꾸는 영역을 스크롤하면 해당 메뉴는 계속 닫혀요.
- 태블릿에서 도우미나 창작 옵션을 열어도 뒤쪽 원고가 제 너비를 유지하고, 확장한 도우미는 화면 너비를 모두 사용해요. 모바일 자료·프롬프트 편집기의 저장 아이콘을 복구하고, 짧은 화면에서는 긴 채팅 메뉴를 끝까지 스크롤할 수 있게 했어요.
- 프로바이더 편집 화면의 배경을 맞추고 팔레트 선택 표시, 작은 화면의 버튼 간격과 터치 영역을 개선했어요. 원작 참고 설정의 검색 비용 안내 문구를 제거하고 실행 확인 메뉴의 이름을 줄였어요.
- 내장 서술 테마의 빠진 번역과 Risu 동작 오류 안내의 다국어 표시를 보완했어요. 사용자가 작성한 테마 이름과 내용, 기존 오류 코드와 진단 메시지는 그대로 유지해요.
- 같은 동작에 쓰는 아이콘과 선택 표시를 정돈하고 앱 아이콘의 세부 모양을 다듬었어요.

앱 버전은 **0.12.7**, SQLite 스키마는 **15**를 유지해요. 일반 업데이트는 기존 데이터 볼륨과 원고·대화·설정·인증 정보를 보존해요. 설치와 업데이트는 [업데이트 안내](../UPDATES.md)를 참고해요.
