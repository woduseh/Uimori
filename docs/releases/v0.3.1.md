# Uimori v0.3.1

`v0.3.0`의 기능과 데이터 형식은 그대로 두고, 왼쪽 탐색 사이드바의 시각적 밀도와 조작 피드백을 다듬은 패치 릴리스예요.

## 주요 변경

- **사이드바의 선택·호버 상태를 정돈했어요.** 현재 위치와 마우스 오버 상태가 서로 구분되도록 색을 조정하고, 서재·프롬프트와 채팅 목록이 같은 시각 문법을 사용해요.
- **봇·폴더·채팅의 보조 메뉴 노출을 통일했어요.** 데스크톱에서는 행에 마우스를 올리거나 키보드로 포커스할 때 나타나고, 메뉴가 열린 동안에는 계속 보입니다. 터치 환경과 작은 탐색 창에서는 항상 접근할 수 있어요.
- **트리 간격과 들여쓰기를 정리했어요.** 중첩 단계의 간격을 맞추고, 보조 메뉴가 나타나도 제목과 행의 위치가 밀리지 않도록 했어요.
- **기존 접기·자동 접기 동작은 유지했어요.** 248px 사이드바와 56px 아이콘 rail의 주요 항목 위치를 맞추고, 도우미·설정 패널과 함께 쓰는 기존 반응형 동작을 바꾸지 않았어요.
- **키보드와 터치 회귀 검증을 보강했어요.** 긴 제목, 폴더 메뉴, 접힘 상태, 다크·라이트 테마, 모바일과 터치 데스크톱을 합성 브라우저에서 확인해요.

## 버전과 데이터

앱 버전은 **`0.3.1`**이에요. 개인 작업실 DB는 계속 **schema 12**를 사용하며, 이 릴리스는 데이터 마이그레이션을 추가하지 않아요.

## 설치와 업데이트

새 소스 설치:

```sh
git clone --branch v0.3.1 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

기존 설치는 업데이트 전에 SQLite 백업과 현재 실행 이미지/커밋 정보를 보관하고 [업데이트 안내](../UPDATES.md)를 따라 주세요. GitHub Release 발행만으로 실행 중인 서버가 자동 배포되지는 않아요.

## 알려진 제한

이번 릴리스는 사이드바 polish에 한정된 패치예요. 기존 `v0.3.0`의 Web Push, ComfyUI, Risu 호환성 및 업데이트 관련 제한은 그대로 적용돼요.
