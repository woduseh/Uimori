# Uimori v0.9.2

v0.9.1 이후 삽화 작업 알림의 상세 조회를 바로잡고, 사용하지 않는 내부 경로를 정리한 패치 릴리스예요.

## 주요 변경

- **삽화 활동 알림:** 삽화 알림의 상세 조회에 해당 작업의 전용 API를 사용하고 실제 실행 세대(`generation`)를 확인해요. 취소나 재실행으로 작업 세대가 바뀐 경우 이전 실행의 결과로 오인하거나 자동 확인 처리하지 않아요. 상세 조회만으로 생성 작업을 다시 시작하지 않아요.
- **프롬프트 내부 검증 단순화:** 컴파일러 버전 검증의 중복 경로를 정리하면서 기존 버전 계약을 유지해요.
- **미사용 경로 정리:** 더 이상 사용하지 않는 보조 작업·이력 처리, UI 스타일과 오래된 검증 코드 일부를 제거해요. 유지 중인 채팅·이야기·알림 동작은 보존해요.

## 데이터 호환성

앱 버전은 **0.9.2**이며 SQLite 스키마는 **15**로 유지해요. 일반 업데이트는 기존 데이터 볼륨·채팅·프리셋·모델 키를 보존해요. 다른 DB 스키마를 자동 변환하지 않아요.

## 설치 및 업데이트

릴리스의 `v0.9.2` 태그를 사용하세요.

```sh
git clone --branch v0.9.2 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.9.2`를 확인하세요. 릴리스 공개만으로 서버가 자동 업데이트되지는 않아요.

## 검증과 한계

삽화 알림 조회와 취소 후 실행 세대 식별, 프롬프트 컴파일러 버전 계약 및 기존 호출 경로를 관련 회귀 테스트로 확인해요. 실제 외부 모델의 생성 품질이나 다양한 실기기 UI는 이 릴리스 검증 범위에 포함되지 않아요.
