# Uimori v0.8.6

v0.8.5 이후 **본문 생성 후 자동 번역의 앱 전체 기본값**과 채팅별 예외 설정을 추가한 업데이트예요.

## 주요 변경

- **전체 자동 번역 기본값:** **설정 → 일반 → 생성 기본값**에서 서버 전체의 본문 자동 번역을 켜거나 끌 수 있어요. 기본 상태는 꺼짐이며 기기마다 다른 값이 아닌 서버 저장 설정이에요.
- **채팅별 예외:** **채팅 설정 → 실행 옵션 → 본문 번역**에서 `전체 기본값 따르기 / 이 채팅에서 켜기 / 이 채팅에서 끄기`를 선택할 수 있어요. 이전에 개별 채팅에 저장한 켜짐·꺼짐은 유지돼요. 상속 중에는 현재 전체 기본값도 표시해요.
- **안정적인 적용 시점:** 본문 생성 요청이 등록될 때 유효한 자동 번역 설정을 고정해요. 실행 중 기본값을 바꿔도 이미 예약된 번역과 기존 원문은 그대로 유지돼요. 자동 번역 결과 알림과 활동 모드는 기존 흐름을 사용해요.
- **설정 저장 및 확인:** 전체 설정은 충돌을 감지해 오래된 화면이 새 선택을 덮어쓰지 않게 하고, 저장 실패 시 스위치를 원래 값으로 되돌려요. 채팅별 예외·실제 자동 번역 예약·설정 재조회에 대한 테스트도 보강했어요.

## 데이터 호환성

앱 버전은 **0.8.6**, SQLite 스키마는 **15**로 유지돼요. 전체 기본값은 기존 `app_metadata`에 저장하므로 데이터베이스 변환 없이 현재 스키마 15 작업실의 기존 원고와 채팅별 설정을 유지해요. 설치 전 진행 중인 작업을 마치고 일관된 백업을 확보해 주세요. 구형 스키마의 직접 변환은 지원하지 않아요.

## 설치 및 업데이트

공개된 GitHub 릴리스의 `v0.8.6` 태그를 사용하세요.

```sh
git clone --branch v0.8.6 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md)를, Oracle 운영 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 참고하세요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.6`과 빌드 식별자를 확인하세요. GitHub 릴리스 발행만으로 실행 중인 서버가 자동 업데이트되지는 않아요.

## 검증 범위와 제한

단위·통합 및 합성 브라우저 테스트는 외부 모델의 실제 번역 결과와 물리 기기의 푸시 수신을 보증하지 않아요. Oracle 이미지·DB 복제본·실제 HTTPS/API는 전용 배포 도구에서 별도로 확인해요.
