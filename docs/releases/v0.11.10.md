# Uimori v0.11.10

이번 패치는 원고·번역·도우미의 읽기 렌더링 규칙을 통합하고, 불필요하게 반복되던 보조 설명을 줄여 주요 조작과 상태를 더 분명하게 표현해요.

## 변경 사항

- **공통 Markdown 읽기:** 일반 원문·저장 번역·완료된 도우미 응답과 Risu 네이티브 화면의 Markdown 처리 규약을 공유해요. 루비 등 안전한 인라인 마크업이 섞인 문단도 주변 대사·생각의 읽기 설정을 적용하고, 코드·링크·작성자 컨트롤은 보호해요.
- **기존 기능 보존:** Risu CBS/Regex/Lua, 카드 HTML/CSS, 버튼 및 입력 상태는 유지해요. 저장된 원고·번역·해시·앵커·이미지 귀속을 읽기 목적으로 다시 저장하거나 변환하지 않아요. 생성 중 공개 텍스트의 리터럴 표시도 유지해요.
- **설정과 관리 UI:** 내비게이션·빈 화면·프리셋·도우미 등의 중복 사용법을 줄이고, 적용 범위와 상태는 레이아웃·그룹·필드명으로 알 수 있게 개선했어요. 비용·데이터 보존·오류 복구 등 중요한 설명은 유지해요.
- **창작 옵션:** 채팅에서 고정 설정과 일회성 설정을 같은 옵션 목록에서 명시적으로 전환해 편집할 수 있어요. 저장본 충돌·초안 복구·기본값 사용은 기존 보호 규칙을 유지해요.
- **검증 강화:** Markdown·인용·루비·안전한 HTML·원문/번역 삽화 귀속·읽기 위치 및 창작 옵션의 합성 테스트를 보강했어요. 여러 상태를 마운트하는 브라우저 회귀 테스트에는 실행 시간에 맞는 제한을 설정했어요.

## 호환성과 확인 사항

- **SQLite 스키마 15 유지**, 자료 이관·저장 원문 변경 없음. 별도의 DB 변환은 필요하지 않아요.
- 업데이트 후 사용하던 채팅에서 **원문/번역 전환, 대사 강조·루비, 삽화 위치, 카드 버튼/입력**이 정상적인지 확인해 주세요. 창작 옵션을 편집할 때도 고정/일회성 범위를 확인하세요.
- 합성 테스트의 통과는 실제 모델 출력 품질·모든 서드파티 카드 HTML에 대한 완전한 호환성을 보증하지 않아요.

설치 업데이트는 [안내](../UPDATES.md), Oracle 인스턴스 배포는 [전용 절차](../ORACLE-RELEASE.md)를 참고하세요.
