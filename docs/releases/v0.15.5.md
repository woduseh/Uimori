# v0.15.5

원문·번역문에서 드래그로 글을 선택했는데 **다듬기 메뉴가 나타나지 않던 문제**를 해결했어요. Risu 봇 화면에서 텍스트를 마우스로 드래그할 때 브라우저가 실제 선택 범위와 다른 선택 상태를 보고하는 경우에도, 우이모리가 진짜 선택 범위로 판단하도록 수정했어요.

- **원문·번역문 다듬기:** 문장을 드래그하면 다듬기·도우미에게 묻기·책갈피·복사 메뉴가 떠요. 이전부터 지원하던 일반 본문과 Risu 봇 화면의 선택 기능을 같은 방식으로 처리해요.
- **선택한 글의 인용:** 장면 메뉴의 책갈피와 도우미에게 묻기에 전달하는 선택 텍스트도 실제 범위를 확인해요.
- **번역 완료 시 읽기 보호:** 원문을 드래그해 선택한 상태에서 번역이 완료되면 강제로 번역으로 전환하지 않고 **번역이 준비됐어요** 안내를 보여 줘요.

**데이터 호환성:** 기존 SQLite 스키마 15와 저장된 원고·번역·설정은 그대로 유지해요. 데이터 마이그레이션은 없어요. [업데이트 안내](../UPDATES.md)

**검증 범위:** 실제 마우스 드래그를 사용하는 Chromium 브라우저 테스트로 Risu 번역문 다듬기와 원문 선택 중 번역 완료를 확인하고, 일반 본문·Risu 표시의 선택 및 기존 번역 보존 동작을 회귀 테스트했어요. 다른 브라우저·모바일 터치 환경의 실제 기기 검증이나 유료 모델의 퇴고 품질 검증은 포함하지 않아요.
