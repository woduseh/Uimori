# Uimori v0.11.11

긴 대화의 번역 준비 비용을 줄이고, 프롬프트 목록의 비동기 읽기와 내부 준비 경로를 정리한 패치예요.

## 변경 사항

- **번역 준비 성능:** 과거 번역을 표현 참고로 모을 때 사용하지 않는 원문 표시 블록과 과거 작업의 실행 입력을 불러오지 않아요. 기존 이력·원문 해시·채팅 범위와 완료 번역의 유효성 검사는 유지해요.
- **측정 결과:** 동일한 로컬 SQLite 합성 데이터에서 각각 9회 측정한 준비 시간 중앙값은 30장면에서 39.88→26.17ms, 300장면에서 438.32→304.64ms로 감소했어요. 300장면의 SQL 조회는 1,500→900회로 줄었고, 참고 결과와 저장 데이터는 동일했어요. 전체 번역 완료 시간이나 실제 LLM 청구액 절감 수치는 아니에요. 재현 방법은 [개발 안내](../DEVELOPMENT.md#translation-reference-preparation)에 있어요.
- **프롬프트 목록:** 선택이 바뀌거나 화면을 닫았을 때 이전 읽기 요청을 취소하고, 늦은 응답이 최신 화면 상태를 덮지 않도록 처리해요.
- **실행 경로 정리:** 프롬프트를 구성하는 동안 동일한 입력 투영을 재사용하고, 도우미의 장면 내보내기는 검증된 원문 이력을 사용해요. 사용하지 않는 UI 스타일·이전 준비 경로와 검증 진입점도 정리했어요.
- **문서 정비:** 현재 지원하는 생성·번역·자료 교환·설치 및 운영 절차에 맞춰 안내를 갱신했어요.

## 호환성과 확인 사항

- **SQLite 스키마 15 유지**. 별도의 DB 변환이나 원고 초기화는 필요하지 않아요.
- 원문·번역·사용자 설정을 보존하고, 번역의 모델 호출 정책과 참고 문구는 유지해요. 새로운 캐시나 의존성을 추가하지 않아요.
- 합성 검증은 실제 유료 모델의 출력 품질이나 모든 외부 카드의 호환성을 보증하지 않아요.

설치 업데이트는 [안내](../UPDATES.md), Oracle 인스턴스 배포는 [전용 절차](../ORACLE-RELEASE.md)를 참고하세요.
