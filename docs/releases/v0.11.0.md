# Uimori v0.11.0

개인 작업실의 읽기·설정 화면을 정리하고, 백업과 집필의 중복 경로를 줄였어요.

## 주요 변경

- **읽기와 모바일 탐색:** 로딩·저장·오류 표시를 통일하고 서재 카드와 긴 대화의 장면 탐색을 다듬었어요. 모바일의 장면 목록과 최신 위치 이동이 원고와 겹치지 않게 배치했어요.
- **설정과 안내:** 과장되거나 뜻이 모호한 설명을 줄였어요. 실행 옵션을 프롬프트·모델에 합치고, 전역·채팅 창작 옵션의 충돌은 입력을 보존한 채 저장본 확인창에서 처리해요. 일반 화면의 검사용 프로바이더 등록과 현재 모드에서 효과 없는 설정은 숨겨요.
- **기본 프리셋:** Phēmē v5.4.1의 RP·소설, Hermēneía v1.1.0 번역 프리셋을 제공해요. 별도 OOC·협업 프리셋은 목록에서 제외하며, RP·소설의 협업 설정은 기본으로 꺼져 있어요. 이미 저장한 프리셋과 현재 작업본을 자동으로 덮어쓰지는 않아요.
- **백업 출력 통일:** 새 자료·채팅 백업은 `.uimori`로 만들어요. JSON 백업 생성 API는 종료하지만 과거 JSON 가져오기는 유지해요. 본문 교환용 JSON과 전체 SQLite 백업은 계속 제공해요.
- **도우미의 가정 장면 생성·편집 종료:** 다른 전개는 기존 ‘이 장면까지 새 채팅으로 복사’ 후 일반 집필로 작성해요. 과거 가정 장면의 원문·요청·수정본은 읽고 복사할 수 있어요. 이 기기에 남은 편집 초안도 자동 삭제하지 않아요.
- **도우미 대화 생성 복구:** 브라우저 저장 공간이 부족하거나 다른 탭의 생성 기록이 있을 때도 현재 탭의 같은 요청 확인을 유지해 중복 대화를 막아요.

## 데이터와 API 호환성

앱 버전은 **0.11.0**, SQLite 스키마는 기존 **15**를 유지해요. 원고·설정·자료·이미지·인증 정보와 과거 가정 장면 기록을 일괄 재작성하거나 삭제하지 않아요. 스키마 15인 기존 설치는 정상 백업 후 업데이트할 수 있어요.

- `GET /api/chats/:id/backup`과 `POST /api/native-transfers/export`의 JSON 신규 출력은 종료해요. 직접 쓰던 스크립트는 archive 출력 경로로 옮겨야 해요. [자료 교환](../NATIVE-TRANSFER.md), [채팅 백업](../CHAT-BACKUP.md)
- 도우미 `artifact.generate`, 가정 장면 수정 API와 새 생성 한도를 제거해요. `artifact.read`와 저장본 GET은 과거 자료 조회용으로 유지해요. [도우미 도구](../HELPER-TOOLS.md)
- 기존 가정 장면의 이미지 참조와 사용량도 보존해요. 기능 종료가 과거 자료를 정리하거나 재생성하는 동작은 아니에요.

새 기본 프리셋은 모델의 결과 품질을 보장하지 않으며, 저장한 사용자 프롬프트를 자동으로 새 버전으로 바꾸지 않아요.

## 설치 및 업데이트

```sh
git clone --branch v0.11.0 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 업데이트 후 설정 → 앱 정보·라이선스에서 `0.11.0`을 확인해요.
