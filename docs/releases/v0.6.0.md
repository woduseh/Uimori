# Uimori v0.6.0

장면의 여러 순간을 문단 삽화로 읽고, 레이아웃·팔레트·배경을 독립적으로 고르는 기능 릴리스예요. v0.5.2 이후의 삽화·테마 개선과 편집·설정 복구 수정을 함께 담았어요.

## 주요 변경

- **문단 삽화 스토리보드:** 한 응답에서 서로 다른 순간을 골라 여러 컷을 만들고 해당 문단 뒤에 표시해요. 대표 삽화 선택, 개별·전체 접기, 현재 설정으로 다시 그리기, 생성 상세를 제공해요. 번역에서는 위치만 다시 연결하고 그림을 유지하며, 정확한 위치를 확인할 수 없는 컷은 이유와 함께 본문 밖에 남겨요. 삽화가 생성 중이거나 실패해도 읽기·쓰기·번역은 계속돼요.
- **프리셋별 생성기:** 삽화 프리셋에 Codex 또는 ComfyUI를 함께 저장하고 전환해요. 진행 중인 작업은 예약 때 고정한 입력을 유지하며, 기존 생성기 없는 프리셋은 호환 규칙으로 읽어요. 기존 자동 생성 설정의 기본은 계속 1컷이라 업데이트만으로 생성량을 늘리지 않아요.
- **Codex 삽화 사전 판정:** 실제 이미지 요청의 텍스트를 JEV로 확인해 노골적인 성적 이미지가 필요하다고 높은 확률로 판정된 컷은 전송하지 않아요. 다른 컷과 본문·번역은 유지해요. 이미지 자체나 장면 선택용 텍스트 요청을 검사하는 기능은 아니며, 판정이 불가능하면 미확인으로 기록하고 프로바이더 판단에 맡겨요. ComfyUI에는 이 가드를 적용하지 않아요.
- **독립적인 레이아웃과 팔레트:** 기본·시네마틱·편지지·스크랩북·클래식 프레임에 팔레트를 따로 적용해요. 봇과 페르소나 이미지를 장면에 배치하고, 작은 화면에서는 각 메시지 위로 쌓아요. 이야기 레이아웃의 긴 본문은 실제 읽기 영역 높이에 맞춰 스크롤하며 읽기 위치·북마크·편집 복귀를 유지해요.
- **별도 읽기 배경:** 채팅·봇·작업실 범위에 배경 이미지, 흐림, 밝은/어두운 모드의 덮개를 설정해요. 레이아웃·팔레트와 독립적으로 상속하며 본문과 버튼을 흐리게 만들지 않아요. 기존 테마 선택과 사용자 테마는 호환 규칙으로 보존해요.
- **이미지 배치와 읽기 조작:** JEV가 고른 Risu 이미지 표시와 재선택을 수정하고 이미지 작업의 호출·토큰 정보를 더 명확히 보여줘요. 삽화·인물 확대와 읽기 조작, 모바일 대화상자, 확인·주요 작업 버튼을 일관되게 정리했어요.
- **복구와 실행 안정성:** 중단된 설정·취소 흐름, 편집 초안 복구와 활동 확인 상태를 보완했어요. 모델 재시도와 읽기 크기를 제한하고, 시간 제한에 걸린 검사와 CI 실패의 진단 자료를 보존해요.

## 데이터 호환성

앱 버전은 **0.6.0**, 개인 작업실 DB는 계속 **스키마 15**예요. **v0.5.2와 데이터 스키마가 같으므로 기존 스키마 15 작업실은 데이터 볼륨을 유지해 업데이트할 수 있어요.** 삽화의 새 계획·위치 정보와 테마 선택은 기존 저장 경계에 보관해요. 업데이트 전에는 앱의 일관된 SQLite 백업과 실행 중인 앱/이미지 정보를 함께 보관해요.

삽화 프리셋 내보내기는 생성기를 포함한 v2 형식을 사용하며 기존 v1 파일도 읽어요. 전체 DB 백업은 프리셋·선택을 포함하지만, 별도 채팅 복사나 채팅 백업은 전역 프리셋 카탈로그를 복제하지 않아요. 자세한 계약은 [장면 삽화](../ILLUSTRATIONS.md)와 [테마 제작](../THEME-AUTHORING.md)을 참고해요.

v0.3.1의 스키마 12 DB를 직접 변환하는 기능은 포함하지 않아요. 구형 DB와 백업은 해당 형식을 지원하는 앱 버전과 함께 보관하고 DB 버전 숫자를 수동으로 바꾸지 않아요. [데이터 안내](../DATA-MIGRATIONS.md)와 [업데이트 안내](../UPDATES.md)에 범위를 설명해 두었어요.

## 설치와 업데이트

```sh
git clone --branch v0.6.0 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x를 사용해요. 기존 설치는 [업데이트 안내](../UPDATES.md)를 따라 앱과 DB 백업을 함께 보관해요. Oracle 운영 설치는 [전용 배포 절차](../ORACLE-RELEASE.md)로 검증한 정확한 main 커밋을 배포해요. GitHub Release 발행만으로 서버가 업데이트되지는 않아요.

## 검증 범위와 알려진 제한

자동 검사는 합성 모델·이미지와 격리된 DB를 사용해 삽화 계획·배치·복구, 테마 선택·장문 읽기와 편집 흐름을 확인해요. 실제 유료 모델의 그림 다양성·지침 준수·응답 품질·최종 청구량이나 물리 모바일 기기 성능을 보장하지는 않아요. 프로바이더가 보고하지 않은 사용량은 0이 아닌 미확인으로 남겨요.

위치가 불확실한 삽화는 임의로 본문에 끼워 넣지 않아요. Codex용 참조 이미지는 ComfyUI에 보내지 않으며, ComfyUI의 모델·LoRA·커스텀 노드는 사용자가 준비해야 해요. 내보내는 워크플로에 직접 넣은 비밀값과 개인 경로는 공유 전에 확인해요.
