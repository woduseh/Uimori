# v0.12.21

- **사용자 이야기 UI 테마**를 만들 수 있어요. 기존 테마 편집기에서 기반 스타일과 CSS를 작성하고 즉시 미리 본 뒤, 앱 레이아웃과 별개로 봇에 적용해요. 채팅에서 직접 고른 스타일이 있으면 그 선택을 우선해요.
- **도우미 테마 제작**을 지원해요. 봇의 설정을 읽고 테마를 저장·수정·적용할 수 있으며 변경 결과에서 해당 봇의 테마 설정을 열어요. 테마 JSON으로 공유할 수 있고, 봇 파일과는 별도로 전달해요.
- **새 채팅 기본값**에서 본문 호출 한도, 이야기 UI 사용 여부와 스타일을 지정할 수 있어요. 새 채팅을 만들 때 복사하므로 기존 채팅·분기·복사·백업 복원의 설정은 유지돼요. 처음 기본값은 8회·이야기 UI 꺼짐·자동이에요.
- **본문 모델 호출 한도**를 전역 기본값과 채팅별 설정 모두 1~128회로 확장했어요. 번역과 도우미의 기존 한도는 유지해요.

테마는 **설정 → 테마와 색상 → 현재 봇의 기본 → 이야기 UI 테마 만들기**, 생성 기본값은 **설정 → 일반 → 새 채팅 기본값**에서 설정해요. [이야기 UI](../STORY-UI.md) · [호출 한도와 기본값](../CONTEXT-LIMITS.md)

기존 자료와 **SQLite 스키마 15**를 유지하며 데이터 마이그레이션은 없어요.
