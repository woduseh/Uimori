# v0.11.24

도우미 대화 편집·삭제와 채팅별 창작 옵션 선택을 개선한 패치 릴리스예요. DB 스키마는 15로 유지하고, 기존 데이터와 설정을 보존해요.

- 도우미의 요청과 답변을 제자리에서 편집하고 저장·취소할 수 있어요. 저장만으로 작업을 다시 실행하지 않아요.
- 메시지 메뉴에서 요청·응답 한 쌍을 삭제하거나 여기부터 이후 대화를 삭제할 수 있어요. 이미 수행한 자료 수정과 작업·사용량 기록은 유지해요.
- 수정·삭제는 이후 도우미 요청에 반영되고, 오래된 요약을 통해 삭제한 내용이 다시 들어오지 않도록 처리해요. 편집한 메시지의 이미지 참조도 보존해요.
- 다른 화면의 변경과 편집 저장이 충돌하면 저장본을 검토하면서 초안을 유지할 수 있어요. 이전 페이지에 불러온 메시지도 변경 이벤트를 빠짐없이 반영해요.
- 다른 채팅의 미적용 옵션이나 저장 작업이 현재 채팅의 옵션 조합·페르소나 선택을 막지 않아요. 채팅을 오가도 옵션 초안은 보존해요.
- 창작 설정의 중복 제목을 없애고, 조합 적용 결과는 기존 완료 알림에서 확인하도록 메뉴를 간략화했어요.

실제 유료 모델 호출과 물리 기기 검증은 포함하지 않아요. 설치 절차는 [업데이트 안내](../UPDATES.md)를 참고해요.
