# v0.12.10

- 도우미가 캐릭터 패키지의 대표 이미지와 CHARX 원본 이미지 이름을 목록에서 확인하고 검색할 수 있어요. 이미지 여러 장을 불필요하게 열지 않고 후보를 좁힐 수 있어요.
- 이미지 열람에 선택적 512px 미리보기를 추가했어요. 기존 상세 이미지 열람과 원본 파일은 그대로 유지돼요.
- 인물 외형을 저장한 결과에서 실제 적용된 참고 이미지 연결을 확인할 수 있어요. 중복 저장과 재조회가 필요하지 않도록 도우미의 도구 설명과 안내를 간결하게 정리했어요.

SQLite 스키마는 **15**로 유지하며 데이터 마이그레이션은 없어요. [삽화 사용 안내](https://github.com/woduseh/Uimori/blob/v0.12.10/docs/ILLUSTRATIONS.md) · [업데이트 안내](https://github.com/woduseh/Uimori/blob/v0.12.10/docs/UPDATES.md)
