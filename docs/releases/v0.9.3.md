# Uimori v0.9.3

v0.9.2 이후 도우미의 프롬프트 탐색·복제·부분 수정을 더 간결하고 안전하게 다듬은 패치 릴리스예요. 별도 세션에서 개발한 프롬프트 토글 값 정합성 수정도 함께 포함해요.

## 주요 변경

- **선택한 프롬프트로 바로 질문:** 프롬프트 목록의 카드 메뉴에서 **도우미에게 묻기**를 누르면 해당 프리셋의 저장된 ID와 리비전을 도우미 요청에 지정해요. 편집기를 열면 이전 카드 선택을 해제해 미저장 초안이 우선 적용되며, 요청 시점에 저장본 변경 여부도 확인해요.
- **프롬프트 본문 일괄 조회:** 도우미 `resource.read`가 프롬프트 블록의 작성된 본문·내부 형식·기본 본문을 선택적으로 함께 읽어요(`includeBodies:true`). 기본 조회는 여전히 가벼운 개요이며, 응답 크기가 크면 다음 블록 위치 또는 긴 블록의 정확한 후속 읽기 경로를 제공해요.
- **복제 시 Risu 내부 이름 동기화:** `resource.clone` 및 HTTP 복제 요청에서 선택적으로 `syncNativeName:true`를 사용하면 복제한 프롬프트의 내부 Risu 이름도 새 제목으로 바꿔요. 기본 복제는 사용자가 작성한 기존 이름을 보존해요.
- **프롬프트 토글 값 정합성:** 도우미가 프롬프트 토글 정의를 변경할 때 기존 저장 값을 새 정의와 일치시키고, 관련 편집·되돌리기 동작을 유지해요.

## 데이터 호환성

앱 버전은 **0.9.3**, SQLite 스키마는 **15**예요. 일반 업데이트에서는 운영 데이터 볼륨, 채팅, 프리셋, 모델 인증 정보를 보존해요. 다른 DB 스키마에 대한 자동 변환은 제공하지 않아요.

## 설치 및 업데이트

릴리스의 `v0.9.3` 태그를 사용하세요.

```sh
git clone --branch v0.9.3 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. **설정 → 앱 정보·라이선스**에서 버전 `0.9.3`을 확인하세요. GitHub 릴리스 공개만으로 운영 서버가 업데이트되지는 않아요.

## 검증과 한계

선택 자료와 미저장 초안 간 우선순위, 긴 프롬프트의 페이지 처리, 복제 원본 보존·내부 이름 동기화, 토글 정의 변경 시 값 보존을 관련 회귀 테스트로 확인해요. 실제 외부 모델 응답 품질과 사용자 기기의 모든 브라우저 환경은 별도 검증 대상이에요.
