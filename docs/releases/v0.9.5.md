# Uimori v0.9.5

v0.9.4 이후 도우미의 프리셋·리소스 편집을 더 정확하고 복구 가능하게 다듬은 패치 릴리스예요.

## 주요 변경

- **프리셋 수정:** 기대 리비전에 맞춘 배열 항목 편집, 고유한 CRLF/LF 줄바꿈 대응, 상속된 토글 값만 갱신하는 조정을 추가했어요. 원본 블록 ID와 기존 순차 편집 경로를 보존해요.
- **다중 리소스 작업:** 범위가 제한된 일괄 조회, 직전 저장본 확인, 원자적 다중 리소스 패치와 묶음 되돌리기를 지원해요. 초안 리비전 충돌과 긴 본문을 처리하는 기존 경로도 유지해요.
- **검증과 복구:** 네이티브 번역 가이드 입력 오류를 수정 가능한 검증 실패로 분류해, 도우미가 같은 작업에서 값을 고쳐 다시 시도할 수 있도록 했어요. 예측하지 못한 저장 실패는 성공으로 취급하지 않아요.
- **진단:** 네이티브 토글 규칙에 따른 프리셋 옵션 변경 진단을 추가했어요. 실제 외부 모델을 호출하지 않는 합성 검증을 사용해요.

## 데이터 호환성

앱 버전은 **0.9.5**, SQLite 스키마는 **15**로 유지해요. 일반 업데이트에서 기존 운영 데이터 볼륨, 채팅, 설정과 모델 인증을 보존해요. 다른 DB 스키마를 자동 변환하지 않아요.

## 설치 및 업데이트

릴리스의 `v0.9.5` 태그를 사용하세요.

```sh
git clone --branch v0.9.5 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. **설정 → 앱 정보·라이선스**에서 버전 `0.9.5`를 확인하세요. GitHub 릴리스 공개만으로 운영 서버가 업데이트되지는 않아요.

## 검증과 한계

도우미 리소스 편집, 일괄 작업, 되돌리기, 프리셋 진단의 합성 테스트와 품질·빌드·릴리스 검사를 활용해 변경을 확인해요. 실제 외부 모델과 모든 사용자 프리셋의 조합은 합성 테스트만으로 보장할 수 없어요.
