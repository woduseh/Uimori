# v0.12.14

- 봇·페르소나 편집에 **기본 인물 외형** 독립 탭을 추가했어요. 번역 지침과 고급 설정 사이에서 이름·외형·참고 이미지를 관리하고, 카드에 포함된 이미지를 바로 연결하거나 해제할 수 있어요.
- 채팅 설정의 **삽화 참고**에서 봇·페르소나 기본 외형을 상속해요. 기본값은 간결하게 표시하고, 수정하면 이 채팅의 외형으로 저장하며, 복원하면 최신 기본 외형을 다시 따라가요. 채팅에서 새로 만든 인물은 독립적으로 편집·삭제할 수 있어요.
- UI에서 반복적인 보조 설명과 불필요한 상태 레이블을 줄였어요. 참고 이미지 선택, 저장 충돌과 초안 보존은 유지해요.
- 기본 외형·채팅별 재정의·실제 적용 외형을 API에서 구분하고, 기존 저장 데이터 및 예전 API 입력과의 호환성을 유지해요. 도우미의 인물 외형 도구도 상속 기준으로 동작해요.

기존 채팅, 삽화, 인물 프로필 및 CHARX 확장은 유지돼요. **SQLite 스키마 15**로 변함없고 데이터 마이그레이션은 없어요. [개발 및 검증 안내](https://github.com/woduseh/Uimori/blob/v0.12.14/docs/DEVELOPMENT.md) · [업데이트 안내](https://github.com/woduseh/Uimori/blob/v0.12.14/docs/UPDATES.md)
