# Uimori v0.8.11

v0.8.10 이후 **도우미의 저장된 장면 편집과 읽기 재시도**를 개선한 패치 릴리스예요. 기존 원고·작업실 데이터 및 SQLite 스키마는 유지해요.

## 주요 변경

- **도우미의 저장된 장면 읽기·편집:** 현재 저장된 원문과 번역을 읽고, 특정 문자열 또는 전체 문장을 수정하며, 보존된 원문의 이전 버전을 복원할 수 있어요. 도우미의 자료 편집은 기존 저장 경로를 재사용하고, 수정 후 진행 중인 관련 작업 취소와 읽기 화면 갱신을 연결해요.
- **충돌 방지와 대상 구분:** 저장 시 리비전·원본 해시·표시된 본문 해시를 확인해 다른 기기나 번역 작업에서 내용이 바뀌었을 때 덮어쓰지 않아요. 실행 시점에 고정된 장면 문맥 및 기기의 미저장 초안은 현재 저장된 장면 수정과 분리돼요.
- **읽기 크기 제한의 재시도 수정:** 도우미의 읽기 예산을 초과한 장면 조회는 서재 검색으로 대체하지 않고, 같은 대화·장면·버전·읽기 위치를 유지하며 요청 크기만 줄여 재시도하도록 안내해요. 텍스트 끝을 벗어난 읽기 위치를 거절하고, 빈 줄의 공백 치환도 지원해요.

## 데이터 호환성

앱 버전은 **0.8.11**, SQLite 스키마는 **15** 그대로예요. DB 마이그레이션은 없으며 기존 데이터 볼륨과 보존된 원문 버전 정책을 유지해요.

## 설치 및 업데이트

GitHub 릴리스의 `v0.8.11` 태그를 사용하세요.

```sh
git clone --branch v0.8.11 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.11`과 빌드 식별자를 확인하세요. GitHub 릴리스만 발행해서는 운영 서버가 업데이트되지 않아요.

## 검증 범위

저장된 장면 읽기·문자열/전체 본문 수정·버전 복원·충돌 검사·읽기 재시도는 합성 테스트로 검증해요. 저장된 원고를 사용하는 두 가지 브라우저 편집/충돌 시나리오도 이전 변경에서 검증했어요. 실제 모델의 도구 선택 품질까지 보장하지는 않아요. Oracle 배포는 정확한 릴리스 커밋의 GitHub CI 통과와 실제 호스트의 이미지·DB 복제본·HTTPS/API 확인을 요구해요.
