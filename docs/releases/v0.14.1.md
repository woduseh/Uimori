# v0.14.1

- **도우미 첨부 파일을 연속으로 추가할 때 누락되지 않아요.** 먼저 고르거나 붙여 넣은 파일이 저장되는 동안 새로 붙이거나 끌어다 놓은 파일도 차례대로 저장돼요. 대화를 지운 뒤에는 그 전에 요청한 추가 작업이 반영되지 않아요.
- **작업 메뉴가 기준 버튼과 함께 동작해요.** 화면 안에서 열린 작업 메뉴는 기준 버튼이 화면 밖으로 나가거나 스크롤로 움직일 때만 닫히고, 메뉴 안에 있던 포커스는 기준 버튼으로 돌아가요.
- **삭제 확인 뒤 포커스가 튀지 않아요.** 삭제 확인 창을 먼저 닫은 뒤 이어지는 화면 갱신을 실행해, 새로 옮긴 포커스가 삭제 버튼으로 되돌아가지 않아요.
- **도우미 도구 설명 5곳을 실제 동작에 맞췄어요.** `illustration.profiles.save`, `image.read`, `resource.patch`, `scene.title`, `data.exec`의 설명이 코드 동작과 다르던 부분을 바로잡았어요.

기존 **SQLite 스키마 15**를 유지하고, v0.14.0과 저장 형식이 같아요. [업데이트 안내](../UPDATES.md)
