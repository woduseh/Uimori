# Uimori v0.1.1

`v0.1.0` 이후 실제 사용에서 거슬리던 읽기 흐름과 에이전트 작업 비용을 다듬고, 새 Claude 모델을 별도 등록 없이 사용할 수 있게 한 소규모 업데이트예요. 개인용 초기 개발 릴리스라는 성격과 데이터 형식은 그대로 유지해요.

## 주요 변경

- **Liquid Gallery 읽기 테마**를 기본 테마에 추가했어요. 긴 소설형 응답을 중심으로 읽으면서 봇·페르소나 이미지를 자연스럽게 함께 볼 수 있고, 좁은 화면에서는 원고 폭을 우선하도록 반응형으로 접혀요.
- **도우미 하네스의 자료 조회 경로를 경량화**했어요. 라이브러리·채팅 자료를 좁은 범위로 검색·읽고 필요한 앱 작업만 호출할 수 있는 bounded data tools와 compact app gateway를 추가해, 단순 사실 확인에 큰 편집 JSON이나 불필요한 컨텍스트를 싣는 일을 줄였어요. 여러 범위를 한 번에 읽는 작업도 더 크게 묶을 수 있어요.
- **컨텍스트 압축 준비 비용을 줄였어요.** 수동 요약 계획에서 같은 writer 입력을 장면마다 반복해서 다시 만들지 않고 배치해 계산해요.
- **Anthropic Messages의 mid-conversation system role을 모든 Claude 모델 ID에 허용**해요. `claude-opus-5-5`처럼 새 모델이 추가되어도 모델별 capability 등록을 기다리지 않아요. Claude의 mid-system 배치 규칙 자체에 대한 검증은 유지해요.
- **채팅 네비게이터 표시 설정**을 읽기 설정에 추가했어요. 설정은 이 기기에 저장되며, 집중 읽기에서는 데스크톱·모바일 모두 네비게이터와 모바일 장면 목록 진입 UI를 자동으로 숨겨 원고에 집중할 수 있어요.

## 버전과 데이터

앱 버전은 **`0.1.1`**이며 **설정 → 앱 정보·라이선스**와 Codex 실행기 식별에 같은 패키지 버전을 사용해요. 빌드 식별자는 소스 변경을 구분하기 위해 별도로 유지해요.

이번 업데이트는 개인 작업실 DB의 현재 형식 자체를 새 버전으로 올리는 릴리스가 아니에요. 기존 `v0.1.0` 작업실은 DB를 초기화하거나 새로 만들지 말고 그대로 업데이트해요. 정확한 현재 스키마와 지원 범위는 [데이터 안내](../DATA-MIGRATIONS.md#현재-버전)를 확인해요.

## 설치와 업데이트

새 소스 설치:

```sh
git clone --branch v0.1.1 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

기존 사용자는 업데이트 전에 SQLite 백업과 현재 실행 이미지/커밋 정보를 보관하고, [업데이트 안내](../UPDATES.md)의 절차로 코드와 앱을 함께 바꿔요. Oracle 설치는 [Oracle 릴리스 안내](../ORACLE-RELEASE.md)를 사용해요. 태그를 만들거나 GitHub에 push하는 것만으로 실행 중인 서버가 자동 업데이트되지는 않아요.

## 알려진 제한

앱 내 업데이트 확인·설치와 무인 자동 업데이트는 아직 제공하지 않아요. 모든 Risu 자료·스크립트의 완전한 호환성도 보장하지 않으며 지원 범위는 [Risu 가져오기 안내](../RISU-IMPORT.md)를 따라요. 한 사람이 사용하는 개인 작업실을 전제로 하므로 다중 사용자 계정·권한 분리는 제공하지 않아요.

자동 검증의 모델 호출은 합성 fixture를 사용해요. 실제 모델의 품질·요금·서비스 제약은 사용하는 프로바이더에 따라 달라져요.
