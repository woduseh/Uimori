# Uimori v0.11.3

도우미가 잘못된 읽기·SQL 인수를 전달했을 때 원인을 파악하고 올바른 요청으로 복구할 수 있도록 오류 안내를 개선한 패치예요.

## 변경 사항

- **장면 페이지 읽기:** `scene.read`와 `scene.versions`에서 페이지 시작 위치가 0보다 크면서 검증 값이 누락되면 `SCENE_PAGE_GUARDS_REQUIRED`(400)를 반환하고 필요한 revision·source hash·text hash를 안내해요. 데이터가 실제로 바뀐 경우의 409 충돌 검증은 그대로 유지해요.
- **과거 장면 버전:** 임의 위치에서 과거 버전을 읽을 때 현재 원문의 텍스트 해시가 아니라 선택한 과거 버전의 `textHash`를 사용하도록 안내해요. 순차 조회는 기존 `nextRead`를 그대로 사용하면 돼요.
- **SQL 조회 오류:** `db.query`의 `no such column` 오류만 `DATA_SQL_UNKNOWN_COLUMN`으로 분류해 스키마 확인 및 SQL 수정으로 복구하도록 안내해요. 기타 문법 오류·접근 권한 거부·서버 오류는 기존 정책을 유지해요. 서버가 SQL을 자동 변경하거나 재실행하지는 않아요.
- **검증:** 잘못된 컬럼 이후 스키마 확인과 정상 조회, SQL 권한 거부, 장면 임의 위치 조회 및 과거 버전 해시 차이에 대한 회귀 테스트를 추가했어요.

## 업데이트와 데이터

앱 버전은 **0.11.3**, SQLite 스키마는 **15**로 이전 버전과 같아요. 데이터 마이그레이션이나 원고·번역 내용 변경은 없어요. 기존 작업을 마치고 정상 백업 후 업데이트하세요.

```sh
git clone --branch v0.11.3 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [업데이트 안내](../UPDATES.md)를, Oracle은 [운영 배포 안내](../ORACLE-RELEASE.md)를 따라요. 배포 후 설정 → 앱 정보·라이선스에서 `0.11.3`을 확인해요.
