# v0.12.6

지연된 응답과 결과를 확인하지 못한 작업에서 **미저장 입력과 읽기 위치를 더 안전하게 보존**하고, 화면의 용어와 조작을 정돈한 패치예요.

- 자료 생성·복제나 도우미 작업의 결과를 다시 확인할 때 원래 요청과 이후에 입력한 내용을 구분해요. 다른 창의 수정이나 새 입력을 이전 응답으로 덮어쓰지 않도록 복구와 충돌 처리를 보완했어요.
- 읽기 위치 저장이 지연된 사이 채팅을 다시 열거나 다른 창에서 이동해도 더 최신 위치를 예전 위치로 덮지 않아요. 저장 결과를 확정하지 못한 경우에는 예전 위치를 자동 재전송하지 않아요.
- 책갈피 편집·삭제가 충돌하거나 응답을 확인하지 못하면 입력과 확인창을 보존하고, 목록을 다시 불러와 결과를 확인할 수 있어요.
- 작업 취소와 프로바이더 응답 처리를 개선했어요. 이미 완료되었거나 오류가 확인된 요청은 원격 스트림 정리의 완료를 기다리지 않고 결과를 반환해요. 결과가 불명확한 이미지 선택 호출은 중복 호출을 피하도록 자동 재전송하지 않아요.
- Vertex 서비스 계정은 파일을 확인할 때 저장하지 않고 연결을 저장할 때 함께 검증·저장해요. 업데이트 전부터 열어 둔 화면에서 등록 중 오류가 나면 다른 편집을 저장하고 페이지를 새로고침한 뒤 JSON 파일을 다시 선택해 주세요.
- 한국어를 비롯한 화면 용어와 아이콘 조작을 정돈하고, 긴 제목에서 헤더 정렬이 흔들리는 문제를 수정했어요.

앱 버전은 **0.12.6**, SQLite 스키마는 **15**를 유지해요. 일반 업데이트는 기존 데이터 볼륨과 원고·대화·설정·인증 정보를 보존해요. 설치와 업데이트는 [업데이트 안내](../UPDATES.md), 복구 동작은 [편집 안내](../EDITING.md)와 [읽기 위치 안내](../READING-STATE.md)를 참고해요. 합성 테스트는 실제 외부 모델의 모든 응답이나 기기 환경을 재현하지 않아요.
