# v0.12.2

도우미의 탐색과 대화 경험을 메인 채팅에 맞추고, 이미지와 파일 첨부를 추가했어요. 기존 원고, 자료, 대화와 실행 기록을 보존하며 **SQLite 스키마는 15로 유지**해요.

- 채팅 검색의 필터 배치와 결과 목록을 정리하고, 데스크톱의 새 대화와 검색 버튼을 사이드바 머리글로 모았어요.
- 도우미도 탐색과 활동 탭을 제공해요. 프로젝트 안의 대화는 들여쓰고, 확인할 활동과 진행 중인 작업, 전체 최근 대화를 채팅과 같은 구조로 보여줘요.
- 프로젝트 안에서 새 대화를 만들고, 프로젝트와 대화를 최근순, 이름순, 수동순으로 정리할 수 있어요. 드래그와 메뉴의 위로/아래로 이동을 지원하며, 프로젝트를 삭제해도 대화는 남아요.
- 미확인 숫자를 활동 탭으로 모았어요. 프로젝트 이동이나 제목 변경은 미확인 작업으로 세지 않아요.
- 도우미 입력창은 텍스트 영역과 도구 행으로 나누고, 실행 상태는 채팅과 같은 표시를 사용해요. 진행 과정은 짧게 보여주며 세부 실행 기록과 사용량은 펼쳐서 확인할 수 있어요. 저장되는 로그는 유지해요.
- 답변의 코드 블록을 각각 복사할 수 있어요. 파일 선택, 붙여넣기와 드롭으로 첨부하고, 보낸 파일은 원본으로 내려받을 수 있어요.
- GPT-6 계열의 Responses 문서 입력, Claude 5 이상의 PDF와 텍스트 입력, Gemini 4의 문서와 오디오, 영상 입력을 연결별 공식 지원 범위에 맞춰 제공해요. 이미지는 기존 이미지 처리 경로를 공유해요. 자세한 범위는 [도우미 첨부](../HELPER-ATTACHMENTS.md)를 참고해요.
- 첨부 초안은 대화별로 복원하고, 복사와 재시도에서도 파일을 보존해요. 응답 유실 후 같은 요청을 확인할 때 새 초안을 지우지 않아요. 연속 도구 호출과 요약 후 재시도에서 첨부 입력이 바뀌거나 중복 합산되는 문제도 방지했어요.

업데이트와 백업은 [업데이트 안내](../UPDATES.md)를 참고해요. 일반 파일 첨부는 선택한 API 연결의 지원 형식과 크기 한도를 따르며, Codex 연결은 현재 이미지 입력을 지원해요. 로컬 합성 검증은 실제 유료 공급자 호출과 구분해요.
