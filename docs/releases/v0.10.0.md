# Uimori v0.10.0

v0.9.6 이후 본문 요청에 참고 이미지를 함께 입력할 수 있도록 확장한 기능 릴리스예요.

## 주요 변경

- **본문 참고 이미지 첨부:** 입력창의 첨부 메뉴, 붙여넣기, 파일 끌어놓기로 PNG·JPEG·정지 WebP 이미지를 최대 8장 첨부할 수 있어요. 이미지로만 요청하는 것도 가능하며 첨부 순서·썸네일 확대·개별 제거를 지원해요.
- **모델 전달:** 이미지 입력을 지원하는 본문 모델에 사용자 메시지의 이미지를 전달해요. OpenAI·Anthropic·Gemini·Codex와 Risu 네이티브 요청 경로를 검토했어요. 이미지 미지원 모델에는 안내를 제공하고, 지원이 확인되지 않은 사용자 정의 모델은 요청을 시도할 수 있어요. 별도 이미지 분석 모델 호출은 추가하지 않아요.
- **초안 보존:** 전송 전 텍스트·이미지를 현재 기기·탭의 IndexedDB에 복구용으로 저장해요. 페이지 재로드, 전송 결과 불명확, 업로드 만료, 탭 복제 및 실패 후 재시도에도 원문과 새로운 초안을 분리해요.
- **요청 기록과 백업:** 수락한 이미지 첨부는 해당 사용자 요청에 귀속되며 과거 대화, 수정·재시도, 독립 채팅 복사, 채팅 백업과 복원에도 보존해요. 오래된 이미지를 요약된 컨텍스트 밖에서 계속 전달하지는 않아요.
- **이미지 처리 제한:** 서버에서 입력을 정규화하고 SHA-256별 한 번 저장해요. 저장본은 정지 WebP를 유지하고, 모델 전송용 이미지는 별도 크기 한도 내에서 준비해요. 이미지 바이트는 영구 모델 입력 JSON이나 텍스트 토큰 예산에 포함하지 않아요.
- **입력 미리보기:** 첨부 장수와 해상도를 기준으로 한 대략적인 입력 여유량을 표시해요. 이는 공식 토큰·실제 청구량 추정값이 아니며, 미리보기에서는 이미지를 업로드하지 않아요.

## 데이터 호환성

앱 버전은 **0.10.0**, SQLite 스키마 버전은 기존 **15**를 유지해요. 이미지 바이트는 기존 `image_blobs`를 활용하므로 새 DB 초기화가 필요 없어요. 일반 업데이트 시 기존 운영 데이터 볼륨, 채팅, 설정, 모델 로그인·인증을 유지해요. 지원하지 않는 구형 DB를 자동 변환하지 않아요.

## 설치 및 업데이트

```sh
git clone --branch v0.10.0 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. **설정 → 앱 정보·라이선스**에서 버전 `0.10.0`을 확인하세요. 릴리스 공개만으로 운영 앱이 바뀌지는 않아요.

## 검증과 한계

정적 검사, 빌드, 이미지 요청 저장·복구·프로바이더 인코딩 테스트와 모바일·데스크톱 브라우저 테스트를 수행했어요. 추가적인 정확한 릴리스 SHA의 GitHub 필수 CI, Oracle의 실제 이미지·DB 복제본·HTTPS 검사는 각각 통과 여부를 별도로 확인해요. 실제 모델의 이미지 이해 품질, 토큰·비용, 모바일 OS의 모든 파일 선택 방식은 합성 테스트로 보장하지 않아요.
