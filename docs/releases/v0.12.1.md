# v0.12.1

채팅과 도우미를 같은 탐색 구조에서 오가도록 다듬고, 도우미 대화를 프로젝트로 정리할 수 있게 했어요. 기존 원고, 자료, 설정과 대화를 보존하며 **SQLite 스키마는 15로 유지**해요.

- 공통 사이드바에서 채팅과 도우미를 전환해요. 새 대화와 검색은 현재 메인 화면을 따르고, 원고나 자료 옆에서 사용하는 사이드 도우미도 유지해요. 전환해도 초안과 읽던 위치가 이어져요.
- 프로젝트를 직접 만들고 대화를 이동하거나 이름을 바꿀 수 있어요. 프로젝트 없이도 사용할 수 있고, 여러 자료를 수정해도 소속이 자동으로 바뀌지 않아요. 프로젝트를 삭제해도 대화는 남아요.
- 대화별 제목 변경, 삭제와 복사를 제공해요. 복사는 현재 보이는 최신 대화와 설정을 독립적으로 보존하며, 과거 작업을 다시 실행하거나 사용량을 중복 생성하지 않아요.
- 도우미 설정은 대화 위의 모달에서 편집해요. 도우미 내역 폭을 따로 설정하고, 본문과 입력창은 공통 읽기 폭을 사용해요.
- 사용량에는 마지막 전송 입력의 추정치와 당시 입력 예산을 비교하는 막대가 표시돼요. 현재 네이티브 에이전트의 컨텍스트 사용률이나 누적 토큰 비율은 아니에요. 한도 기록이 없으면 숫자만 표시해요.
- 익숙한 동작은 아이콘으로 정리하고, 반복 안내와 다국어 문구를 간결하게 다듬었어요. 삭제 효과, 부분 집계와 실패 복구에 필요한 의미는 유지해요.
- 모바일 목록의 터치 영역과 연결 자료를 펼쳤을 때의 배치를 개선했어요.

업데이트와 백업은 [업데이트 안내](../UPDATES.md)를 참고해요. 기존 대화는 프로젝트 소속 없이 보존되며, 프로젝트는 실행 권한이나 자료 접근 범위를 바꾸지 않아요.
