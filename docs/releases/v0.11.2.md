# Uimori v0.11.2

모바일에서 원고를 덜 가리고 장면 탐색과 요청 작업을 더 일관되게 사용할 수 있도록 다듬은 패치예요.

## 변경 사항

- **모바일 맨 아래 이동:** 원고와 입력창 사이에 별도 행을 차지하던 버튼을 입력창의 도구 행에 통합했어요. 이전 장면이나 긴 본문을 읽는 동안에만 보이며, 입력 중에는 숨겨요.
- **장면 목록:** 읽기 설정에서 채팅 네비게이터를 숨겨도 모바일 상단 제목을 눌러 장면 목록·검색을 사용할 수 있어요. 집중 읽기에서는 탐색 조작을 숨기고, 데스크톱 장면 눈금은 그대로 유지해요.
- **요청 작업:** ‘다시 쓰기’를 다른 작업과 동일한 아이콘 버튼으로 표시하고, 이름은 툴팁·접근성 레이블에 유지해요. 좁은 화면의 모델 선택 칩 너비를 조정해 제목이 표시될 공간을 확보했어요.
- **조작 영역과 검증:** 오류 복구 버튼의 최소 높이를 조정했어요. 긴 원고, 화면 폭, 읽기 테마, 장면 검색, 입력 초안과 이동 버튼 동작을 확인하는 브라우저 검사를 보강했어요.

## 업데이트와 데이터

앱 버전은 **0.11.2**, SQLite 스키마는 **15**로 이전 버전과 같아요. 이번 패치에는 데이터 마이그레이션이 없으며, 원고·번역·책갈피·채팅·사용자 설정·인증 자료를 변경하지 않아요. 운영 중인 생성 작업을 마치고 백업한 다음 업데이트하세요.

```sh
git clone --branch v0.11.2 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [업데이트 안내](../UPDATES.md), Oracle은 [운영 배포 안내](../ORACLE-RELEASE.md)를 따라요. 배포 후 설정 → 앱 정보·라이선스에서 `0.11.2`를 확인해요.
