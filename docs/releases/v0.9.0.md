# Uimori v0.9.0

v0.8.11 이후 **채팅별 이야기 가이드**를 추가한 기능 릴리스예요. 원작 설정·인물·현재 이야기의 분기를 참고해 집필할 수 있고, 가이드를 별도로 미리 살펴보거나 질문할 수 있어요.

## 주요 변경

- **채팅별 이야기 가이드:** 채팅 메뉴 또는 채팅 설정에서 작품·판본, 참고 시점과 스포일러 범위, 추가 자료, 원작 사건 전개 참고 여부를 설정해요. 기본값은 꺼짐이며 글쓰기 프롬프트와는 독립적으로 보관해요.
- **자동 집필 참고문:** 켜 둔 채팅에서는 기존 대화·요약·인물 카드와 예시 대화·로어·작가 메모·구성·현재 집필 요청을 바탕으로 본문 모델이 집필 전에 짧은 참고문을 만들어요. 원작 설정과 현재 이야기의 변경 사항을 구분하고, 같은 입력에서만 결과를 재사용해요. 분석 실패나 예산 부족 시 집필은 가이드 없이 이어가요.
- **미리보기·원작 Q&A:** 집필 중인 요청의 수동 미리보기와 자유 질문, 말투·관계/세계관·설정/다음 전개 질문 초안을 제공해요. 수동 결과는 이야기 본문이나 자동 참고문에 저장하지 않아요. 정정이 필요한 정보는 기존 작가 메모에서 직접 관리해요.
- **보관·사용량·취소:** 가이드 관련 호출과 사용량을 따로 기록하고, 늦은 응답·입력 변경 시 오래된 결과를 반영하지 않아요. 채팅 복사와 개별 백업은 가이드 설정만 복사하고 새 채팅에서 다시 분석해요. 전체 SQLite 백업에는 저장된 최근 자동 참고문이 포함돼요.
- **Gemini PDF 입력 경로 제거:** 사용하지 않는 텍스트→PDF 컨텍스트 인코더, 관련 모델 옵션·UI·종속성을 제거하고 Gemini의 기본 텍스트 입력 경로를 사용해요. 과거 저장 옵션은 읽을 때 무시하며 기존 데이터를 강제 변경하지 않아요.

## 데이터 호환성

앱 버전은 **0.9.0**이고 SQLite 스키마는 **15**로 유지해요. 현재 스키마 15 DB를 열 때 `chat_story_guides` 테이블이 없으면 추가하지만 원고·채팅·설정·기존 데이터 볼륨은 보존해요. 다른 DB 스키마를 자동 변환하지 않아요.

## 설치 및 업데이트

GitHub 릴리스의 `v0.9.0` 태그를 사용하세요.

```sh
git clone --branch v0.9.0 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.9.0`과 빌드 식별자를 확인하세요. 릴리즈 공개만으로 운영 서버가 업데이트되지는 않아요.

## 검증과 한계

이야기 가이드의 저장·설정 충돌·수동 질문·자동 집필 결합·실패/취소·사용량·채팅 복사/백업, Gemini 일반 텍스트 경로와 이전 옵션 무시는 자동화된 합성 테스트 대상이에요. 실제 모델이 원작 정보를 정확히 기억하거나 스포일러를 완벽히 준수하는지 검증하지 않아요. 외부 원작 본문을 자동 다운로드하거나 웹 검색하는 기능도 없어요. 자세한 사용법은 [이야기 가이드](../STORY-GUIDE.md)를 참고해요.
