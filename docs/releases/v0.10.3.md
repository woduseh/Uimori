# Uimori v0.10.3

v0.10.2 이후 **Google Gemini 안전 필터의 범주별 제어**를 추가한 패치 릴리스예요.

## 주요 변경

- **Gemini 안전 필터 개별 설정:** 모델 프리셋의 **고급 → Gemini 안전 필터**에서 괴롭힘, 증오 표현, 성적 콘텐츠, 위험 콘텐츠의 차단 기준을 각각 선택할 수 있어요. Google AI Studio와 Vertex AI 직접 연결에 적용해요.
- **명시값과 기본값 구분:** `OFF`(조정 가능한 필터 비활성화), `BLOCK_NONE`(자동 차단 없이 안전성 평가), 높음만·중간 이상·낮음 이상 차단을 선택할 수 있어요. `모델 기본값`인 범주는 요청에서 제외하고, 모두 기본값이면 `safetySettings` 필드를 전송하지 않아요. 기존 프리셋 동작은 유지해요.
- **프리셋·연속 호출 보존:** 본문·번역·도우미 호출과 도구 후속 요청에서 모델에 저장된 안전 필터 설정을 유지해요. 설정 객체의 키 순서만 달라진 경우에도 동일한 설정으로 판단하며, 실제 차단 기준을 바꾸는 요청은 검증에서 거절해요.
- **오류와 지원 범위:** 사용 중인 모델이나 Vertex 프로젝트에서 설정을 거부하면 해당 오류를 전달하고 자동으로 다른 값으로 대체하지 않아요. 직접 Gemini 연결 이외의 프로바이더에는 이 필드를 보내지 않아요.

## 데이터 호환성과 한계

앱 버전은 **0.10.3**, SQLite 스키마는 기존 **15**를 유지해요. 새 프리셋 속성은 선택적이며, 기존 모델·채팅·실행 기록·API 키·운영 데이터 볼륨을 변경하거나 초기화하지 않아요. Gemini API에서 변경할 수 없는 안전 보호 기능이나 모델 자체 응답 거절을 해제하지는 않아요. 실제 설정 지원 여부와 `BLOCK_NONE` 권한 제한은 Google API·프로젝트·모델에 따라 달라요.

## 설치 및 업데이트

```sh
git clone --branch v0.10.3 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설정 → 앱 정보·라이선스에서 버전 `0.10.3`을 확인하세요. 릴리스 게시만으로 운영 서버가 자동 업데이트되지는 않아요.

## 검증

정적 검사, 소스 빌드 및 Gemini 요청 직렬화·저장·모델 바인딩·브라우저 설정 UI 회귀 검증을 수행해요. Oracle 실제 배포에는 해당 릴리스 커밋의 필수 GitHub CI 성공과 호스트 이미지·데이터 복제본·HTTPS 검증이 별도로 필요해요. 합성 테스트는 유료 Google API의 모든 모델·권한 조합을 확인하지는 않아요.
