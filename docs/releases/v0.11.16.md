# v0.11.16

원작 참조에 선택형 웹 검색을 추가하고 채팅 관리와 읽기 설정을 정리했어요. DB 스키마는 15로 유지해요.

## 원작 참조

- 채팅 설정의 원작 참조에서 웹 검색을 켤 수 있어요. 기본은 꺼짐이에요.
- OpenAI Responses, Claude, Codex와 Gemini API·Vertex의 검색 경로를 지원해요. 선택한 모델과 계정의 도구 지원 여부에 따라 사용할 수 있어요.
- 실제 검색 수행과 출처가 확인된 참고문만 사용하며, 출처 링크와 Google 검색 제안을 함께 표시해요. 검색을 켜면 이전 참고문 캐시를 재사용하지 않아요.
- 검색 실패나 미지원 시 참고문 없이 집필을 이어가요. 검색에는 추가 시간과 비용이 들 수 있고 검색 결과에 스포일러가 포함될 수 있어요.

## 채팅과 기억

- 최근 채팅과 도우미 작업을 날짜별로 구분하고, 왼쪽 채팅 메뉴에서 독립 사본을 바로 만들 수 있어요.
- 장면 메뉴에서 해당 장면만 또는 이후 장면까지 삭제할 수 있어요. 삭제 전에 범위를 선택하며, 다른 채팅 사본은 유지돼요.
- 삭제되거나 바뀐 장면의 기억은 자동으로 새 생성에 넣지 않아요. 기억과 메모에서 직접 다시 연결하거나 사용을 중지할 수 있어요. 도우미 검토는 요청 초안을 준비하며 자동으로 전송하지 않아요.
- 채팅 메뉴를 작업별로 묶고, 접힌 설정 안의 기본값 복원 버튼도 함께 숨겨요.

## 읽기와 표시

- 글꼴의 출처·라이선스 입력 및 표시와 기존 등록 메타데이터를 제거해요. 글꼴 파일과 선택은 유지해요.
- 글꼴·색상 미리보기에 저작권이 만료된 이효석의 「메밀꽃 필 무렵」 일부를 사용해요.
- Codex 잔여 크레딧은 정수로 표시해요.

합성 공급자·브라우저 검증은 실제 유료 모델의 검색 품질이나 계정별 지원을 보장하지 않아요. 설치와 기존 데이터 보존 절차는 [업데이트 안내](../UPDATES.md)를 참고해요.
