# Uimori v0.11.13

채팅과 설정의 자주 쓰는 조작을 간편하게 만들고, 읽기 화면과 내장 테마의 표현을 다듬은 패치예요.

## 변경 사항

- **현재 채팅의 모델 선택:** 상단 모델 이름에서 검색 가능한 선택기를 열어 본문 모델을 바꿀 수 있어요. 기본값으로 되돌리기는 현재 채팅의 모델 지정만 해제하며, 프롬프트와 전역 설정은 유지해요.
- **봇에서 새 채팅 시작:** 준비된 봇은 저장된 기본값으로 바로 새 채팅을 열어요. 시작문 선택이나 설정이 필요하면 선택 화면으로 이어지고, 설정을 먼저 확인하는 진입점도 유지해요. 채팅을 여는 것만으로 모델 생성을 실행하지 않아요.
- **모바일 설정과 저장:** 마지막으로 열었던 설정 항목을 기억하고, 생성 설정의 저장 동작을 하나로 모았어요. 저장 일부가 실패하면 반영되지 않은 초안을 보존해요.
- **읽기 조작:** 이전 장면의 복사·편집·원문/번역 전환을 장면 작업 메뉴에 모았어요. 번역 진행과 실패 상태에서는 필요한 복구 조작을 바로 보여줘요.
- **간결한 화면 표현:** 네 언어의 반복 설명과 구분자를 줄이고 글자 크기·간격·테두리를 정리했어요. 내장 팔레트는 Radix 색상 계열을 사용하며, 메뉴와 대화상자는 즉시 열려요. 원고의 읽기 설정과 사용자 테마는 별도로 유지해요.
- **사용량과 알림:** 사용량 차트는 최근 호출이 있는 구간을 기본으로 보여주고, 기기 알림 설정은 서버에서 확인된 상태를 나타내는 스위치로 정리했어요.
- **검증 정리:** 중복 테스트와 구현·문구를 그대로 복제한 검사를 줄이고, 실제 저장·복구·권한·호환성 검증은 유지했어요.

## 호환성과 확인 사항

- **SQLite 스키마 15 유지**. 별도의 DB 변환이나 원고 초기화가 필요하지 않아요.
- Node.js는 v0.11.12와 동일하게 **24.22.1 이상 24.x**를 사용해요.
- 원문·번역·초안·읽기 위치와 저장된 테마 선택을 보존해요. 이전 사본 제목 형식도 계속 인식해요.
- 합성 검증은 실제 유료 모델의 출력 품질이나 모든 외부 카드의 호환성을 보증하지 않아요.

설치 업데이트는 [안내](../UPDATES.md), Oracle 인스턴스 배포는 [전용 절차](../ORACLE-RELEASE.md)를 참고하세요.
