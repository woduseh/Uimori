# v0.12.12

- 도우미가 삽화 문단과 구도를 직접 선택한 경우, 장면 전체 스토리보드 계획 대신 **선택한 컷의 렌더 작업**을 바로 예약해요. 인물·화풍 설정, 프롬프트 모델, 콘텐츠 검사는 기존대로 유지해요. 장면 전체에서 컷을 자동 선택하는 기능은 기존 계획 경로를 사용해요.
- 이미지가 없는 실패·취소·중단 컷을 최신 작업·원문·배치 수정 번호로 검증해 **위치와 구도를 바꿔 다시 요청**하거나 **영구 삭제**할 수 있어요. 이전 실패 기록은 재요청 후에도 남고, 실제 삭제는 관련 컷 이력까지 정리해요.
- 도우미 `task.inspect`에서 삽화 작업 실패 단계와 프롬프트 준비 여부를 볼 수 있어요. 저장된 프롬프트는 명시적으로 요청한 경우에만 반환하며, 프롬프트 작성이 거절됐을 때는 존재하지 않을 수 있어요.
- `task.list`의 작업 종류(`kind`) 필터와 `illustration.scene.read`의 **앵커 중심 문단 조회**를 추가했어요.
- 모바일에서 삽화 작업의 ⋯ 메뉴를 열면 하단 입력창 버튼보다 **메뉴의 표시 순서가 높아져**, 마지막 삭제 항목까지 정상적으로 누를 수 있어요.

기존 데이터와 이미지 파일은 유지돼요. **SQLite 스키마 15**로 변함없으며 데이터 마이그레이션은 없어요. [개발 및 검증 안내](https://github.com/woduseh/Uimori/blob/v0.12.12/docs/DEVELOPMENT.md) · [업데이트 안내](https://github.com/woduseh/Uimori/blob/v0.12.12/docs/UPDATES.md)
