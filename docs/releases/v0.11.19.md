# v0.11.19

앱 로고와 기본 배색을 맞추고 설정 탐색을 간결하게 정리한 패치 릴리스예요. DB 스키마는 15로 유지해요.

- 좌상단 사이드바와 앱 정보의 로고를 파비콘과 같은 헤일로 SVG로 통일했어요. 작은 로고는 단순화한 문양을, 큰 로고는 정교한 문양을 표시해요.
- 앱·채팅 설정 목록은 설정 이름만 보여요. 언어·모델·프롬프트 등의 현재 값은 해당 설정 안에서 확인하며, 미저장 변경을 보호하는 저장·버리기 확인은 유지해요.
- 기본 배색은 밤의 서재에 가까운 차콜 바탕과 헤일로 크림색 강조로 조정했어요. 밝은 모드는 따뜻한 종이색과 금갈색 강조를 사용하고 보조 글자 대비를 보정했어요.
- 기존 팔레트 자료와 선택, 화면 모드, 원고 자료는 유지해요.

기본 색상 대비, 로고 로딩과 사이드바 접기·펼치기, 설정 화면과 앱·채팅 초안 보호를 검증했어요. 설치 및 데이터 보존 절차는 [업데이트 안내](../UPDATES.md)를 참고해요.
