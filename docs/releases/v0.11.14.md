# Uimori v0.11.14

도우미, 로어와 편집 화면의 반복 설명을 줄이고, 색상 대비와 모바일 조작을 다듬은 패치예요.

## 변경 사항

- **도우미 모델 선택:** 도우미 상단에서 검색 가능한 공통 모델 선택기를 바로 열어요. 전역 도우미 모델과 다음 요청에 적용된다는 범위는 유지해요. 작업 기록도 아이콘에서 바로 열 수 있어요.
- **입력에 포함된 로어:** 고정 자료, 자동 선택, 도구 조회와 실제 전달 형태별로 기록을 묶어요. 같은 제목의 자료는 출처로 구분하고, 상세 식별 정보는 필요할 때 펼쳐요. 마지막 장면의 로어 창에서 중복 펼침을 제거했어요.
- **간결한 편집 화면:** 자료, 프롬프트, 메모, 프로바이더와 삽화 설정의 반복 제목과 안내, 중첩 상자를 줄였어요. 연결 모듈은 이름과 해제 조작을 한 행에 모으고, 모델 ID는 바로 입력할 수 있어요. 저장 버튼의 진행 표시와 크기를 통일했어요.
- **색상과 정렬:** Radix 팔레트의 선택 배경을 절제하고 선택된 글자의 대비를 높였어요. 비활성 버튼, 입력 경계와 어두운 화면의 대화상자를 구분하고, 검색 아이콘과 폼 하단 조작을 정렬했어요.
- **모바일 조작:** 스위치와 첨부 제거의 터치 영역을 44px로 확보하고, 입력 번역 언어의 선택 표시를 더했어요. 빈 요청의 미리보기는 작성창에서 비활성화해요.
- **검색과 오류 복구:** 검색 결과가 없을 때 선택과 초안을 보존하며 검색을 지울 수 있어요. 시작문 미리보기 실패는 그 자리에서 재시도할 수 있어요. 카드 변수의 저장 결과 확인이 백그라운드 조회와 겹쳐도 진행되며, 늦게 도착한 조회가 새 초안을 덮지 않아요.
- **등록 버튼 이름:** 신규 자료, 프로바이더와 모델의 버튼을 “등록”으로 표시해 실제 동작과 접근성 이름을 맞췄어요. 기존 항목을 수정할 때는 “저장”을 유지해요.

## 호환성과 확인 사항

- **SQLite 스키마 15 유지**. 별도의 DB 변환이나 원고 초기화가 필요하지 않아요.
- Node.js는 이전 패치와 동일하게 **24.22.1 이상 24.x**를 사용해요.
- 작성된 원고, 프롬프트, 봇 HTML/CSS와 사용자 테마는 보존해요. UI 언어와 생성 및 번역 언어도 독립적으로 유지해요.
- 비용, 저장 범위, 삭제와 오류 복구처럼 레이아웃만으로 알 수 없는 정보와 아이콘의 접근성 이름은 유지해요.
- 합성 검증은 실제 유료 모델의 출력 품질이나 모든 외부 카드 및 실제 모바일 기기의 호환성을 보증하지 않아요.

설치 업데이트는 [안내](../UPDATES.md), Oracle 인스턴스 배포는 [전용 절차](../ORACLE-RELEASE.md)를 참고하세요.
