# Uimori v0.11.6

서재의 모바일 사용성과 자료 로딩 화면을 다듬고, 도우미가 여러 장면을 안전하게 찾아 수정할 수 있도록 개선한 패치예요.

## 변경 사항

- **서재 화면 이동:** 긴 목록에서 봇·자료를 열면 목록에 남아 있던 스크롤 위치를 초기화해 상세 화면의 맨 위부터 표시해요. 자료 편집 화면으로 이동할 때도 같은 원칙을 적용해요.
- **자료 로딩 화면:** 봇과 프롬프트의 편집 데이터를 불러오는 동안 로딩 표시를 화면 중앙에 배치해요. 모바일과 데스크톱의 공간을 모두 고려하며 기존 지연 표시·오류·재시도 동작은 유지해요.
- **도우미의 장면 일괄 수정:** `scene.search`에서 `sourceId`를 생략해 현재 채팅의 여러 장면에서 일치 항목을 탐색하고, `scene.patchMany`로 최대 16개 서로 다른 장면을 각 버전 검증과 함께 하나의 트랜잭션으로 수정할 수 있어요. 한 항목이 실패하면 전체 저장이 취소돼요.
- **분리된 정규식 검색:** `scene.search regex:true`는 제한된 읽기 전용 작업 프로세스에서 유니코드 정규식을 수행해요. 검색 결과와 이어 읽기는 변경된 원문을 혼용하지 않도록 검증하고, 유니코드 문자가 잘리지 않도록 발췌문을 다듬었어요. 실제 저장은 기존 `scene.patch` 검증을 따르며 정규식 직접 치환은 제공하지 않아요.

관련 모바일 브라우저 회귀 검사와 장면 검색·수정 회귀 검사를 보강했어요. 모델이 검색 결과를 올바르게 활용하는지는 별도 문제이며, 실제 유료 모델 호출의 동작을 보장하지 않아요.

## 업데이트와 데이터

앱 버전은 **0.11.6**, SQLite 스키마는 기존과 같은 **15**예요. 이번 패치에 별도 데이터 마이그레이션은 없어요. 운영 중인 작업을 마친 뒤 기존 데이터 백업과 업데이트를 진행하세요.

```sh
git clone --branch v0.11.6 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [업데이트 안내](../UPDATES.md)를, Oracle은 [운영 배포 안내](../ORACLE-RELEASE.md)를 참고하세요. 배포 후 설정 → 앱 정보·라이선스에서 `0.11.6`을 확인할 수 있어요.
