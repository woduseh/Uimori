# v0.12.15

- **도우미 도구 발견과 사용성**을 개선했어요. 전체 도구 목록에서 이름·인자·작업 목적에 맞는 결과를 찾고, 필수 인자와 읽기·쓰기 여부를 확인한 다음 정확한 스키마를 조회할 수 있어요.
- **Uimori CLI**가 익숙한 `--key value` 문법을 지원해요. 숫자·불리언은 실제 도구 스키마에서 해석하며, 배열이나 복잡한 객체는 기존 JSON/`--input`을 사용해요. 저장 작업은 기존 리비전 검사와 영수증을 유지해요.
- 잘못된 **채팅/라이브러리 스코프**와 쉘 명령 실패의 복구 안내를 명확히 했어요. `data.exec`의 비정상 종료는 실패로 전달하되, 출력 파일과 이미 저장된 변경의 영수증은 보존해요.
- 도우미의 **이미지 확인은 512px 미리보기 우선**으로 동작하며, 필요한 경우 `mode:full`로 원본 세부 사항을 살펴볼 수 있어요. 컨텍스트 압축은 새 읽기 자료를 모델이 먼저 살펴본 다음 비용을 고려해 실행해요.
- `chat.list`와 `chat.read`의 결과를 작은 페이지로 나눠 제공하고, 채팅 목록에서 불필요한 설정을 제외했어요. 긴 이야기에서 페이지 바깥 장면의 미리보기를 생성하지 않도록 개선했어요.

기존 봇·페르소나·채팅·삽화·이미지 및 CHARX 자료는 유지돼요. **SQLite 스키마 15**로 변함없고 데이터 마이그레이션은 없어요. [개발 및 검증 안내](https://github.com/woduseh/Uimori/blob/v0.12.15/docs/DEVELOPMENT.md) · [업데이트 안내](https://github.com/woduseh/Uimori/blob/v0.12.15/docs/UPDATES.md)
