# Uimori v0.7.2

v0.7.1 이후 원고 검색, 읽기 복구, 설정·저장 대화상자의 일관성을 개선한 유지보수 릴리스예요. 기존 창작 자료와 모델 실행 계약을 변경하지 않아요.

## 주요 변경

- **채팅·원고 검색 정리:** 사이드바 검색 입력·범위·대상 필터를 일관되게 표시하고 제목 검색과 본문 결과를 분리했어요. 검색어가 있을 때 제목 일치 항목은 5개씩, 비어 있을 때는 30개씩 더 볼 수 있어요. 데스크톱·접힌 탐색·모바일 간 이동에도 검색 상태를 유지해요.
- **원고 로딩과 복구:** 원고가 늦게 열리면 잠시 후 로딩을 표시하고 첫 조회에 실패하면 재시도할 수 있어요. 새 이동의 응답을 이전 조회 결과가 덮어쓰지 않으며 이미 보이던 원고는 갱신 실패 시 유지해요.
- **저장 충돌·복구 확인 통일:** 자료 편집과 설정의 저장 충돌, 미저장 입력 및 요청 접수 불확실 상황에서 확인 절차와 버튼 표현을 통일했어요. 확인 없이 입력을 버리거나 동일 요청을 중복 실행하지 않도록 기존 복구 경계를 유지해요.
- **설정과 알림 화면 다듬기:** 설정·도우미의 버튼과 설명 배치, 공통 알림과 오류 표현, 진단 보고서 표시를 정리했어요. 입력 번역 진행 표시도 일반적인 동작과 모션 감소 설정에 맞게 다듬었어요.

## 데이터 호환성

앱 버전은 **0.7.2**, 데이터베이스는 계속 **스키마 15**예요. v0.7.1과 동일한 형식으로 기존 작업실과 원문·번역·삽화·복구 입력을 유지하며 추가 데이터 변환은 없어요. 업데이트 전에 일관된 SQLite 백업을 보관하고 실행 중인 생성·도우미 작업과 편집을 마쳐 주세요.

## 설치와 업데이트

릴리스 발행 후 `v0.7.2` 태그로 설치할 수 있어요.

```sh
git clone --branch v0.7.2 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md)를, Oracle 운영 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설치 후 **설정 → 앱 정보·라이선스**에서 앱 버전 `0.7.2`와 빌드 식별자를 확인해요. GitHub 릴리스 공개만으로 운영 인스턴스가 업데이트되지는 않아요.

## 검증과 제한

릴리스 후보에서 문서 링크 검사, 코드 품질·빌드·핵심 브라우저 및 버전·데이터 호환성 검사를 수행하고, 발행 전 해당 커밋의 GitHub Quality CI 통과를 확인해요. 로컬 합성 검증은 실제 외부 유료 모델의 품질이나 물리 모바일 기기의 동작을 증명하지 않아요. 운영 환경 배포와 DB/HTTPS 확인은 별도 절차예요.
