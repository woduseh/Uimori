# Uimori v0.11.1

선택한 프롬프트와 실제 집필 설정을 일치시키고, 개인 작업실에서 겹치던 조작과 설정을 정리했어요.

## 주요 변경

- **프롬프트와 옵션:** 현재 프롬프트가 서재 프리셋의 최신 저장본을 따라요. 별도의 ‘최신 저장본 적용’이 필요하지 않아요. 입력창의 빠른 옵션과 조합은 해당 채팅에만 적용하고, 전역 옵션은 설정에서 바꿔요. 옵션 그룹은 처음 접히며 열림 상태를 기억해요. 이전 정의의 조합도 관리 목록에서 확인하고 수정할 수 있어요.
- **이미지 담당 선택:** 작문 모델 또는 JEV 중 하나가 원문과 번역의 이미지 배치를 담당해요. 현재 선택에 맞춰 표시하되 원문과 기존 배치 기록은 보존해요. 등록된 이미지와 일반 링크·외부 이미지를 구분해 중복 표시를 막아요.
- **집필과 읽기:** 다시 쓰기에서 요청과 교체·사본을 함께 확인해요. 번역은 생성·다시 시도·보기로 상태를 구분하고, 장면 검색은 입력 하나에서 목록·본문을 전환해요. 구성 집필의 현재 구성과 추가 지시를 분리하고, 원작·인물 참고는 집필 전 자동 분석과 도우미 연결로 정리했어요.
- **자료와 설정:** 자료를 선택하면 검증 후 초안에 바로 연결해요. 새 채팅의 페르소나는 직접 선택 → 폴더 → 봇 순으로 정해요. 백업 가져오기 입구를 합치고, 테마의 기본 선택·고급 제작과 삽화의 현재 설정·기본 환경 관리를 나눴어요. 시작문을 바꿀 수 있는 봇은 집필 전 같은 채팅에서 미리 보고 선택할 수 있어요.
- **도우미와 비용:** Codex·OpenAI Responses·Anthropic Messages 연결에서 도우미가 제공자 웹검색을 사용할 수 있어요. 단가는 내장 제조사 표 대신 카탈로그 또는 직접 입력을 사용하고, 도우미가 출처·확인일과 함께 가격 필드만 갱신할 수 있어요. 지원 여부는 실제 모델·계정에 따라 달라지며, 검색 요금은 토큰 비용 추정에 포함되지 않을 수 있어요.
- **평가 도구:** 원본 기반 직접 작성을 종료하고 나머지 두 모드와 모델별 프로필을 유지해요. 두 모드 모두 유효한 최종 제출 도구 호출이 있어야 성공하며, 찾아 바꾸기와 수동 라운드 설정은 제거해요. 도구 교환은 10라운드와 최종 제출로 제한하고 기존 전체 호출·시간 한도도 적용해요.

후속 검토에서 도우미가 UTC 날짜 변경을 지나도 같은 작업을 이어가도록 날짜 기준을 고정했어요. 예전 ‘서재’ 테마를 쓰는 경우에도 고급 적용 범위와 관계없이 기본 외관 선택이 실제 저장값을 표시해요.

## 종료한 경로와 데이터 보존

앱 버전은 **0.11.1**, SQLite 스키마는 **15**예요. 기존 원고·번역·자료·설정·인증 정보와 과거 실행 기록은 유지해요. 기존 독립 프롬프트 본문은 부팅 시 프리셋으로 보존한 뒤 참조 방식으로 전환해요. 이미 접수한 요청의 프롬프트 스냅샷은 변경하지 않아요.

- 독립 장면 예약의 신규 생성·취소·삭제, 구성의 신규 영구 점검표, 전용 수동 원작 질문, 도우미 신규 대화 분기·대화별 한도 편집, 연결 모듈을 합치는 Risu 내보내기, 공유용 익명 진단 보고서를 종료해요. 기존 도우미 대화와 기록, 구성 집필에 필요한 내부 명령, 개별 Risu 출력과 작업 오류 상세는 유지해요.
- 도우미의 새 작업은 내부 한도를 사용해요. 도우미 판단 64회·전체 모델 호출 128회·호스트 도구 호출 256회와 20분 기한을 적용해요. 관측할 수 없는 네이티브 내부 요청까지 포함한 금액 상한은 아니에요.
- 과거 `source-bound` 평가 설정은 새 실행에서 평가 도구를 끄며, 저장된 기록을 다른 모드로 바꾸지 않아요. **진행 중이거나 대기 중인 평가 Batch는 기존 버전에서 끝낸 뒤 업데이트해 주세요.** [평가 도구](../EVALUATION-TOOLS.md)
- 유효한 단가가 없으면 비용을 미확인으로 표시해요. 과거 비용 계산에 사용한 단가 스냅샷은 보존해요.

## 설치 및 업데이트

```sh
git clone --branch v0.11.1 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 정상 백업 후 [수동 업데이트](../UPDATES.md), Oracle은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 업데이트 후 설정 → 앱 정보·라이선스에서 `0.11.1`을 확인해요.
