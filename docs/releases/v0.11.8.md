# Uimori v0.11.8

도우미가 많은 장면과 로어북을 더 효율적으로 탐색하고, 새 도우미 대화부터 사용자가 편집할 수 있는 ‘우이’ 말투가 기본 적용되는 패치예요.

## 변경 사항

- **현재 채팅 장면 인덱스:** `current/scenes.json`에 도우미 작업 접수 시점의 장면 순서, 활성화 상태, 문자 수(UTF-16), UTF-8 바이트 수, 짧은 프리뷰와 본문 해시를 제공해요. 17만 자가 넘는 시작 장면도 전체를 읽기 전에 분량을 확인할 수 있어요.
- **저장 장면 인덱스:** `chats/<id>/scenes.json`에도 길이·프리뷰·활성화 정보를 제공해요. 저장·새로고침이 완료된 내용만 인덱스에 반영하고, 미저장 초안이나 충돌을 저장본으로 잘못 표시하지 않아요. `current/` 스냅샷은 수정하지 않아요.
- **도우미 자료 안내:** 작업 공간의 `INDEX.md`에서 `GUIDE.md`를 안내해요. 자료의 원본과 파생 데이터, 봇·페르소나·모듈·로어·작가 노트·서사 요약의 관계, 고정 스냅샷과 실시간 조회의 차이를 설명해요. 정확한 앱 도구 인자는 기존 `app.tools`를 이용해요.
- **우이 기본 프리셋:** 우이 말투 프리셋을 새 문구로 바꾸고, 새로운 도우미 대화는 이 문구가 기본으로 저장돼요. 대화별 편집·저장·우이 프리셋 다시 불러오기 및 빈 값 설정 기능은 유지해요. 기존 대화의 개인화 설정은 덮어쓰지 않아요. 우이 말투는 설명·잡담에만 적용되며 작품·번역 등 결과물은 사용자의 목표 문체를 따르도록 요청해요.

## 호환성과 검증

SQLite 스키마는 **15**로 동일하며 데이터 마이그레이션은 필요하지 않아요. 기존 원고·도우미 대화·개별 설정·사용자 초안은 유지해요. Linux 셸 회귀, 도우미 대화 설정·저장 테스트와 정적 검증을 대상으로 했어요. 합성 검증만으로 실제 모델의 문체 준수나 운영 이미지 배포 성공을 보장하지는 않아요.

기존 설치는 [업데이트 안내](../UPDATES.md)를, 오라클 운영 인스턴스는 [Oracle 릴리스 절차](../ORACLE-RELEASE.md)를 따라 업데이트하세요. 출시 버전은 설정 → 앱 정보에서 확인할 수 있어요.
