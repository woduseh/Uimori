# v0.13.3

- **이야기 UI에 관계도·지도·달력**이 추가됐어요. 관계도는 인물이나 단서를 이름 붙은 선으로 잇고, 원형·트리 배치는 Uimori가 정해요. 지도는 방·벽·물·미탐색 구역과 인물·유닛 표식을, 달력은 실제 달이나 가상의 달의 일정을 보여 줘요. 관계도 노드에도 카드 그림(`{{img::이름}}`)을 쓸 수 있어요. [이야기 UI](../STORY-UI.md)
- **이야기 UI 스타일마다** 세 화면이 고유한 모양으로 그려져요. 동양풍은 인장, 택티컬은 아군 네모·적 마름모 표식, 로맨스는 폴라로이드와 마스킹 테이프처럼 각 스타일의 표현을 따라요.
- **팝 스타일**의 밝은 화면에서 틀 부제목이 보이지 않던 문제를 고쳤어요.

기존 **SQLite 스키마 15**를 유지하고, 이미 저장된 이야기 UI 화면은 그대로 열려요. 이야기 UI를 켠 채팅은 생성 요청마다 새 구성 요소 설명만큼(약 1,400자) 안내문이 길어져요. [업데이트 안내](../UPDATES.md)
