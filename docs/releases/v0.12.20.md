# v0.12.20

- **이야기 UI 스타일 자동 선택**을 추가했어요. 모델이 화면마다 고른 스타일을 저장하며, 채팅에서 직접 지정한 스타일이 있으면 그 선택을 우선해요. 번역과 생성 중 화면에도 같은 선택을 적용해요.
- **블루 아카이브 프리셋**을 추가했어요. 실제 게임 화면의 밝은 기하학 패널, 하늘색 탭·사선 버튼과 노란 선택선을 원고 안의 화면에 맞게 적용했어요.
- **동양풍·서양 판타지·현대·시대극**의 제목, 탭, 입력란, 버튼과 표를 보강했어요. 색상뿐 아니라 먹선, 양피지 프레임, 현대적인 패널, 서간의 선과 서체로 분위기를 구분해요.
- **모델과 도우미의 UI 사용**을 개선했어요. 목록의 이미지·아이콘 바인딩을 지원하고, 글자로 보이던 아이콘을 SVG로 표시해요. 도우미가 이야기 UI와 스타일을 변경할 수 있고, 변경 결과에서 해당 설정으로 바로 이동해요.
- **번역과 입력 처리**에서 입력 안내·이미지 설명 번역을 보완하고, 정상적인 이벤트 데이터를 함수 호출로 오인하던 검사를 정리했어요.

**채팅 설정 → 생성 설정 → 이야기 UI 스타일**에서 자동 또는 원하는 프리셋을 선택해요. 이미 직접 선택한 스타일은 유지돼요. 자세한 사용법은 [이야기 UI](../STORY-UI.md)를 참고해요.

기존 봇·채팅·원고·설정과 **SQLite 스키마 15**를 유지하며 데이터 마이그레이션은 없어요.
