# Uimori v0.10.4

v0.10.3 이후 **채팅 입력창 메뉴와 역할별 모델 설정 화면의 사용성**을 정돈한 패치 릴리스예요.

## 주요 변경

- **입력창 더보기 메뉴 정리:** 참고 이미지 첨부, 창작 설정(옵션 조합·페르소나·창작 옵션), 요청 및 컨텍스트(미리보기·마지막 로어·수동 압축), 이번 생성의 조회 로어 제외를 한눈에 구분할 수 있도록 배치했어요. 옵션 조합과 페르소나의 현재 선택값을 보기 쉽게 정리하고, 모바일 화면에서 메뉴를 스크롤해 모든 도구에 접근할 수 있어요.
- **창작 설정 동작 보존:** 페르소나 선택 대화상자, 미적용 창작 옵션 표시, 로어 제외 스위치, 초안과 포커스 복귀는 기존 동작을 유지해요.
- **역할별 모델 설정 정돈:** 도우미·요약 모델의 긴 설명을 줄이고, 세션·도우미 자동 요약 상한 안내를 한곳으로 모았어요. 접이식 설정 카드와 항목 간격을 기존 우이모리 스타일에 맞춰 데스크톱·모바일 모두 정돈했어요.
- **설정값 유지:** 모델 선택·요약 길이·번역 작업 정책의 저장 규칙이나 실행 동작은 변경하지 않았어요.

## 데이터 호환성과 한계

앱 버전은 **0.10.4**, SQLite 스키마는 기존 **15**를 유지해요. 프롬프트·모델·로어·채팅·운영 데이터 볼륨과 인증 정보의 데이터 형식은 변경하지 않아요. 팝업과 설정 화면의 표시 및 문구 변경이므로 진행 중이거나 기존에 완료된 작업을 변경하지 않아요.

## 설치 및 업데이트

```sh
git clone --branch v0.10.4 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node **24.14 이상 24.x**가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md), Oracle 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 따라요. 설정 → 앱 정보·라이선스에서 버전 `0.10.4`를 확인하세요. 릴리스 게시만으로 운영 서버가 자동 업데이트되지는 않아요.

## 검증

정적 검사·프로덕션 빌드, 입력창 팝업의 데스크톱·모바일 상호작용과 컨텍스트 미리보기, 모델 설정의 반응형 화면·요약 길이 저장·모델 프리셋 경로를 검증해요. 운영 배포 시에는 정확한 릴리스 커밋의 필수 GitHub CI 통과와 Oracle 이미지·데이터 복제본·HTTPS 검증을 별도로 수행해요.
