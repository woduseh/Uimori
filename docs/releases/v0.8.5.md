# Uimori v0.8.5

v0.8.4 이후 본문 생성 후 자동 번역과 작업 완료 알림을 연결하고, 여러 채팅의 작업 상태를 한눈에 확인할 수 있는 **활동 모드**를 추가한 업데이트예요.

## 주요 변경

- **생성 후 자동 번역:** 본문 생성 요청에서 자동 번역 옵션을 사용할 수 있어요. 원문과 번역을 하나의 요청 흐름으로 관리하고, 번역까지 마무리된 최종 결과를 알림으로 알려줘요.
- **완료 푸시 알림 개선:** 완료된 채팅·작업과 최종 결과를 구분해 안내하고 해당 결과로 이동해요. 자동 번역 실패·중단 및 수동 복구 상황에서도 원문과 번역의 결과를 구분해요.
- **전체 채팅 활동 모드:** 사이드바의 말풍선/받은 편지함 아이콘으로 기존 봇 탐색과 활동 보기를 전환해요. 활동에서는 확인할 결과, 진행 중 작업, 최근 대화를 채팅 단위로 표시하며 모바일 탐색에서도 동일하게 동작해요.
- **정확한 확인 상태:** 활동 결과를 선택해 실제 원문·번역을 확인하거나 명시적으로 확인할 때 알림을 정리해요. 기기 간 확인 상태를 서버에 저장하고 기존 채팅별 알림 기록과 동기화해요. 오류나 불확실한 실행 기록은 확인 동작으로 삭제하지 않아요.
- **정리와 검증:** 진행 중 작업 조회를 재사용해 중복 요청을 줄이고, 원문 생성·자동 번역의 알림 중복 방지 및 데스크톱·모바일 탐색 테스트를 보강했어요.

## 데이터 호환성

앱 버전은 **0.8.5**, SQLite 스키마는 **15**로 유지돼요. 스키마 15 작업실은 기존 DB와 원고 데이터를 유지하며 업데이트할 수 있어요. 활동 확인 기록은 기존 메타데이터 저장소를 사용하고 별도 DB 변환은 없어요. 배포 전에는 진행 중인 작업이 종료되고 일관된 백업이 생성되는지 확인해 주세요. 구형 스키마의 직접 변환은 지원하지 않아요.

## 설치 및 업데이트

공개된 GitHub 릴리스의 `v0.8.5` 태그를 사용하세요.

```sh
git clone --branch v0.8.5 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x가 필요해요. 기존 설치는 [수동 업데이트](../UPDATES.md)를, Oracle 운영 환경은 [전용 배포 안내](../ORACLE-RELEASE.md)를 참고하세요. 설치 후 **설정 → 앱 정보·라이선스**에서 버전 `0.8.5`와 빌드 식별자를 확인하세요. GitHub 릴리스 발행만으로 실행 중인 서버가 자동 업데이트되지는 않아요.

## 검증 범위와 제한

단위·통합 및 합성 브라우저 테스트는 유료 모델의 실제 출력과 모든 물리 기기의 동작을 보증하지 않아요. Oracle 이미지·기존 DB 복제본·호스트 HTTPS/API 검증은 전용 배포 도구에서 별도로 수행해요.
