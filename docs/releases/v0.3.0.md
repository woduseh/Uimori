# Uimori v0.3.0

`v0.2.0` 이후 Uimori를 개인용 창작 작업실로 오래 쓰기 위한 기능을 크게 확장한 초기 개발 릴리스예요. 원고를 찾고 다시 읽는 흐름, 검증 가능한 백업과 사용량 확인, 설치형 웹앱과 선택형 알림을 추가했고, 장면 삽화는 재사용 가능한 프리셋과 더 나은 Codex·ComfyUI 프롬프트 해석을 갖추게 됐어요.

## 주요 변경

- **삽화 프리셋을 추가하고 확장했어요.** 작업실 기본·봇·채팅 범위에서 프리셋을 선택하고 복제·가져오기·내보내기할 수 있어요. 프리셋은 그림 지침과 ComfyUI 워크플로를 함께 보관하며, 실행 중인 작업에는 예약 시점의 입력을 고정해 이후 편집과 분리해요.
- **그림 지침을 재사용 가능한 시각적 방향으로 다듬었어요.** Codex는 색감·조명뿐 아니라 선과 윤곽, 질감·재질·불투명도와 제외 조건까지 해석하도록 요청하고, ComfyUI 프롬프트 모델은 원문을 그대로 복사하지 않고 태그·짧은 묘사·필요한 자연어로 변환해요. 특정 모델용 문법은 프리셋에서 적용 대상을 명시할 수 있어요.
- **현재 원고 검색과 저장된 읽기 위치로 이동하는 흐름을 추가했어요.** 긴 채팅에서도 현재 원고를 검색하고 결과 위치로 이동할 수 있으며, 읽기 체크포인트와 북마크를 저장해 다시 들어왔을 때 이어서 읽기 쉬워졌어요.
- **검증 가능한 자동 백업과 보존 정책을 추가했어요.** 일일 백업과 무결성 확인, 보존 범위를 앱 안에서 관리하고 실패한 백업을 정상 백업처럼 취급하지 않아요. 백업·복원 경계와 운영 배포의 데이터 보호도 함께 정리했어요.
- **PWA 설치와 선택형 Web Push 알림을 추가했어요.** 지원하는 브라우저에서는 Uimori를 설치형 웹앱으로 사용할 수 있고, 허용한 경우 긴 작업의 완료 알림을 받을 수 있어요. 서비스 워커는 앱 코드 캐시를 고정하지 않아 새 배포를 불필요하게 붙잡지 않도록 했어요.
- **사용량 기록과 대시보드를 추가했어요.** 역할·모델·프로바이더별 사용량을 확인하고, 삭제된 본문을 사용량 보고를 위해 별도로 보존하지 않도록 집계 경계를 분리했어요. Codex 구독 상태 표시도 설정 화면에 맞게 정리했어요.
- **긴 원고의 준비와 Reader 재진입 비용을 줄였어요.** 실행 준비 스냅샷과 모델 요청 메타데이터를 정리하고, 긴 이야기에서 불필요한 반복 준비와 재진입 비용을 줄였어요. 한국어를 포함한 긴 문장의 줄바꿈과 읽기 위치 보존도 개선했어요.
- **생성·도구 실행의 복구와 호환성을 다듬었어요.** 생성 취소·재시작 경계, Anthropic 도구 별칭, helper 재시도와 compacted context 처리 등을 정리해 공급자별 작은 차이가 실행을 깨뜨리지 않도록 했어요.
- **설정과 공통 UI를 정리했어요.** 설정 화면의 밀도와 그룹 구조, 공통 조작부와 모션, 페르소나 선택, 사용량 화면, 앱 아이콘·favicon 등 실제 사용 중 자주 보이는 부분을 다듬었어요.
- **테스트와 운영 검증을 전수 정리했어요.** 중복되거나 구현 세부사항에 붙잡힌 테스트를 줄이고, 필요한 브라우저·복구·배포 검증은 유지했어요. Oracle 배포는 정확한 main SHA의 CI 성공, 실제 ARM64 이미지, DB 호환성, 백업, HTTPS/API smoke와 쓰기 재개를 확인해요.

## 버전과 데이터

앱 버전은 **`0.3.0`**이며 **설정 → 앱 정보·라이선스**와 Codex 실행기 식별에 같은 패키지 버전을 사용해요. 빌드 식별자는 소스 변경을 구분하기 위해 별도로 유지해요.

개인 작업실 DB는 **schema 12**예요. 같은 `uimori-personal-v1` 형식의 schema 1~11은 지원되는 순서대로 한 번의 트랜잭션으로 현재 형식으로 전환해요. 업데이트 전에는 SQLite 스냅샷과 현재 실행 이미지·커밋을 함께 보관하고, 갱신한 DB를 구버전 앱으로 다시 여는 다운그레이드는 하지 않아요. 정확한 범위는 [데이터 안내](../DATA-MIGRATIONS.md#현재-버전)를 확인해요.

## 설치와 업데이트

새 소스 설치:

```sh
git clone --branch v0.3.0 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

기존 사용자는 업데이트 전에 SQLite 백업과 현재 실행 이미지/커밋 정보를 보관하고 [업데이트 안내](../UPDATES.md)의 절차로 코드와 앱을 함께 바꿔요. Oracle 설치는 [Oracle 릴리스 안내](../ORACLE-RELEASE.md)를 사용해요. 태그나 GitHub Release 발행만으로 실행 중인 서버가 자동 업데이트되지는 않아요.

## 알려진 제한

앱 내 업데이트 확인·설치와 무인 자동 업데이트는 아직 제공하지 않아요. Web Push는 브라우저·OS의 지원과 알림 권한, HTTPS 환경에 의존하며 전달을 보장하는 메시지 큐가 아니에요.

ComfyUI의 참조 이미지 업로드는 아직 구현하지 않아 캐릭터·그림체 참조 이미지는 Codex 경로에서만 직접 사용해요. 특정 체크포인트의 최적 프롬프트 문법이나 생성 품질도 Uimori가 보장하지 않으며, 프리셋의 모델별 지침으로 조정해요.

모든 Risu 자료·스크립트의 완전한 호환성을 보장하지 않으며 지원 범위는 [Risu 가져오기 안내](../RISU-IMPORT.md)를 따라요. 자동 검증의 모델 호출은 합성 fixture를 사용하므로 실제 모델의 품질·요금·서비스 제약은 사용하는 프로바이더가 기준이에요.
