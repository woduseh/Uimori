# Uimori v0.4.0

구성에서 실제 집필로 이어가는 작업실과, 필요한 자료만 읽고 수정하는 도우미를 제공하는 기능 릴리스예요. 설정 검색과 Codex 네이티브 실행을 추가하고, 개인용 작업실에 불필요해진 내부 분기와 완료된 변환 코드를 정리했어요.

## 주요 변경

- **구성·집필 작업실:** 작품 방향부터 회차·작은 사건까지 자유롭게 구성하고 관련 계획을 연결해요. 선택한 단위를 집필하거나 실제 원문과 점검하며, 구성·도우미 전환 중 편집 초안을 유지해요.
- **설정 검색:** 설정 항목을 검색해 해당 화면으로 이동해요. 이동 중 미저장 설정 입력을 보존해요.
- **작은 조회와 부분 편집:** 도우미가 제목·본문 검색과 필요한 필드·범위 조회로 사실을 찾고, 수정한 부분만 저장해요. 로어 추가·삭제, 번역 가이드와 용어 편집, 기존 프리셋 텍스트·옵션 수정을 지원해요. 큰 읽기 결과는 명시적인 이어 읽기 안내를 제공해요.
- **설정·진단·작업 제어:** 적용 모델과 전역·채팅별 선택, 사용량과 작업 상태를 조회해요. 요청한 설정 변경이나 지정 작업 취소·재시도는 기존 저장·실행 경로를 사용하고, 화면을 갱신해도 미저장 초안을 덮어쓰지 않아요.
- **Codex 네이티브 도우미:** 작업 하나를 하나의 네이티브 턴에서 실행하며 도구 결과를 이어서 처리해요. 도구 호출마다 전체 이력을 다시 보내는 처리를 제거했고, 최종 답변과 진행 설명을 구분해요.
- **Codex 삽화 입력 정리:** 이미지 전용 지침을 사용하고 삽화 턴의 검색·코드 실행을 비활성화해요. 선택한 모델·추론 수준·참고 이미지 설정은 유지해요.
- **채팅 중심 내부 구조:** 채팅이 원문과 실행 상태를 소유해요. 내부 분기, 중복 조회, 폐기 설정과 관련 중복 테스트를 정리했어요. 독립 채팅 복사·다시 쓰기, 개정 충돌, 취소 후 늦은 저장 차단과 중복 실행 방지는 유지해요.

## 데이터 호환성

앱 버전은 **0.4.0**, 개인 작업실 DB는 **스키마 15**예요. 빈 DB와 현재 스키마만 열고 다른 형식은 변경 없이 거절해요. 완료된 DB·브라우저 일회성 변환 코드는 포함하지 않아요.

**v0.3.1의 스키마 12 DB를 이 릴리스로 직접 변환할 수는 없어요.** 구형 DB와 백업은 해당 형식을 지원하는 앱 버전과 함께 보관해요. 스키마 15를 이미 사용하는 설치는 기존 데이터 볼륨을 유지해 업데이트할 수 있어요. 현재 운영 자료·백업을 지우거나 DB의 버전 숫자만 바꾸는 방식으로 업데이트하지 않아요.

브라우저의 현재 형식 초안·미확정 요청은 유지해요. 구형 브라우저 키를 자동 이전하거나 삭제하지 않으므로 버전 전환 전 각 기기의 필요한 입력을 저장해요. 자세한 범위는 [데이터 안내](../DATA-MIGRATIONS.md)를 확인해요.

## 설치와 업데이트

```sh
git clone --branch v0.4.0 --single-branch https://github.com/woduseh/Uimori.git
cd Uimori
npm ci
npm run dev
```

Node 24.14 이상 24.x를 사용해요. 기존 설치는 [업데이트 안내](../UPDATES.md)를 따라 앱과 DB 백업을 함께 보관해요. Oracle 운영 설치는 [전용 배포 절차](../ORACLE-RELEASE.md)로 검증한 main 커밋을 배포해요. GitHub Release 발행만으로 서버가 업데이트되지는 않아요.

## 검증 범위와 알려진 제한

합성 모델·App Server를 사용하는 도구 연결, 부분 저장, 취소·재시도, 초안과 데이터 보존은 자동 검사로 확인해요. Codex 네이티브 도구 형식은 실제 CLI 0.158.0에서 생성한 스키마와 대조했어요. 실제 구독 모델의 작업 성공률·토큰 절감량과 삽화 품질 비교는 별도 실사용 검증이 필요해요.

도우미의 **실행 요청** 횟수는 Uimori가 시작한 요청 수예요. 네이티브 턴 안의 모델 판단 횟수와 같지 않으며, 공급자가 알려주지 않은 비용·내부 호출 수는 추정해 채우지 않아요. Risu 원본의 지원 범위와 셀프호스팅 운영 조건은 [가져오기](../RISU-IMPORT.md), [Codex](../CODEX.md), [개인 서버](../SELF-HOST.md) 안내를 참고해요.
