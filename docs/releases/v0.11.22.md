# v0.11.22

설정과 입력 UI를 정돈하고 첫 메시지 선택을 넓힌 패치 릴리스예요. DB 스키마는 15로 유지해요.

- 선택 목록, 스크롤바, 텍스트 선택, 검색 지우기, 입력 상태와 툴팁을 우이모리 테마에 맞췄어요. 키보드 조작과 사용자 콘텐츠의 스타일은 유지해요.
- 채팅 설정과 읽기 설정에 검색을 더했어요. 검색으로 이동해도 작성 중인 설정과 초안을 유지해요.
- 첫 메시지를 바꿀 때 **첫 메시지 없이 시작**을 선택할 수 있어요. 기존 메시지와 편집 기록은 보존하고, 화면 용어도 첫 메시지로 통일했어요.
- Gemini와 Vertex Gemini의 안전 필터에 Jailbreak를 추가했어요. 필터 끄기, 차단 없이 평가, 모델 기본값을 구분하고 설정 화면의 중복 설명을 줄였어요.
- 액션 메뉴 위치와 다이얼로그 바깥 클릭, 참고 메모의 자동 높이를 브라우저 기본 기능으로 단순화했어요.
- JEV에 이미지 입력과 확장 컨텍스트 선택을 더했어요. 선별한 이미지 복사본만 전송하고, 저장된 입력 한도와 최종 로어 예산을 유지해요.

기존 데이터와 설정을 유지하는 업데이트예요. 실제 모델 호출의 품질·비용 검증은 포함하지 않아요. 설치 절차는 [업데이트 안내](../UPDATES.md)를 참고해요.
