# v0.11.23

설정 저장과 취소된 요청 표시, 채팅 메뉴를 다듬은 패치 릴리스예요. DB 스키마는 15로 유지해요.

- 역할별 모델 설정은 서버의 저장 응답을 받으면 완료돼요. 뒤따르는 조회가 늦거나 실패해도 저장 완료와 새 초안을 유지해요.
- 취소된 요청에서 재시도·요청 수정·작업 기록 확인을 제공하고, 본문에서 정리할 수 있어요. 정리해도 실행 기록과 부분 응답은 보존돼요.
- 봇 목록과 최근 채팅 목록이 같은 채팅 메뉴를 사용해요. 이름 변경·복사·삭제 중 현재 채팅의 작성 초안을 유지해요.
- 창작 옵션 초안 검토를 단순화하면서 충돌 확인과 명시적 해제, 저장 버전 채택 동작을 유지해요.
- 개발 검증 도구가 프로젝트의 Node 버전 조건을 함께 사용해요. 모델 설정 테스트는 전체 설정을 복원하고 다시 조회해 다음 테스트로 설정이 새지 않는지 확인해요.

기존 데이터와 설정을 유지하는 업데이트예요. 실제 유료 모델 호출과 물리 기기 검증은 포함하지 않아요. 설치 절차는 [업데이트 안내](../UPDATES.md)를 참고해요.
