# v0.12.3

로어 검색과 작문 카탈로그를 개선하고, 도우미가 저장된 CHARX 이미지를 직접 확인할 수 있도록 했어요. 기존 원고·자료·대화·이미지를 보존하며 **SQLite 스키마는 15로 유지**해요.

- 로어 검색에 관련도 순으로 찾는 `relevant` 모드를 추가했어요. 정확한 제목·ID를 우선하고, 한영 혼합 표현과 유니코드 정규화가 포함된 검색에서도 원문 위치를 유지해요. 기존 기본 검색 방식도 그대로 사용할 수 있어요.
- 매 요청의 작문 카탈로그는 현재 요청, 실제로 보이는 최근 대화와 요약을 참고해 관련 자료부터 보여줘요. 최대 6,000 로컬 토큰을 유지하며 카탈로그에서 빠진 자료도 검색·조회할 수 있어요.
- 도우미의 `image.list`와 `image.read`로 CHARX 안의 이미지 이름을 검색하고 선택한 이미지의 실제 픽셀을 확인할 수 있어요. 이미지 지원 모델이 필요하며, 애니메이션은 첫 프레임을 제공해요.
- 이미지 조회는 저장된 자료의 현재 버전을 사용해요. 셸에서 여러 장을 조회하거나 결과 출력을 파일로 돌려도 이미지가 전달되며, 대화 요약에도 조회한 이미지를 반영해요.
- 전송 조건에 맞는 정지 WebP는 원본 바이트를 그대로 사용해요. 그 외 이미지는 원본을 변경하지 않고 최대 2048px·2MiB 전송용 사본으로 변환해요. 중복 이미지 검사와 전송 시 재해싱, 별도의 도구 조회 8장 제한을 제거했어요.
- 중복 테스트와 반복 안내를 줄이고, 실제 이미지 전달·후속 요청·요약·저장 영수증·검색 회귀 검증을 유지했어요.

업데이트 절차는 [업데이트 안내](../UPDATES.md)를 참고해요. 실제 모델의 검색·시각적 답변 품질이나 비용 절감률은 별도로 측정하지 않았어요.
