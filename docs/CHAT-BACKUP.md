# 독립 채팅 백업

채팅 백업은 다시 읽고 이어 쓸 수 있는 사용자 자료를 담아요. 메시지·사용자 요청·완료된 번역·메모·카드 변수·필요한 이미지와 연결된 봇·페르소나·모듈·고정 프리셋을 포함해요. 자동 요약과 내부 실행 기록, 진행 중 작업, 서버 초안과 일회성 옵션은 복원하지 않아요. 요약이 필요하면 원문과 메모에서 다시 만들어요.

**채팅 내보내기 → 채팅 백업**으로 저장하고, **채팅 가져오기 → 채팅 백업 복원**에서 가져와요. 현재 형식은 `uimori-personal-chat` 버전 1이에요. API 키와 프로바이더는 옮기지 않으며 목적지 작업실의 모델을 사용해요.

내보내기는 선택한 채팅 하나를 담아요. 파일의 `chats` 목록 형식은 유지하므로 여러 독립 채팅을 담은 기존 백업도 복원할 수 있어요.

본문·번역·메모를 담는 transcript는 선택한 장면까지의 원문과 최신 수정본을 검증해 읽어요. 소유 채팅과 번역 연결 확인에는 식별자·현재 원문 hash만 조회하며, 내보내기에 쓰지 않는 Reader 문단을 다시 만들지 않아요. 최신 원문 hash와 맞는 완료 번역, 해당 원고 범위에 유효한 메모만 포함하는 규칙은 같아요.

파일을 고르면 미리보기에 필요한 제목과 본문 목록 구조부터 확인해요. 잘못된 파일은 가져오기 영역에 오류를 표시하고 다시 선택할 수 있어요. 전체 형식·참조 검증은 서버의 복원 경계에서 유지해요.

가져오기는 항상 새 ID의 자료와 채팅을 만들어요. 기존 이름·개정과 비교해 병합하지 않고 묶음 내부의 참조만 새 ID로 연결해요. 같은 통신 요청을 재전송하면 중복 사본을 만들지 않지만, 사용자가 새 가져오기를 시작하면 별도 사본을 만들어요.

저장된 장면·메모·독립 채팅의 개수만으로 복원을 거절하지 않아요. 채팅 백업 전체 256MiB와 개별 원문·번역의 공통 저장 한도는 유지하며, 파일 형식과 메모의 원문 위치·자료 참조는 복원 전에 확인해요.

## 읽기용 원고 내보내기

**채팅 내보내기 → 원고 내보내기**에서 전체 채팅이나 시작·끝 장면을 선택해 `.md` 파일로 저장해요. 원문은 현재 수정본을, 번역은 그 원문과 연결된 저장된 유효 번역만 담아요. 첫 메시지가 있는 채팅은 첫 메시지도 범위에 포함할 수 있어요. 선택한 범위에 유효 번역이 없으면 해당 장면을 알려주고 다운로드를 거절해요. 원문을 대신 섞거나 장면을 조용히 생략하지 않아요.

요청·작업 기록·메모를 제외한 본문만 빈 줄로 연결하며 HTML·Risu 상태창 표기도 텍스트 그대로 담아요. 이미지 묶음과 EPUB는 제공하지 않아요. 원고 파일은 읽기·편집용이며 채팅 백업 복원이나 이어 쓰기용 가져오기 파일이 아니에요. 범위를 고른 뒤 새 장면이 추가되면 내보내기를 다시 열어 확인해요. 내보내기는 모델 호출이나 저장된 자료 변경을 하지 않아요.

## 채팅 복사와 다시 쓰기

원고의 **이 장면까지 새 채팅으로 복사**는 해당 지점까지 독립 채팅을 만들어요. 이후 수정·삭제는 원본 채팅에 전파되지 않아요. 이미지 본문은 불변 BLOB을 재사용하되 원본 채팅의 이미지 행에 의존하지 않아요. 서재의 봇·프리셋은 일반 채팅처럼 참조하고, 개별 백업에서는 필요한 자료를 함께 담아요.

복원과 복사는 원본의 페르소나 선택을 따르며, 선택하지 않았던 상태도 유지해요. 현재 봇·폴더의 새 채팅 기본 페르소나는 적용하지 않아요.

완성된 답변을 다른 방식으로 다시 생성하는 경우도 공유 분기 대신 독립 채팅 사본에서 시작해요. 다음 생성에는 현재 자료·설정을 사용해요. 과거의 모든 모델 전송 입력을 복제하지 않아요. 당시 변수 체크포인트가 없으면 현재의 미래 상태를 과거에 섞지 않고 기본 상태에서 시작해요.

복원 중 외부 모델이나 카드 콜백을 재실행하지 않아요. 키·이미지를 포함한 전체 작업실 복구는 [DB 스냅샷](DATA-MIGRATIONS.md)을 사용해요.

## 책갈피

책갈피 이름·메모·짧은 인용과 장면 위치도 포함해요. 가져올 때 새 채팅의 장면 ID로 연결하고, 기존 텍스트와 문단이 유지될 때만 원문 문단을 다시 연결해요. 선택 지점까지의 독립 복사는 해당 범위의 책갈피만 포함해요. 기기별 읽기 위치는 개별 백업/복사에 포함하지 않아요. 책갈피가 없는 과거 형식도 읽을 수 있어요. [읽기 위치와 책갈피](READING-STATE.md)
