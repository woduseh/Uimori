# 현재 프롬프트와 전체 원문 번역

작문과 번역의 현재 프롬프트는 앱 전체에서 각각 한 벌을 사용해요. `prompt_workspace`에 프로그램·선택값·번역 정책·역할 모델을 저장하고 `expectedRevision`으로 동시 편집을 보호해요. 채팅 프로필은 봇·페르소나·모듈을 관리하며 현재 모델이나 프롬프트를 선택·소유하지 않아요. [전역 역할 모델 계약](GLOBAL-MODELS.md)을 참고해요.

저장된 프롬프트 프리셋을 적용하면 내용과 옵션을 현재 작업본으로 복사하고 `CurrentPrompt.presetId`에 출처를 유지해요. 프리셋의 후속 수정·삭제는 현재 작업본을 바꾸지 않아요. 새 요청은 그때의 작업본과 옵션을 자기 snapshot에 고정하며, 과거 실행은 현재 작업본으로 다시 해석하지 않아요.

## 설정과 제작 화면

설정의 현재 프롬프트는 역할별 프롬프트 선택·현재 창작 옵션·협업 사용 여부만 다뤄요. 이름·본문·제어 정의·기본 옵션·협업 상세는 프롬프트 탭에서 편집하고 전체 저장 버튼 하나로 저장해요. 설정의 프롬프트 편집 링크는 선택한 프리셋을 열어요. 프리셋 저장은 현재 사용본에 자동 반영하지 않고 설정의 최신 버전 적용으로 명시적으로 다시 복사해요.

설정에서 옵션을 변경하거나 조합을 불러오면 현재 선택을 자동 저장해요. 연속 입력은 직렬 저장하며 늦은 응답으로 뒤의 입력을 덮어쓰지 않아요. 실패·동시 변경·복구한 초안은 선택을 유지하고 다시 저장 또는 기존 초안 비교·복구 동작을 제공해요. 이미 예약한 실행은 바꾸지 않아요. 프롬프트 교체 동안은 이전 프롬프트의 옵션 입력을 막아요.

프롬프트 적용 때 기본 선택값도 `CurrentPrompt.defaultValues`로 복사해요. 설정의 기본값 선택은 적용 당시 기본 옵션을 복원하며, 라이브러리의 후속 수정으로 기본값이 바뀌지 않아요. 이 필드는 현재 설정용이며 Run의 프롬프트 snapshot에는 넣지 않아요. 필드가 없는 작업본은 프로그램에 정의된 기본값을 사용해요.

협업은 설정에서 켜고 끄기만 제공해요. 구성이 없으면 프롬프트 편집에서 구성하도록 안내해요. 제작 화면에서는 헤더 스위치와 왼쪽 펼침 화살표를 분리하며, 사용 여부를 바꾸거나 저장해도 펼침 상태를 자동 변경하지 않아요.

프롬프트 JSON은 `title`, `role` (`main`/`translation`), `program`, `values`를 함께 내보내고 가져와요. 협업은 `program.collaboration`에 포함해요. 이름·역할이 없는 단독 프로그램 JSON도 읽으며 없는 메타데이터를 추측하지 않아요. 기존 프리셋에 다른 역할의 JSON을 덮어쓰지 않고 새 프롬프트에서 가져오도록 안내해요. 같은 역할의 가져오기는 구성과 옵션을 함께 실행 취소할 수 있어요.

## 옵션 조합의 소속과 적용

옵션 조합은 선택값과 함께 소속 및 저장 당시 `controls` 정의를 보관해요. 소속은 저장된 프리셋 ID 또는 프리셋 출처가 없는 기본 현재 작업본의 역할이에요. 프리셋에서 복사한 현재 작업본은 출처 프리셋의 조합을 사용하고, 출처가 없는 작문·번역 작업본은 각각 자기 역할에 속한 조합을 사용해요.

목록 표시와 적용은 **같은 소속·같은 역할·같은 옵션 정의**를 모두 만족해야 해요. 서로 다른 프리셋이 같은 control ID나 같은 값 타입을 사용해도 조합을 공유하지 않아요. 같은 프리셋이라도 옵션 정의가 달라지면 이전 정의로 저장한 조합을 제외해요. 호환되지 않는 조합을 현재 기본값으로 조정해서 적용하지 않아요. 본문만 바뀌고 옵션 정의가 같으면 같은 소속의 조합을 사용할 수 있어요.

조합은 설정의 창작 옵션에서 불러오고 새로 저장하거나 관리해요. 조합을 불러온 뒤 직접 바꾼 현재 선택이 우선하며 저장된 조합 자체는 바뀌지 않아요. 재사용하고 싶을 때만 현재 선택을 새 조합으로 저장해요.

조합 적용은 현재 옵션 값만 바꾸며 프롬프트 본문·옵션 정의·프리셋 출처를 바꾸지 않아요. 서버도 소속과 정의 일치를 검증하므로 UI 목록을 우회한 요청으로 다른 프롬프트의 값을 적용할 수 없어요. 현재 작업본 저장과 적용의 revision CAS 및 편집 중 초안 보호를 유지해요.

소속이나 옵션 정의가 없는 기존 조합은 사용 대상에서 제외하고 적용을 거부해요. 이번 변경에는 운영 DB의 물리 삭제나 자동 청소를 포함하지 않아요. 과거 Run snapshot은 유지해요. 사용하려면 해당 프롬프트에서 현재 옵션을 확인한 뒤 새 조합으로 저장해요.

## 번역

전체 원문을 한 번의 번역 입력으로 보내고 일반 텍스트를 받아요. 분할 계획·구간 재시도·JSON 번역 형식·보호 토큰·자연어 구조 검증은 제거했어요. 원문 ID/hash와 작업 소유권·세대·CAS 검증은 유지해요. 번역 프롬프트 외에도 원문 시점의 봇·페르소나·로어·번역 지침과 허용된 요약·메모·자료 조회를 제공해요. 다른 채팅이나 나중에 수정된 자료를 섞지 않아요.

실제 번역은 사용자가 지정한 거절 판정 모델이 필요해요. 특정 모델을 자동 선택하지 않아요. 판정 요청은 번역 응답 앞 1,000자만 받고 원문·자료·도구·대화 기록을 받지 않아요. 번역 거절이 명확할 때만 전체 번역을 자동 재요청해요. 추가 재요청은 기본 1회, 0~5회로 설정해요. 번역·조회 후속 요청·판정은 한 작업의 전체 호출 한도(기본 16, 2~64)에 포함해요.

빈 응답·부분 응답·판정 실패·불확실 판정·HTTP 오류·취소·한도 초과는 자동 재생하지 않아요. 판정 실패의 후보 텍스트는 진단 기록에 보존하지만 성공 번역으로 표시하지 않아요. 실제 문학 번역 품질이나 경량 모델의 판정 정확도는 로컬 합성 검사의 증거 범위 밖이에요.

수동 재번역은 성공·실패 모두 현재 모델·현재 번역 프롬프트·현재 정책으로 새 작업을 만들어요. 진행 중인 중복 요청은 기존 작업을 반환해요. 새 작업이 실패·취소되면 같은 원문 hash의 마지막 성공 번역을 계속 표시해요. 직접 번역 수정도 새 완료본으로 저장하고 모델을 호출하지 않아요. 원문이 바뀌면 이전 hash의 결과를 최신 번역으로 재사용하지 않아요.

## 전송 미리보기와 오류 알림

목록의 작문 미리보기는 합성 이전 입력·응답·현재 요청으로 구성해요. 번역 미리보기는 입력한 원문과 합성 문맥을 `core/translation-preview.ts`에서 만들고, 실제 번역과 같은 `core/translation-prompt.ts`의 컴파일 함수를 사용해요. 번역 대화에는 현재 번역 요청 하나만 넣고 원문은 `source` 슬롯과 런타임 source로 제공해요. 실제 채팅 자료나 모델을 사용하지 않고 결과를 저장하지 않아요. 채팅 연결 미리보기는 기존 서버 경로의 원문·문맥을 사용해요.

프롬프트 구성·미리보기 오류는 편집기 안에 표시하고 전역 알림으로 중복 전달하지 않아요. 오류 알림은 닫기 버튼으로 확인 후 숨길 수 있고, 재시도·구성 수정·역할 전환에 따라 이전 알림을 정리해요. 전역 오류도 닫거나 주 화면을 이동하면 해제해요. 알림을 닫아도 `PROMPT_HISTORY_OMITTED` 같은 검증 규칙과 실패 기록은 바꾸지 않아요.

## 작문 재요청과 도구

`POST /api/runs/:id/retry`는 원래 요청 직전 위치에서 새 분기를 만들고 현재 설정으로 다시 생성해요. 이전 성공 원문·실패 기록을 수정하지 않아요. idempotency key 재전송은 같은 새 실행을 반환해요. 별도의 같은 입력 후보 실험은 기존 고정 snapshot 계약을 유지해요.

도구 오류는 허용된 로컬 교정 가능 오류와 권한·실행 실패를 구분해요. 잘못된 입력처럼 명시적으로 `recoverable`인 결과는 모델에 돌려줘 수정할 수 있어요. 동일한 도구·입력의 두 번째 실패나 전체 네 번째 실패에서 종료해요. 권한 거절과 분류되지 않은 실패는 즉시 종료하며, 이 정책은 외부 공급자 요청의 불확실한 재실행을 허용하지 않아요.

## 삭제와 보관

서재 항목·프리셋·옵션 조합·모델·연결·업로드 이미지는 참조 때문에 삭제를 막지 않고 새 목록·선택에서 제외해요. 과거 자료·이미지·실행 snapshot은 내부에 보존해요. 연결 삭제는 이후 전송 권한을 회수해요. 삭제한 거절 판정 모델은 선택 해제하고, 전용 모델을 삭제한 작문 보조는 자동으로 다른 모델에 보내지 않도록 협업을 꺼요.

schema/archive는 v15예요. 현재 프롬프트 한 행과 숨김 목록을 포함하고 필수 행·참조·원문·실행 입력을 검증해요. 변경된 현재 프롬프트가 있으면 빈 DB로 간주하지 않아요. 구형 DB 자동 이관·운영 DB 초기화는 이 변경에서 수행하지 않아요. UI v2 작업과의 통합도 별도예요.

관련 구현: `server/prompt-workspace.ts`, `server/source-editing.ts`, `server/product-auxiliary.ts`, `core/tool-outcome.ts`, `server/library-deletion.ts`.
