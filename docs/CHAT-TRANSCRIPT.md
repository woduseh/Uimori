# 본문만 내보내기와 가져오기

본문 교환은 요청·완료된 원문·현재 유효한 번역·작성자 메모를 새 채팅으로 옮기는 작은 JSON 형식이에요. 봇·페르소나·모듈·이미지 바이트·변수·Lua 메시지 변경까지 함께 옮기려면 [독립 채팅 백업](CHAT-BACKUP.md)을 사용해요.

## 현재 형식

`uimori-chat-transcript` **버전 2**만 지원해요. 파일에는 제목, `packageAttachments`, `notes`, `entries`가 들어가요. 각 entry는 `request`, `text`, `translation`을 가져요. 번역이 없으면 `null`이에요. 메모에는 `text`, `author`, `atIndex`, `kind`를 명시하고 가져온 메모 종류에는 그 출처도 담아요. 예전 v1 메모 형식을 추측해서 바꾸는 호환 경로는 없어요.

자료 본문은 이 형식에 포함하지 않아요. 가져오기 전에 대상 봇을 준비하고, 연결 자료가 없으면 제외한 항목을 결과에서 알려줘요. 봇 자체가 없으면 계속 쓸 채팅을 만들 수 없으므로 대상 봇을 선택해야 해요. 제목과 역할을 문자열에서 추측하지 않아요.

## 새 채팅으로 가져오기

봇 메뉴 또는 **설정 → 데이터 관리**에서 본문 파일을 선택하고 제목·장면 수·대상 봇을 확인해요. 가져오면 새 채팅·메시지·메모 ID를 만들고 내부 순서를 연결해요. 기존 채팅이나 파일을 수정하지 않아요. 이미지는 자동 다운로드하지 않고 모델·Lua 호출도 실행하지 않아요.

확정 원문은 source로 저장하고 가져왔다는 작은 표시만 남겨요. 이전 모델 요청이나 도구 교환을 가짜로 생성하지 않아요. 가져온 텍스트를 읽거나 다음 장면을 생성할 때는 목적지 작업실의 현재 자료·모델 설정을 사용해요.

같은 통신 요청의 응답을 잃어 다시 보내면 같은 가져오기 결과를 반환해 중복을 막아요. 사용자가 새 가져오기를 시작하면 새 사본을 만들어요. 목적지의 요청 키를 과거 원본의 이벤트 이력으로 대체하지 않아요.

## 검사와 제한

현재 파일 형태, 메모가 가리키는 장면, 텍스트 크기와 연결 봇을 확인해요. 실패하면 중간 채팅을 남기지 않아요. `tests/chat-transcript.test.ts`는 원문·번역·메모·반복 요청·잘못된 파일을, `tests/personal-workspace-flow.test.ts`는 더 넓은 독립 백업의 이어쓰기를 확인해요.

구현은 `core/chat-transcript.ts`의 형식과 `server/chat-transcript.ts`의 저장으로 나뉘어요. 전체 작업실 복원은 이 형식이 아니라 [SQLite 백업](DATA-MIGRATIONS.md)을 사용해요.
