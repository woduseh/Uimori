# 2026-09-11 UI 개편과 도우미 세션

사용자가 제공한 `우이모리 디자인 개편 시안 및 설계안`의 HTML/CSS 개별 화면 40개와 `Uimori_UI_Design_v1` 문서를 바탕으로 기존 앱을 개편해요. 이미지 시안에서는 세이지 색의 두 잎 모티프, 조용한 카드와 본문 표현을 참고해요. 브랜드는 기존 Lucide `Sprout` 아이콘으로 표현해요. 이미지에만 나타나는 통계·태그·외부 서비스 등의 기능을 추가하지 않아요.

## 화면 계약

- 탐색 폭은 248px이고 서재·프롬프트를 직접 열어요. 설정은 아래에 유지해요. 별도 포털 홈을 만들지 않아요.
- 채팅은 기본 본문 폭 760px, 서재는 최대 1280px의 왼쪽 정렬 모음, 긴 편집은 목록과 선택 항목으로 나눠요. 사용자의 읽기 설정을 유지해요.
- 프롬프트는 블록·옵션 정의·기본 옵션·협업·미리보기로 이동해요. 블록 목록은 224px이고 좁은 화면에서는 목록과 상세를 한 단계씩 열어요. JSON 대안 편집과 미적용 초안을 유지해요.
- 자료 편집은 기본 정보와 기존 아홉 분야를 같은 편집기의 열 개 섹션으로 열어요. 로어는 224px 목록과 상세로 나누고, 모바일에서는 목록과 상세를 전환해요. 섹션을 바꿔도 입력값은 유지하며 상단 저장 버튼으로 명시적으로 저장해요.
- 새 채팅은 봇·페르소나·실효 모델과 작문 프롬프트·시작 장면 순서로 확인해요. 사용 모델 설정은 본문·번역·도우미·문맥 요약을 먼저 보여주고 기타 자동 작업과 번역 오류 감지는 펼쳐서 편집해요. 연결·모델 프리셋은 별도의 탭과 저장 흐름을 유지해요.
- 도우미·창작 옵션 패널은 모두 384px이에요. 1152–1399px에서는 패널을 열 때 탐색을 임시로 접고, 탐색을 다시 펼치면 패널을 겹쳐 열어요. 더 좁은 폭에서는 겹쳐 열며 768px 미만에서는 전체 폭을 사용해요. 기존 탐색 접기 선호를 덮어쓰지 않아요.
- 본문·도우미는 공통 입력창, 요청 재시도·상태·작업 기록을 계속 사용해요. 모델 고정, 저장·적용, 미저장 초안, `false`·`0`·빈 문자열의 계약을 바꾸지 않아요.
- 탐색·아이콘 버튼은 조용한 기본 표현을 사용하고 저장·등록·보내기에 강조색을 사용해요. 도우미의 전역 모델 설정은 패널 설정에서 열어요.

## 사용자가 확정한 추가 결정

### 도우미 세션과 분기

같은 채팅·같은 분기에도 여러 도우미 세션을 만들어요. 세션 ID가 기록·개인 요약·입력 초안·원문 선택·읽는 위치·응답 cursor·재시도 키·권한의 소유자예요. 패널은 한 개이고 선택 목록에서 세션을 바꿔요. 세션을 바꾸거나 패널을 닫아도 작업을 취소하지 않아요.

세션 목록은 채팅의 모든 분기를 보여줘요. 다른 분기 소속 세션은 기록을 읽을 수 있고, 새 요청·결과 수정은 **해당 분기로 이동**한 뒤 가능해요. 이미 시작한 다른 분기의 작업은 계속 진행해요. 원문을 도우미에 보낼 때는 클릭한 원문과 그 분기의 세션 ID를 고정해요.

선택은 고른 시점에 **보고 있던 분기**에 묶여요. 그 분기를 계속 보는 동안에는 다른 분기 소속 세션을 골라도 그대로 유지되고 안내가 떠요. 읽는 분기가 바뀌면 그 분기에서 마지막으로 고른 세션을 되찾고, 없으면 그 분기의 세션을 고르거나 새로 만들어요.

새 세션 생성은 요청 키로 중복을 막아요. 제목을 따로 지정하지 않았을 때 첫 요청의 앞부분을 제목으로 사용하며, 사용자가 정한 제목은 유지해요. 세션별 모델을 새로 만들지 않고 전역 도우미 모델을 사용해요. 지속 옵션 위임에는 대상 세션을 지정하며 다른 세션에 권한을 공유하지 않아요.

### 동시 실행과 삭제

전체 도우미 작업은 최대 2개까지 실행하고, 나머지는 대기해요. 각 세션에서는 한 번에 1개씩 접수 순서대로 진행해요. 취소한 작업의 공급자 요청과 worker 정리가 끝날 때까지 실행 자리를 유지해요. 앱 재시작 시 불확실한 요청을 자동 재전송하지 않아요.

세션 삭제는 채팅 삭제처럼 범위를 설명하고 확인받아요. 진행·대기 작업을 먼저 중지하고 외부 요청 종료를 기다려야 삭제할 수 있어요. 삭제 직전에는 세션 revision과 이벤트 순서를 다시 확인해요.

대화·작업·가정 장면·개인 요약·직접 권한을 삭제하고, 미적용 위임 옵션은 취소해요. 이미 본편이나 공유 자료에 저장된 결과는 유지해요. 과거 실행이 검증할 위임 영수증은 권한을 철회하고 대화 소유자를 분리하여 남겨요. 채팅·전개 자체를 삭제하면 이 영수증도 함께 정리해요. 채팅 전체 백업은 여러 세션과 이 영수증을 새 ID로 복원해요.

### 본편 지정

보관된 전개 목록에서 **기본으로 지정**을 선택해 채팅의 본편을 바꿔요. 내용을 합치거나 복제하는 기능이 아니에요. 한 채팅에는 항상 기본 전개가 하나이고, 기존 기본 전개·대상 전개의 revision을 확인하여 표시와 채팅 head를 원자적으로 갱신해요.

과거 원문·실행 snapshot·진행 중 요청·재시도는 원래 전개에 남아요. 다른 창에서 기본 전개가 바뀌어도 현재 읽는 원문과 입력의 전개를 유지해요. 채팅에 새로 진입할 때 새 기본 전개를 선택해요. 현재 기본 전개는 삭제할 수 없으며 다른 전개를 기본으로 정한 뒤 이전 전개를 삭제할 수 있어요.

## 2026-09-11 후속: 4K·스마트폰 검토와 사용자 확정 결정

첫 개편 뒤 412×891과 2560×1440에서 다시 검토했어요. 이전 검증 범위는 390×844·1280×900·1440×900과 dark 중심이었고 두 폭은 들어 있지 않았어요. 사용자는 4K 모니터를 150% 배율로 쓰므로 CSS 뷰포트가 2560×1440이에요. 즉 이 폭이 예외 상황이 아니라 기본 작업 화면이에요.

### 확정한 결정

- **원고 폭**: 기본 880px. 읽기 설정의 `본문 폭`에서 좁게 760 / 기본 880 / 넓게 1040을 고르고 기기별로 보관해요. 집중 읽기는 별도 폭을 쓰지 않고 같은 값을 따라요.
- **입력창**: 원고 폭과 같은 축에 정렬해요. 장면 레일 여백을 한쪽에만 주던 규칙이 원고와 입력창의 중심을 29px 어긋나게 했고, 여백을 좌우 대칭으로 바꿔 해결했어요.
- **헤더**: 폭을 제한하지 않고 제목은 화면 왼쪽 끝, 도우미·모델·채팅 메뉴는 오른쪽 끝에 둬요. 화면 가장자리는 커서가 넘어가지 않아 조준이 쉽고, 읽기 폭을 바꿔도 제어 위치가 움직이지 않아요.
- **중앙정렬**: 채팅뿐 아니라 서재·프롬프트·편집기의 본문 열도 중앙정렬해요. 이는 인수 테스트 **L01(P1, 「작업 영역 좌측 24px에서 시작」)을 의도적으로 뒤집는 결정**이에요. 2560px에서 목록이 화면 왼쪽에만 몰리는 것보다 시선이 한자리에 머무는 편을 택했어요. 페이지 헤더는 전폭을 유지하므로 구분선은 화면 끝까지 이어져요.
- **탐색 접기**: 접기 버튼을 사이드바 안쪽 브랜드 옆으로 옮겼어요. 접으면 사라지지 않고 56px 아이콘 레일로 남아 펼치기·새 채팅·채팅 검색·서재·프롬프트·설정을 제공해요. 봇 트리는 접을 때 숨겨요. 1024px 미만에서는 레일 폭이 0이 되고 기존 드로어 동작을 그대로 써요.
- **패널 폭**: 도우미와 창작 옵션이 같은 우측 슬롯을 쓰므로 폭도 한 설정으로 묶어요. 일반 설정의 `도우미·창작 옵션 패널 폭`에서 좁게 360 / 보통 384 / 넓게 480을 고르고 기기별로 보관해요.
- **도킹 임계값**: 고정 breakpoint 대신 공간 예산으로 계산해요. 사이드바와 함께 도킹하려면 `248 + 패널 폭 + 768`, 레일과 함께 도킹하려면 `56 + 패널 폭 + 768`이 필요해요. 기본 384px에서는 1400과 1208이고, 480px을 고르면 1496과 1304으로 함께 올라가요.
- **창작 옵션 「이 채팅」 탭**: 설계안 P01대로 행마다의 `이 채팅에 고정` 체크박스를 `개별 지정` / `전역 따르기`로 바꿨어요. 전역을 따르는 행은 비활성 폼이 아니라 현재값을 텍스트로 보여줘요. 옵션은 프롬프트 편집기와 같은 규칙으로 그룹에 묶고 그룹마다 지정 개수를 표시해요. 옵션 45개 기준 스크롤 길이가 9,918px에서 4,526px로 줄었어요.

### 값 계약은 바꾸지 않았어요

오버라이드 여부는 그대로 **키 존재 여부**(`Object.hasOwn`)로 표현해요. `개별 지정`은 현재 유효값을 키로 넣고 `전역 따르기`는 키를 지워요. 명시적 `false` · `0` · 빈 문자열 · `null`(미설정) · 미지정의 구분, `expectedRevision` CAS, `operationId` 멱등, 위임·1회 옵션의 경로와 payload는 그대로예요.

### 그 밖에 고친 것

- 사이드바 트리 들여쓰기를 단계당 8px에서 명세값 16px로 올렸어요.
- 시각 상태를 바꾸는 `:hover` 규칙 36개를 `@media (hover: hover)`로 감쌌어요. 터치에서 탭한 자리에 hover 배경이 남아 선택되지 않은 탭이 선택된 것처럼 보이던 문제예요. `:focus-within`과 짝을 이루던 노출 규칙은 감싸지 않아 키보드 접근이 그대로예요.
- `library.css`의 `@media (max-width: 600px)` 페이지 여백 규칙이 뒤에 오는 760px 블록에 같은 특이도로 덮여 한 번도 적용되지 않고 있었어요. 중복을 지웠어요.
