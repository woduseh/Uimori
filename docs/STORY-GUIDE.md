# 원작 참고

채팅 메뉴의 **원작 참고**, 또는 **채팅 설정 → 원작 참고**에서 이 채팅의 참고 범위를 정해요. **집필 전에 원작 참고**는 기본으로 꺼져 있는 선택 기능이에요. 켜면 현재 본문 모델이 집필 전에 원작 설정·인물의 말투와 성격·현재 이야기의 변화를 살펴보고 짧은 참고문을 집필에 전달해요. 생성에 모델 호출과 비용이 추가될 수 있어요. 프롬프트 프리셋을 바꿔도 채팅의 참고 설정은 유지돼요.

## 사용 흐름

1. **작품·판본·세계관**에 참고할 작품과 판본을 적어요. **기준 시점·스포일러 범위**로 공개할 수 있는 시점을 정하고, 기존 카드·로어에 없는 자료는 **추가 참고 자료**에 덧붙여요.
2. 기본은 원작의 설정·성격과 현재 이야기에서 달라진 선택을 함께 존중해요. 원작 사건의 진행도 참고하고 싶을 때 **원작의 사건 전개도 참고**를 켜요. 이 설정이 현재 이야기의 분기를 원작으로 되돌리라는 뜻은 아니에요.
   **원작 정보를 웹에서 확인**은 기본으로 꺼져 있어요. 켜면 지원하는 본문 모델 연결에 웹 검색을 요청해요. Responses, Claude, Gemini, Vertex와 Codex 연결에서 지원하며, 실제 사용 가능 여부는 모델과 계정에 따라 달라요. 검색 비용이 추가될 수 있고, 검색 결과 자체에는 지정한 기준 시점 이후의 스포일러가 포함될 수 있어요.
3. 설정을 저장하고 평소처럼 집필해요. **마지막 집필 참고문**에서 당시 전달한 참고문을 볼 수 있어요. 원작 정보, 현재 이야기의 근거, 앞으로의 제안을 구분하며 인물의 지식과 독자의 지식을 같은 사실로 취급하지 않도록 요청해요.
4. 원작이나 인물에 관한 수동 질문은 기존 **도우미**에서 해요. 채팅 범위 도우미는 `context.read`로 같은 작품·판본, 기준 시점·스포일러 범위, 추가 자료, 메모와 최근 본문의 위치를 읽을 수 있어요. 원작 참고 전용 미리보기와 질문 실행은 제공하지 않아요.
5. 원작과 달라진 설정이나 계속 지켜야 할 조건은 같은 패널의 **메모·정정**에 저장해요. 기존 작가 메모를 사용하므로 기억과 메모 화면에서도 같은 정정을 볼 수 있어요. 도우미의 답변이나 자동 참고문을 새 기억으로 누적하지 않아요.

처음 열 때는 **참고 설정**을 펼쳐 보여주고, 설정을 저장한 뒤 다시 열면 접어서 마지막 참고문을 확인할 수 있어요. 다른 탭에서 설정이 바뀌어도 작성 중인 입력을 유지하며 저장 충돌은 기존 저장본 검토로 처리해요. **마지막 집필 참고문**은 당시 기록이므로 현재 설정과 다를 수 있어요.

원작 전문을 자동으로 내려받지 않아요. 웹 검색을 끄면 모델 지식에 의존한 부분을 `모델 지식·원문 미확인`으로 구분하도록 요청해요. 검색을 켜면 실제 검색 실행과 출처가 확인된 참고문만 집필에 전달해요. **마지막 집필 참고문**에서 받은 출처 링크를 확인할 수 있고, Google 검색을 사용했다면 제공된 검색 제안도 함께 표시해요. 검색 미지원·미실행·출처 없음은 해당 참고문 없이 집필을 이어가며 화면에 이유를 표시해요. 출처가 있다는 사실만으로 참고문의 정확성이나 스포일러 준수를 보장하지는 않아요.

## 실행과 보관

- 자동 참고는 준비된 사용자·모델 대화, 현재 요약, 카드·페르소나·로어, 카드의 예시 대화, 작가 메모와 채팅의 작가 노트, 해당 집필의 구성과 요청을 사용해요. 예시 대화는 인물의 말투를 참고하는 자료이며 실제 발생한 사건으로 취급하지 않아요. 재생성할 때는 교체할 응답을 제외한 입력을 사용해요.
- 보통 모델 한 번으로 참고문을 만들어요. 필요한 원문을 읽는 경우 기존 읽기 도구를 한 번 묶어 실행하고 한 번 더 답변받아요. 집필과 거절 판정에 필요한 호출 한도는 남겨둬요. 참고문 호출은 사용량의 원작 참고 항목에 기록해요.
- 모델의 추론·생성 설정은 그대로 사용하고, 집필에 넣을 참고문 길이는 따로 제한해요. 실제 생성 시간과 사용량은 선택한 본문 모델의 설정에 따라 달라져요.
- 매 집필에 맞는 참고문을 선택해요. 입력·설정·모델·참고 프롬프트가 같은 경우에만 저장된 결과를 재사용해요. 추가 원문을 읽어 만든 결과는 재사용하지 않고 다시 살펴봐요.
- 웹 검색 설정도 채팅 복사와 휴대용 백업에 함께 보관해요. 이 설정이 없던 기존 저장본은 검색을 끈 상태로 읽어요. 검색 출처는 해당 참고문과 함께 남으며 별도의 자료 저장소나 기억으로 누적하지 않아요.
- 기존 대화에 요약이 필요하면 참고문 입력 공간까지 고려해 한 번에 묶어요. 원래 입력이 충분히 들어가면 참고문만을 위해 추가 요약을 시작하지 않아요. 실제 참고문을 넣은 최종 집필 입력을 다시 측정하며, 실패나 한도 부족 시 해당 참고문 없이 집필을 이어가요. 이전 참고문을 대신 넣지 않으며 취소는 모델 호출까지 전달해요.
- 채팅에는 설정과 마지막 자동 참고문을 저장하고, 완료된 집필에는 사용한 참고문과 실패 여부만 작은 기록으로 남겨요. 전체 입력과 설정 전문을 매 장면에 계속 복제하지 않아요. 별도 분기 장부나 연구 서비스를 만들지 않아요.
- 채팅 복사와 휴대용 백업은 참고 **설정만** 옮겨요. 복사한 채팅은 자기 자료로 다시 살펴봐요. 전체 SQLite 백업에는 기존 참고문도 포함돼요.

## 참고 범위

RisuAI용 **원작견 개조판 v3.9.1**의 기능 의도를 현재 집필에 필요한 만큼 반영해요. 모든 항목을 매번 출력하거나 별도 장부로 저장하지 않아요.

| 참고 대상 | 적용 |
| --- | --- |
| 인물의 말투·태도·행동 | 카드의 예시 대화와 현재 관계를 바탕으로 호칭·존댓말/반말·말버릇·행동을 살펴봐요. 제안 대사를 원작 인용이나 실제 발언으로 취급하지 않아요. |
| 원작 설정·판본 | 작품과 판본, 현재 장면에 필요한 세계관 정보를 골라요. 서로 다른 각색의 설정을 섞지 않도록 요청해요. |
| 창작 인물과 달라진 이야기 | 창작 인물·사용자 페르소나·변경 설정을 원작 오류로 교정하지 않아요. 초기 설정과 실제 발생한 사건도 구분해요. |
| 관계·약속·현재 상태 | 기존 대화·요약·메모로 관계, 동행·소지품·부상, 약속의 조건과 이행·포기 여부를 살펴봐요. 독립 장부를 만들거나 참고문을 기억으로 누적하지 않아요. |
| 시점·비밀·사건의 조건 | 인물별 앎과 오해, 독자의 지식, 아직 일어나지 않은 사건을 구분해요. 시간 경과만으로 관계 해결이나 사건 완료를 단정하지 않아요. |
| 다음 전개 | 원작 전개 참고를 켠 경우 사건에 필요한 인물·장소·조건과 현재 분기를 비교해 선택지로 제안해요. 스포일러 범위와 해당 집필에 연결된 구성의 공개 시점을 함께 고려해요. |

원본의 인물/설정별 다중 호출·2차 모델 검증, 자동 시점 이동·화면 밖 사건 진행, 별도 장부 관리, 전용 질문 이력, PDF·번역 체계는 추가하지 않았어요. 짧은 참고문과 필요한 로컬 원문 읽기, 선택한 연결의 웹 검색으로 범위를 유지해요. 요약에 모든 관계 변화가 빠짐없이 남는다고 보장하지 않으므로, 계속 지켜야 할 조건은 메모로 고정할 수 있어요.

## 구현과 검증

`core/story-guide.ts`가 데이터 형식을, `server/story-guide-store.ts`가 채팅별 저장을, `server/story-guide-runtime.ts`가 입력·생성·재사용·사용량을 맡아요. `server/story-guide-routes.ts`는 설정 읽기·저장과 마지막 참고문 조회만 제공하고, `web/StoryGuidePanel.tsx`에서 설정·당시 참고문·메모를 보여줘요. `server/helper-context.ts`는 기존 도우미에 같은 참고 설정을 제공해요. DB 스키마 15의 작은 테이블을 사용하며 별도의 큐·기억 저장소·검색 인덱스는 만들지 않아요.

`tests/story-guide-*.test.ts`는 저장·복사·설정 충돌, 종료한 수동 API의 모델 호출 방지, 도우미의 동일한 참고 설정 읽기, 입력과 캐시·예산, 합성 HTTP 집필 전달·실패·취소를 확인해요. `tests/chat-settings-browser.spec.ts`의 `CSUI10`은 설정·당시 참고문·정정 흐름을 확인해요. 합성 검증은 실제 모델의 원작 지식이나 문학적 품질을 입증하지 않아요.
