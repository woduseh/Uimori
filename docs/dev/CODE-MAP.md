| Typed route contracts: transport-neutral operations and their HTTP bindings | `packages/contracts/src/endpoint.ts`; per domain `packages/contracts/src/domains/<domain>/operations.ts` (zod `input`/`output`, imported as `#contracts/operations`) and `endpoints.ts` (method and path, exported from `#contracts`); `registerEndpoint` and `parseInput` in `server/endpoint.ts`; `callEndpoint` in `web/api.ts`; `tests/endpoint.test.ts` | An operation is an `input`/`output` schema pair that helper tools parse with `parseInput` as well; an endpoint names the operation and adds method, path and an optional success status or body limit. Path parameters come from `:name` segments and the rest of the input from the query for `GET` and the JSON body otherwise (`endpointRequest` on the web, `endpointInput` on the server); a path parameter wins over a body field, and `defineEndpoint<Op>()` fails `tsc` when a `:name` is not a required string or number input key. Query values arrive as strings, so numeric and boolean query fields use `queryInt` and `queryBoolean` (`packages/contracts/src/domains/query.ts`, exported from `#contracts/operations`) rather than `z.coerce`, which reads `''` as `0` and `'false'` as `true`. Input that fails the schema answers `INVALID_REQUEST`. Contract objects are `z.strictObject`, so an unknown input field is refused and, under `testMode`, an extra output field fails the output check; `tests/endpoint.test.ts` fails on a contract object that strips unknown keys, and one that must accept any key says so with `z.looseObject`. The output schema is checked only when `createApp` runs with `testMode`. A write checks `expectedRevision` with `assertRevision` (`server/app-errors.ts`) before it looks up what the input names, so a stale tab gets `REVISION_CONFLICT` rather than a not-found error. Schemas import `zod/v4`; `biome.json` refuses a bare `zod` import, and only `core/story-ui-catalog.ts` imports `zod/v3`, because it extends and hands back `@a2ui/web_core` schemas, which are zod 3. Endpoint files import their operations as types only, so `#contracts` and the startup bundle stay free of zod: the `web/**` override in `biome.json` refuses `#contracts/operations`, and `tests/web-runtime-boundary.test.ts` fails when the eager imports of `packages/contracts/src/index.ts` or `web/main.tsx` reach zod. Domain folders take the feature-map domain names. Routes on it so far: auto-translation defaults, fonts, the usage report and scheduled backups |
