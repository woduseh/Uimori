# 이야기 UI

원고 안에 등장인물의 메시지 창, 조사 기록, 상태표, 선택지 같은 화면을 넣을 수 있어요. 모델이 본문을 생성할 때 화면도 함께 구성해요.

## 켜기와 사용하기

**채팅 설정 → 생성 설정 → 이야기 UI**를 켜고 저장해요. 채팅마다 따로 설정하며, 새 채팅과 이 설정이 없던 채팅은 기본으로 꺼져 있어요. 저장 뒤 시작하는 생성부터 화면 구성 방법을 모델에 알려 줘요. 필요한 장면이라면 요청에 원하는 화면과 담을 내용을 적어 주세요. 예를 들어 “조사팀의 통화 기록을 표로 보여 주고, 다음에 전화할 사람을 선택할 수 있게 해 줘”라고 요청할 수 있어요.

**이야기 UI 스타일**에서 기본, 동양풍, 서양 판타지, 현대, 시대극을 고를 수 있어요. 저장하면 이 채팅의 기존 화면과 생성 중인 화면에 적용되며, 이야기 내용과 모델 지시는 바뀌지 않아요. 화면을 꺼도 저장된 화면의 스타일은 선택할 수 있어요.

탭을 바꾸거나 목록을 살펴보고 입력값을 고치는 동안에는 모델 호출이 없어요. 생성이 완료된 최신 장면에서 이야기 속 버튼을 누르면 선택을 보낼 범위가 열려요.

미전송 입력은 현재 브라우저 탭의 세션에 보관해 원문·번역을 전환해도 유지해요. 원문이 수정되면 이전 화면의 초안을 새 원문에 적용하지 않아요. 다른 기기와의 초안 동기화는 제공하지 않아요.

- **이 대화만 이어가기**를 선택하면 모델에 해당 상호작용의 짧은 응답을 요청해요.
- **다음 장면으로 이어가기**를 선택하면 제출한 행동을 반영해 다음 장면 생성을 요청해요.

응답이 완성되면 새 장면으로 이동해요. 기다리는 동안 다른 장면이나 채팅으로 이동했다면 읽던 위치를 유지해요. 긴 본문을 생성하는 동안에도 완성된 화면 블록은 먼저 표시하며, 이야기 행동 제출은 장면 저장이 끝난 뒤에 가능해요.

**보내기**를 누르면 현재 채팅의 모델로 새 요청을 시작해요. 이야기 UI를 끄면 저장된 화면은 계속 읽을 수 있고, 화면에서 새 생성 요청을 보내려면 채팅 설정에서 다시 켜야 해요. 이전 장면의 선택으로 다른 이야기를 진행하려면 그 장면의 메뉴에서 **이 장면까지 새 채팅으로 분기**한 뒤, 새 채팅에서 선택해요. 분기 지점은 장면 전체를 기준으로 해요. [채팅 백업과 분기](CHAT-BACKUP.md)

## 화면 구성

모델은 A2UI 1.0의 Express 형식으로 본문 사이에 `<a2ui>…</a2ui>` 블록을 만들어요. 각 블록은 자체 화면과 상태를 정의해요. Uimori는 문서나 대화 같은 화면을 아래 구성 요소의 조합으로 표현해요.

| 용도 | 구성 요소 |
| --- | --- |
| 배치와 탐색 | `Row`, `Column`, `List`, `Card`, `Tabs`, `Modal`, `Divider` |
| 내용과 행동 | `Text`, `Image`, `Icon`, `Button`, `TextField`, `CheckBox`, `ChoicePicker`, `Slider`, `DateTimeInput` |
| 수치와 기록 | `BarChart`, `LineChart`, `DataTable`, `Gauge` |

예를 들어 아래 블록은 구성 요소 두 개를 세로로 배치해요.

```text
<a2ui>
root = Column([Text("조사 기록"), BarChart(title="신고 건수", items=[{label: "봄", value: 12}])])
</a2ui>
```

이미지는 앱에 이미 저장된 에셋, 패키지 이미지, 삽화 경로를 사용해요. 탭과 입력 상태는 해당 화면에서 처리해요. 서버는 저장된 화면에 선언된 버튼과 이벤트인지 확인하고, 화면이 계산한 입력값을 사용자의 다음 이야기 요청으로 받아요. 원문의 상태값을 직접 수정하지는 않아요. `roll` 이벤트의 주사위 면 수와 개수는 화면에 정해진 값에서 확인하고 서버가 굴려요. 같은 제출을 재확인하거나 재시도할 때는 이미 기록한 결과를 사용해요.

## 저장, 읽기와 번역

본문 원문이 화면 데이터도 함께 보관해요. 저장할 때 서버가 완성된 Express 블록을 검사하고, 유효한 블록을 `uimori-ui` 코드 펜스의 JSON으로 바꿔요. 저장 형식의 `version`은 `1`이고, `expression`에는 모델이 작성한 Express 표현, `messages`에는 검증한 A2UI 1.0 메시지가 들어가요. 남은 본문과 검증을 통과하지 못한 화면 원문은 보존해요. 이어 쓸 문맥에는 유효한 화면의 문구와 데이터를 투영해요. 원문 오프셋, 소스 해시, 복사와 채팅 백업은 저장된 원문을 기준으로 해요.

Risu 표시 변환을 적용하는 채팅에서도 변환을 거쳐 유지된 이야기 UI 블록은 본문 안의 화면으로 표시해요. 화면에서 보낸 이야기 행동은 일반 Risu 카드 버튼과 별도로 검사해요.

번역할 때는 본문과 화면에 표시할 문자열을 모델에 전달해요. 서버는 번역 문자열을 저장된 화면 구조에 넣어 번역본을 복원하고, 구성 요소와 연결 정보, 이벤트, 수치로 된 값은 원본을 사용해요. 문자열 묶음이 누락되거나 형식이 달라 복원에 실패하면 번역 실패로 표시하며 원문은 계속 읽을 수 있어요.

액션 저장은 장면과 화면을 식별하고 채팅의 최신 장면과 원문 해시를 확인해요. 요청을 받은 뒤 원문이 바뀌면 이전 선택을 그 장면에 적용할 수 없어요. 채팅 복사본에서는 복사된 화면과 그 채팅의 최신 장면을 기준으로 새 선택을 보낼 수 있어요.
