# Uimori UI 개편 자료 1.0

이 묶음은 사용자 저장소의 **실제 UI 수정본이 아니라, 현재 소스 검토에 기반한 설계와 독립 HTML 시안**입니다. 원격 저장소에 커밋·배포하지 않았습니다.

## 먼저 볼 것

- `uimori-ui-prototype.html`: 브라우저로 열어볼 수 있는 독립 시안. 의존성 설치/API 키/서버 불필요. 파일 실행이 금지된 환경에서는 허용된 로컬 웹서버로 제공할 수 있습니다.
- `desktop-chat.png`, `mobile-chat.png`: 가장 중요한 기본 읽기 화면.
- `desktop-library.png`: 봇·자료를 고르는 별도 서재.
- `desktop-context.png`, `mobile-context.png`: 요청할 때 여는 이야기 설정.
- `desktop-light.png`: 밝은 테마의 방향.
- `UI_REDESIGN.md`: 현황·참고 제품·화면/상호작용 규격·구현 범위.
- `CODEX_UI_TASK.ko.md`: 실제 저장소에 맡길 작업 지시.
- `UI_ACCEPTANCE.json`: 아직 실행하지 않은 **실제 제품**의 UI 수용 명세.
- `SOURCE_MAP.json`: 고정 저장소 SHA, 확인한 파일/구간, 공식 참고 문서.
- `prototype-checks.json`: 이번 **독립 시안**의 브라우저 확인 결과. 제품 검증과 다릅니다.

## Codex에서 사용

저장소 안에 `ui-redesign/` 폴더로 이 묶음을 놓고 다음을 전달합니다.

```text
ui-redesign/UI_REDESIGN.md와 CODEX_UI_TASK.ko.md를 읽고,
현재 M1-local 동작을 보존하면서 UI-1부터 UI-3까지 UI를 개편해줘.
HTML은 합성 디자인 시안이지 생산 코드가 아니야.
실제 현재 API에 연결하고, 새 화면 screenshot과 기존 회귀 검증으로 입증해줘.
원격 배포·유료 호출·M2 전체 구현은 이번 범위가 아니야.
```

현재 앱의 기존 명령은 npm 기준이며 실제 루프는 작업 지시문에서 확인하도록 되어 있습니다.

## 시안에서 되는 것 / 안 되는 것

동작: 서재/설정/이야기 탐색, 합성 자료 검색, 창작 프리셋·페르소나 선택 표시, 원문↔번역, 저장된 두 후보 보기, 설정·작업·상태 패널, 테마·글자 크기, 집중 읽기, 합성 요청의 모의 응답 타이머, 브라우저 세션 내 초안 전환.

없음: 실제 서버/API/SQLite 저장, 실제 모델·비밀키·과금·통신 재접속, 실제 봇 import, 편집 저장, 장기기억, 영구 분기 저장, 실제 모바일 백그라운드 유지. 새로고침하면 모의 자료로 돌아갑니다. 이야기 상태 폼 등 연결하지 않은 기능은 시안이라는 안내를 표시합니다. 여러 합성 이야기의 본문은 같은 예시를 재사용합니다. 실제 제품의 규칙을 이 단순화에서 가져오지 마세요.

이번 환경은 Linux Chromium입니다. 원본 앱의 Node 요구사항과 네트워크 제한 때문에 실제 앱을 재실행하지 않았습니다. HTML은 브라우저의 허용된 `set_content` 경로에서 검사했습니다. 실제 폰·Windows·스크린리더·IME 시험을 대신하지 않습니다.

공식 제품을 베낀 소스·로고·스크린샷이나 사용자의 창작 원문을 포함하지 않았습니다. 시안의 이야기와 인물은 중립적인 합성 예시입니다.
